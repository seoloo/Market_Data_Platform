# 오르빗 로컬 아이콘 출처 (2026-10-10)

실행 중 CDN 요청 없이 이 디렉터리의 고정 파일만 사용한다. SVG의 스크립트,
외부 참조, foreignObject 없음은 회귀 테스트로 검사한다. 다운로드한 SVG는
코드 실행 지시가 아니라 그림 자료이며 UI/매매 권한을 추가하지 않는다.

- 공통 19종: [Lucide](https://lucide.dev/), 원본 `https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/<name>.svg`.
  ISC 및 일부 Feather 파생 MIT 라이선스 전문: LICENSE-lucide. 도형 수정 없음.
- BTC·ETH·SOL: [cryptocurrency-icons](https://github.com/spothq/cryptocurrency-icons),
  `https://raw.githubusercontent.com/spothq/cryptocurrency-icons/master/svg/color/<symbol>.svg`.
  CC0 전문: LICENSE-cryptocurrency.md. 도형 수정 없음.
- TQQQ: ProShares 공식 https://www.proshares.com/globalassets/proshares/ps-logo_new.png
- SCHD: Schwab 공식 https://www.schwab.com/favicon.ico
- BTQ: BTQ 공식 https://www.btq.com/favicon.ico
- QS: QuantumScape 공식 https://www.quantumscape.com/wp-content/uploads/2021/09/QS_Logo@2x.png

기업 그림은 회사/ETF 발행사 식별용 상표이며 위 공개 라이브러리의 오픈소스
라이선스를 적용하지 않는다. 제휴·공식 승인·수익 보장을 뜻하지 않는다.
다른 사람에게 배포하기 전 기업 상표 사용 조건을 별도 확인한다.
WQTM/미등록 종목은 Lucide 중립 아이콘으로 표시하며 공식 로고라고 주장하지 않는다.

## 2026-10-10 사용자 재보정

최신 홈은 TQQQ/SCHD/BTQ/QS/WQTM의 작은 비트맵 회사 로고 대신 Lucide의
차트/새싹/원자/빌딩 벡터와 종목별 색상 배지를 사용한다. 회사 공식 로고가 아닌
앱의 종목 식별용 아이콘이다. 위 4개 회사 원본 파일/기존 URL은 호환과 이력 보존용이며
최신 화면에서 확대하지 않는다. 코인의 BTC/ETH/SOL CC0 로고는 그대로 사용한다.
