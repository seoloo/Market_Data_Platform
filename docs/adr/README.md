# 설계 결정 기록 (ADR)

결정마다 한 파일: **맥락 → 결정 → 다른 안 → 치르는 값 → 근거(잰 숫자)**. 근거는 이 저장소에서 실제로 돌려
얻은 숫자만 적고, 재 보지 않은 것은 '추정' · '확인 필요'로 적는다. 결정을 바꾸면 고치지 않고 새 기록을 더한 뒤
옛 기록의 상태를 '대체됨'으로 바꾼다.
