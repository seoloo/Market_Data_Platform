## 1. 목표와 원칙

- **목표:** Binance 에서 BTC·ETH 를 자동으로 실거래하는 것. 지금은 실거래 직전 단계(Paper·테스트넷·데모 관찰 중)다. 실거래 주문 코드는 아직 없다.
- **연구 방식:**
  - 결과를 보기 전에 규칙·기준을 문서로 고정한다(사전 등록). 판정은 **한 번**만 한다.
  - 기각된 가설은 파라미터만 바꿔 되살리지 않는다.
  - 판정이 통과해도 바로 실거래하지 않는다. 앞으로의 관찰(Paper)로 확인한 뒤에 쓴다.
- **비용 가정 (편도):**
  - 판정 기준: 현물 0.15%, 무기한 0.095% + funding.
  - 현실 비용(0.11% / 0.023%)은 참고 줄로만 보여 준다.
- **안전 원칙:**
  - API 키에 출금 권한을 주지 않고 IP 를 제한한다.
  - LLM 이 매수·매도를 직접 결정하지 않는다.
  - 처음부터 실거래를 켜지 않는다.
  - **시장가 주문 금지 (2026-10-05 사용자 지시):** 모든 매매는 가격 한도가 있는 지정가만 쓴다. 예외는 세 가지다(사용자 결정): 거래소 비상 스톱 발동, 보호 등록 실패 때 전량 정리, T/v2 실행기의 시장가 추격. 선물 일반 주문(늘리기·줄이기·정리)은 2026-10-05 에 mark ± 0.3% 지정가 IOC(덜 차면 최대 3 번 다시)로 바꿨다. 테스트넷 훈련 일부는 Phase 7 판정(10/08) 뒤에 바꾼다.
- **위험 한도 (실계좌):** 계좌 누적 낙폭 30% 면 정지(자동 해제 없음), 일 손실 2%. 첫 실거래의 위험은 설계값의 절반.

## 2. 통과한 전략 (유일하게 남은 것)

모두 **BTC·ETH 롱 추세 추종**이다. 백테스트 기간은 2020-03 ~ 2026-08, 초기 자본 10,000 기준이다.

**배운 것:**
- 추세 추종의 실질 가치는 초과 수익보다 **낙폭 축소**다.
- 배율을 0.5배 올릴 때마다 견뎌야 하는 낙폭이 약 7~8%p 늘고, funding 이 배율보다 빨리 늘어 샤프가 떨어진다(1.5배 1.17 → 3배 0.99).
- 수익은 강세장(2020·2023·2024)에서 나오고, 약한 해(2025)는 배율로 나아지지 않는다.
- 2021-11 고점 뒤 약 2년 동안 고점을 되찾지 못했다(물속 기간).
