[연구 215 — USDT 도미넌스 하락 + BTC 도미넌스 상승 → 이후 24시간 BTC 선물 롱 / 결론: 자료 부족, 손익 계산 안 함]

가설
- 완성 4시간봉에서 USDT.D 하락 + BTC.D 상승(동시)이면 이후 24시간 BTC USD-M 롱의 비용 후 수익이 개선되는가
- 비교군: A 도미넌스 조건 / B BTC 현물 4시간 수익 > 0 / C TOTAL 상승 + BTC.D 상승. 주 비교 A − C (연 +1%p 를 의미 있는 최소 개선으로 사전 고정)

중복 감사
- 도미넌스·TOTAL·스테이블 비중을 쓴 연구는 없음 (엘리엇 데모 차트 메모에 '테더 도미넌스' 한 줄뿐)
- 212(BTC beta 잔차로 코인 상대 회복), 213(자기 가격 추세 강도로 비중), 214(자기 4시간봉으로 매수 시점)와 달리 이번은 시장 전체 시가총액 대비 비중 변화로 BTC 방향을 예측하는 새 진입 신호

자료 감사 → 확보 불가
- TradingView CRYPTOCAP(USDT.D, BTC.D, TOTAL)은 TradingView가 직접 계산(TOTAL = Crypto Coins Screener 상위 125개, 코인별 가격 × 유통량). 공식 다운로드 API 없음, 자동 수집은 약관상 불가
- CoinGecko: 과거 전체 시가총액은 유료. 무료는 최근 365일, 90일 넘으면 일봉만
- Coinranking: 전체 과거는 유료(무료 1년). CoinMarketCap: 과거 전체 지표 API 유료. Coin Metrics 커뮤니티: 개별 코인 일 단위만, TOTAL 없음
- 지수 정의도 바뀌어 옴(상위 50개 DeFi 제외 → 모든 순위 코인 → 상위 125개), 일부 과거는 나중에 계산해 붙임 → 지금 보이는 과거 값이 당시 값과 다를 수 있음

하지 않은 것 (프롬프트 금지)
- 일봉 보간, 현재 공급량·구성으로 과거 복원, 바이낸스 거래대금 비중을 도미넌스로 사용, 유료 구매
- 최근 90일 CoinGecko 시간 자료로 만든 별도 지표도 정의가 다르고 표본(4시간봉 약 540개)이 너무 작아 하지 않음

구조상 단서 (추정, 검증 아님)
- Δln(USDT.D) = Δln(USDT 시총) − Δln(TOTAL). USDT 시총의 4시간 변화는 발행·소각뿐이라 작고, TOTAL 변화는 훨씬 큼 → 거의 모든 봉에서 USDT.D 하락 ≈ TOTAL 상승 → A ≈ C. 자료가 있어도 '추가 가치 없음' 가능성이 큼

결론
- 자료 부족(DATA_INSUFFICIENT). 손익·신호 수익 미계산 → 기각도 PASS도 아님
- 다시 열 조건: 사용자가 TradingView에서 약관 범위 안에서 직접 내보낸 USDT.D·BTC.D·TOTAL 4시간봉 파일을 주거나, 유료 자료 구매를 따로 승인할 때
