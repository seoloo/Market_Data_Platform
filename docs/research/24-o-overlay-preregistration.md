## 1. 질문과 수익원

새 방향 예측이 아니라 **자본 배분 연구**다(23). T/v2 롱 추세에는 우위가 있다(T/v1 9년 1회 PASS).
우위가 있는 수익원에 노출을 더하면 수익이 늘어야 한다. 대신 추가분은 선물이라 **funding을 내고**, 증거금·청산·계좌 정지 위험이 생긴다.
묻는 것: **funding·비용·위험 한도를 모두 반영해도 1.5배 노출이 T/v2 단독보다 계좌 순수익을 늘리는가.**

기각된 연구와의 차이: K·M(캐리)·P1(상대 추세)·TA(알트 분산)·단기 방향(H·R·WA·V)은 각각 다른 수익원을 찾았다.
O는 이미 통과한 T의 롱 추세에 **크기만** 더한다. 숏·새 지표·다른 종목은 추가하지 않는다.

## 2. 규칙 (고정, `backtest/overlay.py` 기본값)

| 항목 | 값 |
|---|---|
| 신호·크기 | T/v2 그대로: `TrendConfig(long_only=True)` — 현물 일봉 20·60·120일 부호 평균(음수면 0) × min(15%/σ60, 0.5) = 종목별 `w_i` |
| 총 노출 | 종목별 **1.5 × w_i** (자본 대비 명목). 최대 1.5배 |
| 구성 | 현물 `k·w_i` + 선물 롱 `(1.5 − k)·w_i`, `k = min(1, (3 − 1.5·w) / (2·w))`, w = Σw_i. 현물 밖 자본은 전부 선물 지갑(교차 증거금) |
| 선물 레버리지 | 선물 명목 ≤ **3 × 선물 지갑**. 체결 뒤 넘으면 선물을 줄인다(비용 반영) |
| 체결 | 종가 d 목표 → 종가 d+1 체결(1일 지연). 현물은 현물 종가, 선물은 무기한 종가. 종목별 총 노출 변화 < 5%p × 1.5이고 방향이 같으면 거래 안 함 |
| 청산(손절) | **가격 손절 없음 — 추세 신호로 청산**(사용자 결정). 거래소 청산이 유일한 강제 청산 |
| 비용 | 현물 편도 0.15%(수수료 0.10% + 슬리피지 0.05%), 선물 편도 0.095%(0.045% + 0.05%), 지갑 이체 0 |
| funding | 롱 선물이 정산마다 명목 × rate를 낸다(음수면 받는다). 실측, 결측을 0으로 채우지 않는다 |
| 청산 판정 | 선물 지갑이 무기한 **일봉 저가**에서 유지증거금(명목 0.5%) 이하면 **선물 지갑 전액 손실**(보수적) |
| 일 손실 2% | 그날 손실 ≥ 시작 자본 2%면 그날 **노출을 늘리는 거래만 금지**(축소는 허용) |
| 계좌 정지 30% | 봉 안 최악 자본(현물·무기한 저가)이 종가 기준 고점 대비 −30% 이하면 선물을 그날 종가에 전부 닫고 이후 선물 추가 중단 |
| 연패 4회·재진입 60분 | 일봉 체결이라 적용 대상이 없다(240분·60분 < 1일) |
| 현금 | 이자 0 |

**대조군 A:** 같은 시뮬레이터, 노출 1배·선물 없음·일 손실·정지 없음 = 등록된 T/v2 그대로(`T2_ALONE`).
`simulate_trend(long_only=True)`와 경로가 1e-12까지 같음을 테스트로 확인했다.

## 3. 구간·판정

**2020-03-01 ~ 2026-08-31 한 번 판정.** 시작은 ETHUSDT funding 자료의 시작(결측 funding 금지). 신호 이력은 현물 2017-08부터.

| # | 기준 |
|---|---|
| O1 | 계좌 정지(봉 안 −30%) **0회** |
| O2 | 선물 청산 **0회** |
| O3 | B 종가 기준 MDD **≤ 25%** (T/v2 전향 관찰의 운영 중단선, 16 §3) |
| O4 | B 연환산 순수익 > A 연환산 순수익 (전체) |
| O5 | 2020-03 ~ 2022-12, 2023-01 ~ 2026-08 **각각** B > A |

전부 통과해야 PASS. 실패 시 기각하고 노출 배수·레버리지 상한·일 손실 처리를 바꿔 재판정하지 않는다.
**다른 배수(2배 등)나 다른 레버리지 상한(5배 등)을 계산·보고하지 않는다** — 여러 값 중 좋은 것을 고르는 탐색이 된다.

보고만: 증분(B − A) 일간 평균·2SE·샤프, 현물·선물 손익, funding, 비용, 일 손실 발동일, 현물을 선물로 대신 든 날,
최대 선물 레버리지, 봉 안 최악 낙폭, 평균·최대 노출, 연도별, **고정 수량 50/50 보유**와 매일 재조정 50/50 보유(비용 없음, 23 지적 반영).

## 4. 검정력 — 통계 증명이 아니라 비용·위험 판정인 이유

- 6.5년 → 최소 검출 샤프 2.84 / √6.5 = **1.11**(검정력 80%).
- 증분(B − A)은 사실상 "T/v2 절반 크기의 선물 롱 − funding"이다. 그 샤프가 0.6 / 0.8 / 1.0이면 검정력은 약 32% / 52% / 71%.
  **증분이 0보다 크다는 것을 이 표본으로 통계적으로 증명할 수 없다.** 그래서 증분의 `평균 − 2SE`를 판정 기준으로 쓰지 않는다(보고만).
- 우위의 근거는 T/v1의 9년 1회 판정(PASS, 샤프 0.95)이다. 이 연구가 판정하는 것은 BACKTEST_AND_TESTING의
  **"효과 ≤ 비용" 게이트**(funding·비용이 추세 수익을 넘는가 — O4·O5)와 **위험 한도**(O1~O3)다.
- 따라서 PASS여도 "선물 추가가 통계적으로 우월"이라고 쓰지 않는다. 뜻은 "비용·위험 한도 안에서 수익을 늘렸다"까지다.

## 5. 노출 (정직하게)

- **2020~2026 가격은 이미 봤다.** T/v2의 2018~2026 결과(샤프 1.20, CAGR 21.2%, MDD 15.9%)도 봤고, 그 롱 전용 선택 자체가 사후 선택이다(16 §1).
- 1.5배 선택은 "15.9% × 1.5 ≈ 24% < 30%"라는 **이미 본 낙폭**에서 나왔다. 2배(≈ 32%)를 피한 이유도 같다. O3(25%)는 이 추정과 가깝다 — 통과 여부가 불확실하다.
- BTC funding 국면은 K에서 일부 봤다(2025~2026 축소). 두 종목 funding의 평균·합은 이번에 계산하지 않았다.
- 그러므로 이 판정은 OOS가 아니다. **PASS면 다음은 별도 원장의 전향 관찰**(기존 T/v2 Paper와 분리)이며, 그것도 사용자 승인 뒤다.

## 8. 이번 연구에 넣지 않은 것

- **신호가 꺼졌을 때 현물 유지 + 같은 크기 선물 숏(중립 캐리)**: 수익원이 K와 같다(연 2~3%). 이 실험과 섞으면 두 질문이 겹친다 → 필요하면 별도 후보.
- 신호가 꺼졌을 때 순매도 숏: T/v1·TA 숏 손익 ≈ 0 → 제외.
