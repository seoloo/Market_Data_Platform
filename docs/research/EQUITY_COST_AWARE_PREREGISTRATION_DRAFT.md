# 비용 고려 주식 포트폴리오 — 사전등록 초안

작성: Codex · 2026-10-07 · **IDEAS 20 / 사용자 논문 1번 / Phase 0 / DRAFT / NOT_TESTED**

## 1. 논문과 이번 축소 응용

Jensen·Kelly·Malamud·Pedersen, *Machine Learning and the Implementable Efficient Frontier*, RFS, 2026-03-15 온라인 출판. 거래비용을 고려한 배분과 학습을 결합해 위험 수준별 비용 후 성과를 평가한다. [저자 소속기관 자료](https://research.cbs.dk/en/publications/machine-learning-and-the-implementable-efficient-frontier-2/), [논문 DOI](https://doi.org/10.1093/rfs/hhag022).

원논문은 경제적 목적 함수로 비중 자체를 학습한다. **이번 1차 초안은 동결한 예측 + 비용 고려 배분의 효과를 따로 검증하는 축소 실험이며, 원논문 end-to-end 모델의 정확한 재현이 아니다.** 분리된 효과가 없는데 큰 신경망을 추가해 구제하지 않는다. 공개 [저자 코드](https://github.com/theisij/ml-and-the-implementable-efficient-frontier)는 참고용이며 설치·외부 엔진 채택·유료 원천자료 구매를 제안하지 않는다.

## 2. 질문과 의존성

**가설:** 동일 종목별 예측·위험 정보에서 기존 보유 물량과 예상 교체 비용을 배분 단계에 반영하면, 비용을 무시하고 고른 배분보다 비용 후 수익이 높다.

예측 우위가 없어도 비용 조절만으로 수익원이 생긴다고 가정하지 않는다. [21 예측 초안](EQUITY_RETURN_PREDICTION_PREREGISTRATION_DRAFT.md)이 우선이며, [공통 계약](EQUITY_ML_COMMON_RESEARCH_CONTRACT_DRAFT.md)이 필수다. 21의 최종 확인 결과에 맞춰 20의 비용 계수·기준을 바꾸지 않는다. 21은 별도 원장으로 유지하고 모델 20의 효과와 혼합해 보고하지 않는다.

## 3. 고정 입력과 두 배분군 — 제안값

| 항목 | 두 군 공통 |
|---|---|
| 예측 mu | 21 RF의 당시 저장된 다음 달 상대 수익 예측. 재학습 시점·해시·입력 동일. 비용군만 새 예측을 학습하지 않음 |
| 위험 Sigma | 과거 252거래일 총수익 공분산 × 21거래일로 월 단위 환산, 표본 공분산 50% + 대각행렬 50% 고정 축소. 결측·PSD·상장 이력 감사 |
| 이전 비중 | 실제 부분 체결·권리·가격 변화 뒤 계좌의 보유 비중. 마지막 목표 비중을 실제 보유로 간주하지 않음 |
| 대상 | 공통 계약의 당시 입력 유효 종목군. 신규 부적격 종목은 신규 매수 금지, 보유 잔량은 처분 제약/미체결을 회계에 유지 |
| 제약 | 롱만, 종목 목표 ≤ 5%, 차입 없음. 합계 목표는 21의 그달 사전 목표 투자비중(0~100%)과 동일하여 현금 타이밍을 분리 |
| 위험 선호 | lambda 5 고정, 두 군 같음. 적용 위험 계약·위험 상한·부분 체결 처리 모두 공통 |
| 자본·회계 | 공통 계약의 1,000만 원·정수 주식·한도 지정가·동일 비용·결제·기업행동 |

비용 고려군 목적은 월 기대 효용 `mu'w − (lambda/2) w'Sigma w − C(w − w_prev)` 최대화다. `C`는 회전된 금액당 그 시점 매수/매도 수수료·세금·감사된 실행 비용의 비대칭 비용 함수다. 별도 효과 배수를 튜닝하지 않는다. 시장충격 함수를 감사할 수 없으면 추정/한계를 표시하고 확정 전에 모델 형태를 하나로 정한다.

비용 무시군은 **목적 함수의 C만 0**으로 두며 실제 계좌 실행에는 같은 비용을 전액 차감한다. 비용 고려군만 더 낮은 비용·유리한 체결률을 받지 않는다. 두 군의 공통 gross exposure는 평가 전 목표 제약이며 실제 체결/가격 변화로 생긴 차이는 그대로 보고한다. 그 차이를 숨기거나 사후 노출 맞춤 수익으로 대체하지 않는다.

제약/목표를 못 맞추는 월의 공통 처리(현금·위험 축소·진입 거부), solver tolerance·동점 해 선택, 정수화·미체결·수수료 예약을 확정해야 한다. 거래를 아낀다는 이유로 부적격 보유나 위험 정지를 무시하지 않는다. 비용 절감 목적의 포지션 보유기간 제한·거래 횟수 제한은 추가하지 않는다.

## 4. 주 비교와 실패 조건

**주 비교:** 동일 달 `비용 고려군 계좌 순수익 − 비용 무시군 계좌 순수익`. 예측과 위험 제약을 고정해 배분 단계의 추가 효과만 묻는다. 21의 Ridge 비교를 이번 주 판정으로 다시 사용하지 않는다.

- 공통 계약의 차이 2SE 하한·경제적 최소 효과·양의 순수익·시장/위험 기준을 충족해야 한다. 회전율/지급 수수료 감소만으로 합격하지 않는다.
- 비용 전 기회 손실, 지급 비용, 현금 비중, 실제 노출, 부분 체결, 보유 집중, 종목 수, DD·Sharpe·CAGR를 나란히 기록한다. 비용 절감보다 놓친 수익이 크면 실패다.
- 같은 시그널을 서로 다른 자본 규모로 돌려 가장 유리한 것을 고르지 않는다. 계좌가 작아 정수 주식/분산 제약이 성립하지 않으면 Phase 0에서 보고한다.
- 충분한 검정력의 고정 확인에서 주 기준 미달은 `REJECT`. 예측군 자체의 손실·시장 열위는 자동매매 목표 미달로 기록한다. 비용 효과가 양수라도 실거래로 넘기지 않는다.
- `DATA_NOT_READY`/`DATA_INSUFFICIENT`/`HISTORICAL_SUPPORT`의 구분은 공통 계약을 따른다. 수수료를 낮춘 가정·리베이트·자본 확대·lambda/회전 페널티 탐색으로 실패를 구제하지 않는다.

## 5. 자료·검정력·후속 경계

기간별 비용 및 실제 차이의 장기 SD·독립 월수·최소 검출 효과가 아직 없다. 이전 DMN의 기준선 SD로 비용군 비교의 검정력을 단정하지 않는다. 같은 예측으로 짝지은 비교의 분산이 작을 가능성은 있지만 **실측 전 보장하지 않는다**.

21 실행 전 현재 20의 질문·비교 구조도 기록한다. 21 결과를 본 뒤 바뀐 부분은 열람 영향과 이유를 남기며 이미 본 기간을 최종 확인에 재사용하지 않는다. 20의 확정은 자료 감사와 사용자 선택 뒤 Claude의 별도 성과 전 커밋이다.
