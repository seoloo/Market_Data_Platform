# 281 — Deneb 거시 위험 보완: 시점 자료·검정력 G0 감사

2026-10-18 Codex · Phase 0 · **감사 계획, 전략 사전등록 아님**.

## 1. 승인과 범위

사용자: "좋아 그렇게 해서 결과 나올 때까지 쭉 진행해줘."
직전 제안은 자료 감사 → 80% 검정력 → 단일 보완안 사전등록 → 구현·검증·판정이다.
이번 승인에 검정력 예외·실거래 변경·운영 예약 추가는 포함되지 않는다.
현재 HEAD `740268e` 기준 기존 Deneb·Sirius·Paper·Live, 연구 208과 봉인 가격은 보존한다.
2026-09-01 이후 가격·정답은 읽지 않는다. 공개 거시 자료도 관측일/판본일 모두 2026-08-31로 제한한다.

## 2. 질문과 기존 연구와의 차이

고용·실물경기·금융 여건이 가격·변동성 방어보다 먼저 하방 위험을 알려,
줄였다 복귀하는 비용까지 차감한 Deneb 성과를 개선하는지 묻는다.
Sirius의 종목 상대 순위 예측과 다른 문제다.

- [166](166-qs-decline-warnings.md): BAA10Y 경고/시장 폭/투표 기각 유지.
  경고 문턱 수정·세 규칙 혼합으로 되살리지 않는다.
- [204](204-qqq-ml-preregistration.md): 가격·변동성·장기금리 주간 ML 기각 유지.
  하락 예측 AUC가 있어도 기존 추세 규칙과 중복됐다는 교훈을 반영한다.
- [251](251-net-liquidity-preregistration.md): 순유동성 필터 근거 부족 유지.
- [280](280-deneb-shadow-registration.md): 같은 순수 함수의 기준선 재사용 후보일 뿐,
  종가 전량 체결·수동 배당 단계/세금 작업 누락의 근사를 실거래 parity로 확대하지 않는다.

## 3. 성과 열람 전 고정한 G0 절차

1. ALFRED 공개 다운로드 양식에서 아래 7개 계열의 판본 날짜·원자료를 확보한다.
   가입·키·유료 구매 없이 공개 경로만 사용, HTTP 실패는 실패로 기록한다.
2. 관측일·최초 공개일·판본일을 구분하고 SHA256과 요청 URL/시각을 남긴다.
   값이 없거나 과거 판본이 없으면 최신값/0으로 보간하지 않는다.
3. 월말 결정, 주 정답은 나스닥100 종가가 **결정일 대비 이후 126 거래일 안 -15%**.
   미래 고점 대비 낙폭은 다른 정답이므로 섞지 않는다. G0는 정답 분포만 셀 수 있다.
4. 학습/최종 평가 길이·정답 중첩·6개월 경계 제거를 반영해 표본을 센다.
5. 기준선/무작위 위험 배율 대리의 분산으로 검정력 규모를 추정한다.
   **실제 거시 모델·후보 신호·후보 수익을 계산하지 않는다.**
6. 목표 증분은 기존 [203](203-ml-dl-g0-audit.md)의 계획값과 같은
   **연 산술 3%p = 월 0.25%p**, z=2, power=0.80. 효과를 키워 통과시키지 않는다.
   분산은 실제 후보가 아닌 대리 추정임을 명시하고, 학습/평가 양쪽을 따로 판정한다.
   같은 위기의 월별 경고를 독립 위기 여러 개로 세지 않는다.
7. 자료·검정력 미달이면 `DATA_INSUFFICIENT`/`NOT_TESTED` 결과를 남기며,
   모델 학습·새 계좌 성과는 시작하지 않는다. 예외가 필요하면 별도 사용자 승인이 필요하다.

### 분산 대리와 기간 — 계산 전에 고정

- 계획 분할: 특징이 갖춰진 첫 월~2016-06 결정 TRAIN(정답 끝 2016-12 이전),
  2017-01~2019-06 VALIDATION(정답 끝 2019-12 이전),
  2020-01~정답 끝이 2026-08-31 이내인 월말 역사확인. 경계 label 중첩은 제거한다.
  대략 2026-02가 마지막이지만 실제 거래일 126개로 판정한다.
- Deneb 실제 ETF 기준선만으로 2012-01~2016-06의 NAV 분산을 확인한다.
  기존 184 `simulate(ref='T', park='cash')`를 유한 구간 입력으로 호출하며 기존 결과를 덮어쓰지 않는다.
  184의 소수점·수정주가·고정 환율·세금 근사는 유지하며 운영 일치 인증으로 쓰지 않는다.
- 대리는 **전체 기준선 수익을 절반 감쇠**하는 무작위 Markov 위험 상태다.
  실제 후보의 TQQQ만 축소하는 손익과 같지 않으며 모델 성과가 아니다.
  위험 점유율/평균 지속을 (10%, 63거래일), (20%, 126거래일) 두 가정으로 고정한다.
  seed=281, 가정마다 300회, 전환 때 50%×편도 0.15% 비용.
  평균 수익·유리한 경로·최종 금액은 계산/보고하지 않고 차이 분산만 계획에 쓴다.
- 월 차이 장기 SD(Bartlett lag6)와 겹치지 않는 6개월 합 차이 SD를 둘 다 보고한다.
  6개월 효과=1.5%p, 각 가정 SD의 중앙·90백분위 및 MDE/필요 표본을 보고한다.
  작은 분산 가정 하나만 선택해 통과시키지 않는다. 양쪽 가정·기간·단위의 보수적 90백분위에서
  80%를 확인하지 못하면 정식 학습을 열지 않는다. 대리 통과 자체도 후보의 검정력 인증은 아니다.

## 4. G0 통과 시에만 확정할 단일 연구

- 모델: 기저율 기준, Logistic Regression(주), 작은 트리(추가 복잡도 비교)까지.
  단순 모델의 정보 기여 없이 DL을 열지 않는다.
- 비교: A 현행 Deneb / B 학습 구간에서 고정한 상시 축소 / C 거시 경고 시 TQQQ 몫 0.5.
  SCHD 몫을 늘리지 않고 축소분은 별도 달러. 기존 한도·방어를 완화하지 않는다.
- 경고 진입·해제 문턱, 기존 QQQ 추세 복귀와의 우선순위, 동일 사건 재경고,
  실행시각·부분체결·미체결·수량·세금·배당/환율은 **성과 전에 별도 사전등록**한다.
- A 예측 검증과 B 계좌 경제성 검증을 분리한다.
- 피한 하락, 놓친 상승, 복귀 지연, 비용·세금을 별도 기여로 보고한다.
- 과거 반복 열람 자료는 독립 OOS가 아니다. 정식 채택/Paper/Live는 별도 게이트 유지.
