# 01 — 새 전략 후보 비교 (2026-09-23)

절차: [BACKTEST_AND_TESTING](../current/BACKTEST_AND_TESTING.md) §연구 절차 · §검정력 게이트.
후보는 최대 3개, **사용자가 고른 하나만** 구현·검증한다. 이 문서는 선택을 위한 자료이며
구현 승인이 아니다.

**성과를 열람하지 않고 작성했다.** 측정한 것은 표준편차와 트리거 횟수뿐이고
수익률 평균은 계산하지 않았다. 원자료:
[btc_noise_floor.json](../../reports/phase0/btc_noise_floor.json) ·
[candidate_triggers.json](../../reports/phase0/candidate_triggers.json).

## 1. 먼저 잰 것 — BTC 단일 심볼의 잡음 바닥

`scripts/measure_noise_floor.py`, BTCUSDT 5분봉 706,752개 (2020-01 ~ 2026-09, 6.7년),
중첩 제거(embargo = horizon), 검정력 80%, 비용 18bps.

| horizon | SD | 독립 표본 | 연간 | **증명 가능한 최소 효과** |
|---|---:|---:|---:|---:|
| 2h | 92.9 | 29,447 | 4,383 | **19.5bps** |
| 4h | 129.2 | 14,723 | 2,191 | **21.0bps** |
| 6h | 157.0 | 9,815 | 1,461 | **22.5bps** |
| 12h | 224.0 | 4,907 | 730 | **27.1bps** |
| 24h | 319.8 | 2,453 | 365 | **36.3bps** |
| 48h | 440.2 | 1,226 | 182 | **53.7bps** |
| 72h | 535.7 | 817 | 122 | **71.3bps** |

2023~2026 만으로 다시 재도 마지막 열은 거의 같다 (6h 22.5 → 22.6). SD 가 낮은 국면에서는
표본당 잡음도 같은 비율로 줄기 때문이다. **이 열은 국면에 강건하다.**

### 여기서 나오는 구속 조건

마지막 열은 `18 + 0.77 × 보유시간(h)` 에 거의 정확히 들어맞는다.

> **총 우위 > 18bps + 0.77 × 보유시간(h)**

18 은 왕복 비용이고 0.77bps/h 는 잡음이 요구하는 기울기다. 뒤집으면,
**시간당 0.77bps 를 못 버는 전략은 보유를 늘려도 증명되지 않고**, 시간당 우위가
`e` bps 일 때 필요한 최소 보유시간은 `18 / (e − 0.77)` 이다.

### 변동성 수축은 검정력을 개선하지 않는다 (실측)

| horizon | 무조건 SD | 수축 SD | SD 감소 | 증명가능 (무조건 → 수축) |
|---|---:|---:|---:|---|
| 2h | 92.9 | 68.0 | −27% | 19.5 → **19.9** |
| 6h | 157.0 | 124.7 | −21% | 22.5 → **23.9** |
| 24h | 319.8 | 272.2 | −15% | 36.3 → **41.0** |

수축 국면은 잡음을 21~27% 줄이지만 표본도 63% 줄어서 **순효과는 오히려 불리하다.**
따라서 후보 A 의 근거는 "잡음이 작아서" 가 될 수 없다. **효과가 커야** 한다.
이 사실을 후보 A 의 가설에 반영했다.

### 판정

| 후보 | 게이트 |
|---|---|
| A | **통과.** 6h 보유 기준 30bps 이상의 총우위가 있으면 3년 TRAIN 으로 판정 가능 |
| B | **통과.** 2h 보유 기준 27bps 이상이면 판정 가능. 셋 중 가장 낮은 문턱 |
| C | **탈락.** 두 가지 이유로 탈락하며 어느 쪽도 데이터로 해결되지 않는다 |

**C 를 탈락시키는 이유**

1. 14일 보유의 SD 가 약 1,157bps 인데 연 26회뿐이라 3년 TRAIN 으로는 **390bps(3.9%)**
   이상의 거래당 우위만 증명된다. 추세추종의 통상 기대값을 크게 넘는다.
2. Phase 4 의 실거래 100건에 **3.8년**이 걸린다. 전향적 검증이 사실상 불가능하다.

표본을 늘리려면 보유를 줄이거나 심볼을 늘려야 하는데, 전자는 C 가 아니게 되고
후자는 단일 심볼 실거래 제약에 걸린다. **후보에서 제외한다.**

## 4. 사전등록 전에 반드시 측정할 것 (게이트 결과의 한계)

위 판정은 **낙관적**이다. A·B 모두 **트리거 시점의 SD 가 아니라 근사치**를 썼다.

- A 에는 수축 국면 SD 를 썼지만, A 가 진입하는 순간은 **돌파 = 확장의 시작**이다.
  그 시점의 SD 는 수축 국면 평균보다 **높을 가능성이 크다**.
- B 에는 무조건 SD 를 썼지만, 캐스케이드 직후는 **고변동 구간**이다.

같은 실수를 한 번 했다. [19](../archive/research/19-maker-cost-measurement.md) 는 무작위
시점에서 maker 체결을 재 순개선 4bps 를 얻었지만,
[20](../archive/research/20-signal-time-fills.md) 에서 **신호 시점**으로 다시 재니
역선택이 27배였고 결론이 뒤집혔다.

따라서 선택된 후보는 사전등록 직전에 다음을 **트리거 시점 기준으로** 측정한다.

| 측정 | 이유 |
|---|---|
| 트리거 시점 선행수익 SD | 검정력 게이트를 다시 통과해야 한다 |
| 트리거 시점 스프레드·슬리피지 | 18bps 비용 가정의 검증. B 는 특히 |
| 손절/TP 적용 후 **거래당 손익 SD** | 전략 쪽 표본 계산은 봉 수익률 SD 가 아니라 이 값을 쓴다 |

세 측정 모두 **평균은 읽지 않는다.**

## 5. 선택

A 와 B 가 게이트를 통과했다. 둘 중 하나를 선택하면 §4 의 재측정 → 수치 사전등록으로
넘어간다. 선택 전까지 전략 코드를 만들지 않는다.

| | A 를 고를 이유 | B 를 고를 이유 |
|---|---|---|
| | 데이터가 2020 부터라 TRAIN 이 길다 | 문턱이 가장 낮다 (2h 27.3bps) |
| | 경제적 논리가 단순하고 검증 가능하다 | 기각된 연구들과 수익원이 확실히 다르다 |
| | | 비용 가정만 통과하면 메커니즘이 강건하다 |
| 반대 이유 | **H1 과 겹친다.** 새로운 것은 변동성 조건 하나뿐 | **비용 취약성이 가장 크다.** 급변 직후 스프레드가 가정을 깰 수 있다 |

각 후보의 가장 큰 위험이 서로 다르다 — A 는 **중복**, B 는 **비용**이다.
B 의 비용 위험은 §4 의 측정으로 **사전등록 전에 확인 가능**한 반면,
A 의 중복 위험은 측정으로 해소되지 않고 사전등록 문서의 논증으로만 다뤄진다.
