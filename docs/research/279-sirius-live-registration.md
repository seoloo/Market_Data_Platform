# 279 — ✨ Sirius 실거래 등록: 미장 주도주 GBM 10 종목 × 6 달 보유, 토스 소수점, ₩100 만

작성: 2026-10-18 (Claude) · 트랙: **실거래**(토스) · 상태: **준비 완료 — 설정 `live.sirius` 를 사용자가 켜야 주문. 첫 결정 2026-10-30 종가 → 첫 주문 11-02(월) 미국 정규장**

## 0. 사용자 결정

- "만약 이번 달 말부터 실거래 시작한다 가정하고 100만원으로 하면" → 한투는 Open API 에 소수점 주문이 없어 불가 → **"그러면 토스로 실거래 할 수 있도록 준비 부탁해. 다음달부터 하는데 그러면 100만원의 1/6이니까 16만원 쯤으로 시작"**.
- '모든 매매는 지정가' 규칙은 같은 날 사용자가 삭제(TRADING_CORE §주문 유형) — 소수점은 금액 시장가만 된다.
- 근거 · 한계: [274](274-us-leader-ml-preregistration.md) · [275](275-us-leader-6m-hold-preregistration.md) · [276](276-us-leader-small-account-preregistration.md) · [277 Paper](277-us-leader-gbm-paper-registration.md). 백테스트는 생존 편향 자료 위 값이고(실제는 U2 +27% 보다 낮게 봄), 손절이 없어 −20 ~ −33% 해가 있다. **이 실거래는 운영 확인 · 체결 확인 목적의 소액**이다.

## 1. 규칙 (Paper 277 GBM10F 와 같음)

- 매달 마지막 거래일 종가까지의 자료(LT Paper 일봉 · SEC 실적)로 274 GBM 을 다시 학습해 **상위 10 종목**.
- **다음 거래일 정규장**(23:45 KST 실행)에서 **금액 주문(소수점 시장가)** 으로 산다. 한 번에 쓰는 돈 = min(전략 현금 + 오늘 팔 돈 × 0.99, 평가액 ÷ 6), 10 종목 같은 금액. 첫 달 = $745.55 ÷ 6 ≈ **$124 (약 16.7 만 원), 종목당 약 $12.4**.
- 산 날부터 **126 거래일째** 정규장에서 그 묶음을 **소수점 시장가로 전부 판다.** 손절 · 익절 없음.
- 같은 날 팔 묶음의 종목이 새로 다시 뽑히면 팔지 않고 새 묶음으로 넘기고 **차액만** 사고판다($1 미만 차이는 주문 없음).
- 처음 6 달은 1/6 씩 채워지고, 그 뒤엔 판 돈으로 산다. 돈을 더 넣으면 약 6 달에 걸쳐 들어간다.

## 2. 안전 장치

- 주문 = 설정 **`live.sirius`(기본 꺼짐)** · `.env` `TOSS_TRADING_ENABLED` 둘 다 켜져야. `data/HALT` · `HALT_sirius`('전부 정리' 범위 'all' 에 포함) 면 주문 안 함.
- 정규장 시작 + 1 분 ~ 종료 − 61 분만(토스 소수점 접수 시간). 휴장 · 시간 밖이면 아무것도 안 함.
- 허용 종목 = 그날 주문할 종목만, 금액 주문 한 건 상한 = 평가액 10%($25 이상).
- 보내기 전 저장 · `clientOrderId` · 결과 모름이면 다시 안 보냄(알림, 사람이 확인). 확인 안 된 주문이 있으면 새 주문 안 함.
- **토스 달러는 Deneb 장부 현금과 섞여 있다** — 매수 가능 달러에서 Deneb 현금 · 보관금을 빼고, 모자라면 알리고 다음 실행(같은 결정)에서 다시 산다.
- 일봉(LT Paper)이 멈췄으면 새 묶음 결정을 미룬다.
- 장부는 Sirius 몫(묶음별)만 — 체결 수량 · 금액 · 수수료로만 넣는다.

## 3. 실행 · 확인

- 장부 시작 2026-10-18: ₩1,000,000 = **$745.55**(토스 환율 1,341.3). **11-02 전 토스에서 약 $750 를 달러로 바꿔 두어야** 한다(환전 API 없음).
- 예약 `AutoTrading_Sirius` — 평일 23:45 · 화 ~ 토 02:00 KST (연구 venv pythonw). 텔레그램 ✨ 알림(주문 · 체결 · 달러 부족), 현황(/status)에 Sirius 장부.
- `build/tcn-venv/Scripts/python.exe -m scripts.sirius_live status | preview`.

## 4. 정리 (2026-10-18 추가 — 사용자 "소수점 정리하는 기능도 만들어줘")

- 텔레그램 '정리' · 오르빗 설정 정리에 **"Sirius 만"** 버튼, '전부' 에도 포함. 누르면 ① `HALT_sirius`(새 주문 정지) ② 정리 요청 `data/sirius/LIQUIDATE.json` ③ Sirius 실행기가 **정규장(시작 + 1 분 ~ 종료 − 61 분)에서 Sirius 묶음 전부를 종목별 소수점 시장가 매도**. 장 밖이면 기다리다가 봇(2 분마다) · 예약 실행이 장 열린 뒤 판다.
- 설정 `live.sirius` 가 꺼져 있어도 사람이 누른 정리는 한다(토스 주문 허용은 필요). 결과 모름 · 미확인 주문이 있으면 확인 뒤 다음 걸음.
- 다 팔리면 요청을 지우고 "✅ Sirius 정리 끝" 알림. '정지풀기 → Sirius' 를 누르면 정리 요청도 취소(남은 보유는 그대로).
- 직접: `build/tcn-venv/Scripts/python.exe -m scripts.sirius_live liquidate`.
- 사용자 보유 · 다른 전략의 같은 종목은 건드리지 않는다(Sirius 장부 수량만).
