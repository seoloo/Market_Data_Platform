# 282 Deneb 위험지도와 중지 복귀 관찰 계약

2026-10-18 · 사용자 승인: 위험지도와 전향적 중지·복귀 기록을 먼저 진행하고, 신규 납입금 조절은 자료 감사부터 한다.

## 목적과 경계

거품·자금조달·산업 경쟁·시장 확산을 넓게 관찰하고, 사람이 투자 중지를 판단할 때 어떤 정보가 실제로 있었는지 남긴다. 정보의 존재와 거래의 수익성을 분리한다. 연구 281은 그대로 보존하며 재학습·후향 계좌 계산을 하지 않는다.

이번 산출물은 **정보 관찰 도구**다. 뉴스·LLM·지표 점수로 주문·veto·사이징·복귀를 결정하지 않는다. 기존 Deneb, 280, Paper, Live, HALT, 예약, 텔레그램, UI와 연결하지 않는다. 새 예약도 만들지 않는다. 208 및 봉인 가격 파일을 읽지 않는다. 현재 공개 페이지는 현재 관찰로만 수집하며 과거 연구 정답에 넣지 않는다.

## 관찰할 정보

동결할 36개 항목을 네 역할로 나눈다. 모든 항목을 모델 변수나 독립 표로 세지 않는다.

- 취약성 12개: 버핏 지수, CAPE, 예상 PER, 빚투 잔고, 고객 현금, 기업 이자 부담, 부채 만기, 설비투자 대비 현금, 시장 집중, 투기적 발행, 은행 대출 기준, 사모신용.
- 촉발 9개: 실적 전망, 실적 충격, AI 기업 손실, 메모리 경쟁, 물가 충격, 실질금리 충격, 유가 충격, 정책·지정학, 사이버·운영 사건.
- 확산 11개: VIX, VXN, 변동성 기간구조, VVIX, 옵션 하방 가격, 하이일드 스프레드, 초과채권프리미엄, 단기 조달, 달러 조달, 시장 폭, 펀드 흐름.
- 복귀 4개: 가격 추세, 변동성 정상화, 신용 정상화, 사람이 명시한 복귀 계획.

항목마다 정의·단위·공식 출처·자료 주기·정보 중복·확보 상태를 둔다. 확인되지 않은 항목은 미확보이며 중립/안전이 아니다. 날짜가 오래된 사실과 현재 시장 지표를 구분한다. 과거 수정값·컨센서스 이력·당시 구성종목/비중이 필요하지만 없으면 추정해 채우지 않는다.

## 근거와 시각

- 근거는 관측일, 공개 시각(알 때만), 실제 수집 시각, 원문 SHA256, 출처 URL을 분리한다. 날짜만 있는 미국 발표는 해당 뉴욕 날짜의 종료 시각을 보수적 경계로 쓴다.
- 공개 시각을 모르면 실제 수집 전에는 알 수 있었다고 주장하지 않는다. 수정된 페이지의 과거 사실도 최초 수집 시각 이전 재생에 노출하지 않는다.
- 기록은 독립 SQLite의 append-only 원장이다. 수정/삭제 대신 정정 이벤트를 추가하며, 원문과 연결된 해시 체인을 검증한다. 해시 체인은 현재 DB의 변경 탐지 수단이지 외부 공증·말미 삭제 방지 인증은 아니다.
- 조회는 지정 as-of 시점에 실제 저장돼 있었고 관측/공개 시각을 넘지 않는 기록만 본다. 나중에 같은 원문을 다시 읽어도 당시 첫 기록을 소급 생성하지 않는다.
- 공시 사실, 사용자 진술, 분석 가설, 기존 장부 복사본을 명시적으로 구분한다. 중복 기사 수로 신뢰도를 올리지 않는다. 긍정·반대 근거도 같은 사건 묶음에 남긴다.

## 초기 수집

공식 공개 주소만 허용하는 수동 실행 수집기로 FINRA 잔고, Cboe 공개 CSV, CoreWeave 실적, CXMT 제품을 우선 점검한다. 접근 차단/형식 변화는 실패로 저장한다. 키·로그인·구독·유료 호출·검색엔진 우회 없음. 재배포·상업 사용 허가는 확보한 것으로 취급하지 않는다.

공식 원문을 로컬에 보존하고 필요한 수치/사실만 추출한다. 현재 자료를 읽는 기능 검산이지 새로운 후향 수익 검증이 아니다. 숫자는 Decimal 문자열, 시각은 UTC epoch ms다. 위험 점수·매수/매도 신호·확률은 출력하지 않는다.

## 중지와 복귀 기록

중지/축소/복귀의 실제 수행은 사용자가 별도로 결정한다. 기록에는 행동 범위(신규 매수만/보유 매도/불명), 그때 사유, 근거, 복귀 계획, 진술 시각과 주장한 행동 시각을 남긴다. 범위를 모르면 불명으로 둔다.

이번 대화의 과거 중지 사유는 **2026-10-18에 나중에 진술한 후향 기록**이다. 10월 초에 이 사유가 기록돼 있었다고 소급하지 않는다. 원문 81.29달러는 사용자 진술이며 280의 모형 첫 체결 81.28달러와 혼용하지 않는다. 280 문서의 10-13 정리 이력만으로 그때의 판단 근거와 시각을 만들어내지 않는다.

기존 `reports/deneb_shadow/latest.json`은 읽기만 하고 원본 SHA·시각·시작일·납입·평가액만 별도 기록한다. 기존 280을 새로 실행하지 않는다. 280의 수정주가·그때 환율·종가 체결 근사와 원금 기준 단순 수익률/평가액 낙폭을 운영 성과와 혼동하지 않는다.

같은 시작 자산, 실제 입출금, 수량, 가격, 비용, 세금·배당, 환율, 실제 행동/복귀 자료가 모두 맞기 전에는 **피한 손실·놓친 수익·전략 증분을 계산하지 않는다**. 현금으로 가정해 전량 매도한 계좌를 만들어 비교하지 않는다. 첫 결과는 비교 대기로 표시한다.

## 신규 납입금 조절 연구의 G0

기존 124·165·166·204·251·281의 판정은 유지한다. 지표만 바꿔 같은 경고 전략을 되살리지 않는다. 차별점 후보는 기존 보유분 매도가 아니라 **새 돈의 최초 노출 시점**이며, 대기 중 놓친 상승과 복귀 비용까지 묻는다.

이번에는 공개 시점 자료와 실제 의사결정 사건 수를 감사할 뿐, 진입 문턱·대기기간·비중을 고르거나 새 수익을 보지 않는다. 원장 부재/독립 사건 부족이면 DATA_INSUFFICIENT이고 사전등록하지 않는다. 281의 검정력 예외는 282로 이전되지 않는다.

## 기능 완료 기준

1. 36개 항목의 출처·역할과 미확보 상태가 모두 보이고, 빠진 항목을 안전으로 표시하지 않는다.
2. 미래 관측/공개/늦게 수집한 기록이 과거 as-of 출력에 섞이지 않는다.
3. 같은 요청 재전송은 중복 기록하지 않고, 같은 ID의 내용 변경은 거부한다. 기록 변경과 불법 UPDATE/DELETE를 탐지/차단한다.
4. 출처 차단·빈 CSV·미래 날짜·잘못된 단위·원문 해시 불일치를 실패로 다룬다. 자동 재시도/다른 사이트 대체로 성공을 꾸미지 않는다.
5. 주문·계좌·설정·알림·예약 모듈을 가져오지 않는다. 기존 운영/280 파일은 바꾸지 않는다.
6. 합성 테스트·누수 검사·전체 회귀·타입·린트·계층 검사를 하고 첫 실제 수집 결과와 실패를 함께 보존한다.

완료 판정은 **정보 도구 기능 검증**이다. Phase 4 수익성 PASS·새 Paper/Live 승인과 별개다.
