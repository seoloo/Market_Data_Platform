# 엘리엇 삼각형(삼각수렴) — 자료 수집 정리 (참고 자료)

작성: 2026-10-03 (Opus) · 사용자 요청: "삼각 수렴이 생각보다 많더라 … 다시 검색해서 학습해줘 … 나온 내용을 다시 검색하고 자료를 수집".
방식: 엘리엇 삼각형에서 시작해 나온 주제(러닝·장벽·확장, 돌파 크기, 꼭지점 시간, NEoWave, 차트 패턴 통계, 학계)를 다시 검색하는 **꼬리 물기**. 판정 문서가 아니다.
상위 정리: [ELLIOTT_WAVE_PATTERNS](ELLIOTT_WAVE_PATTERNS.md).

## 1. 정통 엘리엇(Frost·Prechter, Elliott Wave International)

| 항목 | 내용 |
|---|---|
| 구조 | 겹치는 다섯 다리 A-B-C-D-E, **3-3-3-3-3**. 대부분 지그재그, C 는 더 복잡하기 쉽고, 가끔 **E 자체가 삼각형**(9 다리) |
| 종류 | **수렴**(가장 흔함) · **장벽**(B 와 D 가 거의 같은 높이 → 한쪽 선이 평평) · **확장**(드묾, 선이 벌어짐 — 다음 다리가 앞 다리의 100~150%) · **러닝**(B 가 A 시작을 넘어 큰 추세 쪽으로 기움) |
| 수렴 조건 | C 는 A 를, D 는 B 를, E 는 C 를 넘지 않는다(같은 쪽 극값끼리 안쪽) |
| **자리** | **항상 "마지막 추진파 바로 앞"**: 충격파의 **4 파**, A-B-C 의 **B 파**, 이중·삼중 지그재그·복합 조정의 **마지막 X**, 복합 조정의 **마지막 조각(Y·Z)**. 정통 견해로 **2 파·A 파에는 오지 않는다** |
| E 파 | A-C 선을 **덜 가거나 살짝 넘는 경우가 "그렇지 않은 경우보다 많다"** (EWI). 실시간으로 E 끝을 알아보기는 "악명 높게 어렵다" |
| 돌파(thrust) | 삼각형 앞 파동 방향으로 빠르게. 4 파 삼각형 뒤 5 파는 **"때때로 빠르고, 삼각형의 가장 넓은 폭만큼"** 간다. 돌파는 보통 충격파, 가끔 종결 대각선. **강한 시장에서는 짧은 돌파 대신 길게 늘어난 5 파** |
| 돌파 뒤 | 돌파는 그 단계의 **마지막 파동**이라, 실전에서는 새 추세의 시작이 아니라 **이익을 실현할 움직임**으로 본다 |
| 시간 | 수렴 삼각형의 두 선이 만나는 **꼭지점 시각이 흔히 시장의 전환점과 겹친다** |
| 거래량·변동성 | 삼각형이 진행되며 줄어든다 |
| 무효화 | 돌파 뒤 **삼각형 몸통 깊이 되돌아오면** 카운트가 틀린 것. 한 다리가 5 파로 나뉘면 삼각형이 아니다 |

**왜 "삼각형 = 마지막 파동 앞"이 중요한가:** 4 파 삼각형을 확인하면 남은 것은 5 파 하나 → 돌파를 타고, 돌파가 끝나면 더 큰 조정을 대비. B 파 삼각형이면 다음은 C 파(A 방향).

## 2. NEoWave (Glenn Neely, *Mastering Elliott Wave*, 1990)

- 정통보다 규칙이 많다 — 시간·비율·**패턴 뒤 행동**까지 규칙으로 둔다.
- 삼각형 뒤 돌파: **삼각형 전체 가격 폭의 61.8% 이상**을 가고, **삼각형보다 짧은 시간**에 끝나야 한다.
  "중립 삼각형"의 돌파는 삼각형 시간의 **20~40%** 안에, 삼각형에서 가장 큰 다리의 **75~125%** 만큼(실전 해설 인용).
- **제한(limiting) 삼각형**(두 선이 만나는 꼭지점 근처에서 끝나고 돌파가 나옴)과 **비제한(non-limiting)**(삼각형이 더 큰 패턴의 일부로 이어짐)을 나눈다.
- 일부 NEoWave 해설은 제한 삼각형이 **2 파·4 파**에 흔하다고 한다 — 정통("2 파에는 없음")과 **충돌**한다. 정통에서도 2 파 자리의 지그재그 B 파 안에서는 가능.
- 중립 삼각형(C 가 가장 긴 다리), 추출(extracting) 삼각형, 7 다리 diametric 같은 정통에 없는 모양을 더했다.

## 3. 차트 패턴으로서의 삼각형 (Bulkowski, *Encyclopedia of Chart Patterns*)

엘리엇 삼각형(3-3-3-3-3 하위 구조)과 달리 **추세선 두 개만으로** 정의한다 — 사람들이 차트에서 "삼각수렴"이라고 부르는 넓은 개념.

| 패턴 | 표본 | 돌파 방향 | 성과 · 실패 |
|---|---|---|---|
| **대칭 삼각형** | 3,000 건 이상 | 위 **60%** · 아래 40% | 위 돌파 평균 +34%, 본전 실패 **25%** · 아래 돌파 평균 −12%, 실패 **37%**. 성과 순위 **39 개 중 36 위**(위) · 36 개 중 34 위(아래) — "자주 보이지만 성과는 나쁘다" |
| 대칭 삼각형 — 추세 | | 이전 추세 **계속 55% · 반전 45%** | "계속형으로 과대평가" |
| 대칭 삼각형 — 실패 | | 아래 돌파의 **48% 가 실패(bust)** | 한 번 실패한 뒤 반대로 가면 평균 +52% |
| 오름 삼각형 | | 위 약 62% | 위 돌파 순위 16 / 39, 실패 17%, 평균 +43% |
| 내림 삼각형 | 1,300 건 이상 | 위 **53%** (이름과 달리) | 위 돌파 평균 +38% |
| 공통 | | 돌파는 꼭지점까지 거리의 **약 74%** 지점 | 거래량 감소 84~86%. 되돌림(throwback·pullback) 62~65% |

**꼭지점 시간:** 꼭지점 며칠 안에 작은 고점·저점이 나온 비율 **75%**(221 건), 추세가 바뀐 비율 **60%**(239 건), 가장 가까운 고점·저점까지 평균 3.6 일. 표본 작음·관찰자에 따라 다름.

## 4. 빈도 — "삼각수렴이 많다"는 체감과 이 프로젝트의 결과

- 엘갤 PDF(p.10·17, 설계 문서 §3.3): 삼각형은 **15 분 이하에서 주로 등장(약 60%)**. 실전 해설들도 짧은 시간봉에서 잘 보인다고 한다.
- 이 프로젝트(문서 60~62): **엘리엇 정의(3-3-3-3-3)** 의 삼각형은 BTC **4h·일봉**에서 무작위 대조보다 **드물게** 읽혔다(4h 0.35 배 · 일봉 0 개).
- 두 사실이 모순은 아니다: ① 차트에서 보는 삼각수렴은 추세선 두 개짜리 넓은 개념이고, ② 엘리엇 삼각형은 짧은 시간대에 많다. **4h·일봉만 본 우리 결과가 "드물다"였던 것**이다.
  → 1h degree(시간 ×4)에서 다시 볼 이유가 있다. 15 분 degree 는 1m 자료로 하위파·경로를 만들 수 없어 지금은 어렵다.

## 5. 학계·자동 인식

- Lo·Mamaysky·Wang (2000, *Journal of Finance*): 커널 회귀로 패턴을 기계 인식, 미국 주식 1962~1996 — 일부 패턴(헤드앤숄더·이중 바닥 등)이 **추가 정보**를 준다. 삼각형도 대상이었다.
- 신경망 엘리엇 인식(Kotyrba·Volná 등, ECMS 2012·2013): 모양 인식 정확도는 높게 보고하지만 **수익 검증은 아니다**.
- 코인 차트 패턴 투자자 연구(*Financial Innovation*, 2025): 차트 패턴을 많이 쓰는 투자자는 수익 분포가 오른쪽으로 치우치고 거래가 잦다 — **삼각형 단독 수익은 원문 접근이 막혀 확인 못 함**.
- "코인 삼각형 8,144 개 중 63% 적중" 같은 숫자는 검색 요약에만 있고 출처에서 확인되지 않았다 — 쓰지 않는다.

## 6. 시험 설계에 쓰는 것 (문서 98)

1. 삼각형은 **"마지막 파동 앞"** — E 끝에서 삼각형 **앞 파동 방향(−d)** 으로 돌파.
2. 돌파 크기 ≈ **가장 넓은 폭**, 시간은 **삼각형보다 짧게** — 보조로 잰다.
3. 차트 패턴 통계는 기대를 낮춘다(계속 55%, 성과 하위) — 판정 기준을 느슨하게 할 이유가 없다.
4. 엘리엇 삼각형은 짧은 시간대에 많다 → **1h degree**, 깨끗한 자료(SOL).
