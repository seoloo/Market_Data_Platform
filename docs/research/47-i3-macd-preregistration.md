## 1. 질문

사용자가 요청한 지표들 가운데 46 에서 **이미 판정한 신호와 다른 정보를 주면서 숏 꼬리가 한정된 것은 I3 하나뿐**이었다.
T 방향과의 상관은 0.09, 숏 구간 최대 역행이 +50% 이상인 경우는 0번이었다.

**MACD 히스토그램으로 방향을 정하면, BTC·ETH 선물 롱숏이 비용·funding 을 내고도 돈을 버는가? 그리고 숏 다리도 돈을 버는가?**

사전 기대는 낮다. 판정하려면 연 샤프가 1.1 안팎이어야 한다. 빠른 방향 신호들(H1·V·F1b)은 모두 비용을 넘지 못했다.
기각될 가능성이 크고, 기각도 유효한 결과다.

## 2. 규칙 (고정)

**방향 규칙 하나만 45 F1b 와 다르다.** 나머지 자료·체결·비용·스톱·청산·정지·mark 결측 대체는 45 §2 와 같다.
같은 시뮬레이터를 쓴다. 이 변경 뒤 F1b 설정으로 다시 돌려 45 판정의 최종 자본 12,008.67 과 모든 기준값이 같음을 확인했다.

| 항목 | 값 |
|---|---|
| 자산 | BTCUSDT · ETHUSDT **USD-M 무기한**. 신호는 Binance **현물** 일봉 종가(2017-08~) |
| 방향 | MACD 선 = EMA12 − EMA26, 시그널 = MACD 선의 EMA9. **MACD 선 > 시그널이면 롱, 작으면 숏** (같으면 0) |
| 워밍업 | 현물 종가 113 개 이상(4 × 26 + 9). 판정 구간 시작 때 이력은 약 900 일이라 영향이 없다 |
| 크기 | 방향 × min(15% / 현물 60 일 연변동성, 0.5). 두 종목 합 \|비중\| ≤ 1 → **1x** |
| 체결 | 종가 d 판정 → **종가 d+1** 무기한 종가. \|목표 − 현재\| < 5%p 이고 방향이 같으면 건너뛴다 |
| 손익·funding | 무기한 종가 기준. 롱은 양수 funding 을 내고 숏은 받는다 |
| 비용 | **편도 0.095%** (판정 기준). 참고 줄 0.023% |
| 비상 스톱 | 롱: 최종 체결가 저가 ≤ 전날 종가 × 0.8 · 숏: 최종 체결가 고가 ≥ 전날 종가 × 1.2 → 스톱가보다 1% 불리하게 체결 + 비용. 그날 그 종목은 다시 들지 않는다 |
| 청산 | 봉 안 최악 자본(**mark price** 고·저)이 유지증거금 0.5% 이하 → 전액 손실 |
| 계좌 정지 | 봉 안 최악 자본(mark)이 종가 기준 고점의 70% 이하 → 전부 닫고 이후 거래 없음 |
| 현금 | 이자 0 |

**F1b 와 다른 점 하나 더:** F1b 의 방향은 {±1/3, ±1} 이라 신호가 엇갈리면 1/3 만 들었다.
I3 의 방향은 늘 ±1 이라 **항상 크기 상한까지** 든다. 평균 노출이 F1b 보다 크다.

## 3. 판정: 2020-03-01 ~ 2026-08-31, 1회. 전부 통과해야 PASS (45 §3 과 같은 기준)

| # | 기준 |
|---|---|
| M1 | 전체 일간 순수익 평균 − 2SE > 0 |
| M2 | 2020-03 ~ 2022-12, 2023-01 ~ 2026-08 **각각** 일간 순수익 평균 > 0 |
| M3 | **숏 다리 순손익**(가격 + funding − 숏 비용 몫) > 0 |
| 안전 | 청산 0 · 계좌 정지 0 |

판정 코드는 45 의 `judge` 를 그대로 쓰므로 판정 파일에는 M1~M3 이 `F1`~`F3` 이름으로 적힌다.

**실패 시:**
- 기각한다.
- 기간(예: 8·17·9), 봉 길이(4h 등), 스톱, 크기, 밴드를 바꿔 같은 자료로 다시 판정하지 않는다.
- 46 에서 뺀 지표(I1·I5·I6)를 대신 시험하지 않는다.

**PASS 여도** 뜻은 "과거 한 구간에서 MACD 히스토그램 롱숏이 0 보다 나았다"까지다. 레버리지·실거래는 별도 등록과 승인이 필요하다.

## 4. 보고 (판정 아님): 최악의 경우 먼저

45 §4 와 같다.
1. 최악의 경우: 봉 안 최악 낙폭(mark·최종 체결가), 최악의 하루·30일, MDD 구간, 비상 스톱 발동.
2. 성과: 샤프·CAGR, 롱/숏 × 가격/funding/비용 분해, 회전율, 거래 수.
3. 참고 줄: 비용 0.023%, 스톱을 mark 로 발동, 청산을 최종 체결가로 판정.
4. T/v2 와의 관계: 일간 수익 상관, T/v2·I3 반반.

**F1b 와도 나란히 적는다.** 그래야 방향 규칙만 바꾼 효과가 보인다.

## 5. 검정력·노출

- 6.5 년이면 최소 검출 연 샤프는 **1.11**(검정력 80%)이다. M1(평균 − 2SE > 0)은 관측 샤프 약 0.78 이상과 같다.
- 46 에서 6개 후보 중 하나를 골랐다. 고른 근거는 수익이 아니라 **기존 신호와의 중복·꼬리·비용**이다.
  그래도 후보 6개 가운데 하나를 보고 고른 선택이라 엄밀히는 다중 비교다. 6개를 모두 시험했다면 Holm 기준으로 샤프 1.27 이 필요했다.
  이 한계를 판정 보고에 함께 적는다.
- 46 의 숏 구간 **최대 역행**(+30% 이상 3번, +50% 이상 0번)은 숏 손익을 일부 짐작하게 한다. 이 값은 I2 를 빼는 데 썼다.
- 이 구간의 가격과 T·F1b·O 결과는 이미 봤다. 표본 밖 검증이 아니다.
- 12·26·9 는 MACD 의 표준값이다. 결과를 보고 고르지 않았다(46 §1).
