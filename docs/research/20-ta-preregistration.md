[R1](../archive/research/26-r1-preregistration.md)(심볼 간 **상대** 추세)과 달리 각 종목의 **절대** 추세다.

## 3. 규칙 (고정, `backtest/multi_trend.py` 기본값)

| 항목 | 값 |
|---|---|
| 방향 | 종목별 `(sign(r20)+sign(r60)+sign(r120))/3` (선물 일봉 종가) |
| 크기 | 방향 × min(**1.5%** / 60일 연변동성, 0.5). 1.5% = 총 위험 예산 30% ÷ 20 (T/v1의 15% × 2종목과 같은 총 예산) |
| 총 명목 상한 | 자본의 **2배** (레버리지 1~10x 범위 안). 넘으면 비례 축소 |
| 체결 | 종가 d 목표 → 종가 d+1 체결(1일 지연). 종목별 |Δ비중| < **0.5%p** 이고 방향 같으면 거래 안 함 |
| 유니버스 이탈 | 체결일이 속한 달 유니버스에 없으면 목표 0 |
| 이력 부족 | 연속 121일 일봉이 없으면 목표 0 (신규 상장·결측) |
| 비용 (편도) | BTC·ETH 0.095%(0.045% + 슬리피지 0.05%), 그 밖 **0.145%**(슬리피지 0.10%) |
| funding | 보유 중 정산마다 롱 지급·숏 수취, 가격은 그날 종가 근사 |
| 상장폐지 | 보유 종목 일봉이 없으면 마지막 종가에 **1%** 벌점으로 강제 정리 |
| 청산 | 교차 증거금. 그날 모든 보유가 동시에 최악 가격(롱 저가·숏 고가)이면 자본 ≤ 명목 × 1% → 전부 청산 |
| 현금 | 이자 0 |
