## 1. 가설

BTC·ETH 가격 추세는 수 주~수 개월 지속된다(시계열 모멘텀). 과거 20·60·120일 수익률의 방향을 따라
롱(현물)·숏(선물 1x)을 들면 비용·funding 후에도 일간 순수익 평균이 0보다 크다.
[R1](../archive/research/26-r1-preregistration.md)(심볼 간 **상대** 추세 롱숏)과 달리 각 자산의 **절대** 추세다.
[C](01-candidate-comparison.md)(BTC 14일 추세)는 거래 단위 표본 부족으로 탈락했다. T는 기간 전체를 표본으로 쓴다.

## 2. 규칙 (전부 고정, `backtest/trend.py` 기본값)

| 항목 | 값 |
|---|---|
| 자산 | Binance 현물 **BTCUSDT·ETHUSDT** 일봉 종가 (00:00 UTC 기준) |
| 방향 | `(sign(r20) + sign(r60) + sign(r120)) / 3` ∈ {−1, −1/3, +1/3, +1}. `rL` = L일 전 종가 대비 수익률 |
| 크기 | 방향 × min(**15%** / 60일 실현 연변동성, **0.5**). 두 자산 합 |비중| ≤ 1 → 레버리지 없음 |
| 체결 | 종가 `d`에 정한 목표를 **종가 `d+1`**에 체결 (1일 지연). |목표 − 현재| < **5%p**이고 방향이 같으면 거래하지 않음 |
| 롱 | **현물 보유**. funding 없음. 비용 편도 0.15% (수수료 0.10% + 슬리피지 0.05%) |
| 숏 | **선물 1x** (증거금 = 명목). 비용 편도 0.095% (0.045% + 0.05%). 보유 중 정산된 funding 반영(양수면 수취), 가격은 그날 종가로 근사 |
| funding 자료 없는 기간 | BTC 2020-01, ETH 2020-03 이전(선물 자료 전)은 **0** — 이 기간 숏은 현물 가격 기반 가상 숏 |
| 청산 | 숏은 일봉 고가 기준 증거금 + 미실현 ≤ 0.4% 명목이면 청산 (1x ≈ 기준가 2배) |
| 현금 | 이자 0 |

## 3. 구간과 표본

- **판정 구간: 2018-01-01 ~ 2026-08-31 (3,165일, 8.67년)** — 신호에 2017-08-17부터의 이력을 쓴다.
- 독립 검증 구간은 없다(14 §3). 대신 전향 관찰을 병행한다(§6).
- 검정력: 증명 가능한 최소 연 샤프 ≈ 2.84/√8.67 = **0.96** (검정력 80%).

## 4. 판정 — 전부 통과해야 PASS

| # | 기준 |
|---|---|
| T1 | 전체 일간 순수익 평균 − 2SE > 0 (관측 연 샤프 > 약 0.68과 같다) |
| T2 | 앞 절반 2018~2021, 뒤 절반 2022~2026-08 **각각** 일간 순수익 평균 > 0 |
| 안전 | 숏 청산 0건 |

보고만 (판정 아님): 연 샤프·CAGR·MDD·변동성, 롱/숏 손익 분해, funding, 비용, 회전율,
**롱 전용 변형**(숏 신호 → 현금), **BTC·ETH 50/50 단순 보유**.
실거래 위험 규칙(누적 DD 10% 정지)과의 부합 여부는 MDD로 따로 보고한다.

실패 시 기각. lookback·변동성 목표·밴드·자산을 바꾸지 않는다. T2를 만들지 않는다.

## 5. 노출

- 2017~2018·2021 큰 추세는 공공연한 사실이다 → 규칙은 표준형으로 고정하고 튜닝하지 않았다.
- 2020~2026 가격은 H1·A1·WA·C·R1에서 부분 노출. 2017-08~2019 현물은 이번에 처음 적재.
- 이 규칙의 수익·샤프는 계산하지 않았다.

증명이 아니라 "크게 무너지지 않는지" 확인용이다. PASS 여부와 무관하게 실거래 전 필수다.
