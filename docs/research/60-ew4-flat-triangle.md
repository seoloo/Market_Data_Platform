## 1. 왜 — 지금 판독기의 빈칸

EW-3e(58)는 **충격파·지그재그만** 만든다(ELLIOTT_WAVE_ANALYSIS §9 에서 플랫·삼각형을 뒤로 미뤘다). 그래서 횡보장에서 후보가 거의 없다 —
2026-09 BTC 80~87K 횡보에서 최근 꼭짓점마다 해석 0~2 개(56 데모 스캔). 미지원 모양은 "목록 밖(other_or_unknown)"으로만 남는다.

**구조적 이유:** 파서는 "시작이 극값으로 남고 끝이 새 극값"인 구간만 파동으로 본다. 확장 플랫은 B 가 A 시작을 넘고,
삼각수렴은 끝(E)이 극값이 아니다(극값은 A 끝). 그래서 두 단계로 나눈다.

- **1단계(이 문서):** 플랫·수렴 삼각형을 **독립 시나리오**로 인식 — "지금 삼각형 E 종료 후보", "플랫 C 종료 후보".
- **2단계(다음 문서):** 충격파 4파·지그재그 B파 **안의** 플랫·삼각형 — 극값 가정을 바꾸는 더 큰 공사.

## 3. 1단계 규칙 (고정)

방향 d = 첫 다리(A)의 방향, q = d × 가격. 경계 꼭짓점은 교대하고, 각 다리는 자기 구간에서 시작 극단이다(EW-3d′ 의 relaxed 다리 규칙).

### 3.1 플랫 (A-B-C, 3-3-5)

| # | 절대 규칙 |
|---|---|
| F1 | B/A ≥ **0.618** (NEoWave 최소 — 이보다 얕으면 플랫이 아니다) |
| F2 | B/A ≤ **1.618** (그 이상은 다른 구조로 본다 — 1단계 상한) |
| F3 | C/A ≥ **0.382** (C 미달형 허용) · C/A ≤ **2.618** |
| 다리 | A·B 는 조정 3파(지그재그로 읽히면 검증, 아니면 미검증), C 는 충격파 |

지그재그와 같은 경계에서 둘 다 후보가 될 수 있다(A 가 5 인지 3 인지 — 여러 시나리오로 둔다).

### 3.2 수렴 삼각형 (A-B-C-D-E, 3-3-3-3-3)

| # | 절대 규칙 (수렴형) |
|---|---|
| T1 | B 는 A 시작을 넘지 않는다 · C 는 A 끝을 넘지 않는다 · D 는 B 끝을 넘지 않는다 · E 는 C 끝을 넘지 않는다 (두 경계선이 좁아진다) |
| 다리 | 다섯 다리 모두 조정 3파(지그재그로 읽히면 검증) |

확산 삼각형·러닝 삼각형은 1단계 범위 밖.

### 3.3 순위 (ranking v2 — v1 은 동결 그대로)

`ranking.py`(동결 `2dccbb0f…`)는 바꾸지 않는다. 새 모듈 `ranking_v2.py` 가 **충격파·지그재그는 v1 과 같은 값**을 내고 새 패턴만 더한다:

| 패턴 | 검증 다리 요구 | 가이드라인 목표 (로그 비율 거리) |
|---|---|---|
| 플랫 | (지그재그, 지그재그, 충격파) | B/A = 1.0 · C/A = 1.0 (정규 플랫) |
| 삼각형 | 지그재그 × 5 | B/A · C/B · D/C · E/D = 0.618 |

## 4. 내보내는 근거 (FourLeaf 반영, 판정에 쓰지 않음)

- 플랫 하위 유형: B/A < 0.81 **B 미달** · 0.81~1.0 보통 · 1.0~1.382 불규칙(확장) · > 1.382 러닝 / C/B < 1.0 **C 미달** · 1.0~1.382 보통 · > 1.382 연장.
  B 미달 + C 미달 = **이중 미달형**. (81%·100% 는 FourLeaf 글, 1.382 경계는 NEoWave 일반 문헌 — 근거 라벨일 뿐)
- 삼각형 스러스트 목표: E 끝 ± A 다리 폭(가장 넓은 폭), 방향은 삼각형 이전 추세(= A 의 반대).
- 패턴 뒤 함의(가설): 이중 미달형 뒤 100% 되돌림, 5파 연장 뒤 0.618 이상 되돌림 — **검증 전 가설**로만 적는다.
