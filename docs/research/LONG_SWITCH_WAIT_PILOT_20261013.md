# 확정 롱 복귀: 추가 대기 0분 vs 60분 — 설명용 후향 파일럿

작성: 2026-10-13 Codex. 상태 **EXPLANATORY_CONTRACT / UNVERIFIED / NOT_ACTIVATED**.
기존 운영 Phase 6는 유지한다. 관련 [독립 계획](SHORT_LONG_INDEPENDENT_PLAN_20261013.md),

## 1. 사용자 선택·예외·연구 질문

사용자는 예정 롱을 예측해 숏을 미리 보류하는 B 대신, **확정·유효 롱이 오면 현재 숏부터
청산하고 롱으로 복귀**하는 A를 선택했다. 추가 대기 0분과 기존 60분 중 어느 쪽이 이득인지
비교를 요청했고, 이번 대기시간 비교의 설명용 후향 계산을 명시 허용했다.
80% 검정력 선행 게이트 예외는 아래 고정 비교에만 적용한다. PASS·새 OOS·Paper/Live
승인·운영 위험 완화가 아니다. 결과 후 대기시간/신호/한도/비용 재튜닝은 하지 않는다.

0분은 **숏 전량 청산 확인 후 추가로 기다리는 시간을 0으로** 한다는 뜻이다.
청산 주문 전송과 확인·부분체결·UNKNOWN 대조를 생략하거나 롱/숏을 동시에 여는 뜻이 아니다.
60분은 마지막 잔량의 청산 확인 시각부터 잰다. 비교하는 롱은 기존 T/v2의 **현물**이며,
새 선물 롱·레버리지·지표 예측을 추가하지 않는다.

가설: 추가 60분의 현금 대기는 반등 초반 상승을 놓칠 수 있지만, 재하락을 피하거나
더 싼 매수 기회를 줄 수도 있다. 같은 청산·롱 신호·수량·가격 한도로 순차 비교한다.

## 2. 측정 단위와 범위 — 전체 계좌 재시험이 아님

원래 RSI_PRIORITY와 KELTNER_PRIORITY 기본 ALL에서 감사한 복귀 **9건을 모두** 사용한다.
두 규칙의 시각은 같고 숏 수량은 다를 수 있다. 같은 자료를 두 번 독립 표본으로 세지 않는다.
2024-07-02 BTC/ETH 동시 사건 및 겹치는 롱 보유 구간은 묶어 독립성 한계를 보고한다.
8건은 일반 우선 청산, 1건(2022-10-24 ETH)은 기존 봉내 stop 후 복귀다. 후자를 숨기지 않는다.

이번은 **기존 포지션·목표 조건에 고정한 쌍체 실행 사건 연구**다. 대기시간 변경에 따른
이후 숏 진입·공동현금·복리·다른 종목 위험 상태는 재생하지 않는다. 기존 60계좌·신호·결과는
다시 계산하거나 덮어쓰지 않는다. 따라서 사건 손익 합계를 기존 계좌 수익에 더하지 않는다.
사건마다 기준 자본 10,000 USDT, 최초 유효 T/v2 비중 × 기준 자본을 직전 마감 현물
분봉 종가로 나눈 **동일 고정 희망 수량**을 두 군에 준다(현물 step 0.000001, 내림).
실제 채택 가능한 동적 공동계좌 사이징 검증이 아니며 위험 게이트 통과로 부르지 않는다.

## 3. 신호·보유·경계

- 기존 일봉 목표와 d−2 마감자료 → d일 00:00 UTC 적용의 1일 지연을 그대로 사용한다.
- 새로운 1분봉 신호/예정 목표 선행 거래 없음. 분봉은 주문 실행·사후 장부에만 사용한다.
- 매수 전 현재 유효 목표가 0이 되면 잔여 매수 취소. 양수 비중의 일별 크기 변화에 맞춰
  재조정하지 않고 최초 희망 수량만 비교한다. 이는 원래 T/v2 전체 재현과 다른 좁은 계약이다.
- 롱 종료는 **원래 유효 목표가 처음 0이 되는 시각**이다. 미래 종료를 진입 입력에 쓰지 않는다.
- 24h/48h 시점 순평가손익도 보조 진단으로 모두 보고한다. 좋은 horizon을 선택하지 않는다.
- 청산 시도는 최대 240분. 확인 지연 뒤 롱 매수 시도는 각 적격 시각부터 최대 240분.
  롱 목표 소멸 뒤 매도는 최대 24h 시도하며 미청산 잔여는 마지막 종가로 따로 평가한다.
  잔여를 전량 체결·완료로 기록하지 않는다. 자료 상한은 2026-09-01 00:00 UTC 미만.

## 4. 분봉 실행·가격·잔량·확인

현물/선물은 각자 공식 공개 로컬 1m ZIP을 사용한다. 2025년 이후 현물 timestamp의
microseconds는 milliseconds로 명시 변환한다. 읽는 월/행을 사건별 범위로 제한한다.
갭/중복/비정상 OHLCV/음수 거래량이면 중단하고 누락을 결과와 분리한다.
실제 호가·queue·ACK·필터 이력은 없으므로 **체결 대리 모형**이다.

- 일반 주문은 가격 한도 지정가만. 당분 시가에 불리한 슬리피지를 더한 가격이 최초
  의도 시각 직전 마감 분봉 종가의 ±0.3% 한도 안에 있을 때만 체결 대리를 허용한다.
  가격 touch/당분 저가·고가만으로 전량 체결을 가정하지 않는다. 한도 밖이면 미체결.
- 숏 청산의 최초 가격 한도는 롱 신호 시각에 고정. 두 군이 **동일한 청산 경로**를 공유한다.
- 롱 최초 매수 가격 한도도 롱 신호 시각의 현물 기준으로 동일 고정한다. 60분 뒤 한도를
  다시 높이지 않는다. 장점/단점은 이 추격 제한에 조건부라는 것을 보고한다.
- 매도 한도는 롱 목표가 0이 되는 시각의 직전 현물 분봉 종가로 고정한다.
- 체결량 ≤ 직전 마감 1분 거래량 × 0.1%, step으로 내림. 당분 전체 거래량을 사전에 쓰지 않는다.
- 첫/완전 체결·부분체결·미체결·최종 잔량을 분리한다. 숏 잔량 > 0이면 롱 체결량은 항상 0.
- 청산 체결은 분봉 시가의 실행 대리다. 전량 체결 이후 기본 확인 지연 1분을 둔다.
  확인 뒤 0분/60분 대기를 별도로 적용한다. 실제 원격 확인의 역사적 증거는 없다.
- 기존 stop 후 복귀 1건은 신호 시각에 flat 관측, 기본 확인 1분의 조건부 가정을 둔다.
  마지막 stop 체결 시각이 불명인 점은 추가 4시간 확인 지연 민감도로 따로 드러낸다.
- 일반 청산 중 숏의 기존 3% stop을 선물 last 분봉 고가가 건드리면 비상 stop 대리를
  우선한다. gap은 더 나쁜 시가, 기본 불리폭 0.2% 추가. 실제 MARK_PRICE stop과 다르며
  전량 비상 정리 대리는 기존 예외이지 일반 가격한도를 우회하는 새 주문이 아니다.

## 5. 비용·funding·회계

기존 고정 비용: 현물 편도 fee 0.10% + slippage 0.05%, 선물 0.05% + 0.045%.
슬리피지는 체결 가격에 포함하고 손익에서 중복 차감하지 않는다. 추가 주문 조각마다 fee를 낸다.
실제 funding rate와 확보한 정산 mark를 사용하며 mark 결측은 기존 시간봉 시가 대리를
그대로 명시한다. 숏의 양수 funding은 수취, 음수는 지급. 현물 롱에는 funding을 붙이지 않는다.
신호 정확한 경계의 funding은 기존 보유 숏에 귀속하고 청산 뒤에는 붙이지 않는다.
기존 stop 후 이미 flat인 사건은 신호 이후 숏 비용/funding 0이다.

숏은 신호 직전 분봉 종가 대비 **신호 이후 청산 손익**만 계산한다. 과거 숏 진입 손익/비용은
원래 원장에 있으므로 새 사건 장부에 복제하지 않는다. 두 대기 군의 공통 숏 손익·비용을
따로 보여주고 쌍체 차이에서 정확히 상쇄되는지 검사한다.
현금 + 현물 평가 + 숏 미실현으로 매분 equity를 계산한다. 수작업 잔차 검산 필수.

고정 민감도는 BASE, COST2(fee/slip/비상 불리폭 2배), THIN(참여율 0.025%),
ACK5(확인 5분), STOP_LATE(이미 stop된 1건만 확인 4h 추가) 다섯 가지.
모든 9건 × 두 기존 규칙 × 두 대기 군 × 다섯 민감도 = **180 사건 장부**, 한 번 계산한다.
민감도는 최적 조합을 고르는 용도가 아니다.

## 6. 판정·보고·검정력

주 비교는 0분 − 60분의 비용 후 최종 손익 차이. 규칙별·코인별·연도별·사건별,
24h/48h 차이·누락/취소·첫/완전 매수지연·매수 가격·수량·비용·funding·노출·최악 낙폭을 보고한다.
쌍체 차이를 entry 가격, 체결량 차이, 비용, 잔여 평가로 분해한다.
불연속 사건 장부에 전체 기간 CAGR·연환산 Sharpe를 만들어 붙이지 않는다.
평균 노출/MDD는 사건 내부 기준자본 비율이지 공동계좌 위험 개선이 아니다.

BASE의 차이가 양수면 ‘고정 사건 파일럿에서 0분 유리’, 음수면 ‘60분 유리’,
0/자료 실패면 ‘동일/판단 불가’. 민감도 부호·종목/연도 편중을 별도 밝혀 강건성 여부를 설명한다.
어떤 경우도 PASS를 부여하거나 운영 대기 예외를 적용하지 않는다.
표본은 9회/중복 규칙/겹치는 보유이므로 독립 80% 검정력은 인증할 수 없다.
결과 SD를 향후 계획에 쓰더라도 **후향 조건부 사건 SD**라고 표시하며 기존 월별 SD와 섞지 않는다.
