# 281 — Deneb 거시 위험 확률·방어·복귀 설명용 후향 파일럿

2026-10-18 Codex · **성과 전 고정** · 사용자 한정 검정력 예외 승인.
[G0 감사](281-deneb-macro-risk-g0.md)의 학습18개월·하락정답2·80% 미확인 한계를 유지한다.

## 1. 가설·자료 경계

경기·고용·신용의 추가 정보가 가격 기반 방어보다 유용한 경고를 주는지(A 예측),
그 경고로 TQQQ를 절반 줄이고 복귀한 계좌가 Deneb보다 나은지(B 회계)를 분리한다.
Sirius 종목 순위와 다르며 166·204·251 기각/불명은 바꾸지 않는다.

- 가격·정답 끝 ≤2026-08-31. 2026-09 이후 값·208·운영 장부를 읽지 않는다.
- ALFRED 최초 발표 ZIP은 G0 SHA 고정. 일간/주간/월간 공개 지연 한도 7/14/62일.
- INDPRO/PCEPILFE 성장률은 **같은 과거 판본의 지수**로 계산한다.
  월말 결정일보다 최소 2개 미국 거래일 앞선 마지막 판본을 사용한다.
  최초 발표 지수 여러 개를 이어 붙인 성장률은 사용하지 않는다.
- 관측 기간과 공개 시점 분리. 값이 오래되면 결측: 일간20일·주간21일·월간95일.
  전처리의 학습 중앙값 대체/결측 표시는 허용하되 원자료 가용 여부를 별도로 보고한다.
- 원문·요청·SHA·시각을 연구 전용 경로에 보존하고 외부 주문/계좌/LLM 호출 없음.

## 2. 특징·정답·시간 분할

매월 미국 마지막 거래일 마감 결정. 사용 정보는 그보다 2거래일 앞까지.

| 묶음 | 고정 파생변수 |
|---|---|
| T10Y3M | 마지막 공개 수준, 그 3개월 전 공개 수준과의 차(%p) |
| BAA10Y | 마지막 공개 수준, 같은 3개월 변화(%p) |
| UNRATE | 최근3개월 평균 − 직전12개 3개월 평균의 최저(%p) |
| ICSA | 최근4주 평균 / 최근52주 평균 −1 |
| INDPRO | 같은 판본의 최근월 / 3개월 전 −1 |
| PCEPILFE | 같은 판본의 (최근월 / 3개월 전)^4 −1 |
| FEDFUNDS | 마지막 공개 수준, 3개월 변화(%p) |

총 거시10개 + 가격 통제3개(나스닥100 RV20·252일 고점 대비·20/60/120 수익 부호 평균).
가격 통제도 결정일 2거래일 전까지만. 가격-only는 기여 비교용 ablation이다.
정답 = 결정일 종가 대비 다음126거래일 최저 종가 ≤85%면1, 아니면0.
기간 중 미래 고점 기준 낙폭으로 바꾸지 않는다.

- 고정 준비 시작2015-01. 2017~2019 VALIDATION 보고, 2020~2026-08 역사확인(정답은2026-02까지).
- 해마다 첫 결정 전에 expanding 재학습, **정답 마지막 거래일이 학습 시점보다 엄격히 이전**인 월만.
  첫2017 학습은2016년말까지 완전히 알 수 있던 정답만 쓴다. 이후에도 같은 규칙.
- 연도별 시간순 결과를 모두 보존. 가격 통제/거시 feature selection 탐색 없음.
- 전처리: 각 학습 열의1/99백분위 clip → 학습 중앙값 대체 + 결측 표시 → 학습평균/SD 표준화.
  전 열 결측이면 해당 열 대체0·표시1, 상수열 SD1. oversampling 없음.

## 3. 모델·예산·예측 평가

- CONST: (학습 양성수+1)/(학습행수+2).
- **LR(주 판정)**: LogisticRegression(C=0.1, max_iter=2000, class_weight=None, random_state=281).
- 작은 GBM(예측 보고만): HistGradientBoostingClassifier(max_iter=50, max_depth=2,
  learning_rate=0.05, min_samples_leaf=10, l2_regularization=10, early_stopping=False, random_state=281).
- 가격-only LR은 같은 C/전처리의 사전 고정 기여 제거 진단. 계좌/모델 선택에 쓰지 않는다.
- 자료가 같은 클래스뿐이면 상수 모형으로 명시하고 LR 학습인 척하지 않는다.
- 독립 연구 환경 build/tcn-venv, CPU 4스레드, 하이퍼 탐색0, 학습 예산15분.
- 예측: Brier/log-loss/ROC-AUC/PR-AUC·보정표, 경고 precision/recall·오경보, 기존 방어와 중복.
  양성이 없으면 해당 AUC는 미측정. 검증/역사확인/연도별 보고. 독립성/검정력 주장 없음.

## 4. 단일 위험 배율과 복귀 상태

LR의 확률만 계좌에 사용한다. 연도별 학습 기저율 b=(양성수+1)/(행수+2).

- 진입: 월말 p≥2b면 위험, 다음 거래일 종가부터 TQQQ 몫0.5.
- 해제: 월말 p≤b면 다음 거래일 종가부터1.0.
- **가격 복귀 우선**: 위험 뒤 QQQ 추세(20/60/120 수익 부호 합>0)가 꺼졌다 켜지면1.0.
  거시지표가 나쁘다고 무한 대기하지 않는다. 동일 위험 사건의 재경고는 p≤b를 먼저 봐야 허용.
- 예측을 만들 수 없거나 거시 변수 중3개 이상 결측이면 신규 위험을 늘리지 않고0.5.
- 기존 T브레이크/추세 복귀가 먼저이고 거시 신호가 이를 무시해 위험을 늘리지 않는다.
  T브레이크 중 해제되는 거시 보관금은 T 보관금으로 옮겨 기존 복귀를 기다린다.
- 거시 축소분은 별도 달러 현금, 이자0. SCHD에 옮기지 않는다.
- 최초 기저율로 B 상시 배율=1−0.5×b를 고정한다(후향 노출 맞추기 금지).
  정확한 평균 노출 일치 대조는 아니며 그 차이를 함께 보고한다.

## 5. 계좌·비용·회계

A 원래 Deneb / B 상시 축소 / C LR 경고·복귀, 계좌별 독립 상태.
2017-01~2019-12와2020-01~2026-08을 따로 초기화, 매월 첫 거래일 **10만원**, 초기일시금0.
납입액은 같게 하고, 적립 원금이 수익으로 계산되지 않게 단위 NAV/IRR을 구분한다.

- 원형은184의 T·달러 보관 연구 회계다. QQQ RV20에 따라 TQQQ 최대60%×min(1,20%/RV),
  TQQQ 고점−15%절반·−30%전부, 추세 꺼짐→켜짐 재매수, 매월 맞춤을 보존한다.
- 분리된 새 연구 엔진으로 확장하고 A를184와 골든 검산한다. 운영 실행기/280은 수정하지 않는다.
- 모든 계좌 같은 소수점 수량·고정 환율의 연구 모형. **실거래1주 단위/LOC 체결 인증이 아니다.**
- 전날까지 신호 → 당일 종가 가격에 연구상 체결, 편도0.15%(수수료+미끄러짐).
  같은 날 낙관적 stop 체결이 아니라 이미 마감한 전날 조건만 사용한다.
  별도 고정 민감도: 편도0.30%, 추가1거래일 거시 실행 지연. 본 판정 뒤 재튜닝 금지.
- 세금184와 같은 이동평균 원가·연250만원 공제·22%·다음해6월 납부·말년 최종정산.
  실제 환율/다른 전략 손익/배당 지급일·원천세의 완전 재현은 아니며 비교 공통 근사로 명시한다.
- 수정주가의 배당 재투자 근사, 실제 배당 지급 현금/15% 원천징수 별도 검증 미완료.
  실제SCHD/QQQ/TQQQ의 같은 유한 가격 자료만 사용(합성 장기 역사 아님).
- 전역 HALT를 해제하는 연구가 아니다. 184형 규칙 계좌의 후향 회계이며,
  운영 HALT·거래소 보호·실행 안전성·30% 누적정지 parity는 미인증으로 분리한다.
- 금액/수량 원장은 Decimal, 모델/지표는 float. 매도·재매수/거시보관금·브레이크 보관금·세금·수수료 검산.

## 6. 판정·필수 보고

이번에는 PASS를 부여하지 않는다. 역사확인 C−A 세후 최종금액>0, C−B>0,
비용2배/지연에서도C−A>0, 낙폭≤A를 모두 만족하면 **후향 파일럿에서 유리**.
기본 C−A≤0이면 **불리**. 그 밖 **판단 불가**. 검증구간 반대 방향이면 그 사실도 강조한다.
모델 변경/배율 변경/기저율 배수 변경/자산·horizon 변경으로 재판정하지 않는다.

- A/B/C 세후 금액·순이익·IRR, NAV CAGR/Sharpe/MDD, 평균/최대 TQQQ노출·현금·회전·매매 수·비용·세금.
- 예측과 매매를 분리하고 LR/GBM/가격-only와CONST 비교를 모두 공개한다.
- C−A의 가격 손익(주식별)·비용·납세·최종청산세금 차이를 회계 항등식으로 검산한다.
  줄인 보유로 피한 하락/놓친 상승은 가격 기여의 설명이며 정확한 전체 증분과 구분한다.
- 경고/가격복귀/거시해제/결측방어 횟수·월별/연도별·기존 브레이크 중복·반등 포기 비용.
- 최초 연구 전체 결과를 보존하며 예외는이번281에만 적용한다. 운영/주문/예약 변경 없음.
