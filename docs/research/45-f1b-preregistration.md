## 1. 질문

T/v1 의 숏(20·60·120 일)은 9 년 동안 0 근처였다(15 §7). **더 빠른 추세(10·20·40 일)라면 선물 숏이 비용·funding 뒤에도 돈을 버는가,
그리고 롱숏 전체가 0 보다 확실히 나은가?** 사전 기대는 낮다(44 §2) — 기각도 유효한 결과다.

## 2. 규칙 (고정)

| 항목 | 값 |
|---|---|
| 자산 | BTCUSDT · ETHUSDT **USD-M 무기한**. 신호는 Binance **현물** 일봉 종가(T 와 같은 계열, 2017-08~) |
| 방향 | (sign r10 + sign r20 + sign r40) / 3 ∈ {−1, −1/3, +1/3, +1}. 롱·숏 모두 |
| 크기 | 방향 × min(15% / 현물 60 일 연변동성, 0.5). 두 종목 합 \|비중\| ≤ 1 → **1x** |
| 체결 | 종가 d 판정 → **종가 d+1** 무기한 종가에 체결. \|목표 − 현재\| < 5%p 이고 방향이 같으면 건너뛴다 |
| 손익 | 무기한 종가 기준. funding: 롱은 양수 funding 을 내고 숏은 받는다(정산 가격 = 그날 종가 근사) |
| 비용 | **편도 0.095%** (판정 기준, 42 §8). 참고 줄 0.023% |
| 비상 스톱 | 롱: 무기한 **최종 체결가 저가** ≤ 전날 종가 × 0.8 · 숏: **최종 체결가 고가** ≥ 전날 종가 × 1.2 → 스톱가에서 1% 더 불리하게 체결 + 비용. 그날 그 종목은 다시 들지 않는다. (실거래는 mark price 발동으로 걸 수 있다 — 최종 체결가 판정이 더 자주 발동한다, 보수적) |
| 청산 | 봉 안 최악 자본을 **mark price 고·저**로 평가해 유지증거금 0.5% 이하이면 전액 손실 |
| 계좌 정지 | 봉 안 최악 자본(**mark price**, 실제 계좌 평가와 같다)이 종가 기준 고점의 70% 이하면 전부 닫고 이후 거래 없음 |
| mark 결측일 | Binance Vision 아카이브에 없는 날(BTC 9 일 — 2021-07-24~27 포함, ETH 3 일)은 **현물 고·저**로 대체 (mark 는 현물 지수 기반) |
| 현금 | 이자 0 |

**청산·정지를 mark price 로 판정하는 이유:** 무기한 최종 체결가에는 순간 윅이 있다(ETH 2020-03-13 고가 323 = +203%, 같은 날 현물 +30% · mark +29%).
거래소는 청산을 mark price 로 하고 계좌 자본도 mark 로 평가한다. 최종 체결가로 판정하면 실제로 없던 청산·정지가 결과를 지배한다.
**최종 체결가 기준 청산·최악 낙폭도 보고한다(§4).**

## 4. 보고 (판정 아님) — 최악의 경우 먼저

## 5. 검정력·노출

- 6.5 년 → 최소 검출 연 샤프 **1.11**(80%). F1 기준(평균 − 2SE > 0)은 관측 샤프 약 0.78 이상과 같다.
- 이 구간의 가격·T/v1·T/v2·O 결과를 이미 봤다. 2022 하락장·2020-03·2021-05 급락은 공지의 사실이다.
- 10·20·40 은 결과가 아니라 44 의 비용 측정(F1a 연 5.4% vs F1b 3.8%)으로 골랐다. 44 에서 **숏 보유일의 급등 일수**(최종 체결가)는 봤다 — 스톱 발동 빈도를 어느 정도 예상할 수 있다.
- mark price·스톱·정지 규칙은 합성 테스트에서만 확인했고 실제 자료로 돌리지 않았다(§2 점검은 결측만 셌다).

### 6.3 해석

1. **빠른 추세에서도 BTC·ETH 선물 숏은 돈을 잃었다** (−2,188, 참고 비용·mark 스톱 줄에서도 음수). T/v1(느린 추세)의 숏 ≈ 0 과 합치면,
   이 자료(2020~2026)에서 **추세를 따르는 BTC·ETH 숏은 두 속도 모두 수익원이 아니다.** 급반등(2020-03, 2021-07, 2022-11)이 하락 추세의 이익을 되돌린다.
2. **선물 롱은 funding 을 낸다.** 롱 가격 이익의 1/3(−2,371)이 funding 으로 나갔다. T/v2 가 롱을 **현물**로 드는 것이 맞다는 것을 다시 확인했다.
3. 1x 인데도 MDD 31% 로 계좌 정지 기준에 닿았다 — 빠른 추세의 잦은 전환이 2021-09 ~ 2023-05 횡보·하락장에서 손실을 쌓았다.
4. §3 대로 lookback·스톱·크기를 바꿔 다시 판정하지 않는다. F1a 는 계산하지 않는다.

### 6.4 보고 버그 수정 (판정 뒤, 공개)

판정 파일의 `worst_intraday_drawdown`(mark·최종 체결가)은 **1.0** 으로 기록됐다 — 계좌 정지 뒤 날들의 "최악 자본"을 0 으로 계속 센 **보고 계산 버그**다.
정지 뒤에는 세지 않도록 고쳤다(`fast_trend.py`, 테스트 추가). 고친 코드로 같은 설정을 다시 돌려 **최종 자본이 판정 파일과 같음(12,008.67)** 을 확인하고,
최악 낙폭만 바로잡았다(§6.1). 판정 기준·다른 숫자는 바뀌지 않는다.
