## 0. 왜 이 시험인가 · 먼저 적는 것

- 141 판정 뒤 참고 분석(판정 불변): 해마다 크게 오른 5 종목 90 개 중 **가격 순위로 그해 시작 전에 잡힌 것은 18 개(20%)**, 56% 는 이미 오른 뒤에 잡혔다. 한국에서 가격이 강한 종목은 1~3 달 동안 더 강하지 않았다. → **가격 말고 다른 신호로 주도 섹터·주도주를 미리 알아볼 수 있나**가 질문이다.
- 수급(외국인·기관이 사 모으는 종목)은 한국 투자자들이 "주도주·테마" 를 알아보는 가장 흔한 신호다. 이 프로젝트에서 **처음 시험하는 신호**다.
- **본 것과 안 본 것:** 141 의 가격 모멘텀 5 분위 결과는 봤다. **수급과 수익의 관계는 한 번도 계산하지 않았다.** 이 문서의 규칙은 141 의 틀(LT)을 그대로 두고 점수만 수급으로 바꿨다 — 본 결과로 고른 숫자는 없다.
- 약점:
  - 141 과 같은 종목군(거래대금 상위 200)이라, 그 종목군 자체가 18 년 거의 제자리였다(EW 비용 0 연 +0.3%). 비교는 같은 종목군 EW 라 공정하다.
  - 수급 자료는 장 마감 뒤 확정된다 → 신호는 그날 종가 뒤, 실행은 **다음 거래일 종가**(141 과 같음) — 미래를 보지 않는다.
  - 외국인 순매수에는 지수·차익 거래(프로그램)가 섞여 있다. 걸러 내지 않는다.

## 4. 판정 — 141 과 같은 세 기준, 모두 통과해야 PASS

| # | 기준 |
|---|---|
| F1 | 전체 구간 **샤프 FLOW ≥ EW + 0.20** |
| F2 | **두 반쪽 모두** 연수익 FLOW > EW |
| F3 | 최대 낙폭 FLOW ≤ max(EW 낙폭, 40%) |

- **PASS 의 뜻:** 외국인·기관이 사 모으는 섹터·종목을 추세 때 들고 가는 쪽이, 같은 종목군을 고르게 든 것보다 생존 편향 없이 위험 대비 확실히 나았다 → B(143) 의 앞으로 기록에서 확인하고, 그다음 코스닥(새 문서).
- **REJECT:** 수급으로 골라도 고르게 든 것보다 낫지 않았다.
- 숫자(W 20·60, 섹터 3, 종목 10, 추세·−35%, 종목군, 기간)를 바꿔 다시 판정하지 않는다. 외국인만·기관만·개인 반대 같은 변형도 이 문서로 다시 판정하지 않는다(하려면 새 문서).
