# 연구 아이디어 목록 (Codex 관리)

> 역할: [AGENTS §9](../../AGENTS.md) — **아이디어 관리·사전 등록 초안은 Codex**, 자료 점검·코드·확정 커밋·판정·기록은 Claude Code.
> 판정이 난 연구의 결과는 [RESEARCH_HISTORY](../current/RESEARCH_HISTORY.md)가 기준이다. 이 목록은 "다음에 무엇을 시험할까" 만 다룬다.
> 방향 기준점: [DIRECTION_LEADER_TREND](DIRECTION_LEADER_TREND.md). 새 아이디어는 "가설 · 비용 · 판정 기준 · 실패하면 버린다" 로 적는다.

## 쓰는 법

- 상태: `아이디어` → `후보 비교` → `초안`(Codex 사전 등록 초안) → `사용자 선택` → `자료 점검`(Claude) → `확정`(Claude 커밋, 수익 보기 전) → `판정 끝`(RESEARCH_HISTORY 로) · 또는 `보류` · `버림`.
- 같은 자료에서 결과를 본 뒤 숫자만 바꾸는 아이디어는 받지 않는다(데이터 스누핑). 다시 보려면 **새 자료**(다른 시장·자산·기간·앞으로의 기록)이거나 **결과 전에 안 설계 결함**을 고친 판이어야 한다.
- 한 줄에 하나. 출처(사용자 말·영상·논문·다른 연구에서 배운 것)를 적는다.
