## 쓰는 법

- 상태: `아이디어` → `후보 비교` → `초안`(Codex 사전 등록 초안) → `사용자 선택` → `자료 점검`(Claude) → `확정`(Claude 커밋, 수익 보기 전) → `판정 끝`(RESEARCH_HISTORY 로) · 또는 `보류` · `버림`.
- 같은 자료에서 결과를 본 뒤 숫자만 바꾸는 아이디어는 받지 않는다(데이터 스누핑). 다시 보려면 **새 자료**(다른 시장·자산·기간·앞으로의 기록)이거나 **결과 전에 안 설계 결함**을 고친 판이어야 한다.
- 한 줄에 하나. 출처(사용자 말·영상·논문·다른 연구에서 배운 것)를 적는다.

## 17번 상세 후보 — 재고 관리형 시장조성 그리드

작성: 2026-10-06, Codex. **사용자 요청은 상세 아이디어 기록이다. 사전등록 확정·자료 수집 시작·전략 구현·Paper 또는 실거래 활성화 승인이 아니다.** Claude가 진행 중인 다른 연구는 그대로 이어 간다. 아래 규칙은 검토할 구조이며, 숫자와 판정 기준은 미확정이다.

### 연구 질문과 수익원

**매수·매도 지정가로 거래할 가격을 제공하면서 얻는 가격 차이가, 실제 수수료·체결 이후 불리한 가격 변화·재고 정리 손실을 넘는가? 그때 보유 물량을 고려한 주문 조정이 동일한 비용·체결 조건의 고정 주문보다 계좌 결과를 개선하는가?**

가설은 유동성을 제공하는 대가를 얻되, 한쪽 주문만 반복 체결돼 쌓이는 재고의 위험을 제한하는 것이다. 단순히 가격이 평균으로 돌아올 확률이나 상승 방향을 맞히는 가설과 구분한다. 시장조성 모델이 수익을 보장하거나 재고 관리만으로 우위를 만들어 준다고 가정하지 않는다. 즉시 체결하려는 상대 주문이 우리 지정가에 도달할 만큼 있어야 하고, 그 체결이 가격 정보를 가진 상대방에게 불리하게 선택되는 손실보다 유리해야 한다.

쉬운 예: 매수만 반복 체결돼 코인 물량이 목표보다 많아지면, 다음 매수는 작게/멀리 놓고 매도는 더 가까이 놓아 물량을 줄인다. 보유 허용 범위가 찼으면 추가 매수를 막는다. **평균 매수가 아래에서도 정리가 필요할 수 있다.** 손실을 확정하지 않고 기다린 결과를 개선으로 계산하지 않는다.

### 참고 모델과 가져올 원리

- **Avellaneda–Stoikov:** 현재 보유 재고의 위험을 반영해 주문 기준 가격을 조정하고, 체결 가능성을 고려해 매수·매도 가격을 정하는 이론적 출발점이다. 원논문의 가정·단위·시간 지평을 검토해야 하며, 24시간 코인 시장에 식과 기본값을 그대로 복사하지 않는다.
- **Hummingbot Avellaneda / Inventory Skew:** 목표 보유 비중과 현재 물량의 차이로 주문 가격 또는 주문 수량을 조절한다. 보유 범위 밖에서는 한쪽 주문을 중단하는 공개 설명·구현이 있다. 구현 존재는 실계좌 수익 증거가 아니다. 참고 시점 공식 페이지는 Avellaneda V1의 maintainer를 None으로 표시한다.
- **GLFT 다층 주문 예제:** 변동성과 가격대별 주문 도달 빈도를 추정해 호가와 재고 기울기를 정하고, 여러 가격대에 주문을 배치한다. 참고 예제에는 **메이커 수수료 −0.005%(리베이트)**와 며칠의 시험 자료가 포함된다. 그 수익률·연율화 숫자를 우리 기대 수익이나 검정력 효과 가정에 쓰지 않는다.

### 자료와 현실적인 체결 관문

초기 점검은 BTC 하나를 우선 제안한다. Binance 현물 또는 USD-M 중 어느 시장에서 연구할지는 무료 자료·수수료·주문 가능성 점검 뒤 하나를 선택한다. ETH·다종목·헤지는 첫 모델의 자동 확장이 아니다. 예상 평가 주기·갱신 주기·거래 빈도·보유/정리 시간은 아직 미측정이며 원예제의 100ms 주기를 그대로 채택하지 않는다.

필요한 자료는 최우선 호가/수량 또는 호가 깊이, 공격적 체결의 가격·수량·방향·시각, 호가 갱신 순서·결측, 주문 전송·취소·체결 지연, 틱/수량 규격과 실제 적용 수수료다. 선물은 funding·mark·증거금/청산 경로도 필요하다. 공개 자료의 가용 기간과 무료 사용 조건을 먼저 확인한다. 유료 데이터 구매는 하지 않는다. 과거 자료가 부족하면 무료 전향 수집 명세를 제안하되, **이번 기록으로 수집을 시작하지 않는다.**

**기존 1분봉만으로 신뢰할 수 있는 체결 판정을 했다고 주장하지 않는다.** 같은 봉의 고저가가 주문 가격을 지났다는 사실만으로 주문이 도달한 뒤 대기열에서 전량 체결됐음을 알 수 없다. 모델 재생은 대기열·부분 체결·미체결·지연·호가 공백을 포함해야 한다. 모든 주문을 maker로 처리하지 않고, 가격 한도 지정가가 상대 호가를 가져가면 실제 taker 요율을 쓴다. 남은 주문과 재고를 결과 끝에서 비용 없이 없애지 않는다.

### 비용·손익·비교 기준

손익의 기준은 **현금 + 전체 보유 물량 평가액**의 변화이며 외부 입출금·수수료·funding을 별도로 정합시킨다. 왕복을 완료한 칸의 차익과 남은 재고의 손익을 함께 보고한다. 호가 차이·체결 뒤 불리한 움직임(markout)은 원인 분석용 지표다. 이 분석 지표들을 계좌 손익에 다시 빼서 재고 손실을 이중 계산하지 않는다. 평가에는 중간가와 현실적인 지정가 정리 가능성을 구분하고 미체결 위험을 남긴다.

성과 열람 전에 고정할 비교 대상은 다음을 제안한다.

1. 같은 주문 크기·빈도·비용·체결 모델·재고 한도로 운영하는 **고정 대칭 주문 기준선**: 재고/변동성에 따른 조정이 무엇을 더하는지 확인.
2. 같은 초기 자본의 **코인·현금 보유 또는 고정 비중 재조정 기준선**: 코인을 들고 있어서 번 수익과 매매의 추가 효과 구분. 하나의 기준선을 확정 전에 선택.
3. 기존 운영 전략 T/v2 등과의 비교는 별도 참고이며 기존 규칙·원장을 수정하지 않음. 짧은 시장조성 자료를 장기간 T/v2 결과와 바로 비교하지 않음.

실제 적용 수수료에서 판단하고 비용 2배, 더 느린 주문/취소, 더 보수적인 대기열 체결 가정에서도 결론을 확인한다. 예제의 리베이트·VIP 혜택·무료 이벤트를 우리 계좌의 비용으로 가정하지 않는다. 주문을 안 낸 시간을 빼거나 거래가 잘 된 시간만 사후 선택하지 않는다.

### 표본·검정력과 판정 전 순서

현재 **자료 가용 기간·체결률·독립 n·SD·최소 검출 효과·필요 거래 수·관찰 기간·비용 후 평균 모두 미측정**이다. 수천 건의 체결도 같은 재고가 쌓였다가 정리되는 한 사건일 수 있다. 틱 수·주문 수·왕복 건수를 그대로 독립 n으로 쓰지 않는다. 재고 에피소드 또는 시간 블록 중 관찰 단위를 정하고, 중첩/연속 상관·블록별 손익·미체결 때문에 잘리는 표본을 반영해야 한다. 희귀한 급락과 급등의 재고 위험을 며칠의 고빈도 자료로 대체하지 않는다.

| 순서 | Claude가 연구 선택 후 확인할 것 | 미달 처리 |
|---|---|---|
| 1 무료 자료·실행 타당성 | 자료 해시·기간·호가 순서·실제 비용·지연·현재 실행 상태 전이와의 호환성 | 자료/실행 관문 미달로 보류. 전략 수익 기각과 구분 |
| 2 체결·회계 계약 | 단방향 하락/상승·왕복·부분 체결·취소 중 체결·최악 미체결 주문 노출·잔여 재고를 합성 입력으로 검산 | 모델 결함부터 해결. 성과 실행 금지 |
| 3 검정력 | 독립 단위·SD·현실적인 비용·효과 가정의 근거·필요 관찰 기간을 계산 | [80% 게이트](../current/BACKTEST_AND_TESTING.md) 미달이면 사전등록하지 않음 |
| 4 단일 명세 확정 | 한 시장·한 모델·파라미터 산정법·주기·보유/정리·위험 적용 범위·분할·비교/기각 수치 동결 커밋 | 미확정 항목을 남긴 채 실행하지 않음 |
| 5 판정·기록 | 미열람 구간에서 비용 후 계좌 손익·기준선 대비 추가 효과·위험·체결 강건성을 1회 판정 | 실패하면 버림, 성과 뒤 숫자/방향/종목 변경 금지 |

원자료/공개 예제 노출 이력을 남긴다. 예제의 기간·설정은 이미 결과를 봤으므로 우리 최종 미열람 OOS로 부르지 않는다. 변동성/주문 도달 빈도의 추정은 그때까지의 자료만 쓰며, 미래 체결 결과로 과거 호가를 재작성하지 않는다. 필요한 관찰 기간과 연구의 위험 규칙 적용 범위는 확정 전이며, 짧은 시험의 연율화 수익을 목표 수익률로 사용하지 않는다.

### 실패하면 버릴 조건과 확장 경계

- 적용 가능한 실제 수수료에서는 수익이 사라지고 리베이트 가정에서만 살아남음.
- 대기열·지연·부분 체결을 현실화하면 가격 우위가 사라짐, 또는 체결 뒤 불리한 가격 변화가 얻은 가격 차이를 상쇄함.
- 총손익의 양수가 남은 재고 평가손실 누락·외부 자금 보충·마지막 무비용 정리·상승장 코인 보유만으로 설명됨.
- 동일한 위험/체결 조건의 고정 주문 또는 보유 기준선보다 추가 효과가 없거나, 현행 위험 한도 안에서 운용 불가.
- 무료 자료로 재현할 수 없거나 필요한 독립 표본·80% 검정력을 확보할 수 없음. 이 경우 자료/표본 부족으로 보류하며 우위 없음과 구분.
- 실패 뒤 모델 계수·칸 수·간격·목표 재고·레버리지·갱신 주기를 탐색해 같은 구간을 재판정하지 않음. 계수는 성과 전에 이론/자료/위험 예산의 근거로 산정·고정하고, 자유도 개수를 기록.

**DGT와 선물 헤지는 참고로만 남긴다.** DGT는 범위 이탈 때 재배치하고 하단 이탈 물량을 보유하는 별도 방식이다. 선물 헤지는 가격 위험과 함께 거래 비용·funding·두 다리 미체결·증거금 위험을 추가한다. 둘 다 첫 모델에 섞지 않는다. 특히 현물 재고와 반대 선물을 자동으로 늘린다고 수익이 생기는 것은 아니다. 검증 뒤 새 가설이 있을 때 별도로 선택한다.

## 16번 후보 메모 — 어느 시장에서 매수·매도가 발생했는가

**사용자 승인 범위는 이 문서에 후보를 기록하는 것뿐이다.** Claude의 진행 중 연구를 바꾸거나 이 후보를 실행 대상으로 선택한 것은 아니다. 그리드 재검토는 이번 후보에 섞지 않는다.

- **가설:** 가격 상승폭·변동성이 비슷한 상황에서, 현물과 무기한 선물의 공격적 체결 흐름 차이가 이후 수익의 지속/반전을 구분하는 추가 정보를 제공할 수 있다. 현물 수요와 파생상품 수요의 서로 다른 가격 반영을 노리는 가설이며, 현물이 항상 가격을 선도하거나 선물 매수가 항상 되돌려진다고 가정하지 않는다.
- **측정 대상:** `공격적 매수 거래대금 − 공격적 매도 거래대금`. 공개 봉의 전체 거래대금과 taker 매수 거래대금으로 구성할 수 있다. 각 시장의 거래 규모를 반영한 정규화는 과거 자료만 쓰며, 현물·선물 원시 거래대금 크기를 그대로 비교하지 않는다. CVD는 이를 누적한 참고 표현이다. 체결에는 항상 매수·매도 상대방이 있으므로 이 값은 순자금 유입이나 투자자 수가 아니다. 장기 투자자/기관/신규 레버리지 여부도 이 자료만으로 식별하지 않는다.
- **기존 기각과의 차이·중복:** H3의 `X3_rel_taker`는 선물 taker 매수/매도 비율의 종목 간 순위였다([기존 명세](../archive/research/23-h3-preregistration.md)). 새 후보의 질문은 같은 자산의 **현물 정보가 선물 흐름·가격 변화·거래량·추세 기준선에 더하는 정보**다. 지표 이름이나 관찰 창만 바꾸는 H3 재시도는 받지 않는다. 단순 CVD 단독 신호나 펀딩/OI 조건 추가로 후보를 대체하지 않는다.
- **자료:** Binance 공개 현물·USD-M 봉의 quote 거래대금, taker buy quote 거래대금, 가격·시각, 보유 기간의 funding. 우선 BTC·ETH 자료 확보 가능성부터 점검한다. 공식 명세에 필드가 있다는 것과 로컬 파일의 실제 기간·결측·정합성 검증은 구분한다. 유료 자료 구매·호가/틱 전체 수집은 제안하지 않는다.
- **미확정 설계:** 마감 4h 봉에서 측정하고 이후 하루를 확인하는 것은 출발점 제안이다. 방향·정규화 창·임계·보유/청산·손절·사이징·빈도·실행 지연·비교 기준·분할은 아직 확정하지 않았다. 수익을 보기 전에 자료 점검과 사용자 선택을 거쳐 Claude가 하나의 명세로 확정한다. 여러 창/조건을 시험해 성과가 좋은 조합을 고르는 연구는 하지 않는다.
- **비용·체결:** 지정가의 미체결·부분 체결·역선택·실행 지연, 양쪽 수수료, funding, 미실현손익을 포함해야 한다. 지정가를 쓴다는 이유로 모든 주문을 maker 요율로 전량 체결시키지 않는다. 연구의 우위 측정과 위험 규칙을 적용한 계좌 결과를 구분하되, 위험 한도 변경을 승인한 것은 아니다.
- **표본/검정력:** 현재 SD·독립 n·필요 거래 수·판정까지 걸릴 기간 모두 미측정. 하루 관찰 구간이 겹치는 4h 신호나 같은 시장 충격의 BTC·ETH 관찰을 독립 표본으로 중복 계산하지 않는다. [검정력 기준](../current/BACKTEST_AND_TESTING.md)의 80% 관문 미달이면 사전등록하지 않는다. 과거 자료의 프로젝트 내 열람 이력을 남기고 최종 확인에는 별도 미열람 구간이 필요하다.
- **실패하면 버림:** 현물 정보의 추가 효과가 없거나, 효과가 비용·실행 지연을 넘지 못하거나, 충분한 독립 표본을 확보할 수 없으면 버림/보류한다. 성과를 본 뒤 방향을 뒤집거나 임계·보유기간·심볼을 바꿔 구제하지 않는다. 구체적인 통과 수치와 순수익/추가 효과의 판정은 확정 전에 정한다.

**출처와 한계:** [Binance 공개 자료 명세](https://github.com/binance/binance-public-data)는 현물·선물 봉에 전체 거래대금과 taker 매수 거래대금이 있음을 설명한다. [Order flow and cryptocurrency returns (2026)](https://doi.org/10.1016/j.finmar.2026.101047)는 여러 시장의 주문 흐름과 이후 일간·주간 수익 예측의 관계를 연구했다. 이 후보는 그 근거에서 확장한 가설이며, 해당 논문이 Binance 현물·선물 흐름 차이 모델이나 우리 비용·위험 조건의 수익성을 입증한 것은 아니다.

## 5번 사전등록 초안 — 한국 실적 개선형 주도주

[상세 초안](FUNDAMENTAL_KR_PREREGISTRATION_DRAFT.md) 작성 완료, **DRAFT / Phase 0**, 수익 미계산. Codex가 제안하는 단일 모델은 매출 성장 가속·영업이익률 개선·현금흐름 개선 세 순위의 동일 가중이다. 월말 비금융 유동성 상위 200에서 개선 조건을 만족하는 상위 최대 20종목에 각 5%, 부족한 자리는 현금, 매월 재평가하며 선정이 유지되면 보유를 이어간다. 지정가·미체결·거래비용·기업행동을 포함한다. 숫자는 사용자 검토 및 Claude 자료 감사 후 확정할 초안값이다.

주 비교는 같은 재무 계산 가능 종목군 동일가중, 현금 노출을 맞춘 동일가중과 KOSPI 총수익도 확인한다. 순수익/초과수익 2SE 하한, 위험 대비 성과·비용 2배·지연 조건을 함께 고정한다. 연 3%p는 검정력 계획용 검출 대상이며 관측 평균 통과 문턱과 구분한다. 여러 통계 조건을 동시에 통과할 검정력도 확인한다. **실적이 개선된다는 이유만으로 수익 우위가 있다고 가정하지 않는다.**

초안에서 발견한 확정 전 주의점:

- DART의 접수번호 존재만으로 정정 전 수치가 복원되지는 않는다. 원공시·정정 쌍을 먼저 대조해야 한다.
- 원래 가설의 매출 성장 가속에는 매출 12분기가 필요하다. 2015년부터만 확보되면 신호 시작은 대체로 2018년이며 2016년 시작을 자동 채택하지 않는다.
- 141의 현재 산업분류 소급·배당 제외·미래 마지막 가격 강제 청산을 그대로 재사용하지 않는다. 상장폐지 종목을 포함했다는 사실만으로 전체 생존/시점 편향이 해결된 것은 아니다.
- 2018~2020 계획용, 2021~2023 TRAIN, 2024~2026-08 역사 확인을 제안한다. 같은 가격 자료가 이전 연구에 노출됐으므로 최종 OOS는 별도의 전향 자료가 필요하다. SD·필요 관찰 월수·80% 검정력은 아직 미측정이다.
- 위험 규칙의 연구 적용 범위·종료/배당/정산·비용표·검정력이 미확정이면 Claude는 확정 커밋/성과 실행 전에 이를 해결한다. 이 초안의 통과 명칭은 HISTORICAL_SUPPORT이며 전체 Phase 4 PASS와 구분한다.

## 4번 인계 보충 — Opus가 재개할 때 (2026-10-05, Codex)

사용자가 역할 변경을 확인하고 현재 연구의 추가 인계를 요청했다. 이 절은 아이디어·진행 순서 제안이며 사전등록 확정이나 연구 재개 실행 기록이 아니다. 자료·코드·실험은 Claude가 담당한다. 체크포인트 본문의 옛 “Codex 전용/Claude 수정 금지/완료 후 이관”은 역사 기록이며, 현재 담당은 AGENTS §9와 체크포인트 맨 위의 담당 변경 안내를 따른다.

### 연구 목적과 현재 증거

- 질문: **매출 성장세·영업이익률·영업현금흐름이 개선되는 기업을 당시 공개 정보로 골랐을 때, 비용 후에 비교 대상보다 높은 수익이 남는가?** 측정 정의는 [131 §3](131-fundamental-leaders-feasibility.md)를 잇는다. 실적 발표 직후 갭 전략(130), 가격 주도주 LT, 가치·품질 후보 2번을 섞지 않는다.
- 판단: 연구할 경제적 근거는 있으나 우리 신호의 우위는 미측정이다. 좋은 실적이 이미 가격에 반영됐거나 일회성일 수 있다. 관련 실적 모멘텀 논문의 효과 크기를 이 모델의 기대 수익으로 대입하지 않는다.
- 현재 **Phase 0 / REAL_SAMPLE_AUDITED / DATA_NOT_READY / NOT_TESTED**. Apple·Microsoft 실제 공시 검산과 순수 계산·정규화·자료 감사 도구는 있다. 종목 선정 성과, 독립 표본 수, SD, 80% 검정력, 전략 사전등록은 아직 없다. 코드 테스트 통과를 수익성 증거로 쓰지 않는다.
- 최신 자료 조사는 `eba3f81`, 연구 도구 변경은 `2eecab6`. [체크포인트](FUNDAMENTAL_CODEX_CHECKPOINT.md) → [무료 경로 감사](FUNDAMENTAL_FREE_HISTORY_FEASIBILITY.md) 순으로 읽고, 필요한 세부 근거만 131~136·후속 감사에서 찾는다. 기존 구현을 처음부터 다시 만들 필요는 없다.

### 바로 이어갈 범위와 중단 지점

1. **무료 종료 가격의 확보 가능성을 먼저 끝낸다.** Tiingo 공개 목록에는 TWTR·CTXS·NLSN이 있지만 실제 가격 API 제공은 미확인이다. 사용자 제공 무료 계정/토큰이 준비되면 최대 3종목의 metadata·종료 부근 가격만 확인한다. 현재 인계 시점에는 해당 인증 사용에 대한 답변/토큰 제공이 확인되지 않았다. 키는 채팅·문서·Git에 남기지 않는다. 유료 구매는 금지다.
2. **당시 종목군 복원 가능성을 함께 판정한다.** 2022-09-30~11-01은 자료 감사용 제한 구간이다. 공식 시작/끝 명부와 중간 변경 근거를 확보할 수 있는지 확인한다. 이 기간을 전략 TRAIN/OOS로 쓰거나 성공한 기업만 골라 수익을 계산하지 않는다. 확보한 변경 CSV는 공식 근거를 찾는 후보 목록이다.
3. 두 경로를 확인한 뒤 **확보/미확보/추가로 필요한 입력**을 한 번에 보고한다. 가격 또는 명부가 계속 부족하면 DATA_NOT_READY로 보류하고 경로 선택을 사용자에게 제시한다. 이미 빈 응답으로 끝난 요청의 반복이나 끝없는 예외 처리 도구 추가를 다음 성과로 삼지 않는다. 전향 관찰로의 전환은 아직 선택되지 않았다.
4. 자료가 확보되면 공시·증권 ID·달력·기업행동과 연결하고, 회계 커버리지·누락률·독립 표본/검정력을 확인한다. 그 뒤 매수·청산·비중·비용·지정가 미체결·비교 기준·분할을 수익 열람 전에 고정한다. 첫 모델은 기존 세 실적 측정치를 중심으로 단순하게 유지한다. 추가 지표·가중치·Top N 탐색은 제안하지 않는다.
