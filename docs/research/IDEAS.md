# 연구 아이디어 목록

> 판정이 난 연구의 결과는 [RESEARCH_HISTORY](../current/RESEARCH_HISTORY.md)가 기준이다. 이 목록은 "다음에 무엇을 시험할까" 만 다룬다.
> 방향 기준점: [DIRECTION_LEADER_TREND](DIRECTION_LEADER_TREND.md). 새 아이디어는 "가설 · 비용 · 판정 기준 · 실패하면 버린다" 로 적는다.

## 쓰는 법

- 상태: `아이디어` → `후보 비교` → `초안`(사전 등록 초안) → `사용자 선택` → `자료 점검` → `확정`(커밋, 수익 보기 전) → `판정 끝`(RESEARCH_HISTORY 로) · 또는 `보류` · `버림`.
- 같은 자료에서 결과를 본 뒤 숫자만 바꾸는 아이디어는 받지 않는다(데이터 스누핑). 다시 보려면 **새 자료**(다른 시장·자산·기간·앞으로의 기록)이거나 **결과 전에 안 설계 결함**을 고친 판이어야 한다.
- 한 줄에 하나. 출처(사용자 말·영상·논문·다른 연구에서 배운 것)를 적는다.

## 31번 독립 ML/DL 연구 설계 — BTC·ETH 추가 edge 검증 (2026-10-11, Codex)

**상태: 사용자 선택 / Phase 0 / DRAFT / NOT_IMPLEMENTED / NOT_TRAINED.** 사용자 요청으로 이번에는 **이 파일만 수정**한다. 다른 세션의 작업·PROGRESS·Current·코드·의존성·DB·예약·기존 T/v2/Paper/Live는 수정하지 않는다. 아래 수치는 성과를 보기 전의 설계 제안이지 확정 사전등록/검정력 통과/학습 허가가 아니다. 자료·비용·위험·독립 표본·미열람 기간 관문을 해결하고 확정 커밋한 뒤에만 구현·학습한다. 무료 로컬 자료 우선, 유료 구매·GPU/라이브러리 설치·계좌 호출 없음.

### 31.1 가설·기각 연구와의 경계

- **H-A / 독립 모델:** 당시 알려진 추세·변동성·거래량 및 감사된 포지셔닝 정보의 조건부 상호작용이 단순 규칙보다 향후 24시간의 비용 후 방향/거래 edge를 구분한다. LONG/FLAT/SHORT 확률을 연구 전용으로 출력한다. 분류 정확도와 실제 체결 손익을 따로 검증한다.
- **H-B / T/v2 연구용 위험 필터:** 같은 정보로 T/v2의 손실 위험을 감지하여 정상 1.0 / 위험 0.5 / 강한 위험 0.0 배율을 연구 원장에만 적용했을 때, 피한 손실뿐 아니라 놓친 상승·복귀 비용까지 포함해 비용 후 수익을 개선한다. 기존 운영 T/v2를 수정하는 연구가 아니다.
- **H-C / 복잡도 필요성:** 동일 정보·기간·체결·위험 조건에서 비선형 ML이 LR보다, sequence DL이 일반 ML보다, Transformer가 작은 sequence 모델보다 추가 성과를 제공한다. 복잡하다는 이유만으로 승격하지 않는다.
- 기존 [DMN 감사](DMN_PHASE0_AUDIT.md)는 IDEAS 19를 검정력 부족으로 **버림** 처리했다. 이번은 비용 고려 Sharpe 직접 최적화 DMN의 재판정이 아니라, 비용 문턱 label의 지도학습과 분리된 필터 비교다. 하지만 BTC·ETH의 같은 정보/표본 부족은 그대로다. 4h 행 수·모델명 변경만으로 해결됐다고 주장하지 않는다. 신규 미열람 자료와 검정력 관문이 없으면 판정형 연구를 중단한다.
- IDEAS 22 차트 패턴·23/24 ETF flow·25 순서 정보·26 방어/복귀의 기각/보류는 유지한다. 해당 입력을 ML에 넣었다는 이유로 이미 실패한 수익원을 부활시키지 않는다. 기존 가설 대비 추가 정보·동결 비교·새 전향 자료가 필요하다. Elliott/JEV/뉴스 AI 출력과 D22는 초기 입력에서 제외한다.
- A와 B는 독립 가설이며 성과를 보고 둘 중 하나만 남기지 않는다. LONG/SHORT도 개별 보고하고, 롱만 통과하면 숏 우위를 주장하지 않는다. 전략 후보군은 A/B 두 개이고 모델들은 같은 가설의 제한된 비교 도구다.

| F1 ETF flow | 공개된 전체 BTC ETF 순flow/AUM(직전 알려진 AUM), 최근5 미국 세션 합/AUM | AUM 이력 없으면 제외, USD 합으로 몰래 대체 금지. ETH에는 BTC 시장 맥락일 뿐 ETH 자체 flow 아님 |
| X1 cross-asset | 마지막 가용 QQQ/SPY/GLD 1·5 거래일 수익, DGS10 5거래일 변화 | 미장 마감·공식 공개 이후만 as-of join. SPY/QQQ 중복은 Train 상관 제거. VIX는 PIT 확보 전 보류 |
| Q1 품질·레짐 | optional 입력의 age_hours/결측 flag, 자산 식별 BTC/ETH; 추세 부호 평균·vol percentile | 인과적 관측 변수만 사용. 사후 bull/bear/HMM 전표본 fit 레짐 금지 |

**초기 primary = P1~P5 + V1/V2 + R1 + 자산 식별, 선택 후 연속 변수 최대32개.** D/F/X는 가용성·기간·검정력 감사 뒤 수익 열람 전 확정한 추가정보 판에서만 허용한다. 모든 묶음을 합쳐 가장 짧은 기간으로 primary를 축소하지 않는다. 새 피처/기간을 보고 선택하거나 기각 flow의 threshold를 학습 성과에 맞춰 바꾸지 않는다. raw-only 대조는 raw OHLCV를 Train-only scaling한 제한 입력으로 고정하고, 큰 가격 수준 추세가 성과를 지배하는지 따로 보고한다.

### 31.4 label·prediction과 거래 가능성

- Primary label은 마감 시각 t 이후 **t+1분의 기준가격부터 24h 뒤 기준가격**까지의 수익이다. 이는 비교용 가격 anchor이지 시장가 주문/종가 보장 체결이 아니다. 실제 성과는 별도 지정가 원장으로 평가한다. 미래 1m·funding을 입력 matrix에 섞지 않는다.
- 미래 기준수익 bps를 R, 사전 고정 LONG/SHORT 왕복 fee+실행 비용을 c_L/c_S, 보유 구간 실현 funding의 LONG 비용을 F라고 두면 `edge_L=R−c_L−F`, `edge_S=−R−c_S+F`(선형 수익 기준; 정확 회계는 Decimal 원장). **LONG: edge_L>20bps, SHORT: edge_S>20bps, 그 외 FLAT**를 초안으로 제안한다. 20bps는 기대 효과의 근거가 아니라 거래할 최소 잔여 폭 제안이다. 확정 전 비용/표본 관문으로 승인하며 결과 뒤 변경 금지. 두 조건 동시 충족/자료 불명은 오류/label 제외로 처리한다.
- SHORT는 실제 funding·차입/계약·체결 비용을 따로 반영한다. c_L=c_S를 억지로 고정하거나 LONG 비진입을 SHORT로 바꾸지 않는다. 미래 실현 funding을 label 계산에 쓰는 것은 허용하되 예측 시 입력/예상 비용에는 그때 알려진 값만 쓴다.
- label과 체결은 서로 다르다. OHLC anchor 예측을 잘해도 지정가 미체결·비용 때문에 거래 edge가 없으면 FAIL. 훈련용 label이 stop 손익을 정확히 예측한다고 주장하지 않고, 보호 스톱 포함 실제 원장을 별도 평가한다.
- 확률은 p_LONG/p_FLAT/p_SHORT, 합1·결측 상태·모델 버전과 함께 출력. A 행동은 calibrated p_LONG>=0.60 또는 p_SHORT>=0.60 + Train에서 산정한 해당 확률 구간의 보수 순 edge>0 조건, 둘 다 아니면 FLAT. 0.60/구간 수/최소 구간 관찰 수는 수익 전 확정하고 OOS threshold 검색 금지. 모델 argmax만으로 반드시 거래하지 않는다.
- 동일 자산 포지션이 있으면 추가 진입하지 않고, 기본 청산 horizon은 첫 실제 체결로부터24h. SHORT 반전 시 즉시 뒤집기/시장가 추격 없음. 청산 미체결이면 보유 위험/비용은 계속 기록하고 신규 진입 차단; 청산 완료 뒤 기존 재진입 대기·위험 게이트 준수. 하루/같은 방향 횟수 제한을 새로 만들지 않는다.

### 31.5 preprocessing·selection·imbalance

1. 봉 gap/시간 역순·중복·OHLC 모순·음수 거래량·단위 오류를 먼저 검사한다. 품질 이상값을 winsorize로 감추지 않는다. primary 이력 부족/필수 시세 결측/sequence gap은 해당 예측을 거부한다. 거래 표본 감소까지 보고하며 지운 날짜에서 나쁜 거래를 빼 성과를 개선하지 않는다.
2. optional source는 엄격 backward as-of join, available_at_ms<=t. 선물 funding은 다음 정산이 확인될 때까지 마지막 실현값/경과시간, OI 최대8h, 미국 일봉 최대96h, ETF 다음 세션 발표 전 최대96h까지만 허용하는 초안이다. 휴장/주말 age와 누락을 구분한다. 역채움/양방향 보간 금지. history PIT 불명은 미확인으로 제외하고 현재 수집 시각을 과거 첫 공개 시각으로 쓰지 않는다.
3. optional 결측은 Train median + missing/age flag로 처리하되 Train 결측률20% 초과 변수는 그 fold에서 제외; 완전 미출시 묶음은 제거/별도 기간 연구다. 필수 거래 입력 결측을 median으로 대체해 진입시키지 않는다. feature mask/제외 이유를 저장하고 OOS 커버리지로 다시 고르지 않는다.
4. 연속 변수 clipping은 각 Train의0.5/99.5 percentile, scaler는 Train median/IQR(0 IQR은 상수 제거). LR/MLP/TCN 동일 transform, XGBoost도 같은 결측·클리핑 계약. 계산 순서는 split → Train fit → validation/test transform이다. 온라인 rolling z는 과거180개 관측으로 정의하고 전표본 통계 사용 금지.
5. Train에서 상수 및 |Spearman rho|>=0.90 중복 제거, 가족 내 표에 먼저 적힌 변수 우선; 선택 후 최대32개. 기존 Phase2 상관<0.7 기준과 이 연구의 비선형 상호작용 계약 차이는 확정 전 감사/승인 필요하며 기존 기준을 자동 완화하지 않는다. label 기반 importance/RFE 무한 반복은 primary에서 금지. 중요도는 내부 holdout/Train-only 진단 또는 동결 후 설명에만 사용한다.
6. 각 Train에서 클래스별 건수·비율·시간별 분포 보고. 최대/최소 비율>3이면 `min(3, n/(3*n_class))` 가중치를 평균1로 다시 정규화하는 고정 방식; 그 외1. FLAT만 찍는 majority/prior baseline도 보고. 미래 oversampling/전체 기간 SMOTE 금지. 클래스가 없는 fold는 학습 불가로 기록하고 경계를 옮겨 숨기지 않는다.
7. calibration은 Train 내부 마지막 비중의 별도 시간 holdout에서 **단일 temperature scaling**만 fit, outer validation/OOS에 fit하지 않는다. 클래스 가중 학습 확률과 자연 발생 클래스 빈도 차이를 검산한다. calibration에 모든 클래스/필요 표본이 없으면 복잡한 isotonic으로 바꾸지 않고 판정을 보류한다. [sklearn 누수 지침](https://scikit-learn.org/stable/common_pitfalls.html)·[확률 보정](https://scikit-learn.org/stable/modules/calibration.html)을 구현 때 적용한다.

각12개월 Train은 시간순70% fitting /15% 내부 tuning·early-stop /15% calibration으로 나눈다. 하이퍼파라미터는 Train 내부 log-loss 최소(동점 단순판)로만 선택한다. 분할마다 scaler/feature mask/class weight 모두 다시 fit하고 artifact를 고정한다. Train 끝 이후 아직 label이 완성되지 않은 행은 학습 금지한다. BTC와 ETH의 같은 시각은 항상 같은 fold에 두고 자산을 나눠 시간 누수를 만들지 않는다.

label 구간24h + entry/exit 최대 실행 대기 예산을 기준으로 **최소48h purge/embargo**를 제안한다. label_interval이 다음 fold/보정 구간에 걸치는 행은 정확히 제거한다. sequence는 과거 입력이므로 test 첫 sequence가 Train 과거를 참조하는 것 자체는 허용하지만 미래 label/보정값 재유입은 금지한다. 월/분기 경계 열린 포지션은 위험·손익 carry, 새 모델은 그 포지션의 원래 청산 horizon/stop을 바꾸지 않는다. 48h가 실제 최대 실행 구간을 덮지 못하면 계약을 수정한 뒤 확정한다. [TimeSeriesSplit](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)만으로 label 중첩 제거가 자동 해결되는 것은 아니다.

**정보 묶음별 기간:** BTC/ETH OI 공통은2022-12-14 이후, ETF는2024 이후라 primary 2020~2026 전체 입력으로 사용할 수 없다. 묶음의 존재/누락 패턴으로 미래 시기를 암기하지 않게 별도 동기간 대조한다. 학습12개월·워밍업·독립 outer 기간이 모자라면 확장판은 `DATA_INSUFFICIENT`; primary를 줄여 2024 표본에 모든 모델을 몰아 넣지 않는다. 2026-09 이후 기존 Paper/Live로 본 기록도 새 미열람 구간으로 재명명하지 않는다.

### 31.7 baseline·모델 사다리·학습 예산

먼저 baseline 재현 및 회계/누수 테스트, 그다음 **LR → XGBoost → 작은 MLP → 작은 TCN → 조건부 Transformer** 순서다. LightGBM 또는 LSTM으로 바꿀 필요가 있다면 설치/실행 호환성 등 **성과 이전 근거**로 한쪽만 확정한다. XGBoost/LightGBM 또는 TCN/LSTM 둘 다 돌려 유리한 쪽을 고르지 않는다. 초기 검토는 baseline/LR/XGBoost 최대3개만, DL은 앞 단계 자료/검정력 관문 뒤 별도 승격한다.

[PyTorch 재현성](https://docs.pytorch.org/docs/stable/notes/randomness.html)·[AMP](https://docs.pytorch.org/docs/stable/amp.html) 참고, seed만으로 GPU/OS 간 비트 동일성을 보장하지 않는다. checkpoint/lock/CUDA·cuDNN·driver·하드웨어·precision·예측 해시·추론 replay를 저장한다.

### 31.8 A/B 실행 계약·비용·복귀

- **A:** Binance USD-M BTC/ETH 연구용 LONG/FLAT/SHORT, 현물 롱/선물 숏 혼합으로 비용을 숨기지 않는다. 최초 가정은 순노출 합<=100%·종목별<=50%·레버리지1x, 그러나 이는 새 선물 위험 한도를 완화하는 허가가 아니다. 기존 거래 위험1%·증거금10%·일 손실2%·DD30%·보호/청산거리·게이트의 제약을 함께 적용해 더 작은 크기로 제한한다. stop 예시는 마감4h ATR14의2배이며 min-distance/WIDEN C1·실제 stop/mark/규격·사이징을 확정 전 해결해야 한다. 신호당 위험/stop을 A 비교 규칙에도 똑같이 적용한다. O/v2의 무손절/−20% 예외를 복제하지 않는다.
- **B:** 동결 T/v2 BTC/ETH 현물 원장에만 필터 배율을 곱한다. 마지막24h SHORT 확률을 위험 대리로 사용, p_SHORT<0.40은1.0 /0.40~0.60은0.5 />=0.60은0.0의 초안. T/v2 청산이면 ML 확률과 무관하게 목표0.0. 위험 완화 때 **연속2개 마감4h에서 p_SHORT<0.35이면1.0, <0.55이면 최소0.5**로 복귀하는 hysteresis를 함께 고정한다. 위험 진입은 한 봉, 복귀는 두 봉; 모든 계산은 당시 예측만 사용한다. 마지막 두 예측이 없으면 새 증액 금지. 이 thresholds는 수익 전 승인/동결하고 결과 뒤 재진입 규칙 튜닝 금지.
- B의 손실 방지 label은 ‘24h 하락’ 대리이지 장기 crash 보장 아니다. 피한 손실, 위험감소 중 놓친 상승, 재진입 비용, 복귀 지연4h단위, 재차 손실, CASH 지속시간, 감소/복귀 횟수를 같은 원장에 표시한다. 낙폭만 낮고 순수익이 줄면 이 연구의 수익 개선 PASS가 아니다. 동일 평균 exposure의 단순 축소 T/v2와도 비교하여 단순히 덜 투자한 효과를 분리한다.
- **일반 주문은 가격 한도 지정가만:** t+1분부터 last 대비±0.30% IOC 한도, 최대3개의 사전 정한1분 실행 시도·잔여 처리 제안. OHLC에서는 touch=전량 체결 금지; 한도 관통·거래량>0·더 유리한 시가 min/max·부분체결·tick/step·미체결을 보수적으로 모델링하고 동일 실행모형으로 모두 비교한다. 장기 대기/종가 보장/무한 추격 금지. 실제 BID/ASK·틱 경로가 없다는 한계를 명시한다.
- 기본 비용 초안(현행 거래소 요율 사실 아님): 선물 **편도 fee5bps+spread/slippage4bps = 왕복18bps**, 현물 **편도 fee10bps+실행5bps = 왕복30bps**, funding 실현 시계열·mark/보호/강제청산·부분체결 포함. 체결가격과 slippage 가산의 중복 계산을 막는다. 지정가도 taker일 수 있으며 maker 할인 고정 가정 금지. 현재/과거 계정 등급·규격 자료 감사 후 수익 전에 비용 버전 동결한다.
- 수수료·실행 비용2배 스트레스, 불리한 funding은 LONG=max(F,0)/SHORT=max(−F,0)로 수취혜택0 처리하는 별도 스트레스, 실행1개 마감4h 지연을 사전 진단한다. T/v2 시장가 추격 예외는 새 ML에 전이하지 않는다. 비교용 연구 T/v2는 같은 지정가 계약을 사용하며 현행 baseline 실행과의 차이를 병기, 운영 실행기 변경 없음.
- 강제청산0·DD한도·보호주문 계약이 없으면 수익성 결과를 운용 가능으로 인증하지 않는다. C11~13 독립감시/내구성 미해결도 그대로다. 지연·실행3회·cleanup 예산·stop 체결은 확정 전 gate이며 초안 숫자만으로 안전성 통과 아님.

### 31.9 평가·검정력·PASS / FAIL

**G0 / 학습 이전 관문:** 자료 manifest·공개/가용 시각·단위·커버리지·hash·code/config·split 노출표·비용/지정가/보호 계약·Python/CUDA·독립 표본/용량·필요 기간을 감사한다. 과거 DMN의 월 차이 SD3.6%/최소 연16%p는 이번 후보의 실측 분산이 아니라 경고용 대리다. 더 짧은4h 입력으로 바꿨다고 없애지 않는다.

검정력80%, 기본z2 유지. 계획용 최소 유용 증분은 **연 산술3%p(월0.25%p)** 제안이며 그런 효과가 존재한다고 가정/주장하지 않는다. 기준선 차이의 보수 SD/장기 의존을 이용해 필요 월수·가용 월수·MDE·최종 종료일을 계산한다. 비용 후 paired 차이에 비용을 다시 빼지 않는다. 6개 비교 동시성 보정 후의 z로 power도 다시 계산한다. 후보 학습 전 SD 근거가 없으면 승인된 Train-only 계획 파일럿을 별도 사전등록/커밋하거나 `POWER_UNRESOLVED`로 중단한다. 필요 효과를 크게 올리거나 n을4h 행수/BTC+ETH 합으로 부풀려 gate를 통과시키지 않는다.

**출력 지표:** accuracy(보조), 클래스별 precision/recall/F1/support·confusion matrix·PR-AUC, log-loss/Brier·동일10개 확률 구간 reliability/ECE·클래스 prior 대조. LONG/SHORT별 실제 체결 건수·순 edge·PnL·승률도 보고한다. 원장에는 fee/slippage/funding 기여, CAGR/Sharpe/MDD, 월별·worst30/90일, turnover, 노출(평균/시간/롱숏), 실제 체결·미체결/부분체결률, veto/정지, 비용 후 평균 trade edge/SE 및 benchmark 대비 paired 증분을 포함한다.

BTC·ETH 동시각/중첩 horizon·군집 위험 때문에 independent n은 raw 행 수가 아니다. paired 월 수익·거래 사건별 장기 의존을 함께 보고, 두 자산은 같은 시간 block으로 재표집한다. 30일 시간 block bootstrap10,000회/seed11과 month HAC lag3를 사전 제안; 주 통계·SE/CI 계산·block 경계·HAC와 충돌 처리·80% 계산은 확정 전 명시한다. 최대6개 확인 비교(A−규칙, B−T/v2, XGB−LR, MLP−일반ML, TCN−일반ML, Transformer−TCN)는 Holm familywise0.05, 활성화 안 된 비교는 p1로 기록한다. 주장할 숏/feature 묶음별 유의성은 추가 다중성 계약 없이 보조 진단이다. **모든 조건 수치를 유리한 성과에 맞춰 선택하지 않는다.**

Validation에서 단순 incumbent를 잠그고 최종 OOS는 그 선택에 쓰지 않는다. A의 수익 개선 주장은 단순A규칙뿐 아니라T/v2 대비 증분도 통과해야 한다. A−규칙은 두 대조 모두를 요구하는 intersection 판정(p값은 두 대조의 큰 값)으로 사전 동결하며, 시장/위험/노출 차이와 그 비교 한계를 따로 보고한다. T/v2를 못 이겼는데 단순A만 이겼으면 독립 모델의 기존 전략 개선 PASS가 아니다. 모델 사다리 승격은 내부 Train·2024 Validation에서만 수행하며, 필요한 DL 모델·비교·checkpoint를 **최종 OOS 열기 전에 전부 고정**한다. 최종 OOS에서 LR를 본 뒤 MLP/Transformer를 추가 학습해 같은 OOS를 재사용하지 않는다. 새로운 후속 모델은 새 사전등록·별도 미래 구간이 필요하다. Phase4 공통 랜덤95백분위·셔플·민감도±20%·시작일±30일·지연/심볼 교차 계약도 확정 전 정량화하며 이 표로 생략하지 않는다. 민감도 결과에서 승자를 재선택하지 않는다.

### 31.10 ablation — 정보와 모델 효과를 분리

모델이 통과한 뒤 중요 정보를 설명하되 **제거판은 결과 열람 전에 미리 설계/동결**한다. OOS를 보고 제거할 묶음을 고르지 않는다. 주모델/threshold는 그대로이고, 같은 Train에서 제거판을 동일 예산·고정 hyperparameter로 재학습한다. 진단에서 더 좋은 제거판이 나와도 같은 OOS에서 주모델로 교체하지 않는다.

1. raw OHLCV 제한 입력 vs engineered P/V/R(동일 공통 날짜).
2. engineered P/V/R vs +D(OI/funding/basis), 둘 다 D가 가용한 **동일 날짜**로 재학습/비교.
3. P/V/R+D vs +F(ETF), 둘 다 F가 가용한 동일 날짜. 짧은ETF 기간 효과와 feature 효과를 분리.
4. P/V/R+D vs +X(cross-asset), 동일 날짜·missing 규약.
5. full 확정 묶음에서 D/F/X 각각 하나 제거, 동일 날짜. 이 단계는 해당 full판이 처음부터 승인/등록된 경우만.

초기부터5판 모두로 모델 경연하지 않는다. 정보 묶음별 power가 부족하면 설명 통계/불확실성만 보고하고 ‘기여 확인’이라고 부르지 않는다. price-only 우위가 없다면 OI/ETF를 순차 붙여 나올 때까지 탐색하는 방식도 금지한다.

### 31.11 완전 분리 구현 계획·운영 단계·인계

확정 뒤 후속 구현 제안(이번 생성 안 함): `src/auto_trading/research/ml/`의 contract/features/labels/split/preprocess/models/evaluate, 전용 `scripts/` runner·연구 config·Fake/leakage/replay 시험. 기존 회계/체결 원칙을 재사용하고 외부 backtest 프레임워크로 다른 전략 경로를 만들지 않는다. 운영 core/features/strategy/risk/실행기/주문 코드 수정·ML import 없음. 운영 DB는 읽기 전용·짧은 transaction, 동결 시장 스냅숏을 사용하며 라이브 원장 migration 없음.

연구 artifact는 별도 Git 제외 경로, 이후 Shadow DB도 `ml_shadow.db` 같은 별도 DB다. A/B·모델·split·asset·as_of_ms·feature available_at_ms·snapshot_digest·feature_mask·scaler/calibrator/checkpoint/code/config/dependency hash·확률·action·예상비용/edge·veto/결측 사유·추론시간을 주문 유무와 무관하게 남긴다. label은 horizon이 지난 뒤 별도 outcome 행에 기록하고 과거 prediction을 수정하지 않는다. 가상체결/fee/funding/PnL도 연구 run_id로 분리한다. 파일 삭제/키 입력/실계좌 호출/자동 설치 없음.

**상태: 사용자 선택 / Phase 0 / DRAFT / NOT_IMPLEMENTED / NOT_TESTED.** 선택한 1번은 뉴스가 아니라 **엘리엇 후보 해석을 JEV로 보완하는 비교시험**이다. Claude가 자료·계약·비용·검정력 감사 후 사전등록을 확정한다. 이 문서는 API 실행·새 예약·실거래 연결 승인이 아니며, 이번 작업에서 호출·설치·코드/설정 변경은 하지 않았다. 기존 운영 Phase 6·T/v2·O/v2·Paper·데모·일정은 유지한다.

### 30.1 가설과 기존 연구와의 차이

- 가설: 동일한 당시까지의 가격 구조와 동일한 복수 후보를 입력하면 JEV의 맥락 판독이 **동결한 기존 결정론적 순위 규칙보다 올바른 후보를 더 자주 상위에 올린다**. 주 비교는 같은 시험 경로에서 JEV와 기준선의 차이다.
- JEV는 새 기관 자금·뉴스·미래 정보를 제공하지 않는다. 같은 입력을 다른 방법으로 해석하는 도구다. **파동을 더 잘 읽는 것과 향후 가격/비용 후 수익을 예측하는 것은 별개**이며, 정확도 개선만으로 수익원을 발견했다고 부르지 않는다.
- [39번 후보 묶음 검증](39-scenario-set-discovery-validation.md)에는 JEV 연결을 위한 기존 형식과 기준선이 있다. 당시 잡음 있는 합성 확인 세트의 recall@50은 impulse 73.3%·zigzag 88.7%, 정답 포함 시 기존 1등 선택률은 18.2%·41.4%였다. **옛 합성·옛 코드 결과이지 현재 시장 정확도 또는 JEV 성능이 아니다.** 최신 판독기/내보내기와의 호환성을 먼저 감사한다.
- 기존 EW-REV·W3·삼각형·다이버전스의 기각/판정 불가와 [시장형 합성의 한계](103-market-like-synthetic.md)는 유지한다. [63번 검정력 한계](63-elliott-to-model-feasibility.md)도 JEV로 해소됐다고 주장하지 않는다. D22는 제외이며 옛 점수 시스템을 되살리지 않는다. IDEAS 5·26 등 다른 연구도 변경하지 않는다.

### 30.2 데이터·입력·평가 계약

- 대상은 우선 **BTCUSDT, 최소 마감 4h의 주 파동**이다. 기존 `4h-count/1h-subwave`의 1h 하위파 근거는 사용할 수 있지만 주 판정/진입을 1h로 낮추지 않는다. 1m은 품질/내부 경로 점검만, 1m 파동·매매 신호 금지. 12h/1d 맥락은 가용성·구현 감사 후 성과 전에 범위를 정한다.
- 기존 `ew-scenario-set/1` → 공급자 비종속 `ScenarioEvaluator` → `ew-scenario-eval/1` 계약을 우선 재사용한다. 입력은 확정/가용 시각이 `as_of_ms` 이하인 스윙·마감봉·후보 ID·파동 위치·기하/피보나치 근거·무효화 가격·검증 상태다. 같은 시각의 같은 묶음을 두 평가자에 준다.
- hard rule과 수치 계산은 코드가 담당한다. 위반 후보를 JEV가 승인할 수 없고 하위파 `UNVERIFIED`를 AI 의견으로 `PASS`로 바꾸지 않는다. momentum/volume/MTF 등의 `NOT_COMPUTED`를 실제 계산값·중립 근거로 위장하지 않는다. 기능 추가가 필요하면 Claude가 별도 구현 범위를 제안한다.
- JEV는 **입력에 존재하는 후보만** 상대 평가하며 `other_or_unknown`/`ABSTAIN`을 허용한다. 없는 파동 생성·차트 이미지의 자유 해석·장문 예측 생성은 첫 시험에서 제외한다. 평가 실패·시간 초과·형식 오류는 `UNAVAILABLE`, 중립 의견으로 대체하지 않는다.
- 판독 질문은 하나의 명확한 기준을 가진 구조화 판단으로 작성한다. 동일 기준의 Score를 후보별 적용하는 재순위화 방식을 우선 감사하고, 최종 primitive/질문 수/합성 방법은 **검증 결과를 보기 전** 확정한다. 근거 문장은 선택한 관측 근거 ID에서 코드가 구성하며 존재하지 않는 근거를 생성하지 않는다.
- 원응답의 분포/확신값과 프로젝트의 `relative_support`를 분리 보관한다. **상대 근거 점수는 실제 파동 정답 확률·BTC 상승 확률·매매 승률이 아니다.** 합을 1로 만드는 것만으로 확률이 되지 않는다. 점수·동점/거부 처리·표시 규칙도 미리 동결한다.

### 30.3 누수 방지와 기준선 동결

- 정답 패턴/경계·생성기 label·미래 봉·향후 PnL/MFE/MAE·기준선 순위/사이드카를 JEV 입력에서 제외한다. `GUIDELINE_DISTANCE` 같은 파생 필드가 단순히 기준선 정답/순서를 노출하는지도 감사한다. 공통 관측 근거와 평가용 label은 별도로 저장한다.
- 후보 수는 39번 연구용 N=50을 출발점으로 감사한다. 수익/정확도가 가장 좋은 N을 탐색하지 않는다. 계약/비용 때문에 바꿔야 하면 확인 세트 열람 전 이유와 새 값을 기록한다. 기준선·스캐너·질문·모델·동점 처리·허용 근거의 버전/해시를 함께 동결한다.
- 후보는 순위가 드러나지 않는 고정 순서로 입력한다. 순서 민감도는 사전 지정한 진단으로만 측정하며 가장 잘 맞는 순서/여러 호출의 최선 답을 골라 보고하지 않는다.
- 39번의 개발 seed 20260924·확인 seed 20260926은 이미 노출된 자료다. 예약 seed 20260927의 **현재 미사용 여부를 Claude가 재확인**한다. 파일럿에 쓰지 않으며 이미 사용됐으면 새 확인 seed를 결과 열람 전에 정한다. 오래된 문서의 예약 문구만으로 미열람 인증하지 않는다.
- [자료 열람 장부](DATA_EXPOSURE_LEDGER.md)를 따른다. 기존 시장 결과는 개발/역사적 보조 근거이며 새 OOS가 아니다. 2026-09 이후 전향 확인 구간을 프롬프트 개발/예제 탐색에 소비하지 않는다. 전향 시험은 명세 동결 이후 새로 가용해지는 자료로 시작한다.
- 과거 시점의 입력만 준다고 모델 학습 중의 과거 시장 지식까지 배제되는 것은 아니다. 과거 재생 결과를 완전한 누수 없는 OOS라고 주장하지 않는다. 미사용 합성 경로와 진짜 전향 관찰을 구분한다.

### 30.4 검증 순서·판정·중단 기준

1. **G0 — 계약/보안/비용 파일럿:** 이미 본 개발 예제와 정상·모호·패턴 없음·후보 밖 정답·결측·오류 사례로 기능 검산한다. 자격 없는 후보 선택, 입력 밖 ID, 누수, 실패 은폐는 실패다. 파일럿은 연결/비용 확인이지 통계적 우위 판정이 아니다.
2. **G1 — 합성 paired 비교시험:** 교과서형뿐 아니라 시장형 잡음·패턴 없는 경로를 포함한다. 한 경로의 여러 후보/호출을 독립 표본으로 세지 않는다. 두 평가자에 같은 후보 묶음을 주고, 후보를 못 만들거나 정답을 포함하지 못한 경로도 전체 분모에 남긴다.
   - 지표: `recall@N`(정답 포함), 포함된 경우의 top-1/top-k 선택률, **전체 경로 top-1 성공률의 paired 차이 JEV−기준선**, 패턴 없는 경로의 헛검출·거부/판단 범위, 실패율·비용·지연. 후보 생성 실패와 평가자 오류를 따로 보고한다.
   - 주 지표·동점/거부 채점·패턴별 다중검정·최소 실용 개선폭·헛검출 허용 악화폭·확인 경로 수를 사전등록한다. paired 성공/실패 구조에 맞는 검정·신뢰구간·**80% 검정력**을 계산한다. 거래 수익용 SD 공식이나 후보 개수를 그대로 대입하지 않는다. 숫자는 아직 미확정이며 Claude 감사에서 근거와 함께 정한다.
   - 예산 안의 가용 독립 경로가 필요 수보다 적으면 `DATA_INSUFFICIENT`로 멈춘다. 개선이 불명확/기준선 이하이거나 헛검출 안전 관문에 미달하면 미채택한다. 실패 뒤 확인 세트로 질문·가중치·임계값을 고쳐 재판정하지 않는다.
3. **G2 — 전향 Shadow:** G1 통과 뒤 사용자에게 수집/기록 범위와 비용을 제시하고 승인받는다. 매 마감 4h에서 당시 후보·두 평가자 출력·무효화 상태를 저장한다. 시장의 유일한 정답 카운트를 사후 확정하지 말고 사전 정의한 사건/무효화·신호 안정성을 평가한다. 기록 시작·표본/기간·판정 기준을 먼저 정하며 주문·veto·사이징·stop/TP에 영향은 없다.
4. **G3 — 별도 수익 가설(이번 선택/기록 범위 밖):** 판독 개선과 시장 유용성 근거가 둘 다 있어야 새로운 수익 가설 후보를 제안할 수 있다. 기존 기각과의 수익 원리 차이·미열람 자료·80% 검정력·사용자 선택/승인·사전등록이 다시 필요하다. LONG/SHORT을 자동 대칭화하지 않는다. 지정가 체결/미체결·수수료·슬리피지·funding·AI 비용을 반영하고 동일 위험의 AI 없는 기준선과 비교한다. 단순 정확도 통과만으로 전략 적용하지 않는다.

### 29.3 미국 대형 시가총액 기업: 선정·추적·뉴스 계약

**목적:** 개별 보유 종목 뉴스만으로 놓치는 대형 기업의 실적/전망/투자·규제 사건을 포착하고 시장·업종의 맥락으로 제공한다. 대형주 사건이 모든 주식의 하락 원인이라고 가정하지 않는다.

1. **초기 선정안(미확정):** 미국 주요 거래소 상장 보통주 기업 중 발행사 기준 시총 상위 20개 + S&P 500/Nasdaq-100의 비중 상위 각 10개 기업 + 사용자 보유/관심 종목의 합집합. 숫자는 수집 범위/무료 호출 예산 제안이지 성과 최적화 값·현재 순위 사실이 아니다. ADR·해외 발행사 포함/제외, 당시 거래소·주식 종류·중복 처리를 감사 후 고정한다. ETF·우선주는 회사 시총 순위에 섞지 않는다.
2. **당시 목록:** 분석 전에 확보된 최신 명부·시총/지수 비중과 가용 시각·출처를 고정 저장한다. 주간 갱신 제안, 갱신 실패 시 마지막 목록의 기준일/누락 경고를 표시한다. 과거 브리핑에 현재 시총 순위/현재 지수 구성 기업을 소급 사용하지 않는다. 무료 전 시장 시총을 확인 못 하면 "현재 시총 상위 20"이라고 꾸미지 말고 제공 명부 범위·공식 지수 상위 기업 대안 또는 사용자 지정 관찰 목록임을 표시하고 범위를 확인받는다.
3. **기업 단위 식별:** ticker와 발행사 ID/CIK를 구분하고 복수 주식 클래스는 뉴스 사건을 기업 단위로 중복 제거한다. 기업 시총은 클래스별 가격×해당 클래스 주식 수를 같은 기준으로 합산하는 등 출처의 계산 정의를 확인한다. 발행주식 수·주가의 시점 차이를 숨기지 않으며 단순 ticker 가격×전체 주식 수로 두 번 더하지 않는다.
4. **유명 기업의 고정 목록 금지:** Apple·Microsoft·NVIDIA·Alphabet·Amazon·Meta 등은 설명용 예시일 뿐 현재 시총 순위를 확인한 목록이 아니다. 금융·에너지·헬스케어 등 기술주 밖 대형 기업도 같은 선정 원칙으로 포함한다. 하락한 뒤 해당 기업을 추가해 사후 원인 설명을 유리하게 만들지 않는다.
5. **수집 내용:** 위 여섯 사건군 중 회사별 실적/전망·자금/법률·규제·주요 제품/계약·자사주/배당·설비투자와 관계가 확인된 고객/경쟁사 사건. 회사 공식 IR/공시를 우선하고 RSS는 발견/보조 해설로 사용한다. 문서 접근 실패/본문 미확보/요약만 확보 여부를 명시한다.
6. **뉴스 원장과 지수 가격 원장을 분리:** 기업의 사건·발표 시각/근거와 해당 주가/업종/지수 변화는 별도 기록한다. 이전에 가용한 지수 비중 × 같은 관측 구간 종목 수익률로 **기계적 근사 기여도**를 계산할 수 있지만, 뉴스가 그 기여를 일으켰다는 인과 증명은 아니다. 정확한 지수 구성/비중·기업행동·시간 정렬이 없으면 기여도는 계산 불가/대리치로 표시한다. 잔여 구성종목 기여를 빠뜨려 일부 기업이 지수 하락 전부를 설명한 것처럼 제시하지 않는다.
7. **시총과 지수 비중은 다름:** S&P 500은 유동주식 시총 가중, Nasdaq-100은 수정 시총 가중이다([S&P 설명](https://www.spglobal.com/spdji/en/indices/equity/sp-500/), [Nasdaq 설명](https://www.nasdaq.com/newsroom/what-is-the-nasdaq-100-guide-to-one-of-worlds-most-watched-indexes)). 단순 시총 비율로 실제 지수 비중을 대체하지 않는다. ETF 보유 비중은 지수 비중의 대리일 뿐 정확한 지수 자료라고 인증하지 않는다. QNDX 등 사용 상품의 추적 대상/통화도 감사 없이 QQQ/NDX와 같다고 놓지 않는다.

**출력 제안:** "미국 대형주 주요 사건" 카드에 기업·선정 사유/명부 기준일·공식 발표 요약·최초 공개 시각·출처·동일 구간 주가 변화·업종 동행 여부·확인 수준을 표시한다. 지수 비중/가격 기여는 별도 칸. 시장 공통 사건, 대형주 사건, 관심 종목 고유 사건을 서로 연결하되 관계가 불명확하면 불명이라고 표시한다.

### 29.4 VIX와 시장 관측: 기사 대신 수치 자료

- VIX는 SPX 옵션에서 계산한 향후 30일 예상 변동성이며 비방향성 지표다([Cboe 설명](https://www.cboe.com/tradable-products/volatility-trading/)). 하락의 원인 그 자체·매수/매도 신호·다음 반등 보장이 아니다. 기존 QS-VIX(124) 기각은 유지하며 이 초안으로 재개하지 않는다.
- **필드:** 관측 값·전일 대비 포인트/변화율·최근 흐름·분석 시점 이전의 과거 분포 내 위치·시장 세션/관측/공개/수집 시각·종가/지연/장중 구분. 분포 기간/최소 관측 수는 기능 설계에서 고정하고 성과를 보고 고르지 않는다. VIX 현물 지수와 VIX 선물/ETF 가격을 혼동하지 않는다.
- **무료 첫 경로:** [Cboe 일별 역사 자료](https://www.cboe.com/tradable_products/vix/vix_historical_data) 및 기존 무료 자료 확보 방식의 갱신/이용 조건을 감사한다. 전일 종가만 있으면 "오늘 장중 VIX"로 표시하지 않는다. 지연 호가 페이지를 자동 긁어도 된다고 가정하지 않는다. 최신 값 없으면 마지막 기준일/지연·미확보를 표시하고 현재 위험을 확정하지 않는다.
- 시장/업종/종목의 동일 시간 구간 등락·거래량, 국채 금리·환율 등은 검증된 수치 입력으로 별도 전달한다. 뉴스에서 추측한 값으로 채우지 않는다. 출처·거래일·시각·통화·수정 가격/배당락/분할 기준을 맞추며 국내 분석에서 미국 지표의 시차를 명시한다. 현재 확보한 일봉으로 장중 하락 시작 시각을 알아냈다고 주장하지 않는다.

### 29.5 무료 자료·시각·중복 계약

- 우선 자료: 기업 공식 IR, 미국 [SEC EDGAR](https://www.sec.gov/edgar/search/), 한국 DART/KIND, 한국은행·연준·BLS·BEA의 공식 발표. RSS는 기존 제공 주소의 현재 접근 가능성·이용 조건·본문 범위를 다시 확인한다. 유료 구매·유료벽/접근 제한 우회·무승인 가입 금지. 공식 자료 무료와 자동 수집 허용/완전성은 별개다. 출처별 연결 방식/호출 한도/식별 헤더는 Claude가 감사한다.
- **당일 사건:** 시장별 직전 거래일 마감~분석 시각에 처음 공개/확인된 자료. 최근 7일 관련 자료는 "배경"으로 별도 표시. 휴장·주말·서머타임·미국/한국 거래일을 명시하고 미장 전일 사건을 국장 당일 발표로 바꾸지 않는다.
- 사건 발생 시각·최초 공개/공시 접수 시각·기사 수정 시각·최초 수집 시각·분석 기준 시각을 구분한다. 발표 시각만으로 당시 수집/본문 열람을 인증하지 않는다. 시간이 불명이면 순서 불명으로 남긴다. 나중에 수정한 기사를 원래 시점 분석에 소급 넣지 않는다.
- 모든 항목에 원출처 URL·제목/확보 요약 또는 허용 본문·기업/사건 ID·자료 버전/해시·확보 범위·출처/자료 오류를 저장한다. 동일 사건 기사 재전송과 번역/재게시를 묶고 독립 검증 근거인지 구분한다. 유명 기업 기사 수가 많다는 이유로 중요도를 높이지 않는다.
- API 무료 상한·일별 토큰/호출 예산·배치·실패 재시도·캐시를 사전에 정한다. 유료 모델/유료 검색으로 자동 전환하지 않는다. 호출 한도 소진/장애는 "분석 보류"이며 평온/악재 없음으로 대체하지 않는다. 무료 범위를 계정 설정 없이 추정하지 말고 모델별 가용 기능을 감사한다([Gemini 요금 안내](https://ai.google.dev/gemini-api/docs/pricing)).
- 입력에는 공개 시장 자료만 사용한다. 키·계좌번호·개인 잔고·메일 등 민감정보 전송 금지. 무료 서비스 데이터 이용 조건을 명시한다([약관](https://ai.google.dev/gemini-api/terms)). 모델·공급자·프롬프트/스키마 버전·입력 해시·응답·분석 시각을 저장하며 `latest` 이름만으로 동일 모델 재현성을 보장하지 않는다. 원자료·응답 저장과 캐시 재생으로 검산한다. 원자료는 운영 보존 정책 아래 관리하고 이 초안으로 자동 삭제하지 않는다.

### 29.6 Gemini 역할·출력 계약·환각 방지

**역할 분리:** 코드 = 가격/비중/기여도·시각·자료 품질 계산, 수집기 = 공식/기사 원문 확보, Gemini = 전달 자료의 요약/사건 분류/설명 후보 정리, 검증기 = 사실의 출처·값·시각·논리적 근거 검산. 검색을 쓰지 않는 첫 버전은 제공 자료 밖 최신 사실을 알아온 척하지 않는다.

출력은 `확인된 사실 / 원인 후보 / 반대 근거 / 확인 불가 / 추가 확인 대상`으로 고정한다. 주장의 근거 ID·원문 구절·공개 시각·시장/업종/종목 관련성·확보 범위를 함께 표시한다. 지표 수치는 코드가 만든 값을 그대로 사용하고 모델이 가격/금리/시총을 만들어 넣지 않는다. 구조화 JSON 유효성만 통과했다고 사실 정확성 합격으로 처리하지 않는다.

- 없는 ID/URL·원문에 없는 숫자·시각 모순·다른 기업/기간 혼입·미확보 본문 인용은 확인된 사실 출력에서 제외하고 실패 사유를 남긴다. 구절 존재 검사는 최소 조건이며 해당 구절이 그 주장을 실제 지지하는지 별도 검산한다.
- 불확실한 인과 설명은 반드시 후보로 표시한다. 상승한 종목/업종 등 반대 근거도 제공하고, 여러 사건이 동시에 발생하면 단일 원인으로 강제 선택하지 않는다. 거래량 증가를 기관 매도 증명으로 해석하지 않는다.
- 모델 자기 확신 0~1을 정확도 확률로 표시하지 않는다. "공식 원문 확인 / 기사·요약만 확인 / 근거 부족 / 시각 불명" 같은 **증거 상태**를 표시한다. 공식 공시에 적혔다는 사실과 공시 내용의 미래 전망이 실제로 맞는지는 별개다.
- 외부 문서/모델 출력은 비신뢰 데이터다. 기사 속 명령·프롬프트를 실행 지시로 해석하지 않는다. 주문·환경변수·파일 삭제·도구 실행 권한을 주지 않는다. 읽기 전용 브리핑은 자동매매 엔진과 독립한다.

### 29.7 검증·판정 기준: 수익이 아니라 사실 품질

먼저 원자료/시각이 고정된 **기능 검산용 약 30개 사례**를 제안한다. 표본 수는 정확도/인과성/수익성의 통계적 입증이 아니다. 기업 공식 실적/증자, 시장 공통 발표, 대형주·업종 파급 후보, 신규 사건 없음, 상충 기사/늦은 수정, 배당락/분할, VIX 지연/누락, 모델/API 실패를 포함한다. 급락한 성공 사례만 고르지 말고 긍정/중립·원인 불명도 포함한다. 검산 기준은 출력 열람 전에 확정하고 사람이 확인한 원문 사실/시각과 비교한다.

**필수 기능 합격 조건 초안:** 확인된 사실의 출처 연결·숫자/단위/기업/기간 대조, 분석 시각 이후 자료 배제, 종가/지연/누락 표시, 반복/수정 기사 처리, 인과 후보와 사실 분리, 원인 불명/오류의 정상 표시가 테스트에서 만족돼야 한다. 허위 출처·숫자·최신 시각·현재 순위를 사실로 내보내는 중대 오류가 있으면 공개/예약 전 수리·재검산한다. 출처 검사 100%는 링크 형식 검사만으로 달성한 것으로 간주하지 않는다.

사람은 주장별 사실 오류·근거 미지원·시각 오류·누락·반대 근거·불명 처리와 출처별 커버리지/지연·무료 호출 예산을 보고한다. "공식 악재 못 찾음"과 "모든 악재가 없음"을 구분한다. 사건 관련성·설명 적절성은 평가자 해석이 섞이므로 정답 원인으로 확정하지 않고 미일치/불명을 남긴다. 작은 검산에서 오류가 없었다고 100% 정확도로 홍보하지 않는다.

기능 검산 후 별도 전향 브리핑을 쌓고 원문과 대조한다. 자료를 열람한 자산/기간/종류는 [열람 장부](DATA_EXPOSURE_LEDGER.md)에 남기는 계약을 적용하며, 설명 도구의 개발/가격 열람으로 사용한 구간을 나중에 매매 연구의 미열람 OOS라고 부르지 않는다. 기존 전향 전략 원장/판정 창을 변경하지 않는다. **수익 개선·자동 방어/복귀 연결은 이번 목적 밖**이며 필요하면 새 독립 가설·사전등록·80% 검정력·미열람 검증·사용자 승인을 거쳐야 한다.

### 29.8 Opus 인계와 결과

1. 기존 뉴스/테마/시세 경로를 읽기 전용으로 감사하고 재사용/부족 필드와 출처 접근·이용 조건을 표로 작성한다. 현재 제목 위주 분석을 원인 판정기로 소개하지 않는다.
2. 여섯 사건군, 대형주 시총/지수 선정·무료 커버리지, VIX 시각/지연과 같은 구간 가격/기여도 계산 가능성을 점검한다. 미확보 자료·축소 대안은 명시하고 범위 변경을 사용자에게 확인한다.
3. 정보 도구의 자료/출력/모델·예산·캐시·보안·보존·검산 계약을 확정한다. 자료가 부족하면 설명 범위를 줄이거나 보류하며 매매 안전 원칙을 완화하지 않는다.
4. 사용자 구현 요청 후 Claude가 기존 주문 경로와 분리된 정보 도구를 구현/시험한다. 검산을 마친 뒤 저장 보고서 기반 읽기 전용 대시보드·선택 알림을 연결한다. 새로운 수집/알림 예약 등록은 별도 승인 범위다.

**결과: 아직 구현/신규 수집/정확성 검산 없음.** 정보 도구 초안 등록이지 Phase 4 수익 검증이나 새로운 VIX/대형주 매매 전략의 사전등록이 아니다. 기존 26~28 감사의 중단/보류, 25 판정 및 모든 연구/운영 상태는 유지한다.

## 26~28번 후속 연구 인계 — 방어와 복귀 / 실제 배분 / 한국·미국 개별주 (2026-10-08, Codex)

**상태: Phase 0 / DRAFT / NOT_TESTED.** 사용자는 세 방향을 연구 대상으로 선택하고, 특히 26번에서 "손실을 피하더라도 복귀를 못해 수익이 적어지면 안 된다"고 요청했다. 이번 작업은 상세 초안과 Opus 인계 기록이다. 신규 자료 수집·모델 학습·백테스트·판정·코드/설정/예약/실거래 변경은 하지 않았다. Claude는 자료와 검정력 감사 → 필요 시 성과 전 초안 보정/이유 기록 → 확정 커밋 → 미열람 자료에서 1회 판정 순서로 진행한다. 아래 숫자가 미정인 계약은 확정 사전등록이 아니며 임의 값으로 실행하지 않는다.

### 26.1 목표·현행 한계·기존 기각과의 경계

**가설:** 동결 O/v2의 선물 추가 노출을 위험할 때 줄이고, 위험이 완화되면 원래 목표로 복귀하는 하나의 인과적 규칙이, 추가 비용까지 차감한 전체 수익을 유지/개선하면서 손실 위험을 줄일 수 있는가? 새 방향 예측·숏 전략이 아니라 기존 선물 롱 오버레이의 위험/복귀 관리 연구다. 기존 현물 T/v2 매매를 바꾸지 않는다.

- O/v2의 과거 CAGR 31.7%·MDD 23.2%는 [기존 판정](../current/RESEARCH_HISTORY.md)의 역사적 수치이지 미래 보장·새 연구 결과가 아니다. 일봉 손절 시뮬레이션, 실제 mark 기준 보호 주문, 지정가 미체결·부분 체결·갭 사이의 차이를 먼저 감사한다. 비용/체결 현실화로 기존 성과가 약해지면 그 사실부터 보고한다.
- **B′ 기각:** 변동성 급증 때 선물을 끄는 판은 MDD 감소가 0이었다. 급락 탐지만으로 느린 하락의 손실을 막는다고 가정하지 않는다([43](43-vol-spike-overlay-cap.md)).
- **F2/F3 기각:** 추세 20·60·120일이 모두 양수일 때만 선물 추가·선물부터 축소하는 판도 기준 미달이었다. 조건 수/기간/배수만 바꿔 재시도하지 않는다([64](64-o-futures-first-derisk.md)).
- **DDL 기각:** 계좌 고점 대비 낙폭에 연동해 노출을 줄인 판은 MDD를 줄였지만 CAGR이 O/v2보다 낮았다. 과거 고점 아래 장기간 머물며 선물 복귀가 늦어진 것이 핵심 경고다. 고점 창·낙폭 문턱만 바꿔 같은 자료에서 고르지 않는다([83](83-h2-drawdown-linked-leverage-preregistration.md)).
- 따라서 "차트는 방어용"이라는 이름만으로 새 연구가 되지 않는다. Claude가 기존 규칙과 입력·상태·복귀 조건을 대조해 **새 검증 가능한 차이와 미열람 표본**을 확인하지 못하면 중복/보류로 종료한다. Elliott/JEV/News AI는 현재 Shadow 전용이므로 주문·veto·사이징에 사용하지 않는다.

**보완 시 기대 이점(미검증):** 신호의 방향 적중률을 높이는 대신, 이미 통과한 추세 노출의 손실 구간과 반등 참여를 함께 관리한다. 낙폭 감소와 수익 보존을 동시에 입증할 때만 개선이며 "더 안전해서 수익이 낮아도 성공"으로 목표를 바꾸지 않는다.

### 26.2 가장 중요한 설계: 방어와 복귀를 같은 상태 규칙으로 고정

권장 연구 구조는 `NORMAL → DEFENSIVE → RECOVERING → NORMAL`이다. 이는 **경제적 노출 상태**이며 RUNNING/HALTED 같은 실행 안전 상태와 구분한다. 신규 진입·복귀에는 항상 현재 안전 게이트가 우선한다.

| 상태 | 관측/행동의 초안 | 복귀·후퇴 계약 |
|---|---|---|
| NORMAL | 동결 O/v2가 그 시점에 산출한 목표 선물 수량 유지 | 사전 정의 위험 조건을 만족하면 DEFENSIVE. 위험 신호가 없다고 기준 목표보다 더 늘리지 않음 |
| DEFENSIVE | 선물 추가분만 미리 정한 비율로 축소/해제. 현물 규칙은 불변 | 마감봉 기준 위험 완화와 현재 O/v2 진입 자격을 함께 확인. 과거 계좌 고점·매도 가격을 회복할 때까지 무조건 기다리는 조건은 제안하지 않음 |
| RECOVERING | 현재 O/v2 목표의 고정 일부로 복귀하고, 미리 정한 확인 조건에서 나머지 복귀 | 위험 재발 시 축소, 기준 목표가 0이면 복귀 중단. 단계·확인 횟수·분할 비율·중단 우선순위를 성과 전 고정 |
| NORMAL 복원 | 현재 기준 목표까지만 복귀 | 옛 포지션 수량 복원이 아니라 현재 변동성/자금/목표 재평가. 체결·보호 확인 전 복귀 완료로 기록하지 않음 |

**복귀 연구에서 성과 전에 결정할 항목:**

1. **방어 신호의 역할:** 가격 구조 손상(예: 확정된 지지 이탈)과 변동성/갭 위험 중 기존 기각과 다른 경제적 근거가 있는 한 가족만 선택한다. RSI·MACD·패턴을 많이 붙여 수익이 좋은 조합을 고르지 않는다. 예시는 후보 의미 설명이지 진입 규칙 확정이 아니다.
2. **복귀 신호의 역할:** "손실 전 가격까지 회복"이 아니라 현재 위험 조건의 해소와 기준 추세 자격을 사용한다. 구조 회복을 쓴다면 언제 확정되는지·허용 오차·필요한 마감봉 수를 함께 정한다. 미래 스윙·최종 저점·차후 반등으로 과거 복귀 신호를 덮어쓰지 않는다.
3. **빠른 복귀와 가짜 반등의 균형:** 즉시 전량 복귀와 단계적 복귀는 성과로 겨루는 여러 파라미터 판이 아니라 **자료/집행 가능성과 위험 논리로 사전에 하나를 고르는 설계 대안**이다. 위 상태표는 단계적 복귀 제안이며 최종 선택·비율은 미정이다. 같은 OOS를 보고 단계를 바꾸지 않는다.
4. **히스테리시스:** 축소 조건과 복귀 조건의 경계를 달리해 작은 흔들림으로 매번 왕복하지 않도록 정의한다. 조건이 좋아진 뒤에도 끝없이 대기하지 않도록 평가 주기·확인 기간·미충족 사유를 기록한다. 그러나 일정 시간이 지났다는 이유로 위험 지속/기준 신호 0에서 강제 매수하지 않는다.
5. **현재 목표와 기존 대기 규칙:** 복귀는 목표 수량과 현재 체결 수량의 차이만 주문한다. 재진입 60분·연패 대기 등 현행 위험 게이트는 자동 완화하지 않는다. 경제적 부분 증액이 기존 코드에서 어떤 게이트를 받는지 감사하고 충돌은 미해결로 보고한다. 하루 거래·같은 방향 연속 진입 제한을 새로 만들지 않는다.
6. **안전과 재시작:** 결측/stale/UNKNOWN/보호 불명에서는 복귀 금지·위험 축소 허용. 계좌 DD HALTED는 사용자 확인 없이는 해제하지 않는다. 가격 반등으로 안전 정지를 자동 복구하는 규칙은 금지다. 부분 체결·재시작·중복 주문·대기 진입 주문·스톱 교체 상태를 지속 저장하는 구현 계약이 필요하다.

입력 시간대·봉 경계·스윙 확인 시각·위험/복귀 수식·축소 비율·최대 확인 지연·실행 한도를 모두 확정 커밋에 명시한다. 이미 읽은 과거 경로는 실패 원인 진단/개발 자료일 뿐 새로운 OOS가 아니다. 복귀 로직의 설계는 결과 열람 전에 끝내야 한다.

### 26.3 데이터·진입/청산·비용 계약

- 동일 BTC·ETH 현물/선물·funding·mark/보호 기준·당시 주문 규격·동일 초기 자본으로 O/v2 기준선과 비교한다. 위험 신호에 쓰는 봉은 판단 시점까지 마감/가용된 것만. 자금 부족·최소 수량·수량 내림·보호 공백을 이상적인 연속 비중 계산으로 숨기지 않는다.
- 일반 축소·복귀 주문은 **가격 한도 지정가**. 미체결 때의 재평가/취소/부분 체결/가격 한도를 사전 고정하고, T/v2 시장가 추격 예외를 새 선물 복귀에 가져오지 않는다. 기존 거래소 비상 STOP_MARKET·보호 실패 정리 예외는 유지한다([TRADING_CORE](../current/TRADING_CORE.md)).
- 기존 O/v2의 기준 목표/−20% 비상 보호/증거금·레버리지·계좌 한도는 바꾸지 않는다. 목표보다 작은 노출이라고 보호·청산 위험 검사가 면제되는 것은 아니다. 데모·Paper·실거래 실행은 별도 게이트/승인 대상이다.
- 수수료·spread·체결 슬리피지·미체결 기회 손실·funding·stop 갭·재진입 반복 비용을 포함한다. 비용 자료가 없으면 현실화 검증 완료라고 주장하지 않는다. 불리한 비용 스트레스 폭은 성과 전 고정한다.

### 26.4 방어 에피소드 원장: 피한 손실과 놓친 상승을 모두 센다

에피소드는 **최초 방어 결정 시각**에 시작해 완전 복귀/기준선의 자연 청산/사전 고정 종료 조건에서 끝낸다. 중첩 방어는 같은 에피소드에 귀속하며, 끝까지 복귀하지 않은 것은 마지막까지 열린 사건으로 남긴다. 성공적으로 복귀한 사건만 골라 계산하지 않는다.

| 기록 | 계산/해석 원칙 |
|---|---|
| 방어 시점/노출 차이 | 판단 시각·정보 가용 시각·기준 목표/실제 체결 수량·축소 사유·미체결 수량 |
| 피한 하락 손실 | 기준선 대비 줄인 노출이 하락 구간에서 절약한 가격 손익. 위험 구간을 미래 저점으로 재정의하지 않음 |
| 놓친 상승 수익 | 줄인 노출 때문에 상승 구간에서 놓친 가격 손익. 방어부터 복귀 완료/고정 종료까지 전부 포함 |
| 추가 비용·funding 차이 | 실제 축소/복귀 거래비용과 기준선 비용 차이, funding 지급/수취 차이. funding 감소를 무조건 이익으로 부르지 않음 |
| 복귀 뒤 재차 손실/회복 참여 | 복귀 후 고정 관측 구간의 가격 손익·추가 방어·왕복 비용. V자 반등·완만한 상승·가짜 반등·지속 하락을 같은 원칙으로 보고 |
| 미복귀/지연 | 자격 회복부터 의도/체결/완전 복귀까지 지연, 미복귀 이유, 대기 중 누적 기회 손익, 미체결·안전 차단을 분리 |
| 전체 결과 | 동일 기간·자금 조건의 최종 순자산/CAGR·MDD·하방 꼬리·수중 기간·회전율·연도/구간별 증분 |

**회계 항등식:** 기준선과 후보의 순자산 차이를 가격 손익 차이 + funding/현금 수익 차이 − 거래비용 차이로 먼저 대조한다. "피한 하락"과 "놓친 상승"은 같은 가격 손익 차이의 분해이고, 복귀 뒤 손익도 같은 가격 원장의 부분 집계다. 전체 차이에 다시 더하거나 빼서 이중 계산하지 않는다. 반등 시작/최저점/회복 속도 등 미래를 알아야 정하는 분류는 사후 진단 전용이며 주문 입력이 아니다.

**사용자가 보고 싶은 결론:** "손실 X를 피했지만 상승 Y와 비용 Z를 잃었고, 완전 복귀/미복귀까지 포함한 최종 차이가 얼마인가?"를 에피소드별 및 전체 계좌로 함께 제시한다. 반등 일부에 참여한 것만으로 수익 보존을 선언하지 않는다.

### 26.5 대조군·검정력·채택/버림 기준

- **주 대조:** 동결 O/v2 vs 사전에 선택한 방어+복귀 한 규칙. 같은 날짜·자금·현물·체결/비용 계약을 쓴다. 위험관리의 효과와 체결 가정 변경의 효과를 섞지 않도록 기존 역사 재현과 현실화 기준선의 차이를 별도로 보고한다.
- **필수 보조 대조:** 항상 선물 추가분을 작게 유지하는 고정 노출 축소판. 비율은 성과 전에 고정하며 OOS에서 나온 후보 평균 비중에 맞춰 역선택하지 않는다. 차트 없이 단순히 덜 투자한 효과인지 구분한다. 복귀하지 않는 방어판은 미리 정한 종료 경계의 진단용이며 실거래 제안/최종 채택 후보가 아니다.
- **Phase 0 관문:** 성과를 보기 전에 최소 의미 있는 낙폭/하방 개선 폭, 비용 후 증분 수익의 최소 효과, 독립 블록/에피소드 정의와 필요한 표본을 정한다. 공통 시장의 BTC·ETH·겹친 복귀 사건은 독립 표본으로 부풀리지 않는다. 정책 80% 검정력이 없으면 `DATA_INSUFFICIENT`/전향 기록 계획으로 멈춘다. 사건이 적다고 기간/조건을 늘려 유의성을 만들지 않는다.
- **공동 채택 조건:** (1) 비용 후 전체 수익/CAGR이 기준 O/v2 이상이고, (2) 사전 고정 하방 개선 기준을 충족하며, (3) 증분 효과의 불확실성 기준(원칙상 paired 평균의 2SE 하한 양수, 계열 의존성 보정)을 충족하고, (4) 사전 구간/비용 스트레스에서 효과가 한 번의 폭락/반등에만 의존하지 않으며, (5) 기존 계좌/보호/주문 게이트를 통과해야 한다. 구체적인 블록·단측 검정·경제적 문턱은 감사 뒤 확정한다. 하나라도 미달이면 채택하지 않는다.
- **수익 유지의 의미:** 낮은 MDD·높은 샤프만으로 수익 감소를 합격 처리하지 않는다. 표본 수익이 비슷하다는 사실만으로 미래 수익 비열등을 입증했다고 부르지 않는다. 수익 감소 허용폭은 현재 사용자 목표에 따라 **0**이며 임의로 1~2%p로 완화하지 않는다. 통계적으로 결론을 낼 수 없으면 보류/자료 부족이다.
- 이미 본 자료에서는 실패 원인/회계/코드 검산까지만. 최종 확인은 확정 뒤 미열람 자료 또는 별도 전향 Shadow 계획을 사용한다. 기존 [O/v2 전향 등록](28-o2-paper-forward-registration.md)의 원장/종료일/판정 조건을 덮어쓰지 않는다. 새 관찰 시작·수집 예약은 승인 후 별도 기록한다.

**결과: NOT_TESTED.** Opus 첫 산출물은 기존 기각과의 중복 감사, 현재 실행/가격/비용 차이, 방어·복귀 공동 계약 한 개, 검정력, 미열람 구간 확보 여부다. 유효한 차이/표본이 없으면 구현하지 않는다.

### 27.1 가설·현행 한계·보완 이점

**가설:** 동결 T/v2와 미국 주식 운용을 실제 적립/입출금·환율·현금·거래비용 조건에서 함께 배분하면, 현재 병행 운용보다 비용 후 계좌 수익을 유지/개선하면서 집중/낙폭을 줄일 수 있는가?

[ALLOC 판정](127-crypto-stock-allocation-preregistration.md)은 무레버리지 QQQ 추세와 코인 T/v2의 배분 권고였다. 실제 QNDX 적립·QS_SWITCH의 TQQQ·계좌 간 이동·리밸런싱 비용이 같은 조건으로 검증된 것이 아니다. 낮은 과거 상관도 미래 위기에서 유지된다고 가정하지 않는다. 보완 이점은 새 예측이 아니라 실제 자금 배분의 중복 위험·유휴 현금·마찰을 줄일 여지이며 수익 개선은 미검증이다.

### 27.2 자료 → 배분/매매 정의 → 비용 → 판정 → 결과

- **자료:** 실제 상품 식별/거래 통화/추적 지수/수수료, 당시 가격과 환율, 현행 적립·QS_SWITCH 규칙, 사용자 제공 입출금 기록을 감사한다. QNDX를 QQQ로 자동 치환하지 않는다. TQQQ는 일일 재설정 상품의 실제 가격/분배금 이력으로 평가하며 QQQ 수익률 ×3을 실제 성과로 쓰지 않는다([SEC 설명](https://www.sec.gov/files/investor/pubs/leveragedetfs-alert.htm)). 다른 개별주 적립은 별도 슬리브로 분리하고 전략 수익에 섞지 않는다.
- **회계:** TWR(외부 자금 효과 제거), MWR/XIRR(투자자가 실제 경험한 수익), 순납입액/최종 자산을 함께 보고한다. 실제 흐름이 없으면 사전에 고정한 가상 적립 일정이라고 표시하고 계좌 검증으로 부르지 않는다. 같은 입출금·기준 통화·현금 수익을 모든 대조에 사용한다.
- **배분 정의:** 코인/미국 주식 목표 비율·리밸런싱 주기/허용 띠·새 납입금 우선 배분·매매/이체 우선순위·현금 부족 처리·계좌 위험 집계는 성과 전 한 계약으로 고정한다. 실제로 이동 불가능한 계좌 간 즉시 재배분을 가정하지 않는다. 원래 전략 진입/청산 규칙은 고정한다. 일정/적립금/레버리지/운영 계좌를 이번 문서로 변경하지 않는다.
- **비용:** 지정가 미체결·최소 주문·수수료·환전 spread·이체 지연/비용·현금 대기·계좌별 적용 가능한 세금 회계를 감사한다. 세율을 임의 확정하지 말고 확인된 조건과 가정을 나눈다. 실제 ETF 가격에 포함된 보수를 다시 차감하지 않는다. 리밸런싱으로 추가 실현/환전이 생기는 부담을 누락하지 않는다.
- **대조/판정:** 현행 병행 운용 vs 고정 비율 단순 배분 vs 선택한 현실화 배분을 최대 세 구조로 비교하되 성과로 비율을 탐색하지 않는다. 26과 혼합하지 말고 우선 기존 T/v2/QS 규칙 그대로의 계좌 효과를 분리한다. 비용 후 수익 보존·사전 고정 위험 개선·독립 월/블록·paired 증분 불확실성과 80% 검정력을 확정한다. 기존 ALLOC 기간을 새 OOS로 부르지 않는다. 효과가 가상의 무비용 이체/한 장세에만 있거나 표본 부족이면 채택하지 않는다.
- **결과: NOT_TESTED.** Opus는 127의 회계와 현재 상품/적립 조건 차이표부터 작성한다. 별도 계좌 조회·API 키 확인·주문·예약 활성화는 이번 작업에 포함하지 않는다.

### 28.1 한국 FLOW: 통과 효과가 무엇인지부터 분해

**가설:** 기존 FLOW-KR/KQ의 EW 대비 우위에 수급 정보의 고유한 기여가 있는지, 아니면 대형/저변동성/저회전·섹터·최근 상승장이 설명하는지 구분한다.

현행 [판정](../current/RESEARCH_HISTORY.md): FLOW-KR 연 5.1%는 KOSPI 7.6%보다 낮고 MDD 45.7%; KQ 연 3.5%는 코스닥 지수 3.2%와 비슷하며 MDD 55%. 둘 다 2026 성과 의존과 약한 종목 단위 수급 예측이라는 한계가 있다. PASS를 현행 계좌 30% 위험 한도 안의 실거래 자격으로 해석하지 않는다.

- **자료/대조:** 기존 종목군/룰 고정 상태에서 당시 섹터·시총·변동성·거래대금·추세·회전율을 맞춘 수급 없는 대조와 비교한다. 당시 가용 시각·폐지/종료 회계·집계 누락을 점검한다. 종목 수만큼 독립 표본이 있다고 보지 않는다.
- **보완 정의:** 먼저 기여도/집중/비용 분해만 한다. 이를 본 뒤 과거 성과가 좋은 창·섹터·종목 수로 고친 판은 금지다. 고유 효과가 없으면 수급을 새 수익원으로 주장하지 않는다. 규칙 변경이 필요하면 새 가설·미열람 자료·사용자 선택으로 분리한다.
- **비용/판정:** 동일 지정가·회전·비용의 기준선 및 적절한 시장 지수와 비교한다. 기존 노출/대형주 효과를 통제한 증분의 사전 기준과 80% 관문을 충족해야 신규 검증으로 진행한다. 역사 분해는 새 OOS 판정이 아니다.
- **기대 이점(미검증):** 성과를 수급 덕으로 오인하지 않고 단순/저비용 대조와 무엇이 다른지 파악한다. 원래 연구 판정을 덮어쓰지 않는다.

### 28.2 미국 개별주: SEC 13F 기관 보유 변화의 별도 가설

**가설:** 공시된 기관의 개별주 보유 수량 변화가 기존 가격 추세/섹터/규모와 다른, 공개 후 비용 차감 수익의 추가 정보를 주는가? 한국 일별 수급을 미국에서 똑같이 재현하는 연구가 아니다.

- **자료의 의미:** 13F는 분기말 보유를 나중에 보고하는 자료이며 일반적으로 분기말 뒤 45일 이내 제출한다. 실제 매수 날짜/가격·일별 순매수·순숏은 알 수 없고 short position을 long에서 빼서 보고하는 자료도 아니다. 워런 버핏 등 유명 기관을 사후 선택하거나 기관 의도를 단정하지 않는다([SEC FAQ](https://www.sec.gov/rules-regulations/staff-guidance/frequently-asked-questions-about-form-13f), [공개 데이터](https://www.sec.gov/data-research/sec-markets-data/form-13f-data-sets)).
- **PIT 관문:** 분기말 날짜가 아니라 원본 공시의 실제 공개/접수 시각 이후부터만 사용한다. amendment·비공개 보유의 늦은 공개를 원래 분기로 소급하지 않는다. 운용사 CIK와 발행사 식별을 구분하고 CUSIP→당시 ticker/상장·폐지 이력, 기업행동, 분할을 점검한다. 보유 가치의 상승을 매수로 부르지 않고 조정 수량 변화를 감사한다. 2023 전후 보고 금액 단위 변경 등 스키마 차이도 확인한다.
- **집계 관문:** 같은 두 분기에 관측된 기관의 보유 변화와 신규/탈락 기관을 분리한다. 보고 없음·비공개·면제/소액 누락을 0 보유로 채우지 않는다. 공동/상위·하위 운용사 중복·옵션/ETF/비보통주 혼입을 제거하는 기준과 기관 종목군을 사전에 고정한다. 운용사 수준 자료만으로 펀드별 능동/수동 매수를 분리했다고 주장하지 않는다.
- **무료 자료 관문:** SEC 공시는 무료여도 미국 상장폐지 가격·PIT 식별/섹터/주식 수 이력 확보는 미확인이다. 현재 살아남은 미국 종목만으로 PASS를 만들지 않는다. 기존 미국 실적 연구의 폐지 가격 병목을 함께 점검하고, 유료 구매 없이 해결 못 하면 `DATA_NOT_READY`. 전향 자료 수집은 명세와 승인 후 별도 진행한다.
- **진입/청산 초안:** 공시 기반 기관 보유 증가로 LONG 종목 선택만 제안한다. 정확한 변화 정규화·공시 대기·판단일·유니버스·보유/교체·추세 게이트는 자료 감사 뒤 성과 전에 하나로 고정한다. 감소를 대칭 SHORT으로 만들지 않는다. 개별주 기본 가격 모델/섹터·규모 대조에 추가하는 효과를 검증하며 한국 FLOW를 그대로 이식했다고 부르지 않는다.
- **비용/판정:** 지정가·거래대금/최소 주문·기업행동/폐지 정리·교체 비용·통화 기준을 포함한다. 주 비교는 같은 입력/노출 조건에서 기관 보유 변화 추가판 − 없는 판. 지수는 당시 유니버스와 맞는 것을 사전 지정한다. 분기·공시 군집·공통 시장 의존을 반영한 80% 검정력, 비용 후 증분·두 사전 구간·집중/위험 기준을 확정한다. 많은 종목 행이 적은 독립 분기를 대체하지 않는다.
- **결과: NOT_TESTED.** 보완 시 기대 이점은 미국 개별주에 가격 밖의 관측 정보를 추가해 볼 수 있다는 것이며, 정보 지연/가격 반영 때문에 edge가 없을 가능성도 그대로 검증한다. 기관 매수 추종의 수익 보장은 아니다.

### Opus 진행 순서와 경계

1. **26번:** 기존 기각 중복과 실제 O/v2 비용/집행 차이 감사 → 방어와 복귀를 묶은 단일 계약 및 에피소드 회계/검정력 계획. 수익이 줄어드는 방어를 성공으로 취급하지 않는 판정 조건을 먼저 확정한다.
2. **27번:** 실제 상품·적립·환율/계좌 이동/세금/비용 회계 감사 → 현행 병행 운용 대비 배분 효과의 독립 검증 설계. 26번의 미검증 규칙을 집어넣지 않는다.
3. **28번:** 한국 FLOW 기여도 분해와 미국 13F 무료/PIT/폐지 자료 가능성 감사는 별도 트랙. 가능할 때만 미국 개별주 사전등록 초안을 확정한다.

사용자가 세 방향을 선택한 것은 대규모 조합 탐색·안전 한도 완화·미검증 운영 적용 승인이 아니다. 각 트랙에서 여러 새 전략 후보가 생기면 최대 3개를 비교하고 사용자 선택 하나만 구현한다. 기존 IDEAS 5·25 및 Opus 진행 중인 161, T/v2·O/v2 등 운영/전향 관찰·일정은 유지한다. 이번 세 초안의 연구 결과는 모두 미실행이다.

### 25.1 가설과 기존 연구와의 차이

**질문:** 같은 가격·거래량 관측값에서도 변화가 발생한 순서를 보존하면, 단순 추세 및 순서를 제거한 동일 정보보다 이후 수익 예측과 비용 후 성과가 나아지는가?

예: "상승 → 거래대금 감소와 작은 조정 → 가격 유지"와 "가격 유지 → 거래대금 증가와 상승 → 상승분 반납"을 구분해 기록한다. 어느 경로가 유리한지, 큰 거래량이 기관의 매수/매도인지 미리 단정하지 않는다. 가능한 원인은 주문의 시간 분산·충격 뒤 가격의 유지/소멸이지만 **원인 미확인 가설**이며 OHLCV만으로 참여자 의도나 인과성을 식별하지 못한다.

H1·KB·158/159처럼 정해진 돌파/반전 모양의 완성 여부를 매수 조건으로 쓰는 대신, 같은 구간 관측값의 **시간 순서 표현이 더하는 효과**를 비교한다. 다만 가격·거래량을 재표현한 것이므로 새 수익원을 확보한 것으로 간주하지 않는다. [34항목 감사](INDICATOR_COMBINATION_PHASE0_AUDIT.md), H1·KB·158/159, [DMN 감사](DMN_PHASE0_AUDIT.md)와 입력·질문·표본·자유도를 대조한다. 기존 기각 규칙의 이름/기간/조건만 바꾸는 재시도라면 중복으로 종료한다. DMN의 표본 부족은 Ridge로 바꾸었다는 이유만으로 해결되지 않는다.

### 25.2 자료와 분석 단위

- 첫 감사 대상은 기존 무료 Binance 현물 USDT **폐지·거래 중단 포함 종목군의 4시간봉**. 종목군은 당시까지의 거래대금으로 정하며 현재 생존 종목으로 역선택하지 않는다. 기존 월별 선정에 사용한 기간·가용 시각·종료 회계를 재확인한다. 유료 자료는 구매하지 않는다.
- 입력은 마감된 4시간봉·일봉만 사용한다. 종목별 별도 모델 없이 공통 모델 하나. 상장 직후 warm-up, 누락/0 거래량, 토큰 교체·가격 단위 변경, 종료 종목의 label 처리를 성과 전에 고정한다. 종료 구간을 조용히 삭제하지 않는다.
- 판단 빈도·UTC 경계·자료 지연은 감사에서 확정한다. 4시간봉 입력을 4시간마다 독립 거래하는 것으로 오해하지 않는다. 기존 시스템 평가 주기/하루 거래 한도를 바꾸지 않는다.
- 주식은 이번 첫 실행에 섞지 않는다. 현물 차트의 정보가 확인되어도 선물 적용에는 당시 선물 상장·선물 OHLC/mark·funding·체결 규격과 비용 검증이 별도로 필요하다. 다종목 현물 또는 BTC 선물 실거래를 승인한 문서가 아니다.

| S: 순서 제거 | 같은 3개 구간을 수익률 순으로 정렬하고 각 구간의 수익·범위·거래대금 묶음은 유지 | 시간 순서를 잃은 정보의 예측력 |
| O: 순서 보존 | 같은 구간을 실제 발생 순서로 입력 | 시간 순서를 사용할 때 추가 효과 |

세 모델은 **Ridge 계열 하나**로 제안하며 S/O는 입력 수·전처리·상호작용 생성 규칙·벌점 규칙·학습 표본·가중치·재학습 일정을 맞춘다. 동률은 관측값에 의한 결정론적 정렬로 처리하며 원래 시간 인덱스는 전달하지 않는다. 같은 구간 집합의 순서를 바꾸면 S의 입력/예측은 같아야 하고 O는 달라질 수 있어야 한다.

정렬 대조는 정보 표현 비교이지 인과 실험이 아니다. 같은 차원이어도 벌점·상호작용·정렬로 모델의 유효 복잡도가 달라질 수 있으므로, 성과 없이 구조·합성 시험으로 공정성을 확인한다. O가 이겨도 모든 차트 시계열의 보편적 우위를 증명했다고 부르지 않는다.

**주 비교는 O−S**, B는 추세 기준선이다. 순서 비교의 주 예측 지표는 동일 평가 표본의 평균 제곱오차 차이 `MSE(S) − MSE(O)`를 제안한다. 양수는 개선을 뜻하되 거래 수익으로 대체하지 않는다. 정확한 loss·표본 가중치·Ridge 목적함수/벌점·최소 실질 개선량·불확실성 계산·다중 검정/계층 순서를 성과 전에 확정한다. TRAIN의 계수 추정은 허용하지만 모델/벌점/입력 조합을 넓게 탐색해 최고 성과를 고르지 않는다. CNN·LSTM·LLM 판독과의 성과 경연은 제외한다.

### 25.5 예측 대상 → 진입·청산·비용 계약

주 label은 **이후 5일 수익률 하나**를 제안한다. 수익 단위·label 시작 시각·상장 종료 처리를 확정하고 1/3/5/10일 중 최고 성과를 고르지 않는다. 사후 MFE/MAE·미래 고저는 입력으로 역유입하지 않는다.

예측력과 비용 후 거래 성과를 모두 확인하되, 아래 거래 계약은 **예측 성과를 보기 전에도** 확정해야 한다. 예측 결과를 보고 진입 문턱·방향·보유기간을 만들지 않는다.

- **진입:** 예측 수익과 당시 가용 왕복 비용 추정치를 연결하는 하나의 사전 지정 문턱. LONG/FLAT 또는 방향별 계약을 확정해야 하며 음수 예측을 자동 SHORT으로 만들지 않는다. 판단 이후 지정가 한도/유효시간/재시도·미체결·부분 체결·역선택을 명시한다. 신호 종가 즉시 체결 금지.
- **청산:** 5일 label과 실제 체결 이후 보유기간의 관계, 청산 미체결, 거래소 보호 스톱, 갭·동일 봉 순서, 종료 종목 회계를 고정한다. 5일은 이번 연구의 제안 평가기간이며 기존 전략의 최대 보유시간을 변경하지 않는다. 보호 스톱은 별도 승인 없는 임의 완화 금지.
- **비용·계좌:** 수수료·스프레드·슬리피지·유동성/규모·선물 funding 부호/정산·mark/청산·포지션 크기·동시 노출·계좌 정지 적용을 확정. 미래 실제 비용으로 진입 문턱을 정하지 않는다. S/O는 같은 거래 변환/위험 규칙을 쓰며 달라지는 진입 빈도·노출·회전율도 보고한다.
- **기준선·스트레스:** B·무작위 시점·동일 위험/노출 대조·단순 보유와 비교하고 비용 2배를 포함한다. 매수 한도 가격 자체를 항상 체결가로 가정하는 158의 오류를 반복하지 않는다. 선물 연구에 T/v2 시장가 추격 예외를 자동 상속하지 않는다.

미확정 거래·비용 계약이 있으면 순수 예측 연구의 범위/한계를 먼저 보고한다. 그 결과를 매매 PASS나 전체 Phase 4 통과로 쓰지 않는다.

### 25.6 분할·검정력·열람 경계

1. 기존 코인 자료의 연구/가격 열람 이력을 먼저 작성한다. 과거 시간 순서 fold는 개발·역사 검증이며 프로젝트 전체의 미열람 OOS가 아니다. 기본 12개월 TRAIN/3개월 평가의 적합성, 재학습 일정, label 5일 중첩 purge/embargo와 경계 포지션 처리를 성과 전에 고정한다. 달력 날짜 무작위 분할 금지.
2. 최종 확인에는 모델·전체 연구 절차 동결 뒤의 미열람 자료를 별도로 정한다. 기간·최소 표본·단일 판정일/중단 조건을 미리 적고 좋아질 때까지 관찰하거나 새 기간을 계속 연장하지 않는다. 이번 문서는 자동 수집/예약을 켜는 승인이 아니다.
3. 코인 수 × 봉 수를 독립 n으로 세지 않는다. 같은 날짜의 시장 공통 움직임·5일 중첩·종목 재등장·자산 간 상관을 보존하는 날짜 블록 불확실성 계산을 계획한다. 실제 거래 n은 label 수와 분리한다.
4. **80% 검정력 관문을 성과 실행 전에 적용한다.** 예측 loss 차이의 최소 실질 개선량/분산과 비용 후 거래 차이의 효과/분산은 서로 다른 계획이다. 근거 있는 기존·외부 계획용 분산이 없으면 미확인으로 보고하며 O/S 성과를 몰래 계산해 이를 대신하지 않는다. 계획용 파일럿이 필요하면 자료·열람·폐기 경계를 별도로 정한다.
5. 검출 가능한 최소 효과와 필요한 전향 관찰기간을 함께 보고한다. 표본/검정력 미달이면 `DATA_INSUFFICIENT`로 멈추며, 효과 가정을 높이거나 기준을 낮춰 진행하지 않는다. 큰 종목군이나 작은 모델이 이 관문을 자동 해결하지 않는다.

### 25.7 판정·실패 처리·현재 결과

- 자료/검정력 부족: `DATA_NOT_READY` / `DATA_INSUFFICIENT`. 전략 또는 차트 분석 전체의 실패로 부르지 않는다.
- 충분한 표본에서 O−S의 등록한 최소 추가 효과를 지지하지 못함: 이번 정의·모델 가설을 기각. 기간·지표·상호작용·방향을 바꿔 같은 자료에서 재판정하지 않는다.
- 예측력만 개선되고 비용 후 거래 우위 없음: 정보 증거와 매매 부적합을 구분한다. 적중률만으로 채택하지 않는다.
- 다음 검토에 필요한 것: O−S 및 단순 기준선 대비 사전 지정 추가 효과, 비용 후 순기댓값/하한·비용 악화·시간 안정성. 후속 운영에는 [BACKTEST_AND_TESTING](../current/BACKTEST_AND_TESTING.md)의 전체 Phase 4 조건과 [TRADING_CORE](../current/TRADING_CORE.md)를 별도로 충족한다. 선별 통과를 전체 Phase 통과로 바꾸지 않는다.
- **현재 결과: NOT_TESTED.** 실제 자료 완전성·수식/벌점·비용/위험·독립 표본·80% 검정력·최종 OOS 기간은 미확정. 코드·학습·성과·실거래 실행 없음.

## 23·24번 인계 — 미국 현물 BTC ETF 흐름, LONG / SHORT 독립 연구 (2026-10-07, Codex)

**사용자 지정:** 23 순유입/순유출 기반 LONG, 24 short-selling flow 기반 SHORT. 목표는 Binance 내부 OI/funding과 다른 ETF 시장 정보가 **공개 이후의 BTC 수익률에 비용 후 edge를 갖는지**다. 두 트랙을 별도로 감사·사전등록·순차 판정하며 서로의 결과로 규칙을 바꾸지 않는다. 이번 Codex 작업은 IDEAS에 초안과 인계를 기록하는 범위이며 자료 적재·신호 계산·백테스트·운영은 실행하지 않았다.

수익 발생 원리는 **가설**이다. ETF 투자자 전체를 기관으로 부르거나, 설정/환매를 반드시 신규 방향성 BTC 매매로 해석하지 않는다. 기존 H2/H3/IDEAS 16 판정은 불변이다. 새 정보라는 이유만으로 우위·인과성·독립성을 인정하지 않고 가격 추세와 기존 정보로 설명되는지 따로 확인한다.

### 23 — ETF-NET-LONG

**1. 가설**

현물 BTC ETF의 상대적으로 큰 순유입이 자금 수요의 지속성을 반영한다면, 이미 알려진 BTC 가격 추세만으로 설명되지 않는 **공개 이후** 양의 수익이 남을 수 있다. 당일 BTC 상승에 ETF 자금이 뒤따른 것인지와 공개 뒤 미래 수익을 구분한다. 총순유출일은 원칙적으로 LONG을 새로 잡지 않는 날이며, 이를 뒤집어 SHORT하지 않는다.

**2. 데이터**

- 미국 현물 BTC ETF의 당시 존재 종목군과 순유입/순유출 USD, AUM/NAV·발행주식수, BTC 보유량 및 각 공개/수정 버전. 현물 상품만 대상으로 하며 선물 ETF·레버리지/인버스 상품은 제외한다. 현재 ETF 명부를 2024년으로 소급하지 않고 GBTC 전환·분할/자산 이전·신상품 편입을 구분한다.
- [Farside 공개 표](https://farside.co.uk/bitcoin-etf-flow-all-data/)는 2024-01-11부터 일별 ETF 흐름을 표시한다. 무료 원본 후보이지 그 날짜에 지금 보이는 최종값을 알 수 있었다는 증거는 아니다. 2024~현재 자료의 완전성·역사적 첫 공개 시각·수정 이력·이용 조건은 미확인이다.
- [iShares IBIT 발행사 페이지](https://www.ishares.com/us/products/333011/ishares-bitcoin-trust-etf)는 발행주식수·보유량·데이터 다운로드를 제공한다. 다른 발행사의 원자료도 비교하되 전체 과거 다운로드 가용성을 이번 열람으로 인증하지 않는다.
- 주식수 변화와 NAV로 추정한 순설정 금액은 방법·평가 시점·오차를 기록한다. **AUM 증감 자체는 BTC 가격 변화를 포함하므로 순유입으로 대체하지 않는다.** 보유 BTC 변화에도 보수·이전 등의 조정을 확인한다.
- [SEC의 2025-07-29 현물 설정/환매 허용](https://www.sec.gov/newsroom/press-releases/2025-101-sec-permits-kind-creations-redemptions-crypto-etps)으로 현금 설정만을 전제할 수 없다. 펀드별 실제 적용 시점·방법을 감사하고 흐름 발표가 동시 현물 신규 매수를 뜻한다고 가정하지 않는다. 제도 구간별 진단은 사전 정의하며 좋은 구간만 선택하지 않는다.

**3. 진입/청산 정의 — 성과 전 확정할 단일 초안**

- 기본 입력 제안: `F_t = 해당 세션 전체 ETF의 순유입 USD 합 / 그때 알려진 직전 전체 AUM`. 유출 ETF를 합산에서 빼거나 수익을 보고 GBTC를 제외하지 않는다. 필요한 ETF 값이 빠지면 0으로 채우지 않는다.
- 진입 제안: `F_t > 0`이며 이전 60개 완료 미국 거래 세션의 80백분위보다 큰 날, 모든 필요한 값이 사용 가능해진 뒤 평가하여 **BTCUSDT 무기한 LONG만** 의도 생성. 이전 세션만으로 문턱을 계산하며 동일 데이터 행으로 반복 주문하지 않는다.
- 평가/주문 제안: 자료 사용 가능 시각 이후 첫 정시 평가 → 다음 1분부터 가격 한도가 있는 지정가. 미국 장마감 가격이나 자금 집계 대상일의 BTC 종가에 소급 진입하지 않는다. 주문 유효기간·가격 한도·부분 체결·미체결 처리·평가 격자는 Claude가 자료 감사 뒤 수익 보기 전에 고정한다.
- 청산 제안: 실제 진입 후 72시간에 지정가 청산 의도, 그 전에는 사전 확정한 거래소 보호 stop. 평균 추가 진입/연장·TP 탐색 없음. 이 horizon은 연구의 거래 정의이지 프로젝트 전역 최대 보유시간 제한 신설이 아니다.
- 기간 60·문턱 80%·보유 72h는 실측 최적값이 아닌 **초안 제안**이다. 자료/검정력 때문에 변경이 필요하면 성과를 보지 않은 상태에서 이유·자유도를 기록하고 확정한다. stop·사이징·위험 및 지정가 세부 계약이 미정이면 아직 실행하지 않는다.

**4. 비용**

BTC 선물 진입/청산·손절의 실제 수수료 등급, spread·슬리피지·지정가 역선택·부분/미체결과 보유 중 funding을 반영한다. ETF는 정보 출처이며 ETF 자체를 매수하는 연구가 아니다. 지정가라고 모두 maker 요율을 쓰지 않는다. 비용 기본값/불리한 funding·mark/강제청산 처리를 고정하고 비용 2배도 검사한다. ETF 투자자의 비용과 Binance 체결 비용을 혼동하지 않는다.

**5. 판정 기준 초안**

- 자료·PIT·80% 검정력 관문 통과 후, 미리 지정한 Validation/OOS 또는 walk-forward에서 비용 후 거래당 평균 및 최소 2SE 하한이 양수인지 확인. 거래당 주 평가량·경제적으로 필요한 최소 효과·주 검정의 다중검정 처리를 성과 전에 확정한다.
- 같은 방향·보유기간·시간대/요일·위험/노출 조건을 맞춘 대조 시점 및 동결 가격 추세 기준선보다 추가 정보/순성과가 있어야 한다. 무조건 BTC 상승장 보유로 번 것을 ETF 신호의 edge로 인증하지 않는다. 회귀 통제나 진단 제거판의 가장 좋은 결과로 주 규칙을 재선택하지 않는다.

**6. 결과**

### 24 — ETF-SHORT-FLOW

**1. 가설**

현물 BTC ETF의 평소와 다른 공매도 거래 흐름이 정보성 매도 압력을 반영한다면, 공개 이후 BTC 하락을 예측하여 BTC 선물 SHORT이 비용 후 이익을 낼 수 있다. 그러나 시장조성·차익거래·기존 롱 헤지일 수 있으므로 그 해석을 검증한다. 23의 순유출이나 LONG 신호의 음수를 SHORT 신호로 쓰지 않는다.

**2. 데이터**

- [FINRA Daily Short Sale Volume](https://www.finra.org/finra-data/browse-catalog/short-sale-volume-data/daily-short-sale-volume-files)의 미국 현물 BTC ETF `ShortVolume / ShortExemptVolume / TotalVolume / Market` 및 원본/수정 파일. FINRA Consolidated NMS와 개별 TRF/ADF 파일을 중복 합산하지 않는다. 상장 거래소 자료는 별도 범위이며 무료 확보 여부를 감사한다.
- [FINRA 공식 설명](https://www.finra.org/rules-guidance/notices/information-notice-051019): 거래량은 잔존 short interest와 다르고, 상쇄 매수가 빠질 수 있으며 거래소 자료와 통합된 전체 시장 자료가 아니다. **순공매도량·잔고 증감·기관 순숏으로 부르지 않는다.** 투자자 유형·헤지/시장조성 구분도 이 자료로 인증할 수 없다.
- [공식 필드 정의](https://www.finra.org/sites/default/files/2021-07/DailyShortSaleVolumeFileLayout.pdf)에서 `ShortVolume`은 exempt 거래를 포함하므로 `ShortExemptVolume`을 다시 더하지 않는다. `ShortVolume / TotalVolume`의 분자·분모는 반드시 같은 보고 시장·세션 범위다. FINRA 분자를 전체 거래소 거래량 분모와 섞지 않는다.
- [일별 파일 안내](https://www.finra.org/finra-data/browse-catalog/short-sale-volume-data/daily-short-sale-volume-files)는 해당 거래일 18:00 ET까지 게시하고 이후 수정 가능함을 명시한다. 과거 행의 거래일만으로 장중 가용성을 만들지 않는다. 원본/Updated 구분·실제 공개 시각·당시 일정 적용 여부를 감사한다.
- short interest·대차잔고·대차비용은 다른 자료다. 무료 역사/PIT를 확보하지 못하면 구매하거나 ShortVolume으로 몰래 대체하지 않는다. FINRA만 가능하면 **ETF 장외 보고 공매도 거래량 대리지표 연구**라고 한계를 명시한다. 사용자가 원한 실제 순숏/기관 흐름과 동등하다고 주장하지 말고 차이를 보고한다.

**3. 진입/청산 정의 — LONG의 대칭 반전이 아닌 단일 초안**

- 기본 입력 제안: ETF별 직전 가용 가격 `P_i`로 가중한 `S_t = Σ(ShortVolume_i × P_i) / Σ(TotalVolume_i × P_i)`. 여러 ETF 주식 수를 가격 없이 더하지 않는다. 보고 범위·가중 방식은 고정하고 결측/분모 0이면 진입 거부한다.
- 비정상 압력 제안: `A_t = S_t − 직전 20개 완료 미국 거래 세션 S의 평균`. `A_t > 0`이며 직전 60개 세션의 당시 계산된 A의 90백분위보다 큰 경우만 **BTCUSDT 무기한 SHORT** 의도. 과거 A도 해당 시점 이전 자료로 계산한다. 50% 이상이라는 이유만으로 숏하지 않는다.
- 평가/주문 제안: 전체 필수 자료 가용 이후 첫 정시 평가 → 다음 1분부터 가격 한도 지정가. FINRA 공개 상한을 이용하는 역사 연구라면 19:00 ET 이후 같은 보수적 컷오프를 사전 제안하되, 당시 원본/PIT를 증명하지 못한 최종 수정본은 여전히 PIT 인증 불가다. 실제 수신이 늦으면 수신 이후에만 사용한다.
- 청산 제안: 실제 진입 후 24시간에 지정가 청산 의도, 그 전에는 사전 확정한 보호 stop. 23과 입력·조건·horizon을 독립적으로 정하고 실패 후 LONG으로 방향을 뒤집지 않는다.
- 20·60 세션/90백분위/24h는 초안 제안이지 데이터에서 찾은 최적값이 아니다. 가용 범위·stop·사이징·체결 계약·의미/커버리지·검정력 감사 뒤, 수익 보기 전에 별도 확정한다. 기존 위험 한도·G6 예외를 자동 상속하지 않는다.

**4. 비용**

BTC 무기한 SHORT의 진입/청산·보호 stop 수수료, spread·슬리피지·미체결/역선택과 실제 보유 시각의 funding 부호를 반영한다. 숏 funding이 항상 수입이라고 가정하지 않는다. ETF를 빌려 공매도하는 전략이 아니므로 ETF 대차료를 BTC 선물 비용에 넣지 않지만, 대차 정보가 필요하면 데이터 비용/가용성 관문으로 구분한다. 비용 2배·mark/청산 위험도 검사한다.

**5. 판정 기준 초안**

- 23과 독립된 사전등록/원장/주 검정. 미래 하락 폭을 보고 높은 공매도량의 방향을 정하지 않는다. 자료/PIT·80% 관문을 만족한 뒤 비용 후 평균·최소 2SE 하한 양수와 최소 경제적 효과를 검증한다.
- 같은 시간대·보유·방향·위험/노출을 맞춘 무작위 SHORT 대조, 동결 BTC 가격 추세와 알려진 ETF 거래량/프리미엄 등 통제 조건에서도 추가 정보가 있는지 사전 정의한다. 총거래량 급증이나 이미 하락한 날의 효과를 short-selling 정보로 오인하지 않는다. 이 진단에서 가장 좋은 조건을 신규 필터로 추가하지 않는다.
- 지정한 분할/시간 구간에서의 일관성·비용 2배·안전성 및 Phase 4 전체 조건을 확인한다. 장외 비중 변화·보고 시장 변경·ETF 종목 구성 변화가 만든 가짜 신호를 감사한다. 실제 기관 순숏이라고 해석할 근거가 없으면 해석상 한계를 유지한다.

**6. 결과**

`NOT_TESTED`. FINRA 공식 자료의 정의·게시 시각·수정/범위 한계만 확인했다. ETF별 과거 파일 확보·PIT·커버리지·신호/성과·검정력은 미확인이다. 자료 부족은 SHORT 효과 없음과 다르며, 대리지표의 실패를 실제 기관 숏 거래 전체의 실패로 확대하지 않는다.

## 22번 초안 인계 — 넓게 조사하고 제한된 조합을 설계 (2026-10-07, Codex)

[상세 초안](INDICATOR_COMBINATION_RESEARCH_DRAFT.md)은 앞서 언급한 지표에만 한정하지 않는다. 추세(EMA/KAMA/HMA 등), 모멘텀(RSI/TSI/CCI 등), 변동성·위치(ATR/채널 등), 거래량(RVOL/OBV/CMF 등), 확정 가격 구조, 차트 패턴을 **34개 초기 조사 항목**으로 정리했다. 각 항목의 공식·역할·확인 지연·중복·자료/기존 구현 상태를 먼저 비교한다. 조사 목록은 전략 후보 34개가 아니다.

질문은 단순한 다수결이 아니라 **장세 조건과 진입 계기를 나눴을 때 상호작용이 비용 후 정보를 더하는가**다. 구성 지표 각각의 단독 수익은 필수 조건이 아니지만, 같은 가격 변환 여러 개를 독립 증거로 세지 않는다. H1·KB·MJ/다이버전스·삼각형·V·체결 흐름의 기각을 지표 추가/기간 변경으로 뒤집지 않는다.

Opus는 **Phase 0 지표 조사 → 기각 중복 감사 → 무료 자료/열람·인과성·지정가/보호·검정력 감사 → 최대 3개 후보 설계**부터 진행한다. 사용자가 하나를 고르고 관문이 해결된 뒤 Claude가 성과 전에 사전등록을 확정한다. 지금은 구현/학습/백테스트/성과 열람/운영 적용 승인이 아니다. 수백·수천 조합 탐색은 시도 장부·다중검정·미열람 검증 계획과 별도 사용자 승인이 필요하다.

19 DMN 버림, 20·21은 5번 결과 뒤 재검토하는 보류 상태 그대로다. 기존 운영 전략과 연구 판정은 변경하지 않는다. Elliott/뉴스/JEV는 Shadow 전용, D22 제외를 유지한다.

## 19번 초안 인계 — 비용 고려 DMN (2026-10-07, Codex)

[상세 초안](DMN_COST_AWARE_PREREGISTRATION_DRAFT.md)에 논문 비교·단일 모델 제안·자료/체결·비교 기준·검정력·기각 조건·Opus 확정 체크리스트를 남겼다. 모델은 추세 방향과 포지션 강도를 숫자로 학습하는 소형 LSTM 후보이며 뉴스/LLM 매매가 아니다. 첫 범위는 BTC·ETH 마감 일봉이고 기존 T/v2·O 계열 운영은 수정하지 않는다.

**다음은 Phase 0 자료·실행·검정력 감사다.** 무료 자료 실제 가용·노출 이력, 보호주문/위험 역산과 지정가 미체결, 독립 월수·모델 용량·80% 검정력·최종 미열람 구간을 Opus가 먼저 확인한다. 계획용 분산 측정을 위해 모델 파일럿이 필요하면 별도 승인·노출 계약이 먼저다. 현 문서는 확정 사전등록/학습/성과 실행 승인이 아니다.

## 17번 상세 후보 — 재고 관리형 시장조성 그리드

작성: 2026-10-06, Codex. **사용자 요청은 상세 아이디어 기록이다. 사전등록 확정·자료 수집 시작·전략 구현·Paper 또는 실거래 활성화 승인이 아니다.** Claude가 진행 중인 다른 연구는 그대로 이어 간다. 아래 규칙은 검토할 구조이며, 숫자와 판정 기준은 미확정이다.

### 연구 질문과 수익원

**매수·매도 지정가로 거래할 가격을 제공하면서 얻는 가격 차이가, 실제 수수료·체결 이후 불리한 가격 변화·재고 정리 손실을 넘는가? 그때 보유 물량을 고려한 주문 조정이 동일한 비용·체결 조건의 고정 주문보다 계좌 결과를 개선하는가?**

가설은 유동성을 제공하는 대가를 얻되, 한쪽 주문만 반복 체결돼 쌓이는 재고의 위험을 제한하는 것이다. 단순히 가격이 평균으로 돌아올 확률이나 상승 방향을 맞히는 가설과 구분한다. 시장조성 모델이 수익을 보장하거나 재고 관리만으로 우위를 만들어 준다고 가정하지 않는다. 즉시 체결하려는 상대 주문이 우리 지정가에 도달할 만큼 있어야 하고, 그 체결이 가격 정보를 가진 상대방에게 불리하게 선택되는 손실보다 유리해야 한다.

쉬운 예: 매수만 반복 체결돼 코인 물량이 목표보다 많아지면, 다음 매수는 작게/멀리 놓고 매도는 더 가까이 놓아 물량을 줄인다. 보유 허용 범위가 찼으면 추가 매수를 막는다. **평균 매수가 아래에서도 정리가 필요할 수 있다.** 손실을 확정하지 않고 기다린 결과를 개선으로 계산하지 않는다.

### 참고 모델과 가져올 원리

- **Avellaneda–Stoikov:** 현재 보유 재고의 위험을 반영해 주문 기준 가격을 조정하고, 체결 가능성을 고려해 매수·매도 가격을 정하는 이론적 출발점이다. 원논문의 가정·단위·시간 지평을 검토해야 하며, 24시간 코인 시장에 식과 기본값을 그대로 복사하지 않는다.
- **Hummingbot Avellaneda / Inventory Skew:** 목표 보유 비중과 현재 물량의 차이로 주문 가격 또는 주문 수량을 조절한다. 보유 범위 밖에서는 한쪽 주문을 중단하는 공개 설명·구현이 있다. 구현 존재는 실계좌 수익 증거가 아니다. 참고 시점 공식 페이지는 Avellaneda V1의 maintainer를 None으로 표시한다.
- **GLFT 다층 주문 예제:** 변동성과 가격대별 주문 도달 빈도를 추정해 호가와 재고 기울기를 정하고, 여러 가격대에 주문을 배치한다. 참고 예제에는 **메이커 수수료 −0.005%(리베이트)**와 며칠의 시험 자료가 포함된다. 그 수익률·연율화 숫자를 우리 기대 수익이나 검정력 효과 가정에 쓰지 않는다.

외부 봇이나 백테스트 프레임워크를 설치·연결하거나 별도 전략 경로로 채택하는 제안은 아니다. 구현이 선택되면 Claude가 기존 Pure Core·실행·회계 경로와의 호환성부터 확인한다.

### 자료와 현실적인 체결 관문

초기 점검은 BTC 하나를 우선 제안한다. Binance 현물 또는 USD-M 중 어느 시장에서 연구할지는 무료 자료·수수료·주문 가능성 점검 뒤 하나를 선택한다. ETH·다종목·헤지는 첫 모델의 자동 확장이 아니다. 예상 평가 주기·갱신 주기·거래 빈도·보유/정리 시간은 아직 미측정이며 원예제의 100ms 주기를 그대로 채택하지 않는다.

필요한 자료는 최우선 호가/수량 또는 호가 깊이, 공격적 체결의 가격·수량·방향·시각, 호가 갱신 순서·결측, 주문 전송·취소·체결 지연, 틱/수량 규격과 실제 적용 수수료다. 선물은 funding·mark·증거금/청산 경로도 필요하다. 공개 자료의 가용 기간과 무료 사용 조건을 먼저 확인한다. 유료 데이터 구매는 하지 않는다. 과거 자료가 부족하면 무료 전향 수집 명세를 제안하되, **이번 기록으로 수집을 시작하지 않는다.**

**기존 1분봉만으로 신뢰할 수 있는 체결 판정을 했다고 주장하지 않는다.** 같은 봉의 고저가가 주문 가격을 지났다는 사실만으로 주문이 도달한 뒤 대기열에서 전량 체결됐음을 알 수 없다. 모델 재생은 대기열·부분 체결·미체결·지연·호가 공백을 포함해야 한다. 모든 주문을 maker로 처리하지 않고, 가격 한도 지정가가 상대 호가를 가져가면 실제 taker 요율을 쓴다. 남은 주문과 재고를 결과 끝에서 비용 없이 없애지 않는다.

### 비용·손익·비교 기준

손익의 기준은 **현금 + 전체 보유 물량 평가액**의 변화이며 외부 입출금·수수료·funding을 별도로 정합시킨다. 왕복을 완료한 칸의 차익과 남은 재고의 손익을 함께 보고한다. 호가 차이·체결 뒤 불리한 움직임(markout)은 원인 분석용 지표다. 이 분석 지표들을 계좌 손익에 다시 빼서 재고 손실을 이중 계산하지 않는다. 평가에는 중간가와 현실적인 지정가 정리 가능성을 구분하고 미체결 위험을 남긴다.

성과 열람 전에 고정할 비교 대상은 다음을 제안한다.

1. 같은 주문 크기·빈도·비용·체결 모델·재고 한도로 운영하는 **고정 대칭 주문 기준선**: 재고/변동성에 따른 조정이 무엇을 더하는지 확인.
2. 같은 초기 자본의 **코인·현금 보유 또는 고정 비중 재조정 기준선**: 코인을 들고 있어서 번 수익과 매매의 추가 효과 구분. 하나의 기준선을 확정 전에 선택.
3. 기존 운영 전략 T/v2 등과의 비교는 별도 참고이며 기존 규칙·원장을 수정하지 않음. 짧은 시장조성 자료를 장기간 T/v2 결과와 바로 비교하지 않음.

실제 적용 수수료에서 판단하고 비용 2배, 더 느린 주문/취소, 더 보수적인 대기열 체결 가정에서도 결론을 확인한다. 예제의 리베이트·VIP 혜택·무료 이벤트를 우리 계좌의 비용으로 가정하지 않는다. 주문을 안 낸 시간을 빼거나 거래가 잘 된 시간만 사후 선택하지 않는다.

### 표본·검정력과 판정 전 순서

현재 **자료 가용 기간·체결률·독립 n·SD·최소 검출 효과·필요 거래 수·관찰 기간·비용 후 평균 모두 미측정**이다. 수천 건의 체결도 같은 재고가 쌓였다가 정리되는 한 사건일 수 있다. 틱 수·주문 수·왕복 건수를 그대로 독립 n으로 쓰지 않는다. 재고 에피소드 또는 시간 블록 중 관찰 단위를 정하고, 중첩/연속 상관·블록별 손익·미체결 때문에 잘리는 표본을 반영해야 한다. 희귀한 급락과 급등의 재고 위험을 며칠의 고빈도 자료로 대체하지 않는다.

| 순서 | Claude가 연구 선택 후 확인할 것 | 미달 처리 |
|---|---|---|
| 1 무료 자료·실행 타당성 | 자료 해시·기간·호가 순서·실제 비용·지연·현재 실행 상태 전이와의 호환성 | 자료/실행 관문 미달로 보류. 전략 수익 기각과 구분 |
| 2 체결·회계 계약 | 단방향 하락/상승·왕복·부분 체결·취소 중 체결·최악 미체결 주문 노출·잔여 재고를 합성 입력으로 검산 | 모델 결함부터 해결. 성과 실행 금지 |
| 3 검정력 | 독립 단위·SD·현실적인 비용·효과 가정의 근거·필요 관찰 기간을 계산 | [80% 게이트](../current/BACKTEST_AND_TESTING.md) 미달이면 사전등록하지 않음 |
| 4 단일 명세 확정 | 한 시장·한 모델·파라미터 산정법·주기·보유/정리·위험 적용 범위·분할·비교/기각 수치 동결 커밋 | 미확정 항목을 남긴 채 실행하지 않음 |
| 5 판정·기록 | 미열람 구간에서 비용 후 계좌 손익·기준선 대비 추가 효과·위험·체결 강건성을 1회 판정 | 실패하면 버림, 성과 뒤 숫자/방향/종목 변경 금지 |

원자료/공개 예제 노출 이력을 남긴다. 예제의 기간·설정은 이미 결과를 봤으므로 우리 최종 미열람 OOS로 부르지 않는다. 변동성/주문 도달 빈도의 추정은 그때까지의 자료만 쓰며, 미래 체결 결과로 과거 호가를 재작성하지 않는다. 필요한 관찰 기간과 연구의 위험 규칙 적용 범위는 확정 전이며, 짧은 시험의 연율화 수익을 목표 수익률로 사용하지 않는다.

### 실패하면 버릴 조건과 확장 경계

- 적용 가능한 실제 수수료에서는 수익이 사라지고 리베이트 가정에서만 살아남음.
- 대기열·지연·부분 체결을 현실화하면 가격 우위가 사라짐, 또는 체결 뒤 불리한 가격 변화가 얻은 가격 차이를 상쇄함.
- 총손익의 양수가 남은 재고 평가손실 누락·외부 자금 보충·마지막 무비용 정리·상승장 코인 보유만으로 설명됨.
- 동일한 위험/체결 조건의 고정 주문 또는 보유 기준선보다 추가 효과가 없거나, 현행 위험 한도 안에서 운용 불가.
- 무료 자료로 재현할 수 없거나 필요한 독립 표본·80% 검정력을 확보할 수 없음. 이 경우 자료/표본 부족으로 보류하며 우위 없음과 구분.
- 실패 뒤 모델 계수·칸 수·간격·목표 재고·레버리지·갱신 주기를 탐색해 같은 구간을 재판정하지 않음. 계수는 성과 전에 이론/자료/위험 예산의 근거로 산정·고정하고, 자유도 개수를 기록.

**DGT와 선물 헤지는 참고로만 남긴다.** DGT는 범위 이탈 때 재배치하고 하단 이탈 물량을 보유하는 별도 방식이다. 선물 헤지는 가격 위험과 함께 거래 비용·funding·두 다리 미체결·증거금 위험을 추가한다. 둘 다 첫 모델에 섞지 않는다. 특히 현물 재고와 반대 선물을 자동으로 늘린다고 수익이 생기는 것은 아니다. 검증 뒤 새 가설이 있을 때 별도로 선택한다.

## 16번 후보 메모 — 어느 시장에서 매수·매도가 발생했는가

**사용자 승인 범위는 이 문서에 후보를 기록하는 것뿐이다.** Claude의 진행 중 연구를 바꾸거나 이 후보를 실행 대상으로 선택한 것은 아니다. 그리드 재검토는 이번 후보에 섞지 않는다.

- **가설:** 가격 상승폭·변동성이 비슷한 상황에서, 현물과 무기한 선물의 공격적 체결 흐름 차이가 이후 수익의 지속/반전을 구분하는 추가 정보를 제공할 수 있다. 현물 수요와 파생상품 수요의 서로 다른 가격 반영을 노리는 가설이며, 현물이 항상 가격을 선도하거나 선물 매수가 항상 되돌려진다고 가정하지 않는다.
- **측정 대상:** `공격적 매수 거래대금 − 공격적 매도 거래대금`. 공개 봉의 전체 거래대금과 taker 매수 거래대금으로 구성할 수 있다. 각 시장의 거래 규모를 반영한 정규화는 과거 자료만 쓰며, 현물·선물 원시 거래대금 크기를 그대로 비교하지 않는다. CVD는 이를 누적한 참고 표현이다. 체결에는 항상 매수·매도 상대방이 있으므로 이 값은 순자금 유입이나 투자자 수가 아니다. 장기 투자자/기관/신규 레버리지 여부도 이 자료만으로 식별하지 않는다.
- **기존 기각과의 차이·중복:** H3의 `X3_rel_taker`는 선물 taker 매수/매도 비율의 종목 간 순위였다([기존 명세](../archive/research/23-h3-preregistration.md)). 새 후보의 질문은 같은 자산의 **현물 정보가 선물 흐름·가격 변화·거래량·추세 기준선에 더하는 정보**다. 지표 이름이나 관찰 창만 바꾸는 H3 재시도는 받지 않는다. 단순 CVD 단독 신호나 펀딩/OI 조건 추가로 후보를 대체하지 않는다.
- **자료:** Binance 공개 현물·USD-M 봉의 quote 거래대금, taker buy quote 거래대금, 가격·시각, 보유 기간의 funding. 우선 BTC·ETH 자료 확보 가능성부터 점검한다. 공식 명세에 필드가 있다는 것과 로컬 파일의 실제 기간·결측·정합성 검증은 구분한다. 유료 자료 구매·호가/틱 전체 수집은 제안하지 않는다.
- **미확정 설계:** 마감 4h 봉에서 측정하고 이후 하루를 확인하는 것은 출발점 제안이다. 방향·정규화 창·임계·보유/청산·손절·사이징·빈도·실행 지연·비교 기준·분할은 아직 확정하지 않았다. 수익을 보기 전에 자료 점검과 사용자 선택을 거쳐 Claude가 하나의 명세로 확정한다. 여러 창/조건을 시험해 성과가 좋은 조합을 고르는 연구는 하지 않는다.
- **비용·체결:** 지정가의 미체결·부분 체결·역선택·실행 지연, 양쪽 수수료, funding, 미실현손익을 포함해야 한다. 지정가를 쓴다는 이유로 모든 주문을 maker 요율로 전량 체결시키지 않는다. 연구의 우위 측정과 위험 규칙을 적용한 계좌 결과를 구분하되, 위험 한도 변경을 승인한 것은 아니다.
- **표본/검정력:** 현재 SD·독립 n·필요 거래 수·판정까지 걸릴 기간 모두 미측정. 하루 관찰 구간이 겹치는 4h 신호나 같은 시장 충격의 BTC·ETH 관찰을 독립 표본으로 중복 계산하지 않는다. [검정력 기준](../current/BACKTEST_AND_TESTING.md)의 80% 관문 미달이면 사전등록하지 않는다. 과거 자료의 프로젝트 내 열람 이력을 남기고 최종 확인에는 별도 미열람 구간이 필요하다.
- **실패하면 버림:** 현물 정보의 추가 효과가 없거나, 효과가 비용·실행 지연을 넘지 못하거나, 충분한 독립 표본을 확보할 수 없으면 버림/보류한다. 성과를 본 뒤 방향을 뒤집거나 임계·보유기간·심볼을 바꿔 구제하지 않는다. 구체적인 통과 수치와 순수익/추가 효과의 판정은 확정 전에 정한다.

**출처와 한계:** [Binance 공개 자료 명세](https://github.com/binance/binance-public-data)는 현물·선물 봉에 전체 거래대금과 taker 매수 거래대금이 있음을 설명한다. [Order flow and cryptocurrency returns (2026)](https://doi.org/10.1016/j.finmar.2026.101047)는 여러 시장의 주문 흐름과 이후 일간·주간 수익 예측의 관계를 연구했다. 이 후보는 그 근거에서 확장한 가설이며, 해당 논문이 Binance 현물·선물 흐름 차이 모델이나 우리 비용·위험 조건의 수익성을 입증한 것은 아니다.

## 5번 사전등록 초안 — 한국 실적 개선형 주도주

[상세 초안](FUNDAMENTAL_KR_PREREGISTRATION_DRAFT.md) 작성 완료, **DRAFT / Phase 0**, 수익 미계산. Codex가 제안하는 단일 모델은 매출 성장 가속·영업이익률 개선·현금흐름 개선 세 순위의 동일 가중이다. 월말 비금융 유동성 상위 200에서 개선 조건을 만족하는 상위 최대 20종목에 각 5%, 부족한 자리는 현금, 매월 재평가하며 선정이 유지되면 보유를 이어간다. 지정가·미체결·거래비용·기업행동을 포함한다. 숫자는 사용자 검토 및 Claude 자료 감사 후 확정할 초안값이다.

주 비교는 같은 재무 계산 가능 종목군 동일가중, 현금 노출을 맞춘 동일가중과 KOSPI 총수익도 확인한다. 순수익/초과수익 2SE 하한, 위험 대비 성과·비용 2배·지연 조건을 함께 고정한다. 연 3%p는 검정력 계획용 검출 대상이며 관측 평균 통과 문턱과 구분한다. 여러 통계 조건을 동시에 통과할 검정력도 확인한다. **실적이 개선된다는 이유만으로 수익 우위가 있다고 가정하지 않는다.**

초안에서 발견한 확정 전 주의점:

- DART의 접수번호 존재만으로 정정 전 수치가 복원되지는 않는다. 원공시·정정 쌍을 먼저 대조해야 한다.
- 원래 가설의 매출 성장 가속에는 매출 12분기가 필요하다. 2015년부터만 확보되면 신호 시작은 대체로 2018년이며 2016년 시작을 자동 채택하지 않는다.
- 141의 현재 산업분류 소급·배당 제외·미래 마지막 가격 강제 청산을 그대로 재사용하지 않는다. 상장폐지 종목을 포함했다는 사실만으로 전체 생존/시점 편향이 해결된 것은 아니다.
- 2018~2020 계획용, 2021~2023 TRAIN, 2024~2026-08 역사 확인을 제안한다. 같은 가격 자료가 이전 연구에 노출됐으므로 최종 OOS는 별도의 전향 자료가 필요하다. SD·필요 관찰 월수·80% 검정력은 아직 미측정이다.
- 위험 규칙의 연구 적용 범위·종료/배당/정산·비용표·검정력이 미확정이면 Claude는 확정 커밋/성과 실행 전에 이를 해결한다. 이 초안의 통과 명칭은 HISTORICAL_SUPPORT이며 전체 Phase 4 PASS와 구분한다.

## 4번 인계 보충 — Opus가 재개할 때 (2026-10-05, Codex)

사용자가 역할 변경을 확인하고 현재 연구의 추가 인계를 요청했다. 이 절은 아이디어·진행 순서 제안이며 사전등록 확정이나 연구 재개 실행 기록이 아니다. 자료·코드·실험은 Claude가 담당한다. 체크포인트 본문의 옛 “Codex 전용/Claude 수정 금지/완료 후 이관”은 역사 기록이며, 현재 담당은 AGENTS §9와 체크포인트 맨 위의 담당 변경 안내를 따른다.

### 연구 목적과 현재 증거

- 질문: **매출 성장세·영업이익률·영업현금흐름이 개선되는 기업을 당시 공개 정보로 골랐을 때, 비용 후에 비교 대상보다 높은 수익이 남는가?** 측정 정의는 [131 §3](131-fundamental-leaders-feasibility.md)를 잇는다. 실적 발표 직후 갭 전략(130), 가격 주도주 LT, 가치·품질 후보 2번을 섞지 않는다.
- 판단: 연구할 경제적 근거는 있으나 우리 신호의 우위는 미측정이다. 좋은 실적이 이미 가격에 반영됐거나 일회성일 수 있다. 관련 실적 모멘텀 논문의 효과 크기를 이 모델의 기대 수익으로 대입하지 않는다.
- 현재 **Phase 0 / REAL_SAMPLE_AUDITED / DATA_NOT_READY / NOT_TESTED**. Apple·Microsoft 실제 공시 검산과 순수 계산·정규화·자료 감사 도구는 있다. 종목 선정 성과, 독립 표본 수, SD, 80% 검정력, 전략 사전등록은 아직 없다. 코드 테스트 통과를 수익성 증거로 쓰지 않는다.
- 최신 자료 조사는 `eba3f81`, 연구 도구 변경은 `2eecab6`. [체크포인트](FUNDAMENTAL_CODEX_CHECKPOINT.md) → [무료 경로 감사](FUNDAMENTAL_FREE_HISTORY_FEASIBILITY.md) 순으로 읽고, 필요한 세부 근거만 131~136·후속 감사에서 찾는다. 기존 구현을 처음부터 다시 만들 필요는 없다.

### 바로 이어갈 범위와 중단 지점

1. **무료 종료 가격의 확보 가능성을 먼저 끝낸다.** Tiingo 공개 목록에는 TWTR·CTXS·NLSN이 있지만 실제 가격 API 제공은 미확인이다. 사용자 제공 무료 계정/토큰이 준비되면 최대 3종목의 metadata·종료 부근 가격만 확인한다. 현재 인계 시점에는 해당 인증 사용에 대한 답변/토큰 제공이 확인되지 않았다. 키는 채팅·문서·Git에 남기지 않는다. 유료 구매는 금지다.
2. **당시 종목군 복원 가능성을 함께 판정한다.** 2022-09-30~11-01은 자료 감사용 제한 구간이다. 공식 시작/끝 명부와 중간 변경 근거를 확보할 수 있는지 확인한다. 이 기간을 전략 TRAIN/OOS로 쓰거나 성공한 기업만 골라 수익을 계산하지 않는다. 확보한 변경 CSV는 공식 근거를 찾는 후보 목록이다.
3. 두 경로를 확인한 뒤 **확보/미확보/추가로 필요한 입력**을 한 번에 보고한다. 가격 또는 명부가 계속 부족하면 DATA_NOT_READY로 보류하고 경로 선택을 사용자에게 제시한다. 이미 빈 응답으로 끝난 요청의 반복이나 끝없는 예외 처리 도구 추가를 다음 성과로 삼지 않는다. 전향 관찰로의 전환은 아직 선택되지 않았다.
4. 자료가 확보되면 공시·증권 ID·달력·기업행동과 연결하고, 회계 커버리지·누락률·독립 표본/검정력을 확인한다. 그 뒤 매수·청산·비중·비용·지정가 미체결·비교 기준·분할을 수익 열람 전에 고정한다. 첫 모델은 기존 세 실적 측정치를 중심으로 단순하게 유지한다. 추가 지표·가중치·Top N 탐색은 제안하지 않는다.

### 재개 후 사용자에게 전달할 내용

“이번에 실제 확보한 자료 / 그래서 가능해진 검증 / 아직 막힌 한 가지 / 다음 작업”을 설명한다. 연구 성과가 없는 단계에서는 테스트 수나 파일 수를 수익성 진전처럼 표현하지 않는다. 수익성 검증을 시작하면 동일 종목군 기준선·시장 기준선과 비용 후 결과를 함께 보고하고, 누락 기업/거래불가/현금 가용의 영향을 공개한다. 최종 판정은 Claude가 기록하고 Codex는 이 목록의 상태와 다음 아이디어를 갱신한다.
