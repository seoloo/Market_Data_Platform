# 기업정보 기반 주식 수익 예측 — 사전등록 초안

작성: Codex · 2026-10-07 · **IDEAS 21 / 사용자 논문 2번 / Phase 0 / DRAFT / NOT_TESTED**

## 1. 논문과 응용의 차이

Gu·Kelly·Xiu, *Empirical Asset Pricing via Machine Learning*, RFS 2020. 미국 장기 주식 자료에서 여러 학습법을 비교하며 비선형 특성 조합의 예측·투자 효과를 연구했다. [원논문](https://academic.oup.com/rfs/article/33/5/2223/5758276).

본 초안은 **무료 PIT 기업정보·한 가지 얕은 모델·주식 롱만**으로 적용 가능성을 확인하는 축소 응용이다. 미국 수십 년 자료와 대규모 특성·롱숏 결과를 재현하거나 수익을 승계하지 않는다. 논문이 쓴 모든 알고리즘을 시험해 가장 좋은 것을 고르지 않는다.

공통 자료·회계·검정력은 [공통 계약](EQUITY_ML_COMMON_RESEARCH_CONTRACT_DRAFT.md)을 따른다. 시장은 미확정이며 기존 한국 재무 자료 경로를 우선 제안한다.

## 2. 가설과 기존 연구와의 구분

**가설:** 실적 개선·기업 가치·가격/유동성의 관계가 단순 선형 합보다 복잡해, 동일 입력의 선형 예측보다 비용 후 수익이 높아진다.

이미 기각한 12-1 모멘텀을 AI라는 이름으로 다시 시험하는 것이 아니다. 기업정보 추가 기여와 비선형 조합을 확인해야 한다. ML 자체는 새로운 경제적 수익원이 아니며 위험 프리미엄/정보 반영 차이를 추정하는 도구다. 기존 5번의 실적 개선 조건·동일 가중 점수와도 별개 원장으로 비교하고 그 연구를 바꾸지 않는다.

## 3. 입력과 label — 제안값

월말 당시 유효 종목에 아래 **8개만** 사용한다. 각 재무 특성의 계정 정의·분모·음수/0·연결/별도 전환 처리는 기존 PIT 감사와 대조해 확정한다. 미확보 특성을 빼고 성과를 다시 보는 방식은 금지다.

| 입력 | 정의/경계 |
|---|---|
| 매출 성장 가속 A | TTM 매출 YoY 성장률의 전년 동기 대비 변화, 필요한 과거 12분기 |
| 영업이익률 개선 M | TTM 영업이익/매출의 전년 동기 대비 변화 |
| 영업현금흐름률 개선 F | TTM 영업현금흐름/매출의 전년 동기 대비 변화 |
| 가치 | 당시 공개된 보통주 귀속 자본/당시 시가총액. 자본 ≤ 0 또는 정의 불명은 결측 |
| 가격 추세 | 직전 1개월을 뺀 과거 12개월 총수익. 기업정보 효과와 구분할 통제 특성 |
| 변동성 | 과거 63거래일 총수익의 표준편차 |
| 유동성 | 과거 63거래일 평균 원시 거래대금의 log |
| 크기 | 당시 시가총액의 log |

공통 계약의 당시 횡단면 순위로 변환한다. 미래에 정정한 재무 값과 현재 시총은 금지. label은 **다음 달 종목 총수익 − 같은 당시 종목군의 다음 달 동일 가중 총수익**을 제안한다. 이는 시장 중립 거래나 절대 수익 예측이 아니다. label의 종목 폐지/권리를 완결하고, 미래를 모르는 예측과 학습 완료된 과거 label을 분리한다.

## 4. 단일 모델·고정 선정

- 후보: Random Forest 회귀 **100 trees / max_depth 3 / min_samples_leaf 100 / max_features 8 / bootstrap true / seed 20261007**. 고정 구조로만 학습한다. 이 값은 성과로 선정한 값이 아니며 자료·용량 감사 전 초안이다.
- 월별 학습 가중치 합이 같도록 행 가중치를 둔다. 많은 종목 행을 많은 독립 시간으로 착각하지 않는다. 실제 학습 월수·기업 수·유효 leaf·상관·예측 안정성을 기록하며 용량 관문 미달이면 멈춘다.
- 선형 비교군: 같은 입력·label·학습 기간·월 가중치의 Ridge, 정규화 후 alpha 1 고정. intercept 포함, alpha 탐색 없음. 정확한 목적 함수/가중치의 정규화 단위와 라이브러리 의미를 확정해 산출을 재현한다.
- 매월 예측이 양수인 상위 **최대 20종목**, 종목당 목표 5%, 부족한 자리는 현금. 동점은 고정 종목 식별자 순. 임의로 수익 높은 종목 수·예측 문턱을 탐색하지 않는다. 양수는 상대 기대수익일 뿐 절대 수익 보장이 아니다.
- 두 군에 같은 제한 주문·부분 체결·현금/위험 사이징을 적용한다. 위험 한도 때문에 목표를 줄이면 실제 실행 비중으로 평가한다. 12개월 TRAIN / 다음 3개월 고정 모델을 기본 제안하며 세부 label 경계는 공통 계약을 따른다.

## 5. 비교와 판정

**주 비교:** 동일 달 `RF 계좌 순수익 − Ridge 계좌 순수익`. 같은 특성을 쓰므로 이 차이는 기업정보의 존재 자체가 아니라 비선형 예측 방법의 추가 효과다.

보조 비교는 동일 종목군 동일 가중, 기존 실적 개선 동일 가중 점수, 시장 총수익 기준선이다. 기존 5번의 미확정/진행 중 결과를 가져와 승리 문턱을 바꾸지 않는다. 기준선 규칙/비용/위험을 성과 전 봉인한다.

**기업정보 기여 진단:** 동일 RF 구조에서 가격 추세·변동성·유동성·크기 4특성만 쓰는 제거판을 사전에 고정한다(`max_features 4`, 나머지 동일). full − price-only 월 차이를 보조로 보고한다. 새 기업정보 우위를 주장하려면 이 비교의 오류율·검정력도 별도로 충족해야 한다. 제거판이 더 좋다고 그것을 새 주 전략으로 선택하지 않는다.

- 공통 계약의 주 차이 2SE 하한·경제적 최소 효과·계좌/시장 기준을 적용한다. 실제 독립 월수와 **차이 SD**가 아직 없으므로 80% 통과를 주장하지 않는다.
- IC/R²가 양수여도 거래 비용 후 차이가 없으면 경제적 가설은 기각한다. 가격 특성만 기여하거나 특정 업종/최근 한 시기만 기여하면 그 한계를 기록하고 종목군을 바꿔 구제하지 않는다.
- 무료 PIT 자료 부족은 `DATA_NOT_READY`, 독립 기간/검정력 부족은 `DATA_INSUFFICIENT`. 충분한 고정 확인에서 주 기준 미달은 `REJECT`. 이미 본 역사 자료의 지지는 `HISTORICAL_SUPPORT`이며 신규 운영 승인과 다르다.

## 6. 확정 전 체크리스트와 인계

미확정: 시장, 완결 자료 기간, 자본/시총·업종 PIT, 비용표, 보호·위험/체결 계약, 학습 용량, label purge/embargo, 계획 파일럿 필요성, 최소 효과, 확인 구간과 필요 관찰 기간, 보조 가설 오류 처리.

Opus는 **자료·용량·실행·검정력 감사부터** 진행한다. 아직 학습·성능 비교·계좌 수익 계산은 실행하지 않는다. 감사가 끝나면 사용자 선택을 확인하고 성과 전에 확정 커밋한다. 이후 승인된 구현은 기존 연구 경로에 추가하며 학습/추론 해시·미래 무관성·폐지/기업행동 회계·동일 입력 결정론을 시험한다.
