## 1. 규칙

| 항목 | 값 |
|---|---|
| 종목 | **QNDX** (State Street SPDR Portfolio Nasdaq 100 ETF, 나스닥) — 2026-09-26 조회 25.22 USD |
| 적립 | 시작일부터 **달력으로 매일 1 만 원** 가상 적립 (주말·휴일 포함) |
| 월 한도 | **30 만 원** — 이번 달 매수 + 1 주 가격이 넘으면 "이번 달 한도" |
| 1 주 가격 | KIS 현재가상세 `last` × 당일 고시 환율 `t_rate` × (1 + 0.25% 수수료) |
| 살 차례 | 적립 ≥ 1 주 가격 |
| **자동 매수** | 살 차례 · 평일 밤(KST 월~금) · `.env` 의 `KIS_TRADING_ENABLED=true` · `data/HALT` 없음 · 오늘 주문 없음 · 확인 안 된 주문 없음 · 매수 가능 수량 ≥ 1 → **예약 매수 1 주** |
| 주문 | 해외주식 예약주문 `TTTT3014U`, **지정가 = 현재가 × 1.03** (매수 지정가가 시장보다 높으면 실제 체결은 시장 가격), **당일 유효**. 접수 10:00~23:20 KST(서머타임 22:20), 정규장 시작 때 거래소로 |
| 체결 확인 | 다음 날 밤 해외 잔고 수량 증가 → 실제 매입액(USD × 그날 환율 × 1.0025)을 적립금에서 뺀다, 남은 돈 이월. 수량이 늘지 않았으면 그 주문은 **만료**로 보고 다시 판단 |
| 실행 | `scripts/qndx_alert.py run` 매일 **21:00 KST** (사용자 스케줄). 텔레그램 하루 1 회 |
| 화면 | 대시보드 독립 **해외 주식**(`/overseas`) — QNDX·BTQ 각각의 마지막 저장 보고서, 상태·마지막 실행 당시 자동 매수 스위치·적립금·1 주 가격·진행 막대·이번 달 매수·마지막 실행 때 확인한 보유 수량·매수/매일 기록. 실시간 계좌 조회는 하지 않는다. **평가 손익·수익률은 일부러 보여 주지 않는다**(사용자: "계좌를 보면 팔고 싶어서") |

## 2. 안전 (주문 경로)

- `KisReservationBuyer` 만 주문한다: **예약 매수만**, 매도·정정·취소 코드 없음. 허용 종목 `{QNDX}`, 수량 정확히 1, 지정가 ≤ **40 USD**. 어기면 요청을 보내지 않는다.
- `KIS_TRADING_ENABLED=true` 는 **사용자가 직접** `.env` 에서 켠다. 꺼져 있으면 알림만(앱 안내).
- **선기록:** 보내기 전에 주문을 "결과 모름"으로 상태 파일에 먼저 적는다 — 실행이 끊겨도 같은 날 두 번 보내지 않는다.
- **다시 보내지 않는다:** 네트워크 오류면 "결과 모름"으로 두고 다음 날 잔고로 확인한다. 토큰 무효·초당 한도처럼 거래소가 **거절한** 응답만 한 번 더 보낸다.
- 하루 1 건, 한 번에 1 주, 월 30 만 원. 최악의 경우도 하루 1 주(약 3.5 만 원)다.
- 기존 `KisOverseasReadOnly.place_order` 는 그대로 항상 막혀 있다.
- 테스트: 가짜 서버로 요청 모양(경로·`tr_id`·본문)·가드 5 종(요청 0 건)·네트워크 오류 1 회만·거절·토큰 재발급 1 회, 스크립트 선기록·같은 날 두 번째 실행·잔액 부족·꺼짐·긴급 정지.

## 3. 한계

- **첫 실제 주문이 곧 실서버 첫 시험이다.** 요청 형식은 한국투자증권 공식 예제대로 만들었지만 실계좌로 보낸 적은 없다. 거절되면 텔레그램에 코드·사유가 오고, 돈은 움직이지 않는다.
- 달러 예수금(또는 통합증거금)이 없으면 매수 가능 수량 0 → "입금 필요" 알림, 주문하지 않는다.
- 밤사이 3% 넘게 오르면 체결되지 않는다 → 다음 날 다시. 미국 공휴일은 따로 보지 않는다(만료 → 다음 날).
- 환율은 KIS 고시 환율이라 적립금 차감은 근사값이다.
- 하루 한 번(밤 9 시)만 본다. PC 가 꺼져 있으면 그날은 건너뛴다(적립은 달력대로 계속 쌓인다).

## 4. 켜는 순서 (사용자)

1. 스케줄 등록 (§5) — 아직 안 했다면.
2. 한국투자증권 앱에서 달러 예수금 또는 통합증거금(원화로 해외주식 주문)을 확인.
3. `.env` 의 `KIS_TRADING_ENABLED=true` 로 바꾼다. 끄려면 `false`, 급할 때는 `data/HALT` 파일.
