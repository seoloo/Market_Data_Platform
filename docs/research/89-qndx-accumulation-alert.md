# 89 — QNDX 적립 알림 (조회 전용 · 주문 없음)

작성: 2026-09-26 (Opus) · 상태: **구현·첫 실행 완료** (적립 시작 2026-09-26). 연구 판정이 아니라 **개인 적립 보조 도구**다.
사용자 요청 (2026-09-26): QNDX 가 앱 "모으기"에 안 돼서 "매일 1 만 원씩 매수한다고 가정하고 1 주 매수할 기간이 되었을 때 1 주 매수"
→ 자동 주문은 권한 검사에서 막혔다(아래 §4) → 사용자 선택 **"3번으로 알림만 만들어줘 · UI 에 따로 추가"**.

## 1. 무엇을 하나

| 항목 | 값 |
|---|---|
| 종목 | **QNDX** (State Street SPDR Portfolio Nasdaq 100 ETF, 나스닥 `NAS`) — 2026-09-26 조회 25.22 USD |
| 적립 | 시작일부터 **달력으로 매일 1 만 원** 가상 적립 (주말·휴일 포함) |
| 월 한도 | **30 만 원** — 이번 달 매수 + 1 주 가격이 넘으면 "이번 달 한도" |
| 1 주 가격 | KIS 현재가상세 `last` × 당일 고시 환율 `t_rate` × (1 + 0.25% 수수료) |
| 알림 | 적립 ≥ 1 주 가격이면 **"오늘 1주 살 차례"** + 권장 지정가(현재가 +2%, 장 전이면 예약주문). 아니면 "약 N 일 뒤" |
| 실행 | `python -m scripts.qndx_alert run` 매일 **21:00 KST** (사용자 스케줄 등록). 같은 날 텔레그램은 한 번만 |
| 매수 확인 | 사용자가 **앱에서 직접** 사면, 다음 실행이 해외 잔고의 수량 증가를 보고 실제 매입액(USD × 그날 환율 × 1.0025)을 적립금에서 뺀다. 남은 돈은 이월 |
| 기준 수량 | 첫 실행 때 이미 가진 수량은 적립에 넣지 않는다. 잔고가 줄면(매도) 알리기만 한다 |
| 화면 | 대시보드 **QNDX 적립**(`/qndx`) — 상태·적립금·1 주 가격·진행 막대·이번 달 매수·매수 기록·매일 기록. 실행 현황에도 한 줄 |

## 2. 한계

- **하루 한 번**(밤 9 시)만 본다 — 가격을 계속 지켜보지 않는다. PC 가 켜진 시간(20:45~21:20)에 맞췄다.
- 환율은 KIS **고시 환율**이다. 실제 환전 적용 환율·스프레드와 조금 다르다 — 적립금 차감은 근사값이다.
- 주말(KST 토·일 밤)에는 미국 장이 없다 — "살 차례"여도 "월요일 밤에 사면 된다"고 알린다. 미국 공휴일은 따로 보지 않는다.
- 문서 88: 과거 자료에서 "기다렸다 사기"보다 "바로 사기"가 조금 더 남았다 — 이 도구는 1 주 단위로 사야 해서 생기는 며칠의 대기만 있다.

## 3. 안전

- 한국투자증권 **읽기 전용** 어댑터만 쓴다: 현재가상세(`HHDFS76200200`) · 해외 잔고(`TTTS3012R`). 주문 API 호출 없음.
- `KisOverseasReadOnly.place_order` 는 그대로 항상 막혀 있다.

## 4. 자동 주문을 하지 않은 이유

처음에는 예약 매수 1 주 전용 경로(`TTTT3014U`, 지정가만, 당일 유효, 접수 10:00~22:20 KST 서머타임)를 만들려 했다.
실제 돈 주문 코드를 더하는 단계에서 Claude Code 자동 권한 검사가 막았고, 우회하지 않았다. 다시 하려면 사용자가 권한 설정을 바꾼 뒤 별도로 요청한다.

