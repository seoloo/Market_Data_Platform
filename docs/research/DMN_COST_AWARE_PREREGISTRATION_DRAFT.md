## 1. 질문과 경제적 가설

**같은 위험 예산과 지정가 실행 조건에서, 거래비용을 학습에 반영한 추세 모델이 단순 추세 규칙 및 기존 T/v2 연구용 기준선보다 비용 후 수익을 높이는가?**

경제적 출발점은 기존 연구에서 살아남은 BTC·ETH의 장기 추세다. 모델이 추세의 강도와 지속성을 구분하고, 작은 목표 비중 변화의 거래 대가를 학습하면 불필요한 매매를 줄일 수 있다는 가설이다. 새로운 독립 수익원 발견이나 AI의 수익 보장이 아니다. 추가 정보가 없거나 표본보다 모델 자유도가 크면 실패할 수 있다.

- T/v2·O/v1~v3의 운영 코드·설정·원장·일정은 그대로 둔다. 실제 운용 교체가 아니라 별도 연구용 비교다.
- H1~H3·WA·TA·KB·그리드의 기각 판정은 유지한다. KB는 [157](157-kb-survivorship-free-preregistration.md)에서 폐지 포함 종목군까지 기각됐다. 기각된 패턴·체결 흐름에 신경망만 붙여 재시도하지 않는다.
- 이번은 살아남은 추세 계열의 효율 개선 후보다. 숏은 기여를 따로 확인할 연구 요소이지, 기각된 숏 우위가 되살아났다는 전제가 아니다.
- 강화학습은 이번 모델에 섞지 않는다. 추세 학습과 거래 환경 학습을 동시에 비교하면 원인·자유도가 늘어난다.

## 4. 첫 단일 모델 제안 — 아직 확정값 아님

첫 범위는 BTC·ETH, 마감 일봉, 하나의 공통 소형 LSTM이다. 알트 선별·시간봉 비교·모델 간 경연은 하지 않는다. 다음 수치는 검토용 시작 설계이며 성과에 맞춰 고른 값이 아니다.

| 구성 | 초안 제안 | 확정 전 확인 |
|---|---|---|
| 판단 시점 | 00:00 UTC 일봉 마감 이후 일 1회; 주문은 결정 후에만 유효 | 실제 봉 timestamp·도착 지연·warm-up |
| 입력 | 20·60·120일 수익률을 당시 변동성으로 정규화한 3값 + 과거 60일 변동성 | 0/결측 처리·단위·규모; 추가 지표 없음 |
| 시퀀스 | 최근 120 마감 일봉의 입력 열 | 입력 내부 120일 계산까지 포함한 충분한 과거 자료 |
| 모델 | 단일 LSTM 1층·hidden 16·tanh 출력 1개, BTC·ETH 공유 가중치 | 파라미터 수·자료 대비 용량; 심볼별 모델 선택 금지 |
| 출력 | `s_t ∈ [-1,1]`: 양수 롱, 음수 숏, 0 중립 | 확률·신뢰도나 레버리지 배수가 아님 |
| 목표 비중 | 변동성 조정, 종목별 연 변동성 목표 15%; 종목 절대 비중 ≤50%, 합계 절대 비중 ≤100% | 모든 현행 위험·증거금·보호 한도가 더 먼저 적용됨 |

| 내부 확인 | TRAIN의 마지막 10%를 early stopping 전용; 개선 없는 25 epoch에서 종료 | label 경계 purge; 이후 VALIDATION과 분리 |
| 재학습 | 확정된 walk-forward 경계에서만; 구간 중 가중치 동결 | 기본 TRAIN 12개월/다음 3개월 규약과 용량의 정합성 |

수익률 계산의 원가격·정규화·변동성 연율화는 암호화폐 달력과 맞춰 명세화한다. 전체 표본 평균/표준편차를 사용하지 않는다. 후보와 기준선 모두 같은 사전 변동성·명목 상한을 쓰며, 사후 실현 변동성으로 좋은 쪽의 수익을 재배율하지 않는다.

batch마다 서로 다른 자산이나 시간창을 이어 붙여 가짜 하루 거래비용을 만들지 않는다. 경계의 직전 목표 비중·상태를 보존하는 방법을 확정한다. 내부 early stopping은 학습의 일부이며 독립 검증 통과가 아니다. 겹치는 시퀀스·BTC와 ETH를 독립 표본으로 늘리지 않는다.

이 용량이나 기본 학습 창이 자료와 맞지 않으면 **그 사실부터 보고**한다. 기간·hidden·입력·seed를 여러 개 돌려 좋은 것을 고르지 않는다. 자료/안전/계산 결함에 근거한 성과 전 보정만 이유·자유도·노출 범위를 기록하고 Claude가 확정한다. 성과 뒤 구조 변경은 이 후보의 구제가 아니다.

## 5. 학습 목표와 실제 평가를 분리

학습 목표 제안은 **비용 후 수익 근사의 음의 Sharpe 최소화**다. 목표 비중 변경의 비용을 학습 안에 넣는다. 손익은 직전 결정의 비중으로 다음 구간 수익에 연결하며, 당일 종가를 본 비중으로 그 당일 수익을 얻지 않는다.

- 비용 항은 `명목 비중 변경량 × 편도 비용 계수`다. 계수는 적용 요율·실측 또는 근거 있는 보수 가정으로 정하고 수익에 맞춰 벌점 배수를 탐색하지 않는다.
- 변동성 조정 때문에 신호가 같아도 비중이 바뀌면 비용이 발생한다. 목표 변경량과 실제 체결 변경량은 다를 수 있다.
- funding은 실제 부호·지급 시점의 보유 비중에 귀속한다. 과거 학습 목표에 사용한 사후 실현값은 당시 입력/예측 funding으로 되돌리지 않는다.
- 이 미분 가능한 근사는 지정가 미체결·계좌 정지·보호 실패를 완전히 표현하지 못한다. **학습 Sharpe나 근사 손익으로 통과 판정하지 않는다.**

최종 평가에는 기존 프로젝트 엔진의 동일 결정 경로·실제 체결 계약·회계·위험 상태를 사용한다. 학습용 근사와 계좌 결과의 차이를 비용·미체결·사이징·veto별로 보고한다. I/O와 학습은 Pure Core 밖, 고정된 모델의 추론/출력 변환은 동일 snapshot에서 결정론적으로 재생 가능한 경계로 설계한다. ML 라이브러리 설치와 생산 의존성 추가는 이번 문서 범위가 아니다.

## 6. 진입·보유·정리와 안전성 — 중요한 확정 보류

목표 비중과 현재 비중 차이로 늘리기·줄이기·정리 의도를 만든다. 비중 변화가 최소 주문·수량 단위를 만족하지 않으면 거래하지 않는다. 추가적인 데드밴드/확률 문턱을 수익 보고 도입하지 않는다. 청산 후 FLAT·재진입 대기 등은 현행 코어와 맞춰야 한다.

보유시간 상한·하루 거래 횟수·같은 방향 연속 진입 제한을 새로 넣지 않는다. 일 1회 판단은 관측 주기이며 사용자 계좌의 일 거래 한도를 만든다는 뜻이 아니다. 신호가 반대여도 손익이 양수가 될 때까지 청산을 미루지 않는다.

**일반 주문은 가격 한도 지정가만 쓴다.** [TRADING_CORE](../current/TRADING_CORE.md)의 비상 스톱·보호 실패 예외는 유지하되 T/v2 시장가 추격 예외를 새 DMN/연구용 기준선에 자동 적용하지 않는다. 가격 한도·대기/취소·재시도·부분 체결·만료·종료 잔여 포지션 계약은 성과 전에 고정한다. maker 체결을 보장하거나 마지막 미체결 물량을 무비용으로 없애지 않는다.

선물의 보호 스톱 위치·위험 역산·증거금 상한·청산 거리·G1~G7 적용 범위는 **미확정 핵심 관문**이다. 현물 T/v2의 무손절 예외나 O 연구의 예외를 새 선물 모델에 넘기지 않는다. 후보/기준선이 같은 보호·위험 예산에서 비교 가능한지부터 확인하고, 불가능하면 설계 보류 및 사용자 결정이 먼저다. 일손실·DD·연패 정지를 끄는 연구 모드도 자동 승인되지 않았다.

## 7. 비교 대상과 숏의 기여

비교 대상은 후보 경연이 아니라 한 후보의 원인을 구분할 기준선이다.

| 이름 | 내용 | 목적 |
|---|---|---|
| DMN-C | 비용 고려 소형 LSTM의 롱숏 목표 | 유일한 학습 후보 |
| SIMPLE-LS | 20·60·120일 수익률 부호의 평균으로 같은 시장에서 롱숏 | 학습 자체가 단순 추세보다 추가 효과를 내는가 |
| TV2-REF | T/v2 동결 신호의 연구용 현물 롱·현금 재생 | 사용자의 현재 대안보다 나은가; 운영 코드는 불변 |
| DMN-LONG-ABLATION | 재학습 없이 `max(s_t,0)`로 숏만 제거하고 전 경로 재생 | 숏이 수익을 더하는가; 통과한 대체 후보로 선택하지 않음 |

동일 자본·시장 시각·사전 위험 예산·보수 비용과 지정가 원칙을 적용한다. 현물과 선물의 실제 비용/funding은 서로 다르므로 억지로 동일 요율을 만들지 않는다. 같은 추세 신호를 현물/선물로 재생하는 회계 대조는 원인 설명용으로만 사전 명세화한다. 사후 배율 조정으로 기준선을 약하게 만들지 않는다.

숏 손익만 합산한 값과 숏 제거 계좌의 차이는 다른 질문이다. 포지션 경로·현금·비용·정지 상태가 달라지므로 후자는 전체를 다시 재생한다. 두 값·표본·SE를 함께 보고, 숏 구간이 부족하면 숏 기여는 판정 불가로 남긴다. 숏 제거판이 잘 나와도 이번 롱숏 가설을 통과시키거나 즉시 채택하지 않는다.

## 8. 분할·누출·모델 저장 계약

기간은 이번에 임의로 확정하지 않는다. 자료·프로젝트 열람 이력을 먼저 기록하고 계획용/학습/내부 early stopping/VALIDATION/역사 확인/최종 미열람 전향 기간을 달력 날짜로 채운다. 공통 walk-forward 기본은 TRAIN 12개월/다음 3개월이며, 이를 원논문의 긴 학습 기간으로 몰래 대체하지 않는다.

- 학습과 이후 label 구간 중첩은 purge한다. 무제한 보유에 가짜 최대 보유일을 넣어 embargo를 정하지 않는다.
- 입력 warm-up은 평가 시작 전 자료만 사용한다. 각 독립 재생은 현금으로 시작하는 안을 제안하며 구간 간 포지션·가중치 승계는 별도 명세가 필요하다.
- 일별 mark-to-market 손익을 한 구간에만 귀속하고, 경계 관통 거래의 거래 단위 통계는 중복 계산하지 않는다.
- 과거 미래 봉을 붙여도 과거 입력·정규화·판단이 바뀌지 않아야 한다. 테스트 label/funding/성과로 이전 시점 모델을 고치지 않는다.
- raw/manifest·code/config·model artifact·입력/출력 hash, 학습 cutoff, feature/학습 버전, seed·라이브러리/하드웨어·시도/실패 목록을 저장한다. CPU/GPU 차이와 저장 모델의 추론 재생을 따로 검증한다.
- 결과가 나쁜 seed를 버리거나 장애 재시도 명목으로 새 seed를 만들지 않는다. 같은 artifact 재생과 새 학습 실행을 구분한다.

## 9. 검정력 — 확정 전 필수, 현재 미측정

주 관찰 단위는 **달력 월의 BTC·ETH 합산 포트폴리오 비용 후 수익**을 제안한다. 체결 없는 달도 포함하며, 매일 발생하는 학습 샘플 수·가격 행 수·두 코인 수·거래 수를 월별 독립 n으로 쓰지 않는다. 거래당 평균/실제 체결 거래 n은 공통 Phase 4 검증용으로 따로 보고한다.

통계량 제안:

- `d_simple,m = DMN-C 월 순수익률 − SIMPLE-LS 월 순수익률` (주 추가 효과).
- `d_tv2,m = DMN-C 월 순수익률 − TV2-REF 월 순수익률` (현재 대안 대비).
- `r_m = DMN-C 월 순수익률` (절대 수익).

SE는 동시 월의 포트폴리오 시계열에 Newey–West HAC lag 3개월을 적용하는 안을 제안한다. lag 6개월은 감사용으로만 보고 좋은 쪽을 선택하지 않는다. 적은 월수에서 HAC가 불안정하면 게이트를 통과했다고 하지 않는다.

**검정력 계획용 검출 대상은 각 통계량의 연 산술 평균 3%p, 월 0.25%p를 초안으로 제안한다.** 기대 수익 예측이나 표본 평균의 통과 문턱이 아니다. 문헌의 샤프를 이 효과의 근거로 이식하지 않는다. 사용자가 의미 있다고 볼 추가 효과와 현실적으로 검출 가능한 효과를 함께 보고 확정한다.

1. 별도로 동결한 계획용 자료에서만 장기분산 기반 `SD_LR`의 근거·가용 월수·자기상관·위험 정지에 따른 표본 절단을 점검한다. 평균/성과 곡선을 숨겨도 계산에서 수익을 사용했다면 노출 사실을 적는다.
2. 개별 80% 참고 계산은 `N_required = ((2 + 0.8416) × SD_LR / 0.0025)^2`, `MDE = 2.8416 × SD_LR / sqrt(N)`다. 비용 후 값이므로 비용을 다시 빼지 않는다. 연 MDE = 월 MDE ×12는 산술 표시이며 CAGR이 아니다.
3. 아래 K1의 세 검정을 모두 요구하므로 각각 80%만으로 동시 80%라고 하지 않는다. 실패확률 0.20/3씩 배분해 각 검정력 ≥93.33%, `z_beta ≈1.501`의 필요 N 중 최대를 적용하는 보수안을 제안한다. 다른 강건성·위험 조건까지 포함한 전체 채택 확률 80%는 주장하지 않는다.
4. TRAIN·각 판정 구간의 가용 N/필요 N/달성 검정력/MDE와 도달 기간을 각각 채운다. 긴 TRAIN으로 짧은 OOS 부족을 덮지 않는다. 공통 Phase 4의 실제 체결 거래 요건도 별개다.

현재 **SD_LR·가용 독립 n·필요 월수·최소 검출 효과·확인 종료 시점 모두 미측정**이다. 후보를 학습하지 않은 상태의 기준선 분산은 추정 입력일 뿐 후보 차이의 실측 SD가 아니다. 이를 확정 통과로 포장하지 않는다. 후보를 먼저 학습해 분산을 구해야 한다면, 성과 실행 금지·신호 전 검정력 원칙과의 순서를 해결할 **별도 계획용 파일럿 승인/노출·제외 계약**이 먼저 필요하다. 이번 문서는 그 승인을 만들지 않는다.

구간이나 독립 표본이 부족하면 사전등록 확정 없이 보류한다. 효과 가정을 키우거나 코인 수·시간봉을 늘려 계산상 통과시키지 않는다.

## 10. 판정 기준 제안 — Claude 확정 전 실행 금지

| 번호 | 제안하는 필요 조건 |
|---|---|
| K1 통계 | `mean(r) − 2SE >0`, `mean(d_simple) − 2SE >0`, `mean(d_tv2) − 2SE >0`를 TRAIN 및 사전 지정 확인 구간 각각 충족 |
| K2 목표 적합성 | 같은 평가 구간에서 후보 CAGR > TV2-REF, Sharpe ≥ SIMPLE-LS 및 TV2-REF; MDD는 현행 한도 이내, 강제청산 0 |
| K3 비용·지연 | 수수료·실행 비용 2배에서도 순수익·두 기준선 대비 차이의 평균 >0; funding은 실제 시계열 유지 및 별도 불리한 스트레스 계약; 판단 후 실행을 1일 더 늦춰도 같은 세 평균 >0 |
| K4 숏·노출 | 순숏 기여와 숏 제거 전 경로 대비 차이가 양수인지 보고. 음수면 롱숏 개선 가설 실패; 충분한 숏 표본/SE 계약이 없으면 숏 기여 판정 불가. 단순 노출 증가만으로 차이가 설명되면 채택하지 않음 |
| K5 재현·안전 | 인과성·저장 모델 결정론·체결/회계·정지/보호·구간 경계 검사 충족; 비용 근사만 좋은 결과는 불인정 |

숏 기여의 독립 단위·필요 표본·통계 문턱, K3의 지연 및 불리한 funding 수치, 전체 Phase 4 게이트의 민감도/랜덤/셔플/창별 기준은 확정 전 명시해야 한다. 자유도가 있는 학습 모델의 민감도는 재학습 경연이 아니라 사전 정한 검사로 제한한다. 이 표로 [공통 Phase 4 게이트](../current/BACKTEST_AND_TESTING.md)를 생략하거나 완화하지 않는다.

- `DATA_NOT_READY` / `EXECUTION_NOT_READY`: 자료·체결/안전 계약 결함; 전략 수익 기각과 구분.
- `DATA_INSUFFICIENT`: 필요한 검정력·독립 구간/숏 표본 부족; 단순 실패와 구분.
- `REJECT`: 유효하고 충분한 판정에서 필요 기준 실패. seed·hidden·시간봉·종목·숏 방향을 바꿔 같은 자료로 재판정하지 않음.
- `HISTORICAL_SUPPORT`: 확정된 역사 확인 조건 충족. 최종 미열람 전향·전체 게이트·사용자 승인이 남아 있으며 전체 Phase 4 PASS/운영 교체/실거래 승인 아님.

TRAIN 실패 시 이후 성과 구간을 열지 않는다. 이후 구간도 예정한 횟수만 평가하며 중간 곡선을 보고 종료일을 바꾸지 않는다. 숏 제거판·다른 모델이 좋아 보이면 결과 설명만 남기고 새 독립 검증 가설로 사용자에게 제안한다.
