# RSI 다이버전스 수익 시험 — 사전 등록

작성: 2026-09-25 (Opus) · 트랙: 연구 전용 (거래·Shadow 경로 무관) · 상태: **사전 등록. 수익률 미열람.**
형식은 [37](37-fib-retracement-edge-test.md) 과 같다: 사건 수만 세어 검정력 관문 → **연구자 승인 뒤에만** 수익률을 한 번 연다.

## 1. 질문

EW-0 규칙의 **강세(상승) 다이버전스**가 확정된 4h 마감 뒤 1 일(6 봉) 동안 가격이 오르고, **약세(하락) 다이버전스** 뒤에는
내리는 쪽으로 평소보다 더 움직이는가?

## 2. 자료·사건 (고정)

- 자산·기간: BTCUSDT(DB) + ETHUSDT(내려받은 1m) USD-M, 2020-01 ~ (37 §2 와 같음). 1m 공백 4h 에서 구간을 끊는다.
- 다이버전스: `exposure.DivergenceIndex`(문서 38 §3 과 같은 규칙) — EW-3d′ 스캐너 발동 꼭짓점 열에서 같은 종류의 연속 4h 가시
  꼭짓점 두 개와 각 극값 4h 봉 종가의 RSI(14, Wilder)를 엄격 부등호로 비교. 사건 시각 t = 두 번째 꼭짓점이 발동한 4h 마감.
- 부호 s: 강세 +1, 약세 −1. 결과 R = s × ln(close[t+6] / close[t]).
- 대조: 사건이 아닌 모든 4h 마감(6 봉 뒤 자료가 있는 것), r = ln(close[t+6] / close[t]).

## 3. 검정 (고정)

- 독립성: 두 자산을 **한 시간축에서** 겹침 제거(앞에 남긴 표본의 6 봉 창 안이면 버림) — 사건·대조 각각.
- **주 추정량 (두 종류 합산):** D = mean(R_사건) − (w₊ − w₋) × mean(r_대조). w± = 남긴 사건 중 강세·약세 비율.
  대조를 사건의 부호 구성에 맞춰 부호화한 평균을 빼는 것이다. SE² = var(R_사건)/n1 + (w₊ − w₋)² × var(r_대조)/n2.
- H1 (한쪽): D > 0, 정규 근사, α = 0.05.
- 보조(기술 통계, 확증 아님): 강세·약세 따로, 자산별, 연도별.

## 4. 검정력 관문 (수익률 열람 전)

SD = 두 자산 모든 4h 마감의 6 봉 선행 로그수익 표준편차. **보수적으로 MDE = 2.84 × SD × √(1/n1 + 1/n2)** 로 계산한다
(부호 구성 가중치 |w₊ − w₋| ≤ 1 이므로 실제 MDE 는 이보다 작거나 같다). **관문: MDE ≤ 0.5%p.** 미달이면 수익률을 열지 않는다.

## 5. 판정 규칙

| 결과 | 판정 |
|---|---|
| 관문 미달 | 판정 불가 — 수익률 미열람 |
| 관문 통과·승인 후 p ≥ 0.05 | 다이버전스 방향 우위 증거 없음 |
| p < 0.05 이고 D > 0.1%p | 새 검증 가설로만 등록(다른 기간·자산 재현 필요). 바로 전략에 넣지 않는다 |

한 번만 판정한다. 결과를 보고 RSI 기간·호라이즌·사건 정의를 바꾸지 않는다.
