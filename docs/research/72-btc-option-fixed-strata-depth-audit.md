# 72 — BTC 옵션 무료 depth: 사전 고정 만기·행사가 범주 비교

작성: 2026-09-26 · Phase 0. [71의 6계약 결과](71-btc-option-fixed-depth-quality.md)가 연도와 내가격·등가격·외가격을 동시에 바꾸는 문제를 줄이기 위해, [67에서 이미 선택한 4일·48계약](67-btc-option-quote-quality-sample.md)의 **같은 날짜 안** 만기·행사가 범주를 비교했다. 이 비교는 전략 선별·손익 검정이 아니라 무료 자료의 범위와 표시 호가 품질 감사다. 유료 자료 구매, 인증, 원시 파일 저장, 주문, 기존 Paper·데모·실거래 변경은 없었다.

## 판정

`STRATIFIED_FREE_DEPTH_OBSERVED / YEAR_ROUND_EXECUTION_NOT_INFERABLE / ACCOUNT_RISK_NOT_CLEARED`.

네 무료 날짜에 사전 고정된 48계약 중 **45계약에 depth 프레임이 있었고, 3계약에는 없었다.** 각 날짜의 등가격 부근 계약은 관측된 프레임에서 양방향 표시 스프레드가 바깥 행사가보다 대체로 작았다. 먼 만기 등가격의 계약별 표시 스프레드 중위는 이 네 10분 창에서 콜 **43–189bps**, 풋 **60–190bps**였다. 하지만 프레임이 많다고 실제 유동성이 많은 것은 아니다. 2023년 가까운 만기 26k 풋은 **1,676프레임에서 최우선 bid/ask 가격·수량 상태가 1개**였고, 스프레드도 10,000bps였다. 등가격에 상대적으로 좁은 표시 호가가 있다는 사실만으로 양 옵션 다리와 선물 헤지를 체결할 수 있다거나 비용 후 수익이 있다고 결론 내리지 않는다.

## 사전 고정 표본과 계산

[Tardis 무료 원시 HTTP API](https://docs.tardis.dev/api/http-api-reference)에서 각 날짜에 `GET /v1/data-feeds/binance-european-options` 한 요청씩, `sliceSize=10` 및 해당 채널의 **사전 고정 12계약** 필터를 사용했다. [67](67-btc-option-quote-quality-sample.md)의 첫 관측 지수 **다음 1분부터 10분**을 범위로 정했다. 2023-08-01·2025-12-01·2026-09-01은 UTC 00:01–00:11(`offset=1`), 2024-08-01은 UTC 06:01–06:11(`offset=361`)이다. 2024년 00:00 지수는 없었으므로 06:00 이후만 사용한다. 2023–2025년은 `depth100`과 대문자 심볼, 2026년은 `depth20`과 소문자 심볼을 썼다([공급처 채널 변경 명세](https://docs.tardis.dev/historical-data-details/binance-european-options)). 한 날짜에 가까운/먼 만기 각각 지수 대비 약 90·100·110% 행사가의 콜·풋 6계약씩이다. 날짜·만기·행사가·구간은 호가 결과를 본 뒤 바꾸지 않았다.

각 원시 프레임을 [공식 옵션 매퍼](https://github.com/tardis-dev/tardis-node/blob/3361bcd310c6de608a1fda16c1976cb814c07dde/src/mappers/binanceeuropeanoptions.ts)와 같이 **독립적인 상위 N레벨 스냅샷**으로 읽었다. 양수 가격·수량 중 최고 bid·최저 ask가 있고 `ask > bid`면 양방향으로 분류했다. 표시 스프레드는 `10,000 × (ask−bid) / ((ask+bid)/2)` bps이고, 아래 중위값은 **해당 계약의 유효 프레임에 조건부**다. 프레임 무관측은 호가창이 비었다는 뜻이 아니다. 연결 중단 빈 줄은 2025년 요청에서 1개, 다른 세 요청에서 0개였다. 요청·분석은 메모리에서만 했고 원시 응답을 보관하지 않았다.

## 48계약의 관측량과 표시 스프레드

표의 각 칸은 고정 행사가 비율의 **콜 / 풋** 순서다. `—`는 해당 10분에 depth 프레임 0개라 스프레드도 계산할 수 없음을 뜻한다. 2024년 90%·110% 가까운 만기 무관측은 [71](71-btc-option-fixed-depth-quality.md)의 바로 앞 06:00–06:10 구간 첫 두 프레임과 모순되지 않는다. 두 프레임은 06:00:21 부근이고, 이번 창은 06:01부터 시작한다.

### 양방향 결손과 연결 경계

양쪽 가격·수량이 있는 프레임에서 교차·역전 호가는 48계약 어디서도 관측되지 않았다. **결손 프레임은 각 계약의 유효 분모에서 제외했지만, 자료 품질 판정에서는 제외하지 않았다.** 아래는 프레임이 있었으나 하나 이상의 bid/ask가 결손된 **모든 계약**이다(`유효/전체`).

| 날짜 | 가까운 만기 | 먼 만기 |
|---|---|---|
| 2023-08-01 | 없음 | 26k-C 7/8 |
| 2024-08-01 | 없음 | 58k-C 253/340 |
| 2025-12-01 | 81k-C 173/277, 81k-P 2,022/2,063, 90k-P 3,319/3,346, 99k-C 1,552/1,585, 99k-P 118/207 | 80k-C 156/265, 100k-P 141/209 |
| 2026-09-01 | 71k-C 122/145, 85k-P 106/110 | 70k-C 104/130, 86k-P 97/98 |

2025년의 연결 중단 전후는 한 연속 호가 상태로 이어 붙이지 않는다. 가장 넓은 표시 스프레드 중위(2025년 먼 만기 100k 풋 약 19,963bps)는 **141개 유효 프레임에만** 계산한 것이며, 나머지 68개는 ask가 없다. 2026년 가까운 만기 78.5k 콜·풋의 중위 스프레드 124/97bps 및 먼 만기 79k 콜·풋의 43/60bps도 **그 시각 표시 가격**일 뿐, 주문 시점 체결가가 아니다.

## 해석과 다음 게이트

같은 날짜 안의 비교로 [71](71-btc-option-fixed-depth-quality.md)의 연도·moneyness 혼합을 일부 줄였지만 **4개 월초 날짜×각 10분**, 서로 다른 시장 환경, 2025-12-17의 피드 형식 변경, 연도별로 다른 만기 길이 때문에 연중 체결 품질을 추정할 수 없다. 호가 갱신이 없는 사이 주문·취소와 실제 큐 위치는 관측 불가다. 상위 N레벨 표시 수량은 동시 다리 체결 용량이 아니며, 좁은 ATM 호가를 옵션 매도 수익의 증거로 사용하지 않는다. **사전등록·백테스트·실거래 게이트는 여전히 미통과**다.

다음 Phase 0에서 할 수 있는 것은 **이 48계약·같은 10분 창 안에서만** 사전에 정한 보호 옵션 매수·매도 다리 쌍의 동시 양방향 표시 여부와 두 계약의 마지막 관측 시각 차이를 측정하는 일이다. 이는 체결/위험의 필요조건 감사일 뿐 전략 진입이나 PnL 계산이 아니다. [69의 독립 증거금·숏 단독 체결·거래소 측 보호주문 충돌](69-btc-option-free-depth-and-leg-risk.md)은 별도 승인과 장애 시험 전까지 실거래 차단으로 유지한다. 유료 데이터는 구매하지 않는다.
