# 코인 차트 TCN V2 — 예측과 매매 정책 분리, 사용자 지시와 인계

2026-10-18 · 문서 인계 완료 · V2 설계/구현/학습/평가 미실행.

## 1. 사용자 지시와 이번 커밋 범위

사용자는 V1의 정답에 지정가 체결·최소 수량·3% 손절·24시간 보유·비용 후 20bp 기준이 함께 들어간 이유를 확인한 뒤, 차트 예측 연구와 매매 정책 연구를 별도로 진행하는 방향을 선택했다. 이어 다음과 같이 요청했다.

> 그렇게 진행할 수 있도록 너가 명시해서 커밋 가능하니? 다른 에이전트도 확인 가능하게?

이번 커밋은 **V1 보존, 별도 V2 신규 연구 허용 범위, 후속 에이전트의 진행 절차를 기록하는 문서 작업**이다. 모델 재학습·새 예측·계좌 재계산·운영 변경은 이번 커밋에서 실행하지 않는다.

후속 에이전트는 아래 범위에서 V2의 기술 세부를 성과 열람 전에 문서로 고정하고, 연구용 구현·실제 학습·평가까지 진행할 수 있다. 설계 문서만 작성하고 학습을 생략하라는 지시가 아니다. 기존의 제한된 후향 탐색처럼 학습 가능성 확인과 정식 수익 우위 입증을 구분한다. 작은 개선을 입증할 검정력이 부족하다는 이유만으로 유효한 자료의 탐색 학습 자체를 금지하지 않되, 그 결과를 정식 PASS로 승격하지 않는다.

## 2. V1 동결은 V2 연구 금지가 아니다

- V1은 [사전등록](TCN_CHART_20261018_PREREG.md), [결과](TCN_CHART_20261018_RESULTS.md), [검증](TCN_CHART_20261018_VALIDATION.md)와 커밋 `25b51b8` → `34a943e` → `e1bf580` → `e51f24c`로 식별한다.
- V1의 원본 문서·코드·자료·가중치·예측·계좌·해시는 보존한다. 결과는 실용적 매매 우위 미확인, 역사확인 TCN 전부 관망·거래 0건이다.
- V1의 결과 후 재튜닝 금지는 **V1 조건을 바꿔 기존 검증을 성공으로 바꾸거나 같은 후보를 구제하지 말라**는 뜻이다. 사용자가 선택한 새 목표의 V2까지 영구 금지한다는 뜻이 아니다.
- 이번 요청은 V1의 실패를 취소하거나, 체결이 실제로 가능했음을 인증하거나, 차트 딥러닝의 수익성을 인정하는 지시가 아니다.
- 기존 DMN/203/204/229 및 다른 연구의 판정과 T/O/AG 계열 운영 상태는 바꾸지 않는다.

## 3. 문제와 변경 이유

V1은 가격 방향 자체가 아니라, 고정 실행 모형으로 계산한 사후 최선 행동을 3분류로 학습했다. 정답 확정 7,243개 중 관망 5,431개이며, 그중 3,467개는 양쪽 진입 미체결/수량 조건, 1,964개는 체결 가능한 방향도 비용 후 20bp 미달이었다. 4시간 차트 입력에 다음 분 체결 가능성과 매매 조건의 결과까지 섞인 목표다.

이는 코드 미실행이 아니다. TCN은 실제 학습됐으며, 선택된 모델이 관망만 출력했다. 불균형 정답이 유일한 원인이라고 확정하거나, 관망 비중이 높으면 모든 모델이 반드시 관망한다고 단정하지 않는다. 이번 V2의 목적은 **가격 정보의 예측 가능성과 매매 실행의 경제성을 구분해 측정하는 것**이다.

## 4. 연구 A — 예측 전용 V2

- 첫 비교는 BTC/ETH, 완성 4시간봉 96개, V1의 10개 특징과 작은 TCN 몸통을 기준으로 한다. 여러 모델·입력·기간을 한꺼번에 바꿔 승자를 찾지 않는다.
- 첫 주 목표는 **신호 시점 이후 24시간의 순수 가격 로그수익률**이다. 신호 시점 마감가격을 C_t로 하면 `y_t = ln(C_(t+24h) / C_t)`로 정의한다. 봉 시작/마감 타임스탬프와 정확한 미래 봉 대응을 구현 전에 검산한다.
- 24시간은 첫 실험에서 V1과 비교를 단순화하는 예측 기간이다. 실제 매매에서 반드시 24시간 보유하라는 제한이나 모든 시간 범위를 학습했다는 주장이 아니다. 다른 기간은 별도 버전으로 사전 정의한다.
- **진입 미체결·최소 주문 수량·3% 손절·수수료·funding·20bp 이익 기준으로 가격 예측 정답을 관망/0으로 치환하지 않는다.** 예측 정답에 관망 행동 클래스를 두지 않는다.
- 가격 결측과 잘못된 봉은 결측 정답으로 기록한다. 가격 정답 가용성과 주문 가능 여부를 다른 필드로 보존하고, 미래 미체결 여부로 예측 입력 행을 선별하지 않는다.
- 목표를 회귀로 바꾸므로 출력층·손실은 그에 맞게 변경한다. TCN 몸통 유지와 출력/손실 변경을 구분해서 기록한다. V1 가중치를 덮어쓰지 않고 V2를 별도 학습한다.
- 연속 정답의 단순 기준으로 0수익 예측·TRAIN 평균 및 동일 입력의 정규화 선형 회귀 등을 사용한다. V1의 로지스틱 3분류를 그대로 주 회귀 기준이라고 부르지 않는다. 선택 이유·정규화·모형 예산을 성과 전에 고정한다.
- 예측 MAE/MSE·단순 기준 대비 개선·방향 구분·기간/자산별 안정성을 보고한다. 가격 변화 크기와 불확실성/확률을 추가 출력한다면 산출 방법과 검산 지표를 미리 정하고, 점수를 실제 승률로 부르지 않는다.
- 거래 수를 늘리기 위한 class weight/확률 문턱 조절이나 좋은 난수 선택으로 결과를 구제하지 않는다. 학습 횟수·난수·중단 규칙·총예산은 성과 전에 확정한다.

## 5. 연구 B — 별도 매매 정책

- 입력은 연구 A가 만든 예측과 그 시점까지 알 수 있는 시장/계좌 정보다. 출력은 진입·관망·비중·손절·청산이다. **관망은 이 단계의 결정**이다.
- 처음에는 단순한 고정 정책 하나로 예측의 기여를 평가한다. 강화학습·다수 정책 탐색을 이번 변경의 기본 작업으로 추가하지 않는다.
- 수수료·불리 체결·funding·수량 단위·최소 명목·지정가 미체결·부분 체결·위험 제한은 계좌 평가에 남긴다. 가격 정답에서 비용을 분리하는 것이 비용 없는 매매 성과를 채택한다는 뜻은 아니다.
- 손절·보유·진입 문턱·노출 한도 등 정책의 수치는 후속 명세에서 성과 전에 확정한다. V1의 3%/20bp가 가격 학습 목표의 영구 제한이라고 해석하지 않는다. 기존 운영 위험 한도를 임의 완화하지 않는다.
- V1 체결 모형의 `가정 불리 가격이 분봉 범위 밖이면 미체결` 조건은 비용 가정과 체결 가능성의 연결을 별도 감사한다. 현재 관망 결과만을 이유로 낙관적 체결·전량 체결을 가정하지 않고, 과거 호가 부재와 불확실성을 남긴다. V1 실행기를 소급 교체하지 않는다.
- 정책 개발/선택에는 예측 모델이 같은 정답 표본에 맞춘 학습 내 예측을 쓰지 않는다. 시간순 교차 학습 또는 별도 개발 구간에서 얻은 예측을 사용한다. 최종 결합 평가 전 예측 모델과 정책을 모두 고정한다.
- 예측 개선, 거래 선택 개선, 비용 후 계좌 개선을 각각 보고한다. 거래 0건도 숨기지 않되 거래 자체를 강제해 성공 기준으로 삼지 않는다.

두 연구의 명세와 코드는 분리해서 진행할 수 있다. 결합 계좌 평가는 예측 결과와 고정 정책이 준비된 뒤 수행한다.

## 6. 자료와 검증 경계

- V1 원자료를 읽는 것은 허용하되 읽기 전용으로 사용하고 원본 산출물은 덮어쓰지 않는다. V2의 경로·시도 식별자·모델·전처리·예측·원장을 별도로 둔다.
- TRAIN/검증/평가 분할, 정답 중첩 제거, TRAIN 전처리, 난수, 모델/정책 선택 절차를 첫 V2 성과 열람 전에 고정한다. 시간 무작위 분할과 전체 표본 전처리는 금지한다.
- 2020~2026-08 등 이미 노출된 역사를 재사용한 개발/진단은 허용하지만 **탐색적 후향 결과**로 표기한다. 같은 자료에서 새 모델을 학습했다고 독립 미사용 OOS가 되는 것은 아니다.
- 최종 독립 확인에는 별도로 보존된 적법한 자료나 이후 자료가 필요하다. 이 지시로 2026-09 이후 자료·연구208·기존 봉인 자료의 열람 권한이 추가되지 않는다.
- 높은 예측 정확도·낮은 예측 손실·일부 양수 계좌를 정식 PASS나 운영 승인으로 대체하지 않는다. 불리/불명/자료 오류를 구분하고 중단 근거를 기록한다.

## 7. 후속 에이전트 실행 순서

1. AGENTS와 최신 handoff, Current 문서, 이 인계, V1 원문/코드를 확인한다. V1 종료 문구만 보고 V2를 재연구 금지로 처리하지 않는다.
2. V2 전용 경로와 사전 명세를 만들고 예측 정답·출력/손실·기준 모델·분할·학습 예산을 고정/커밋한다. 명세는 새 학습/평가 전에 확정한다.
3. 인과적 특징·정답 시점·경계·결측·전처리·모델 저장/재생 검증 후 연구 A를 실제 학습/평가한다. 단순 기준이 약하다는 이유만으로 TCN 학습을 생략하지 않는다.
4. 연구 B는 실행 모형 감사와 정책 명세를 별도로 남긴다. 비용 후 매매 판단은 예측과 다른 평가라는 점을 유지한다.
5. 각 결과와 한계를 보존하고 PROGRESS/연구 이력/LLM 요약에 실제 실행 범위와 다음 작업을 기록한다. 성과에 맞춘 반복 변경은 새 버전/탐색 이력으로 남기고 최종 확인 자료를 재사용하지 않는다.

현재 상태는 **V2 신규 연구 지시 기록 / 기술 명세 미확정 / 구현·학습·성과 없음**이다. 이 문서는 V2 전체 기술 사전등록이나 이미 실행한 결과 보고서가 아니다.

## 8. 주식 확장과 운영 경계

주식 확장은 향후 별도 자료·모델 학습·검증으로 진행할 수 있도록 자료/특징/예측/정책/시장별 실행 모듈을 분리한다. 이번 인계에서 주식 학습은 실행하지 않는다. 당시 종목군·상장폐지·분할/배당·세션/휴장·거래정지·공매도/대차를 별도로 확인하며 코인 가중치를 그대로 주식 수익 근거로 사용하지 않는다.

기존 운영 전략·주문·모의매매 운영·예약·알림·유료 자료/외부 모델·운영 환경·위험 한도는 변경하지 않는다. V2의 연구용 구현/학습과 실거래 배포 권한을 구분한다.
