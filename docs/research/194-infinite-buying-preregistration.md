## 1. 규칙 — V2.2 (2 차 자료 여러 곳이 일치하는 부분만)

| 항목 | 규칙 |
|---|---|
| 분할 | 원금 C 를 **40** 등분, 1 회분 u = C / 40 (단리 — 수익은 쌓아 두고 1 회분은 늘리지 않음) |
| T (회차) | T = 들어간 원가(평단 × 수량) ÷ u, 소수 둘째 자리 올림 |
| 별% | **10 − T / 2** (%) — 별지점 가격 = 평단 × (1 + 별%) |
| 첫날 | 1 회분을 그날 종가에 산다 |
| 전반전 매수 (T < 20) | 0.5 회분 LOC @ 평단, 0.5 회분 LOC @ 별지점 (종가 ≤ 주문가면 종가에 체결) |
| 후반전 매수 (T ≥ 20) | 1 회분 LOC @ 별지점 |
| 매도 (매일 두 건) | 수량 1/4 LOC @ 별지점 (종가 ≥ 주문가면 종가) · 수량 3/4 지정가 @ 평단 × 1.10 (그날 고가 ≥ 주문가면 체결, 시가가 이미 넘으면 시가) |
| 사이클 끝 | 수량이 0 이 되면 다음 날 새로 시작 (첫날 규칙) |
| 돈이 모자라면 | 남은 현금만큼만 산다 |

- **원금 소진 처리(T ≥ 39) — 원문 확인 실패, 두 판을 미리 정해 둘 다 낸다**
  - **H 버티기**: 더 사지 않고 위 매도 주문만 계속한다. 별% 가 음수라 1/4 매도가 손실로도 체결될 수 있다.
  - **Q 쿼터 손절**: T ≥ 39 인 날 종가에 수량 1/4 을 판다(그날 다른 주문 없음). 그 뒤 위 규칙대로 이어간다.
- 판정에 쓰는 기본은 **H** 다. Q 는 함께 보고하고, 판정 기준을 똑같이 적용한 결과도 적는다.
