# BTC·ETH 차트 TCN — 제한된 후향 학습 실험

2026-10-18 · Phase 0 성과 전 고정. 운영·기존 연구 판정 불변.

## 승인과 질문

사용자의 첨부 요청에 따라 감사에서 멈추지 않고 작은 TCN을 실제 학습한다.
연 3%p 개선/80% 검정력은 이번 학습 선행 조건에서 제외한다. 이는 정식 PASS,
미사용 OOS, Paper/Live 승인이나 기존 기각 취소가 아니다. 결과 후 재튜닝하지 않는다.
Laya 지표 질문과 로컬 지도학습은 다르다. DMN/203 코인은 학습 전 중단,
204 주식 LR/XGB는 실제 학습 후 기각, 229/Laya와 차트 조합 기각은 그대로다.

질문: 96개 마감봉의 변화 순서를 학습한 작은 비선형 모델이 같은 정보의 선형 모델과
고정 추세 규칙보다 이후 구간 판단 및 비용 후 손익을 개선하는가? 새로운 정보원이
아닌 가격 표현 연구이며, 같은 가격 연구의 반복·선택 오염과 낮은 사전 기대를 인정한다.

## 자료와 범위

- 입력·체결 모두 Binance USD-M BTCUSDT/ETHUSDT. 현물 가격을 선물로 오인하지 않는다.
- 공개 월별 1분봉 2020-06~2026-08를 4시간봉으로 재집계한다. DB의 일부 과거 4h와
  분봉 재집계가 달랐던 이력을 보존하며 분봉을 이번 일관된 기준으로 쓴다.
- 현재 목록에는 다수 코인 4h/5m가 있으나 월별 선물 1m는 BTC/ETH만 각 80개월이다.
  다종목의 부분 기간·폐지·funding 결측과 분봉 정밀도를 통일하지 못했으므로 첫 실험을
  두 자산으로 축소한다. 이는 생존편향 없는 전체 코인 결과가 아니다. 현재 상장 종목을
  소급 선별해 성공했다고 주장하지 않는다. 다종목 PIT 모델 학습은 미실행으로 남긴다.
- 2026-09-01 UTC 이후 원자료/봉인 자료 및 연구208 폴더를 열지 않는다.
- raw ZIP 해시·CRC·OHLCV 유효성·정렬·중복·1m 간격/4h 완성도를 검사한다.
  gap/비정상가격을 보간하지 않는다. 해당 96봉 입력/미래 경로는 사용 불가로 기록한다.
- 기존 short_validation_laya_20261013의 funding_rest.json과 mark_hour_supplement.json,
  공식 mark1h ZIP을 읽기만 한다. 정산 mark가 없으면 해당 hour 시가를 대리 사용하며
  rate/시각은 실제 기록 그대로다. mark 고저 불리 경계도 보고한다. 원자료는 수정하지 않는다.
- 과거 거래규격 전체 이력은 없다. BTC/ETH 수량단위 0.001, 최소수량 0.001,
  최소명목 100 USDT, 가격단위 BTC 0.1 / ETH 0.01을 보수적 고정 모형으로 사용한다.
  이를 역사적 거래소 규격 인증이라고 하지 않는다.

## 입력과 정답

4h는 UTC 00/04/08/12/16/20시 경계, 완성 후만 사용한다. window=96.
10개 특징: ln(O/Cprev), ln(H/Cprev), ln(L/Cprev), ln(C/Cprev), (H-L)/Cprev,
ln(V/직전20봉 평균 V), ln(C/SMA20), ln(C/SMA60), (RSI14-50)/50, ATR14/C.
SMA는 해당 마감봉 포함, RSI/ATR는 Wilder 초기 14개 평균 뒤 alpha=1/14.
gap이면 지표 상태를 재시작한다. 모든 96개 값이 유효해야 한다.
TRAIN 입력값만 평균/표준편차 fit, sd=0은1, z를 [-8,8]로 고정 clip.
종목ID/절대가격/날짜/funding은 모델 입력에 넣지 않는다. feature selection/추가 탐색 없음.

주 목표: 고정 거래의 단위 체결명목 순손익을 비교한 3분류(0 FLAT / 1 LONG / 2 SHORT).
각 4h 마감 t에 같은 1,000 USDT 희망명목의 독립 가상 롱·숏 사건을 평가한다.
미체결 방향은 선택 대상 아님. 정상 종결된 방향 중 최고 순손익 > 0.002(20bp)면 그 방향,
둘 다 손실/최고≤20bp/동점이면 FLAT. 자료누락·미종결 방향이 있으면 정답 불명으로 제외한다.
정답은 학습 시점 미래 관측값이며 feature에 절대 들어가지 않는다.
미래24h 가격 방향은 부속 진단일 뿐 주 학습 목표가 아니다. 출력은 softmax 점수이며
calibration 검산 전 실제 승률/기대손익이 아니다. 계좌 gate가 별도로 주문을 거부할 수 있다.

## 분할과 학습 예산

TRAIN 2020-07-01~2023-12-31, VALIDATION 2024년, 최종 역사확인 2025-01-01~2026-08-31.
모든 종목 같은 경계. 각 경계 전 26시간의 결정은 purge(24h+최대1h 정리+지연 여유).
확인 시작 전 과거 입력 warmup은 허용. 미래 정답은 경계를 넘지 않는다.
시간 무작위 split 금지. 학습 minibatch 셔플만 고정 seed로 허용한다.
재학습/rolling 모델 경연은 하지 않는다. 이번은 고정 시간분할 실험이며 walk-forward 검증은 미실행.
역사 전체가 기존 연구 노출 구간이다. 모델 미학습 이후 구간과 독립 미사용 OOS를 구분한다.

- A RULE: C>SMA20>SMA60 및 RSI14>50이면 LONG, 반대이면 SHORT, 그 외 FLAT.
- B LR: TCN과 동일한 96×10 입력을 펼친 L2 다항 로지스틱, C=0.1, max_iter=1000.
  hyperparameter 탐색 없음. 같은 입력시간을 제공해 TCN만 과거를 보는 불공정 비교를 피한다.
- C TCN: 16채널, kernel3, dilation1/2/4/8/16의 잔차블록(각2 causal conv),
  dropout0.1, 마지막시점→3class, 파라미터 20,000 이하. BTC/ETH 공통 가중치.
- CrossEntropy(가중치 없음), AdamW lr0.001/weight_decay0.001, batch128,
  최대30 epoch, validation log-loss 0.0001 이상 개선 없는5회 중단. grad norm1.
  seed20261018 하나, 최저 validation loss checkpoint 하나. 좋은 seed 선택 없음.
- RTX3060 12GB CUDA 우선, 4 CPU threads, VRAM8GB 이하 목표. OOM이면 batch만64로
  축소한 재시작을 실패 이력에 남긴다(동일 seed). 모델/학습률/특징 변경 금지.
  최대 총 학습60분. CPU fallback은 동일 모델/seed, 시간상한120분.
- 운영 .venv 변경 없음. build/tcn-venv에 torch/numpy/scikit-learn만 별도 설치.
- 신호는 argmax 클래스 그대로, 확률문턱 최적화/재보정 없음. 동점은 FLAT.
  LR 불리여도 TCN은 반드시 학습한다. 재생용 checkpoint/scaler/예측/환경/시도 해시 보관.

## 체결과 위험 회계 계약

기존 프로젝트의 다음분 진입·직전분 참여량·가격한도·Decimal 회계 방식을 재사용하는
독립 연구 모형이며 외부 backtest 프레임워크를 도입하지 않는다. 실주문 import 없음.

일반 주문은 지정가만. t+1분(지연검사는 t+6분)의 시가에 불리0.045%를 반영한 가격이
직전 완성분 종가±0.3% 한도 안이고 해당분 실제 고저 범위 안에 있으면 체결 가능으로 모형화한다.
가격 한도 밖/거래량0이면 미체결. touch만 보고 전량체결을 보장하지 않는다.
수량≤직전 완성분 volume×0.001, 수량내림/최소명목 적용. 남은 진입량 즉시 취소.
호가/큐 부재로 이것도 실제체결 인증은 아니다. 주문 latency는 1분 보수 가정이다.
진입가±3% 비상stop(허용 STOP_MARKET 예외), gap이면 더 불리한 시가와 추가0.2% 적용.
정산을 보유수량에 반영한 뒤 stop 우선, 그 다음 24h 시간청산. TP/추가매수/반대신호 청산 없음.
일반청산은 같은 가격한도·참여량으로 매분 잔량 재시도. 24h는 정리 시작이며 지정가라
정확히24h 내 전량 종료를 보장할 수 없다. 최대1h 뒤 잔량은 UNRESOLVED/MTM으로 남기고
계좌 신규진입 중단. 강제 시장가나 잔량 삭제 없음. 경계26h purge.
진입분은 해당분 최악 stop경로, stop과 시간청산 동분이면 stop우선. funding은 진입시각 제외,
보유 중 정산시각 포함. stop분의 순서 불명 funding은 debit 유지·credit 생략한다.

계좌는 각 구간/모델/민감도마다10,000 USDT 현금 시작, 동시에 한 포지션(두 자산 합산).
같은 시각 두 신호는 직전20봉 평균 거래대금 높은 자산 우선, 동점 symbol순.
레버리지1x, 명목≤equity10%, 비용 포함손절예산≤equity1%, 현금여유≥증거금1.5배.
일손실2% UTC 일 시작 equity 대비, 누적DD30% 영구신규정지, 4연패240분,
청산 후60분 대기. 정지 중에도 보호·시간청산 계속. 미실현 포함 equity/minute 위험 점검.
fee0.05%+가격불리0.045%=통상편도0.095%, 추가주문별수수료, 실제funding rate 적용.
1x와3%stop은 청산거리 여유가 크지만 historical tier/mark-stop 정확한 강제청산 parity는 미인증.
G1 실거래 시스템/호가, G5 전체, G6 역사달력, G7 실시간기대edge는 복원하지 않는다.
금융위험 한도는 적용하되 이 계좌는 설명용 회계이지 운영 gate 통과 인증이 아니다.

주 비교3개×구간3개. 역사확인에만 사전고정 민감도: 비용2배, 진입추가5분,
참여량절반(0.0005), funding mark 불리 bound. 모델/신호 재학습·승자 재선택 없음.

## 평가·판정·검증

분류: macroF1/accuracy/클래스별precision·recall·support, confusion,
log-loss/Brier/10bin calibration, TRAIN상수확률과 비교, 종목/연도별 결과.
계좌: 순손익/CAGR/일수익Sharpe(365)/minuteMDD/최악월/횟수/평균최대명목노출/
회전율(체결명목÷초기자본)/fee/funding/평균승패/롱숏/자산·연도·상위5거래 기여/
미체결·부분량·지연·거부·미종결. 비슷한 날짜 코인들을 독립 n으로 세지 않는다.
동일달 포트폴리오 수익차의 Newey-West lag3 SE·2SE 범위를 보조 보고한다.

후속가치 있음(탐색적): TCN 역사확인 net>0, RULE/LR보다 net와Sharpe 모두 높음,
MDD가 두 대조 중 작은 값보다2%p 초과 악화하지 않음, 앞뒤 반쪽 증분 모두양수,
고정민감도에서 TCN net양수, 확인체결100건 이상, 누출/회계/재현 오류0.
아니면 불리/혼재/판단불가 이유를 구분한다. 어느 경우도 PASS/운영승인 없음.
표본이 작거나 CI가0 포함이면 수익 우위 확정불가. 결과 후 특징/정답문턱/손절 재튜닝 금지.

테스트: 미래추가시 과거특징불변, 96봉/정답 경계purge, train-only scaling,
양방향정답/동점/미체결, 가격한도·부분체결·최소수량, funding부호·보유량,
stop/gap/시간우선순위, 계좌정지/재진입, 손계산Decimal 원장, 저장모델추론재현.
학습 전 명세 커밋. 테스트 결함은 결과와 무관한 교정으로 기록하며 실패결과를 덮지 않는다.

## 주식 확장 경계

data(시장자료/종목군), features(시장공통), labels(거래결과→정답), models(학습/예측),
execution(시장별 비용/세션/funding), account/metrics 분리. torch모델에 코인시계·funding 없음.
주식에서는 PIT/폐지, 분할·배당·수정OHLC, 세션·휴일, 정지·가격제한,
공매도·대차, 분봉범위를 별도 확보하고 새 기간분할/학습/평가가 필요하다.
이번에 주식학습/이미지학습/Shadow·Paper·Live·알림·예약·외부게시를 하지 않는다.
