# IDEAS 5 — 한국 실적 개선형 주도주 사전등록 초안

작성: 2026-10-05, Codex. 기준 커밋 `3149824`. **DRAFT / Phase 0 / NOT_TESTED**.
사용자 요청: “IDEAS.md 5번 사전 등록 초안 써 줘”. [역할 분담](../../AGENTS.md) §9에 따라 Claude가 자료 감사·구현·확정 커밋·1회 판정을 담당한다.
이 문서의 수치는 **검토할 설계 제안**이며 수익으로 최적화한 값이 아니다. 초안 작성 요청을 전체 수집·실험·실거래 승인으로 확대하지 않는다. 아래 확정 보류 항목을 채우기 전 성과 판정을 실행하지 않는다.

## 1. 질문·수익 가설·실패 원인

질문: **당시 공개된 매출 성장세·영업이익률·현금흐름의 개선으로 한국 비금융 기업을 고르면, 같은 투자 가능 종목군을 고르게 보유하는 것보다 비용 후 수익이 높은가?**

사업 개선의 지속성을 시장이 충분히 반영하지 못한다는 가설이다. 이미 가격에 반영됐거나 일회성 회계 변화·산업 사이클·높은 매입 가격이면 실패할 수 있다. 보고 실적을 유기적 성장으로 자동 인증하지 않는다.
[131](131-fundamental-leaders-feasibility.md)의 재무 측정치를 한국에 적용한다. 141의 가격 순위, 142의 수급 순위와 입력 정보가 다르다. LT의 기간·손절을 바꿔 재시험하지 않는다. 미국 4번, 실적 갭 130, 가치·품질 후보를 합치지 않는다. 뉴스·AI·추세 필터·공매도·레버리지는 이번 주 가설에 추가하지 않는다.

목표를 두 단계로 나눈다. 이번 초안은 **실적 신호 선별과 지정가 체결을 반영한 연구 모형의 역사적 우위**를 판단한다. 통과하더라도 전체 위험 규칙·보호주문·독립 전향 자료를 갖춘 실거래 전략 승인이 아니다. 기존 운영 전략과 위험 한도는 별도다.

## 2. 자료 점검 결과의 범위와 확정 전 관문

[Claude 경로 B 감사](FUNDAMENTAL_KR_DART_FEASIBILITY.md)는 회사 연결 970/970, 재무제표가 나온 표본 52/52의 세 계정 존재·접수일을 확인했다. 이는 **접근·항목 존재 소표본 통과**다. 정정 전 수치·연속 분기·전체 커버리지·종료 총수익의 검증 완료는 아니다. 금융 표본의 미제공을 모든 금융회사·전 기간 API 미지원이라고 일반화하지 않는다. 금융 제외는 회계 비교 가능성에 따른 사전 설계다.

| 관문 | 확정 전에 필요한 증거 | 미달 처리 |
|---|---|---|

90%·100종목은 이번 초안의 자료 품질 제안값이다. 충족해도 누락이 무작위라는 뜻은 아니다. 당시 상장기간/필요 공시 이력이 모자란 신규 상장사는 사전 자격 제외로 따로 집계하고, API 복원 실패를 자격 제외로 재분류해 적재율을 높이지 않는다. 후기 상장폐지 여부는 누락 감사에만 사용하고 당시 선정에는 사용하지 않는다.

**먼저 할 일:** 기존 표본에서 원공시/정정 한 쌍과 연결·별도 전환/누적 분기 사례를 검산하고, 12분기를 채울 수 있는 최초 시점을 계산한다. 이 점검 뒤 전체 수집 규모를 산정한다. 기존 “약 2.6만 요청·이틀”은 원문/정정/재시도까지 포함한 보장 일정이 아니다.

## 3. 당시 사용 가능한 재무 값의 계약

1. 공시검색 `last_reprt_at=N`으로 원본·정정 이력을 보존하고 `rcept_dt`를 사용한다. 접수번호 앞 8자리는 교차 확인용이다. 날짜만 있으므로 접수일 장중에 알고 있었다고 가정하지 않는다. **접수일 다음 실제 거래일의 장 마감 이후** 가용으로 간주한다. 월말 마감 의사결정에 가용한 공시만 포함, 주문은 다음 세션부터다.
2. `fnlttSinglAcntAll`은 회사·사업연도·보고서·연결/별도 인자로 요청하고 응답에 접수번호를 돌려준다. 원본 접수번호를 요청 인자로 지정하는 API가 아니므로, 응답 하나로 정정 전 버전까지 확보했다고 할 수 없다. 필요하면 접수번호별 `document.xml` 또는 XBRL 원문에서 복원한다. 실제 제공 여부는 Claude가 확인한다.
3. 관측 당시 가용한 버전만 채택한다. 사후 정정본을 추가해도 정정 가용일 이전 신호는 바뀌면 안 된다. 현재 다운로드 시각·공시 접수일·정정일·회계기간 종료일을 각각 저장한다.
4. 비교에 쓰는 전체 창은 CFS를 우선한다. CFS 미제공이 확인되고 OFS로 전 창이 일관되게 복원될 때만 OFS를 쓴다. 요청 실패를 OFS 전환 사유로 쓰지 않는다. 두 기준을 같은 TTM에 섞지 않는다. 당시 공시된 재작성 비교값은 가용일 이후에만, 동일 기준의 전체 비교 창이 성립할 때 사용한다.
5. 매출·영업이익은 IS/CIS의 동일 범위 계정, 현금흐름은 CF의 누적 기간을 확인한다. 이름 일치만으로 합계/부분 계정을 선택하지 않는다. `thstrm_amount`와 `thstrm_add_amount`의 의미를 보고서별 원문으로 확인한다. Q2=H1−Q1, Q3=9개월−H1, Q4=FY−9개월은 모두 같은 기준·같은 회계연도 누적일 때만 가능하다.
6. 정정 충돌·누락·0 이하 매출 분모는 결측이다. 임의 0·업종 평균으로 채우지 않는다. 최신 공시의 회계기간 말에서 월말 결정일까지 **180일 초과**면 신규 매수 대상에서 제외한다. 보유분은 §5의 다음 재평가 청산 규칙을 따른다.

## 4. 종목군과 실적 점수 — 초안 단일 모델

월말 실제 거래일 마감에 당시 유가증권시장에 상장된 보통주 중 비금융 일반 사업회사만 대상으로 한다. 우선주·ETF/ETN·SPAC·REIT는 제외한다. 금융/자격은 당시 확인 가능한 기업 정보로 판단하고 현재 KSIC를 과거에 그대로 쓰지 않는다. 확인 불가 비율도 기록한다.

직전 **63거래일 평균 거래대금 상위 200종목**을 먼저 고른다(63일 중 거래정지일 거래대금은 확인된 0, 자료 결측과 구분). 그 다음 필요한 회계 이력이 원래 존재할 자격과 실제 재무 복원 여부를 구분한다. 재무가 누락됐다고 201위 이하 기업을 채워 넣지 않는다. 기존 141의 수익률 모멘텀 자격조건·시장 필터는 가져오지 않는다. 200/63은 기존 자료 경로와 일관된 유동성 설계 제안이며 최적값 주장이 아니다.

회사별 최신 가용 분기 q에서 TTM 매출 R(q), 영업이익 O(q), 영업현금흐름 C(q)를 계산한다. q−4는 1년 전, q−8은 2년 전 같은 분기다.

| 요소 | 정의 | 단위 |
|---|---|---|
| 매출 성장 가속 A | g(q)=R(q)/R(q−4)−1, A=g(q)−g(q−4) | 비율 차이, 표시할 때 %p |
| 이익률 개선 M | O(q)/R(q)−O(q−4)/R(q−4) | %p |
| 현금흐름 개선 F | C(q)/R(q)−C(q−4)/R(q−4) | %p |

매출 가속은 R(q−8)까지 필요하므로 **매출 최소 12개 분기**, 나머지는 최소 8개 분기다. 2015 Q1부터만 복원되면 최초 q는 2017 Q4이고 그 공시가 가용해진 **2018년부터** 가능하다. 2016년 시작은 자동 채택하지 않는다. 2015 공시의 과거 비교표로 더 오래된 값을 검증할 수 있어도 이번 평가 시작을 성과를 보고 앞당기지 않는다.

계산 가능한 모든 종목 E에서 A/M/F 각각의 오름차순 평균순위 백분위 `(평균순위−1)/(N−1)`를 계산하고 **세 백분위의 단순 평균**을 점수로 쓴다. 동점이면 동일 평균순위, 최종 동점 정렬은 안정된 증권 ID 오름차순. 전체 기간 fit·가중치 최적화·업종별 결과를 본 뒤 보정은 없다.

매수 자격은 **g>0, A>0, M>0, F>0, C(q)>0**를 모두 만족하는 기업으로 제안한다. 이 중 점수 상위 **최대 20종목**, 목표 비중은 각 **5%**, 부족한 자리는 현금이다. 영업이익 자체가 음수에서 개선 중인 기업은 허용하고 그 비중을 별도 보고한다. 조건이 너무 드물어 검정력이 부족하면 숫자 완화로 통과시키지 않는다.

## 5. 보유·청산·주문·비용

- 매월 말 재평가해 다음 세션부터 목표 비중으로 조정한다. 다음 달에도 선정된 기업은 계속 보유한다. 최대 보유일·하루 거래 횟수·같은 방향 연속 제한은 두지 않는다. 순위 탈락·자격 상실·재무 stale 시 목표 비중 0, 미체결 청산은 잔여 포지션으로 남긴다. 종목군에서 빠져도 보유 기록을 삭제하지 않는다.
- 연구 모형은 롱·현금, 차입 없음, 연구 초기 자본 **1,000만원** 제안(실계좌 금액 아님). 정수 주식 내림·수수료 예산·기업행동을 반영한다. 해당 월 주문 크기는 직전 63일 평균 거래대금의 **0.1%** 이하, 줄어든 비중은 현금으로 둔다.
- **가격 한도가 있는 지정가만** 가정한다. 매수 한도는 직전 거래일 비수정 종가 ×1.005를 호가 단위 내림, 매도 한도는 ×0.995를 올림. 해당 세션 하루 유효, 미체결 주문은 취소하고 다음 세션 직전 가격으로 다시 계산, 최대 5세션. 이후 매수 잔여분은 다음 월 재평가까지 현금, 매도 잔여분은 일별로 같은 방식 재시도한다. 새 월 목표는 옛 미체결 매수 의도를 취소·대체한다.
- 일봉 연구 체결은 **매수일 종가 < 매수 한도 / 매도일 종가 > 매도 한도**, 확인된 거래량 >0, 정상 세션·정지 아님일 때만 후보로 잡는다. 접촉만으로 채우지 않고, 가격제한에 잠긴 날은 미체결이다. 후보 가격은 매수 `min(한도, 당일 고가)`, 매도 `max(한도, 당일 저가)`로 보수적으로 잡되 일봉 범위 밖 체결을 만들지 않는다. 수량은 일 거래량의 0.1% 이하로 제한한다. 비수정 OHLC·거래량이 없으면 이 모형은 실행 불가다. 이 조건도 큐·장 마감까지의 주문 존속을 검증한 실제 체결 증거는 아니다. 장중 호가·체결 자료가 없으면 결과를 **일봉 체결 대리모형**으로 표시한다.
- 동일 종목 같은 날 매수·매도 동시 실행 금지. 날짜 시작의 가용 현금만 매수에 배분하며, 매도대금·배당·합병대금은 확인된 결제/입금 가용 규칙 이후 사용한다. 자금 부족이면 그날 매수 의도에 비례 배분하고 정수 내림한다. 확정 전 결제 달력·호가 단위·가격제한·수정 가격 연결을 문서화한다.
- 비용 초안은 **매수/매도 각각 거래대금의 최소 25bps**. 실제 기간별 수수료·거래세·불리한 체결 비용 합이 더 크면 큰 값을 적용한다. 이는 현행 법정 세율 주장이 아니다. Claude가 공식 근거와 기간별 비용표를 확정하기 전 실행하지 않는다. 가격 한도에서의 체결 불리함과 별도 비용을 각각 보고해 이중 차감을 확인한다. 스트레스는 그 최종 비용의 2배다.
- 배당·분할·합병을 포함한 총수익 회계가 기본이다. **141의 ‘데이터 마지막 날 종가 매도’ 및 ‘배당을 양쪽 다 빼면 공정’ 가정은 복사하지 않는다.** 미래의 마지막 행을 미리 알 수 없고, 실적 선별이 배당 노출을 바꿀 수 있기 때문이다. 미확인 종료 사건을 임의 현금화/0 평가하지 않는다. 결과를 뒤집을 수 있는 미확인 사건은 판정 보류다.
- **위험 규칙 연결은 확정 보류 항목:** 이 초안은 종목 선별 우위의 연구 모형이므로 기술적 손절/익절·계좌 정지를 새로 발명해 붙이지 않는다. 기존 위험 규칙의 비적용을 승인받았다는 뜻도 아니다. Claude는 성과 실행 전에 ‘신호 우위 측정의 범위’와 ‘전체 위험 규칙 계좌 재생’을 구분해 사용자와 적용 범위를 확정해야 한다. 전체 위험 규칙 재생 및 보호주문 설계 전에는 운용 가능/Phase 4 PASS를 선언할 수 없다.

## 6. 비교 대상과 노출 분리

주 비교 **EW-E**: 매월 같은 계산 가능 집합 E를 동일가중으로 보유, 같은 자본·비용·지정가·정산 규칙을 적용한다. 항상 목표 총노출 100%(유동성/정수/체결 제한은 동일). 시장 비교는 **KOSPI 총수익 지수**다. 가격 지수밖에 없으면 참고로만 제시하고 시장 대비 통과를 선언하지 않는다.

선별 기여 확인용 **EW-match**: EW-E의 종목은 유지하되 후보의 그 월 목표 총노출 `선정 수×5%`로 맞춘다. 결정 시점에 아는 목표만 사용하고 실제 사후 체결 노출에 맞춰 소급하지 않는다. 이 비교는 현금 보유 효과와 기업 선택 효과를 구분한다. 매수 자격 필터와 순위의 결합 전체를 시험하며 각 요소의 인과 기여로 과장하지 않는다.

보고에는 후보·EW-E·EW-match의 실제 평균 노출·회전율·미체결률·정산 대기 현금·산업 구성과 KOSPI 대비 결과를 함께 둔다. 현재 분류를 사용한 사후 산업 설명은 매매 입력과 구분한다. 개별 요소 제거 실험·Top 10/30 변형을 보고 난 뒤 승자로 갈아타지 않는다.

## 7. 기간·80% 검정력·미열람 범위

제안 분할(자료 준비도에 따라 **성과 열람 전** 확정): 재무 워밍업 2015~2017, **계획용 2018~2020**, **TRAIN 2021~2023**, **역사 확인 2024-01~2026-08**. 월말 신호 다음 달을 평가하므로 각 구간 마지막 성과 월의 신호는 전달 말이다. 2026-08-31까지의 가격만 사용하고 경계 보유분은 평가 표시하되 가상 청산하지 않는다.

계획용 최초 성과 월은 2018년 안에서 §2의 워밍업·월별 커버리지를 처음 충족한 월말의 다음 달로 자료만 보고 확정한다. 정확한 시작 월은 아직 미측정이다. 그 이후 자료가 부족한 월을 건너뛰거나 2021년 이후를 계획용으로 옮기지 않는다. 시작이 늦어지면 가용 N이 줄고 검정력 관문에서 그대로 반영한다.

141·142에서 같은 가격 기간과 결과를 이미 봤다. 새 재무 입력이라고 역사 확인 구간을 깨끗한 OOS라 부르지 않는다. 최종 채택에는 확정 시각 이후의 전향 미열람 구간이 필요하며, 그 종료일/필요 월수를 아래 계산 뒤 별도로 고정한다. 이번 문서는 자동 관찰 수집/예약을 켜지 않는다.

주 통계량은 달력 월별 비용 후 차이 `d_m = 후보 수익률 − EW-E 수익률`. 순수익 평균과 EW-match 대비 차이도 같은 방식으로 계산한다. **기업 수×분기 수·가격 행 수·매매 수를 독립 n으로 쓰지 않는다.** 동일 달 기업들을 함께 묶은 포트폴리오 시계열로 SE를 구한다. Newey–West HAC lag **3개월**을 주 SE로 고정 제안한다. lag 6은 감사용, 유리한 값을 선택하지 않는다.

검정력 계획의 검출 대상은 **연 산술 차이 3%p(월 0.25%p)**를 제안한다. 이 정도의 차이를 놓치지 않을 자료가 있는지 묻는 설계값이며 기대 수익 예측·문헌 효과 이식·표본 평균의 통과 문턱이 아니다. 사용자 선택 전 확정값이 아니다. 관측 평균에도 3%p 이상을 요구하면서 참효과 3%p에서 80% 통과를 주장하면 잘못된 검정력 계산이 되므로 두 기준을 섞지 않는다.

검정력 계산 절차:

1. 자료·계산·체결 규칙을 먼저 잠근 계획 버전을 커밋한다. 계획용 구간에서만 변동성/자기상관/가용 월수/사건 수를 측정한다. 전략 평균·누적곡선·종목별 수익은 열람하지 않고, 계산 자체의 수익 노출 범위도 기록한다. 이는 최종 수익 판정 전 제한된 분산 측정이며, 이 구간을 이후 독립 검증 표본으로 재사용하지 않는다.
2. 비용 후 월별 d의 장기분산 기반 SD_LR로 개별 80%의 참고값 `N_required=((2+0.8416)×SD_LR/0.0025)^2`를 계산한다. 순수익 양수·EW-match 초과수익도 각각 월 0.25%를 검출 대상으로 별도 분산을 측정한다. 비용 후 차이에서 비용을 다시 빼지 않는다. 이는 각 참효과가 그 설계값일 경우의 조건부 검정력이며 실제 효과가 있다는 증거가 아니다.
3. K1~K3를 모두 요구하므로 각각 80%라는 것만으로 동시 80%라고 하지 않는다. **확정 관문은 각 검정의 실패확률을 0.20/3 이하로 배분**, 각 검정력 ≥93.33%의 보수적 필요 N을 적용한다(`z_beta=Phi_inverse(1−0.20/3)`, 약 1.501). 세 필요 N 중 최대와 가용 월수를 비교한다. TRAIN·역사 확인·전향 각각 계산한다. K4/K5까지 포함한 전체 채택 확률을 80%라고 주장하지 않는다.
4. 각 검정의 MDE는 `(2+z_beta)×SD_LR/√N`, 개별 80% 참고 MDE는 `2.8416×SD_LR/√N`로 구분한다. 양의 자기상관을 무시해 n을 늘리지 않으며, 적은 표본에서 분산 추정 자체가 불안정하면 통과로 취급하지 않는다. 연 MDE 표시는 월 MDE×12인 산술값이며 CAGR이 아니다.
5. **동시 검정력 관문 부족이면 확정하지 않는다.** 검정력을 맞추려고 효과 가정을 올리거나 기준을 낮추지 않는다. 관찰 기간 연장·자료 확보 범위 변경은 결과 전 별도 결정이다. 3%p를 잡을 표본이 없는 경우 ‘유망한데 실패’가 아니라 판정 설계 불충분이다. 현재 SD/필요 N/MDE는 모두 **미측정**이다.

TRAIN 시작 전 2020-12 신호는 warm-up 입력으로 허용하되 TRAIN 수익을 계획용 추정에 쓰지 않는다. 분할을 가로지르는 거래 손익을 어느 쪽에도 두 번 배정하지 않고, 일별 mark-to-market으로 각 달에 귀속한다. 거래 단위 보조 검정은 경계 관통 거래를 purge하며, 보유가 무제한이므로 임의 고정일 embargo로 대체하지 않는다. 전향 시작은 과거 포지션 승계 없이 현금으로 시작한다.

## 8. 1회 판정 기준 — 초안

먼저 데이터·검정력 관문 통과와 아래 수치/회계/실행을 Claude가 확정 커밋해야 한다. **TRAIN 불합격이면 역사 확인을 열지 않는다.** 역사 확인도 한 번이며, 검정 중간 결과로 조건을 고치지 않는다.

| 번호 | TRAIN 및 역사 확인 각각의 필요 조건 |
|---|---|
| K1 | 비용 후 월 평균 순수익 − 2×HAC SE > 0 |
| K2 (주 가설) | 월 평균 d − 2×HAC SE > 0. 평균·하한·계획용 3%p 대비 크기를 함께 보고하되 3%p를 별도 표본 통과 문턱으로 쓰지 않음 |
| K3 | EW-match 대비 비용 후 월 평균 차이 − 2×HAC SE > 0 |
| K4 (목표 적합성) | 총수익 기준 후보 CAGR > EW-E 및 KOSPI, 후보 Sharpe ≥ EW-E + 0.20, 후보 MDD ≤ 30% |
| K5 | 전체 비용 2배에도 후보 순수익 평균 >0 및 EW-E 대비 초과수익 평균 >0. 신호 입력 1거래일 추가 지연에도 두 평균 >0 |

연간 수익은 진단으로 전부 보고한다. ‘매년 양수’나 ‘2025년 제거 시 통과’ 같은 사후 관문을 추가하지 않는다. Sharpe의 무위험금리는 본 연구·기준선 모두 0으로 고정 제안하고, CAGR·산술 평균·통계적 우위를 혼용하지 않는다. K1~K5 모두 요구하는 교집합 판정이며, 어느 기준이나 여러 변형 중 하나만 통과하면 채택하는 방식이 아니다.

- **DATA_NOT_READY:** 원본/당시 가용/종료/배당/체결 자료 결함으로 유효한 평가 불가.
- **DATA_INSUFFICIENT:** 자료는 사용할 수 있지만 80% 검정력/독립 관찰 기간 부족.
- **REJECT:** 관문을 충족한 유효한 시험에서 필요 기준 하나 이상 실패. 같은 자료로 조건·가중치·보유 수를 바꿔 재판정하지 않는다.
- **HISTORICAL_SUPPORT:** 두 구간 모두 필요 기준 통과. 전체 Phase 4 PASS나 실거래 승인은 아니다. 미열람 전향·전체 위험/실행 검증이 남는다.

[공통 Phase 4 게이트](../current/BACKTEST_AND_TESTING.md)의 랜덤/셔플·민감도·walk-forward·거래 n·실행 안전 요건을 이 표로 대체하지 않는다. 해당 단계로 넘어가기 전 수치·적용 범위·미해결 C2/C4를 따로 확정해야 한다. BACKTEST 문서의 과거 시장가 기본 문구는 새 지정가 사용자 지시와 충돌하므로 이번 설계는 [TRADING_CORE 주문 유형](../current/TRADING_CORE.md)을 따른다. 기존 문서는 이 초안에서 수정하지 않는다.
