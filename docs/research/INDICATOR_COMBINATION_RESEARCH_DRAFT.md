# 차트·보조지표 조합 연구 — Phase 0 조사·설계 초안

작성: 2026-10-07 · Codex · IDEAS 22 · **DRAFT / NOT_TESTED**

사용자 요청: 앞서 언급한 지표에 한정하지 않고 다양한 차트 기법·보조지표를 조사하여 조합 연구를 설계한다. 이번 승인은 **아이디어 기록과 Opus의 Phase 0 조사·감사 인계**다. 확정 사전등록·성과 실행·운영 적용 승인이 아니다.

기준: [AGENTS](../../AGENTS.md), [CURRENT_SPEC](../current/CURRENT_SPEC.md), [검증 게이트](../current/BACKTEST_AND_TESTING.md), [위험·주문 계약](../current/TRADING_CORE.md), [연구 이력](../current/RESEARCH_HISTORY.md). 충돌하면 Current와 최신 사용자 지시를 따른다. 운영 Phase 6과 이 신규 연구의 Phase 0은 별개다.

## 1. 연구 질문과 구분할 주장

**서로 다른 역할의 차트 정보가 결합될 때, 단순 기준선보다 비용 후 추가 효과가 생기는가?** 지표 수를 늘려 다수결 점수를 높이는 것이 목적은 아니다. 장세를 구분하는 조건과 실제 진입 계기를 나누고, 그 상호작용을 재현 가능한 규칙으로 시험할 수 있는지 먼저 살핀다.

- 단일 지표가 약해도 조건부 조합에는 정보가 있을 수 있다. 따라서 구성 지표 모두가 단독으로 수익을 내야 한다는 관문은 만들지 않는다.
- 반대로 같은 OHLCV를 변환한 RSI·MACD·여러 이평선은 독립 증거가 아니다. 지표 10개 일치는 새로운 정보 10개를 뜻하지 않는다.
- 기존 조합의 실패는 모든 기술적 분석의 실패를 증명하지 않는다. 그러나 **같은 기각 가설에 지표 하나를 붙이거나 숫자만 바꾸는 일**은 새 연구가 아니다.
- 조건부 가격 정보, 거래당 순기댓값, 위험·노출을 맞춘 계좌 성과는 다른 질문이다. 예측 정확도·승률·패턴 발생 빈도만으로 수익성을 선언하지 않는다.

## 2. 지금 Opus가 할 일 / 아직 하지 않을 일

지금 진행할 범위:

1. 아래 지표·패턴의 원문 정의와 기존 구현 유무를 조사한다. 기존 코드는 읽기만 하고 지표 이름과 실제 식의 차이를 기록한다.
2. 기존 연구와 경제적 가설·자료·조건의 중복을 표로 감사한다. 단순한 지표 목록 차이가 아니라 **왜 다른 수익 기회인지** 설명한다.
3. 무료 자료의 가용 기간·폐지 종목·결측·거래량 단위·수수료·체결 자료·열람 이력을 점검한다. API 키나 계좌 정보를 문서에 남기지 않는다.
4. 성과를 보지 않고 후보 설계를 최대 3개 제시한다. 시장·시간봉·규칙·비용·독립 표본/80% 검정력의 미확정 항목을 사용자에게 보고한다.
5. 사용자가 하나를 선택하고 관문이 해결되면 Claude가 확정 사전등록 커밋을 담당한다. 구현·1회 판정은 그 다음 승인된 범위에서 진행한다.

이번 인계만으로 진행하지 않을 범위:

- 수백·수천 조합의 백테스트, 수익 순위로 지표/기간/시장 고르기, 학습·가중치 최적화, OOS 확인, 최종 사전등록 확정.
- 유료 데이터 구매, 기존 전략·위험 한도·운영 설정 수정, 실거래 활성화, 라이브러리의 임의 설치.
- 기각 판정을 뒤집기 위한 새 점수선·신호 반전·조건 추가. 19 DMN은 버림, 20·21은 5번 결과 뒤 재검토하는 보류 상태를 유지한다.

목록 조사는 전략 후보 34개의 구현 승인이 아니다. **대규모 조합 탐색이 필요하다면 별도 사용자 승인**을 받아 탐색 범위·총 시도 수·다중검정·시간 분할·중단 기준을 먼저 정한다. 이를 하나의 전략으로 부른다고 최대 3개 후보 규칙이 사라지지 않는다.

## 3. 초기 조사 목록 — 6개 역할, 34개 항목

항목은 조사의 출발점이며 전부 채택하거나 구현할 의무는 없다. 같은 계열의 이름을 여러 개 모으기보다 입력·역할·확인 시점의 차이를 비교한다. 기간·문턱·시장·시간봉은 **아직 고정하지 않았다**.

| 역할 | 초기 항목 | 조사할 차이 / 중복 위험 |
|---|---|---|
| 추세·장세 (6) | EMA, KAMA, HMA, MACD, DMI/ADX, Supertrend | 방향·추세 강도·적응 속도. 여러 평활 가격 변환을 독립 확인으로 세지 않는다 |
| 모멘텀 (6) | RSI, Stochastic, ROC, CCI, TSI, Williams %R | 되돌림·가속·범위 내 위치. RSI 과매수와 Stochastic 과매수의 중복을 확인한다 |
| 변동성·가격 위치 (5) | ATR, Bollinger bandwidth, Bollinger %B, Keltner channel, realized volatility | 변동성 크기·수축/확장·채널 위치는 서로 다른 출력. 수축 자체가 미래 돌파 수익을 보장하지 않는다 |
| 거래량·가격/거래량 (6) | RVOL, OBV, CMF, MFI, VWAP, Chaikin Oscillator | 상대 거래량·누적 압력·거래량 가중 가격. OHLCV 추정 압력을 실제 공격적 매수/매도 체결로 부르지 않는다 |
| 가격 구조 (5) | 확정 HH/HL·LL/LH, Donchian channel, 확정 피벗 지지/저항, failed breakout, pullback/retest | 확인 지연·레벨 형성·돌파 실패의 기계 정의. 미래에 보이는 최종 고저점을 당시에 알았다고 하지 않는다 |
| 차트 패턴 (6) | 이중 천장/바닥, 헤드앤숄더/역형, 삼각형, 컵앤핸들, 깃발, 쐐기 | 대칭·기울기·접촉 횟수·기간·허용 폭을 수치로 정의. 결과를 보고 사람이 패턴을 붙이지 않는다 |

일목구름·Fibonacci·다이버전스 등 앞서 다룬 항목도 기존 조사/구현 표에 연결한다. 위 34개는 전체 지표의 완전한 목록이 아니다. 기존 항목의 정의·확인 시점 점검과 기각 가설의 재실험을 구분한다. 여러 시간봉을 결합하는 후보는 각 시간봉의 마지막 마감 시각과 업데이트 순서까지 규칙에 명시한다.

각 항목의 조사 카드에는 다음을 남긴다:

- 공식/원문 출처·버전, 입력 필드·단위, 기간/평활 방식, warm-up, 결측 처리, 출력 해석.
- 사용하는 마감봉과 `as_of_ms`, 피벗/패턴의 `confirmed_at_ms`, 처음 알 수 있는 시각과 확인 지연.
- 재현 가능한 정의와 경험적 해석을 분리. “깔끔한 모양”, “강한 매수세”는 수치화 전에는 거래 규칙이 아니다.
- 거래량의 base/quote/계약 단위, 주식 분할·배당·폐지 처리, VWAP의 세션/앵커를 사전에 고정하는 방법. 결과가 좋았던 저점을 사후 앵커로 고르지 않는다.
- 같은 입력/역할의 중복, 기존 구현·테스트 상태, 자료 가용 여부와 적용 불가 조건.
- 후속 구현 시 고정 입력 기대값·미래 데이터 추가에 대한 불변성 테스트 계획. 중심 이동평균·음수 shift·전체 표본 정규화·미완성 봉·사후 최종 거래량을 금지한다.

가격·특성 상관 등 자료 진단도 수행한다면 먼저 개발 구간과 진단 목적을 기록하고 미래 수익/PnL로 지표를 골라내지 않는다. 새로운 결과 라벨이 필요한 파일럿은 별도 승인과 노출 기록이 먼저다.

Elliott/뉴스/JEV는 현행 **Shadow 전용**을 유지하고 주문·veto·사이징 조합에서 제외한다. Elliott를 참고 조사할 때도 최소 마감 4시간봉 조건을 지킨다. 이는 다른 모든 지표를 자동으로 4시간봉에 고정한다는 뜻은 아니다. D22는 INCOMPLETE / EXCLUDED이며 이번 연구의 현행 전략으로 넣지 않는다.

## 4. 기존 연구 중복 감사 — 후보 설계보다 먼저

아래는 감사의 최소 범위다. 실제 규칙·판정은 [RESEARCH_HISTORY](../current/RESEARCH_HISTORY.md)와 연결된 연구 문서로 확인한다. Archive 전체를 자동으로 읽지 않는다.

| 기존 연구 | 그대로 다시 시도하면 안 되는 것 | 새 후보에서 필요한 설명 |
|---|---|---|
| H1 | HTF 추세 + LTF 되돌림/구조 + 거래량 점수에 지표나 점수선만 추가 | 새 경제적 가설·상호작용과 기존 복합 조건의 차이 |
| KB / KB-ALTS / KB-UNIV (139·156·157) | 이평 정배열 + 박스 돌파에 RSI/ADX/OBV를 붙여 재판정 | KB 계열은 닫힘. 다른 지표 이름이 아니라 다른 수익 기회인지 |
| DIV / MJ (140) | RSI 다이버전스에 거래량·매물대·익절 배수를 추가하거나 oscillator 교체 | 기각된 역추세/다이버전스 가설의 구제가 아닌지 |
| 삼각형 진입 (146) | 같은 주도주·삼각형을 허용 폭/기간 변경으로 재시도 | 패턴 이름·모양 차이가 경제적 차이인지 |
| V | 변동성 돌파에 Bollinger/Keltner 기간만 변경 | 이미 본 수축/돌파 가설과의 구분 |
| H2·H3 / IDEAS 16 | funding/OI/체결 흐름을 새 가중치로 합산 | 차트 압력 지표도 기존 흐름 가설의 재포장인지 확인 |
| T/v2 등 운영 전략 | 새 조건을 운영 전략에 직접 추가하고 결과 비교 | 기존 경로는 동결. 별도 연구와 기준선 사용만 검토 |

기존 기각 가설의 중복이면 후보에서 제외하고 이유를 기록한다. 차이·자료·검정력이 불명확하면 “관문 미확정”으로 남긴다. 아직 수익을 보지 않은 후보에 PASS/REJECT를 만들어 붙이지 않는다. 새 심볼·새 시간봉·최근 연도라는 이유만으로 미열람 자료나 독립 가설이라고 단정하지 않는다.

## 5. 조합 설계 방법 — 역할을 결합하고 무작정 다수결하지 않는다

설명 틀은 **장세 조건 → 가격 사건 → 보조 확인 → 청산/위험**이다. 예를 들어 추세 강도와 가격 위치가 역할을 나누는지, 거래량 확인이 단순 가격 사건에 추가 정보를 주는지, 가짜 돌파 후 반대 흐름이라는 상호작용이 기존 기각과 정말 다른지 조사한다. 이 예시는 새 진입 전략 3개의 승인이나 수익 주장으로 쓰지 않는다.

- 초기에는 실제 입력 역할을 3~4개 이내로 제한하는 안을 우선 검토한다. 34개를 한 점수에 모두 넣지 않는다. 제한 값 자체도 확정 전 사용자 선택 사항이다.
- 서로 다른 역할에 하나씩 두는 이유를 사전에 설명한다. 중복 지표를 교체하는 기준은 공식·정보 중복·계산/자료 품질이며 수익 순위가 아니다.
- 상호작용 가설은 구체적으로 쓴다. “지표가 많이 동의하면 상승” 대신 “어느 장세에서 어느 가격 사건의 결과가 달라질 것으로 예상하는가”를 적는다.
- 전체 조합과 미리 정한 제거판을 비교하는 진단은 가능하지만, 가장 좋은 제거판을 새 승자로 채택하지 않는다. 이 비교도 시도 장부·다중검정 계획에 포함한다.

후보 카드(최대 3개)에 반드시 적을 항목:

1. **시장·종목군·방향·시간봉:** 코인/주식 중 선택 이유, 당시 구성 종목·폐지 포함, 롱/숏 허용 여부. 넓은 목록 조사와 동시에 양 시장 성과 경연을 시작하지 않는다.
2. **경제적 가설·기각 연구와 차이:** 가격 변환의 새 조합이 왜 비용을 넘을 수 있는지, 장세 조건과 진입 계기의 역할.
3. **정확한 규칙:** 공식·기간·문턱·입력 역할·동시 확인 시점·진입/청산·stop·예상 보유/빈도. 전역 최대 보유시간·하루 거래 수·같은 방향 연속 제한을 임의로 만들지 않는다.
4. **지정가·보호·위험 계약:** 가격 한도, 제출 시점·유효기간·미체결/부분 체결·다음 봉 처리, 손절 이후 수량 계산, 거래소 보호주문. 봉의 고저가가 주문가에 닿았다는 것만으로 전량 체결을 가정하지 않는다.
5. **비용:** 실제 수수료 등급, spread·슬리피지·호가/역선택·funding·차입 가능 여부. 코인과 주식 비용을 동일 상수로 뭉뚱그리지 않는다.
6. **비교군과 주 평가량:** 동일 자료·노출/위험/체결 조건의 동결 단순 기준선, 비용 후 추가 효과 및 계좌 지표. 코인에서는 T/v2를 참고 기준선으로 사용할 수 있지만 규칙을 수정하지 않는다. 주식의 보유 기준선에는 총수익·종료 회계를 반영한다.
7. **진단과 다중검정:** 미리 정한 구성 제거판, 장세·노출을 맞춘 대조 시점, 모든 후보/지표/기간/시간봉/종목/가중치/청산/비용 가정의 시도 수. 각 진단을 독립 발견이라고 세지 않는다.
8. **자료 노출·분할:** 이미 본 기간, 개발/계획용 구간, 검증/최종 미열람 구간, 데이터·규칙·코드 digest, purge/embargo. 이후 전향 자료가 필요하면 기간을 성과 전에 정한다.
9. **검정력:** 효과 가정의 근거, 거래 손익/차이의 SD, 독립 표본 단위·필요 실제 체결 수·도달 기간, TRAIN/OOS 중 큰 요구량, 계좌 정지·G5 등으로 잘리는 표본.
10. **종료:** 자료 미달/검정력 미달/기각 시 멈추는 조건. 성과를 보고 기준선·효과 문턱·정지 규칙을 고치지 않는다.

현재 시장·후보·기간·문턱·주 평가량·최소 효과·최종 구간은 모두 미확정이다. 그러므로 **이 문서만으로 구현하거나 사전등록을 확정할 수 없다**.

## 6. 체결·위험 및 검정력의 필수 경계

일반 매매는 가격 한도가 있는 지정가만 사용한다. 허용된 비상 STOP_MARKET·보호 등록 실패/공백 전량 정리는 안전 예외로 별도 기록한다. **T/v2 실행기의 시장가 추격 예외를 새 후보로 가져오지 않는다.** 옛 검증 문구에 시장가 기본값이 있더라도 최신 TRADING_CORE의 주문 계약이 우선한다.

기존 위험 한도는 완화하지 않는다. C1 손절 WIDEN 등 명시적 미해결 항목이 부딪히면 사용자에게 보고한다. 우위 측정과 모든 계좌 위험 규칙을 적용한 재생을 분리하려면 적용/비적용 규칙과 G6 처리까지 확정 전에 승인받고 기록한다. 옛 연구의 예외를 자동 상속하지 않는다.

- 34개 지표, 봉 수, 종목×봉 수는 독립 투자 성과 표본 수가 아니다. 공통 시장 충격·중첩 보유·횡단면 상관을 반영한다.
- 거래당 순기댓값과 기준선 대비 차이는 서로 다른 검정이다. 기준선 단독 SD를 전략 간 차이 SD로 쓰지 않는다. 거래가 서로 대응하지 않으면 억지로 paired 표본을 만들지 않는다.
- 거래당 검정은 stop/청산·실제 체결을 반영한 손익 분산을, 계좌 차이는 대응 시간 블록의 차이와 자기상관을 고려한 분산을 사용한다. 계산 가능한 자료가 없으면 추정/대리라고 표시한다.
- [80% 검정력 게이트](../current/BACKTEST_AND_TESTING.md)는 사전등록 전 필수다. 최소 효과를 근거 없이 크게 잡아 통과시키지 않는다. 필요 표본과 현재 표본으로 검출 가능한 최소 효과를 함께 보고한다. Phase 4의 실제 거래 n≥100은 필요한 여러 관문 중 하나일 뿐이다.
- 많은 조합을 훑었는데 마지막 승자만 평균−2SE로 검사하는 것은 충분하지 않다. 넓은 탐색을 별도 승인받는다면 전체 탐색군과 선택 절차, Reality Check/SPA 등 적합한 보정 또는 동등한 선택 후 검증 방법을 **탐색 전에** 구체적으로 확정한다. 이름만 적어 다중검정이 해결됐다고 하지 않는다.
- 새 과거 구간도 프로젝트의 기존 노출 이력을 감사한다. 개발 자료의 지지는 최종 미열람 검증과 구분한다. 기간·시장별 좋은 부분만 골라내지 않는다.

## 7. 조사 근거 — 수익 보장이 아니라 설계의 근거

- [Lo·Mamaysky·Wang (2000), Foundations of Technical Analysis](https://www.nber.org/papers/w7613): 차트 패턴을 자동 인식하고 조건부 수익 분포의 추가 정보를 조사했다. 기술적 분석의 기계 정의를 연구할 근거지만, 현재 코인/주식의 비용 후 수익이나 이 초안의 조합 효과를 입증한 것은 아니다.
- [Sullivan·Timmermann·White (1999), Data-Snooping, Technical Trading Rule Performance, and the Bootstrap](https://doi.org/10.1111/0022-1082.00163): 기술적 규칙의 선택을 평가할 때 전체 시험 규칙군의 데이터 스누핑을 고려한다. 최종 승자 하나만 검사하지 않는 설계의 근거다.
- [Bajgrowicz·Scaillet (2012), Technical trading revisited: False discoveries, persistence tests, and transaction costs](https://doi.org/10.1016/j.jfineco.2012.06.001): 장기 주가지수 규칙에서 거짓 발견·지속성·비용 문제를 조사했다. 그 결과를 모든 시장/시간봉의 불가능성으로 확대하지 않되, 비용 전 좋은 조합을 발견했다고 채택하지 않는다.
- [TA-Lib 공식 함수 목록](https://ta-lib.org/functions/): 지표 정의·구현 위치 조사 출발점. 목록의 존재는 우위의 증거가 아니며 위 34개 모두가 이 라이브러리에 있다는 뜻도 아니다. 신규 의존성 채택은 별도 필요성·호환성 감사 후 결정한다.

## 8. Opus 제출물과 완료 조건

이번 Phase 0 결과는 **수익 보고서가 아니라 조사·감사 보고서**다. 다음을 제출하면 사용자 선택으로 넘길 수 있다:

1. 34개 초기 항목의 정의·입력·확인 시점·중복·구현/자료 상태표. 제외·추가한 항목은 이유 기록.
2. 기존 기각 연구 중복표와 경제적 가설 차이. 차이가 없는 후보는 제외.
3. 무료 자료·열람 지도, 지정가/보호/위험의 가능한 범위와 막히는 관문.
4. 살아남는 설계가 있으면 **최대 3개 후보 카드**, 없으면 없다고 보고. 각 카드에 필요한 독립 표본·최소 효과·예상 기간과 아직 계산할 수 없는 항목을 표시.
5. 사용자에게 필요한 선택 목록: 한 후보·시장/방향/시간봉·주 평가량/효과·필요한 별도 파일럿·새 자료 기간. 자료 또는 검정력이 부족하면 확정하지 않는다.
