# 구간을 모를 때의 시나리오 묶음 검증 — 사전 등록 (JEV 섀도 연결 전 단계)

작성: 2026-09-25 (Opus) · 트랙: `EW-WA-CONTEXT` · 상태: **사전 등록 (개발 seed 채점 전)**

## 1. 목적

연구자 계획: Elliott 합성 테스트·후보 생성 검증을 끝낸 뒤 JEV 를 **섀도 모드**로 붙여 기존 순위 규칙(`ranking.py`)과 나란히 비교한다.
JEV 는 **목록에 있는 해석 중에서만** 고를 수 있으므로, 시장처럼 시작점을 모르는 조건에서 스캐너의 시나리오 묶음에 진짜 해석이
들어가는 비율이 JEV 성능의 상한이다. 지금까지는 정답 구간을 알려 준 채점(33 §29)과 구간 찾기 1등 점검(34 §6, 개발 seed)뿐이었다.
JEV 형태는 이 문서에서 정하지 않는다.

## 2. 고정 사항

- **기준 순위 규칙 동결:** `ranking.py` (SHA-256 앞 16자 `2dccbb0f1ba255d7`), 판독기·스캐너 커밋 `c302a06` 기준. 이 문서의 수치가
  JEV 비교의 기준선이다.
- **시나리오 묶음 크기 N = 10:** 매 발동에서 모든 시작 후보의 EW-3d′ 후보(34 §3)를 한 목록에 모아 `rank_key` 순으로 상위 10 개를
  내보낸다. 나머지는 "목록 밖(other_or_unknown)" 으로 남긴다. 동점은 비관적으로 센다(진짜 순위 = 1 + 근거가 같거나 좋은 다른 후보 수).
- **합성 시험지:** 33 §22 생성기와 칸 구성 그대로(degree 3 × 패턴 2 × 잡음 0.1% 50 · 잡음 0 20 = 420 경로).
  - 개발 seed **20260924** (이미 여러 번 본 세트)
  - 확인 seed **20260926** (새 세트, 이 문서의 관문에 **한 번만**)
  - **20260927 은 JEV 대 순위 규칙 비교용으로 예약 — 생성·채점하지 않는다.**

## 3. 지표 (진짜 5파 또는 C 끝 꼭짓점이 발동한 마감 기준)

1. **발동 없음:** 진짜 끝 꼭짓점에서 발동이 없던 경로 비율.
2. **전체 목록 포함률:** 진짜 패턴·진짜 경계(시작~끝 모든 경계)가 그 발동의 전체 후보 목록에 있는 비율 — 분모는 전체 경로.
3. **상위 N 포함률 (N = 1, 3, 10):** 진짜 해석의 비관적 순위 ≤ N 인 비율. 무작위 순서 기준선 = 경로별 [포함] × min(N, 후보 수)/후보 수 평균.
4. **구간 일치 (보조):** 진짜 패턴이고 시작·끝이 같은(내부 경계는 달라도 되는) 후보 중 가장 좋은 순위 ≤ 10 인 비율.
5. 후보 수 중앙값·90 백분위.

## 4. 관문 (확인 seed 20260926, 잡음 0.1%, degree 합산, impulse·zigzag 각각)

(1) 전체 목록 포함률 ≥ 80%, (2) **상위 10 포함률 ≥ 50%**, (3) 상위 10 포함률 ≥ 무작위 기준선의 2 배.
셋 다 넘으면 "구간을 모를 때의 후보 생성 검증 완료" 로 기록하고 JEV 섀도 연결 준비(시나리오 내보내기)로 간다.
개발 seed 로 먼저 채점하고, 설계를 바꾸면 여기에 먼저 적는다. 확인 seed 는 설계를 고정한 뒤 한 번만 채점한다.

## 6. 연구자 결정 — 묶음 크기 N = 50 (연구용 기본값, 확인 seed 채점 전, 2026-09-25)

연구자 결정: **N = 50** 으로 진행한다. 근거: 개발 seed 에서 30 → 50 의 impulse 포함률 개선(63% → 70%)이 아직 의미 있고,
50 → 100 부터는 한계효용이 크게 줄어든다(70% → 74%, zigzag 87% → 87%). **최종값으로 확정하지 않고 연구용 기본값**으로 쓴다.

§4 관문의 (2)·(3) 은 N 에 맞춰 **상위 50** 으로 바꾼다: (1) 전체 목록 포함률 ≥ 80%, (2) 상위 50 포함률 ≥ 50%,
(3) 상위 50 포함률 ≥ 무작위 상위 50 기준선의 2 배. 보고에는 상위 1·3·10·20·30·50·100 을 모두 적는다. 나머지는 §2~§4 그대로.
이 결정은 개발 seed 결과를 본 뒤의 것이며, 확인 seed 20260926 은 아직 쓰지 않았다 — 이제 한 번만 채점한다.

**JEV 섀도 모드 측정 요구 (연구자 지시, 이후 문서에서 반드시 지킨다):** 두 단계를 분리해 평가한다.
1. **recall@N** — 후보 생성기(+기준 순위 규칙 사전 걸러내기)가 정답 시나리오를 상위 N 묶음에 넣었는가.
2. **JEV 선택률** — 묶음에 정답이 **있는 경우에 한해**, JEV 가 정답을 골랐는가(1등 및 상위 k).
전체 성공률(= 1 × 2)만 보고하지 않는다. 같은 묶음에서 기준 순위 규칙의 선택률도 나란히 적는다.

## 7. 확인 seed 결과표 (20260926, 1회, N = 50) — 관문 통과

**recall@N — 후보 생성기 + 기준 순위 규칙이 정답을 상위 N 묶음에 넣은 비율 (분모 = 전체 경로)**

degree 별 impulse @50 (잡음 0.1%): D1 72% · D2 72% · D3 76%. 약점: D3 impulse 잡음 0 칸(20 경로)은 전체 목록 포함 55% · @50 35%.

**관문(§6):** (1) 전체 목록 ≥ 80% ✔ ✔ (2) @50 ≥ 50% ✔ ✔ (3) @50 ≥ 무작위 2 배 ✔ ✔ → **구간을 모를 때의 후보 생성 검증 완료**
(연구용 기본값 N = 50 기준). 개발 seed(impulse @50 70% · zigzag 87%)와 비슷하거나 높아 과적합의 증거는 없다.

**JEV 섀도 비교의 기준선:** 위 recall@50 이 JEV 가 고를 수 있는 상한이다. 기준 순위 규칙의 **묶음 안 선택률**
(정답이 묶음에 있을 때 1등으로 고른 비율) = @1 / @50: impulse 13.3/73.3 = **18.2%**, zigzag 36.7/88.7 = **41.4%** (잡음 0.1%).
JEV 는 같은 묶음에서 이 값과 나란히 비교한다(§6 요구: recall 과 선택률 분리).
