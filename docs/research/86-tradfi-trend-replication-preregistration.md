## 1. 질문

## 2. 규칙 (고정)

| 항목 | 값 |
|---|---|
| 방향 | `(sign(r20) + sign(r60) + sign(r120)) / 3`, **음수면 0(현금)** — T/v2 와 같다 |
| 크기 | 방향 × min(**15%** / 60봉 실현 연변동성, **0.5**) |
| 봉 | **각 자산의 거래일 봉.** r20·r60·r120·60봉 변동성은 봉 수로 센다(TradFi 는 거래일, 암호화폐는 역일). 연율화 √(연간 봉 수): TradFi **252**, 암호화폐 365 (T/v2 코드 그대로) |
| 체결 | 종가 d 에 목표를 정하고 **그 자산의 다음 종가**에 체결. 밴드 5%p |
| 비용 (판정) | 편도 **0.15%** — T/v2 현물 가정 그대로 (실제 ETF 비용보다 보수적) |
| 현금 | 이자 0 (T/v2 와 같다) |
| 포트폴리오 (Q2) | 자산마다 위 규칙으로 목표 비중을 구한다. **합이 1 을 넘으면 모두 같은 비율로 줄여 합 = 1.** 그 밖의 조정은 없다 |
| 달력 (Q2) | UTC 역일 기준 일간 계좌. 쉬는 날(주말·휴장) TradFi 자산은 전날 종가로 평가(수익 0)하고 거래하지 않는다 |

**봉을 거래일로 센 이유(자료 전에 정함):** T/v2 코드는 "20봉"을 쓰고, 암호화폐는 봉 = 역일이다. TradFi 에서 역일로 세면 20일이 약 14거래일이 된다.
문헌의 "20일 모멘텀"은 거래일이다. 역일 해석은 판정하지 않는다(두 해석 중 좋은 쪽을 고르지 않기 위해).

## 4. 판정 — 한 번

### Q1 — 자산마다 따로 (네 번의 판정)

| # | 기준 |
|---|---|
| X1 | 일간 순수익 평균 − **2.5 SE** > 0 (네 자산 동시 검정이라 T 의 2 SE 보다 엄격하게) |
| X2 | 두 반쪽 구간 **각각** 일간 순수익 평균 > 0 |

두 기준을 모두 통과한 자산을 "재현"으로 본다. **Q1 의 답은 재현된 자산의 수다**(0~4).

**검정력(먼저 적는다):** 19.7년에 X1 로 증명 가능한 최소 연 샤프는 약 (2.5 + 0.84)/√19.7 = **0.75** 다.
단일 자산 추세의 샤프는 흔히 이보다 낮다. **X1 실패는 "우위 없음"이 아니라 "증명할 만큼 크지 않음"일 수 있다.**

### Q2 — 포트폴리오 (전부 통과해야 PASS)

A = T/v2 (BTC·ETH), B = 6자산 T/v2 (§2 포트폴리오 규칙). 같은 기간·같은 비용.

| # | 기준 |
|---|---|
| Y1 | 샤프(B) > 샤프(A) |
| Y2 | 종가 MDD(B) ≤ MDD(A) |
| Y3 | 두 반쪽 구간 **각각** 샤프(B) > 샤프(A) |
| Y4 | 비중 합 ≤ 1 이 모든 날 지켜진다 (레버리지 없음) |

**샤프 차이를 통계적으로 증명하는 기준은 넣지 않았다.** 8.67년으로는 차이 0.3 도 증명할 수 없다(24 §4). Q2 는 T/v2 를 **대체할지가 아니라** 분산이 과거에 도움이 됐는지를 본다.
PASS 여도 뜻은 "과거 한 구간에서 도움이 됐다"까지다. 쓰려면 별도 전향 관찰이 먼저다.

**실패 시:** 기각한다. lookback·변동성 목표·비중 상한·자산 구성·봉 해석·비용을 바꿔 다시 판정하지 않는다. 자산을 빼거나 더해 재판정하지 않는다.

## 6. Binance TradFi 무기한 실행 가능성 (판정과 별개)

역사가 5~9개월뿐이라 **우위 판정에는 쓰지 않는다.** 이 계좌로 실제로 거래할 수 있는지만 본다. 공개 자료만 쓰고 주문하지 않는다.

| # | 기준 | 자료 |
|---|---|---|
| C1 | 10,000 USDT 시장가의 호가 비용(반 스프레드 + 충격) 중앙값 ≤ **5 bp** — 미국 정규장 시간 | 호가 스냅숏 (여러 날·시간대) |

| C4 | 테스트넷·데모에 같은 종목이 있어 주문 경로를 훈련할 수 있다 | 데모 exchangeInfo |

**함께 적을 설계 문제:** 신호는 ETF 종가(미국 장 마감)로 정하는데 무기한은 다른 시각에도 거래된다. 체결 시각·휴장 중 가격(mark)을 어떻게 쓸지는 판정 뒤 설계한다.
무기한은 선물 계정이 필요하다 — 실거래 1단계(현물)가 아니라 2단계 이후의 이야기다.

## 7. 먼저 적는 약점과 노출

- **이미 알려진 사실:** 금·주가지수의 장기 추세 추종(관리형 선물)은 널리 연구됐다. 2008년 주가 폭락 때 추세 규칙이 현금으로 빠진 것도 공공연하다. 규칙을 튜닝하지 않고 T/v2 그대로 쓰는 것이 방어다.
- **ETF 는 선물이 아니다.** 보수와 추적 오차가 있다. 금·은은 현물 대신 ETF 로 본다(보수적).
- **현금 이자 0.** 미국 금리가 높았던 기간(2023~)에는 현금에 이자가 붙는 실제 계좌보다 불리하다. T/v2 와 같게 둔다.
- **Q2 의 비중 축소 규칙(합 > 1 이면 비례 축소)은 T/v2 에 없던 요소다.** 두 자산 × 0.5 는 합이 1 을 넘지 않아서 필요 없었다. 레버리지 없이 여섯 자산을 담으려면 필요하다.
- **공통 달력:** 주말에 암호화폐만 움직인다. 주말 뒤 월요일 TradFi 종가로 한꺼번에 반영된다.
