## 1. 가설

레버리지 롱 수요 프리미엄(funding)은 BTC보다 알트 무기한에서 크고 며칠 단위로 지속된다.
직전 7일 funding이 높은 종목에 현물 롱 + 선물 숏으로 들어가면 BTC 단독(K/v1)보다 캐리가 크다.
방향 예측이 아니다. K/v1과 달리 **종목 선택**이 수익원의 일부이며, K/v1의 재판정이 아니다.

## 2. 유니버스 (`scripts/m_data.py`, 매월 1일 00:00 UTC, 그 시점 정보만)

1. USD-M `*USDT` 무기한. 1000배수 계약(숫자로 시작)·스테이블코인 기초자산 제외
2. 상장 90일 이상 (선물 1일봉 첫 봉 기준. 상장폐지 종목 포함 전체 목록 864개에서 고름 → 생존 편향 없음)
3. 직전 30일 선물 거래대금 합 상위 30 → 그중 **같은 이름의 현물 페어가 직전 24시간 안에 거래**된 종목을 순위대로 **20개**
   (현물 조건이 금·주식 기초 무기한도 걸러낸다)

유니버스 파일 `reports/m/universe.json` sha256 `b4aa8d91…829` (80개월, 등장 종목 165개, 2020-06부터 매월 20개, 2026-07·08은 19·18개).

## 3. 규칙 (전부 고정)

| 항목 | 값 | 근거 |
|---|---|---|
| 포지션 | 종목마다 현물 롱 + 선물 숏 같은 수량, **선물 1x** (현물 1/2, 증거금 1/2) | K의 안전 발견: 알트는 1h 급등 꼬리가 BTC보다 두껍다. 1x 청산가 ≈ 기준가의 약 2배 |
| 슬롯 | 최대 **4종목**, 진입 시 슬롯 자본 = 총자본/4 (가용 현금 한도) | 사용자와 합의한 3~5 중간, 종목당 25% |
| 신호 | 직전 7일에 정산된 funding 합 / 21 (8시간 환산; 4h·8h 주기 모두 같은 척도). 7일 창의 첫 정산이 판단 시각 6일 전 이전이어야 함 | 1주 지속성 |
| 판단 | 8시간마다 (00·08·16 UTC). 체결은 **다음 1h봉 시가**에 두 다리 | K와 같은 지연 |
| 진입 | 유니버스 종목 · 미보유 · 신호 ≥ **0.01%** · 신호 높은 순으로 빈 슬롯만큼 | 기준 이자율. 1x에서 자본 대비 연 5%에 필요한 명목 캐리 ≈ 연 10% |
| 해제 | 신호 < **0.005%** 또는 이번 달 유니버스에서 빠짐 | 히스테리시스로 잦은 교체 방지 |
| 재조정 | 선물 종가가 기준가 대비 **±30%** → 다음 봉에 현물 1/2·증거금 1/2로 재배분 | 1x는 청산까지 여유가 커서 20%보다 넓게. 알트 재조정 비용 억제 |
| 비용 | 현물 taker **0.10%**, 선물 taker **0.045%**, 다리별 슬리피지 **0.05%** (BTC 0.02%의 2.5배) | 알트 유동성 보수 가정 |
| 유지증거금 | 명목의 **1%** (1h 선물 고가 기준 판정) | 알트 등급 보수 가정 |
| 상장폐지·결측 | 현물·선물 봉이 24시간 연속 없으면 마지막 가격에 다리별 **1%** 벌점 슬리피지로 강제 정리 | 폐지 공지·정산가 불확실성 |
| funding | 정산마다 증거금 += 수량 × 정산 시각 선물 1h 시가 × rate | K와 같은 mark 대용 |
| 현금 | 빈 슬롯 현금 이자 0 | 보수적 |
| 구간 끝 | 모든 포지션을 마지막 가격에 청산 비용 반영 | |

**대조군 (보고용, 판정 기준 아님):** 같은 규칙에서 funding 순위 대신 **거래대금 순위**로 고른다(문턱은 같다).
종목 선택이 캐리를 키우는지 보려는 것이다.

## 5. 판정 — K/v1과 같은 기준, 전부 통과해야 PASS

| # | 기준 |
|---|---|
| M1 | 연환산 순수익률 **≥ 5.0%** |
| M2 | 월간 순수익률 평균 − 2SE > 0 |
| M3 | 구간 안 **각 연도** 순수익 > 0 |
| M4 | 1h 평가 자본 **MDD ≤ 5%** |
| 안전 | 청산 0건 |

VALIDATION: M1~M4·안전 (연도 2025, 2026). STRESS: 안전(청산 0) · **MDD ≤ 10%**, 수익은 보고만.
강제 정리(폐지) 건수·손실은 별도 보고한다. TRAIN 실패 시 기각, 슬롯·문턱·유니버스 크기·레버리지를 바꾸지 않는다.

## 6. 검정력·데이터 (SD만, 적재 후 기록)

§9에 적재 결과와 SD를 기록한다. 판정 기준은 위에서 이미 고정했으며 이 값으로 바꾸지 않는다.

## 7. 노출

- H3가 2023~2024 다중 심볼 funding을 **포지셔닝 신호**로 사용 → 분포 일부 노출.
- K에서 BTC funding이 2025~2026에 축소된 것을 봤다. 알트 funding과 상관이 있으므로 VALIDATION 방향이 부분 노출.
- 알트 funding 평균·종목별 캐리는 열람하지 않았다.

## 8. 실거래로 가기 전에 필요한 것 (범위 밖)

다종목 현물 주문·이체, 두 다리 체결 실패 처리, 종목 폐지 공지 감시, 스펙(다중 종목 실거래) 변경 승인, 전향 검증.

**해석:**
- funding 수입은 현물 명목(자본의 절반) 대비 연 약 12%로, BTC 단독 K/v1 TRAIN(명목 대비 연 약 10.6%)보다 **조금** 컸다.
  7일 funding 순위로 고른 효과는 대조군 대비 연 약 0.6%p였다.
- 교체·재조정 비용이 funding의 41%를 가져갔다. 알트는 funding 상위가 자주 바뀌고(진입 72회) 가격 변동이 커서 재조정도 많았다.
- 선물 1x는 자본의 절반만 캐리에 쓴다. 안전을 위해 필요한 설계지만 수익률을 절반으로 만든다.
- 결론: 알트로 넓혀도 캐리의 크기는 BTC와 큰 차이가 없었고, 안전한 레버리지에서 자본 대비 연 5%를 넘지 못했다.
  §5에 따라 기각하고 VALIDATION·STRESS는 실행하지 않는다. 슬롯·문턱·유니버스·레버리지를 바꾸지 않는다.
