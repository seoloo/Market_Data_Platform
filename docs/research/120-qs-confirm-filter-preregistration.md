# 120 — QS 휩쏘 줄이기: "N 일 연속 켜져야 켜짐" 확인 필터 — 사전 등록

사용자 (2026-10-04): "그래 1번 진행해줘" — 1번 = QS 휩쏘 줄이는 변형 연구.
배경: [119](119-qs-dotcom-stress-preregistration.md) — 1995~1998 시작 창에서 QS 가 거의 다 졌다(2000~2002 반등마다 TQQQ 를 샀다가 다시 꺾여 판 휩쏘). 실거래 QS([118](118-qs-live-registration.md))는 사용자 결정으로 그대로 둔다 — **이 결과가 통과해도 실거래 반영은 따로 사용자가 정한다.**

## 1. 변형 (하나의 가족, 결과 보기 전 고정)

QS 의 신호(QQQ T 규칙: 20·60·120 거래일 부호 평균 > 0)를 이렇게 거른다:

- **켜짐으로 보는 날 = 원래 신호가 N 거래일 연속 켜져 있는 날.** 꺼짐은 원래 신호가 꺼지는 그날 바로.
- 나머지 QS 규칙은 110 그대로(꺼짐 → QNDX 멈춤·현금 쌓기 · 켜짐 전환 날 현금 전부 TQQQ · 꺼짐 전환 날 TQQQ 전부 매도 · 22% · 0.25%).
- 후보 N ∈ {3, 5, 10, 20}. 기준 = N 1 (지금 QS).

## 2. 자료

[119](119-qs-dotcom-stress-preregistration.md) 와 같은 FRED `NASDAQ100`·`DTB3_full` (SHA256 고정), 가상 TQQQ = 3 × 지수 − (2 × DTB3 + 0.84%)/252. 계산은 110 의 `simulate` 그대로(신호만 거른다).

## 3. 고르기 — 1986~2007 로만 (학습)

- 학습 창: **1987-01 ~ 1997-12** 매달 시작 10 년 창 132 개 (끝 ≤ 2007-12, 닷컴 포함).
- 각 N 의 **QS_N ÷ A 최솟값**(가장 나쁜 창)이 가장 큰 N 을 고른다. 같으면 중앙값이 큰 쪽, 그래도 같으면 작은 N.
- **학습 문턱:** 고른 N 의 최솟값이 기준(N 1)의 최솟값보다 **0.05 이상** 높아야 한다. 아니면 그 자리에서 `REJECT`(검증 안 함).

## 4. 검증 — 2008~2026 으로 한 번 (시험)

- 시험 창: **2008-01 ~ 2016-08** 매달 시작 10 년 창 (끝 ≤ 2026-09, 약 104 개). 학습에 쓰지 않은 구간.
- **T1:** 시험 창 QS_N ÷ A 중앙값 ≥ 기준 QS ÷ A 중앙값 × 0.97 (상승장 이득을 3% 넘게 버리지 않는다).
- **T2:** 시험 창 중 QS_N > A 비율 ≥ 90%.
- 둘 다 통과 → `PASS` — 사용자에게 실거래 QS 를 N 일 확인 필터로 바꿀지 제안. 하나라도 실패 → `REJECT` — 지금 QS 유지.

보고만(판정 아님): 학습·시험 각 N 의 최소·중앙·최대·승률, 2000~2002 TQQQ 매매 횟수, 시험 구간 최대 낙폭 차.

## 5. 약점 (먼저 적음)

- 시험 구간 2008~2026 은 110 에서 기준 QS 를 이미 본 구간이다 — 다만 N 은 그 구간을 보지 않고 고른다.
- 지수에 배당이 없고 가상 TQQQ 는 실제 상품이 아니다(119 와 같음).
- 확인 필터는 회복 초반 상승을 놓친다 — 2020·2022 같은 빠른 V 자 반등에서 손해가 날 수 있다(T1 이 그것을 본다).
