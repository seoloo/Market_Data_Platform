## 0. 무엇을 묻는가

T 는 20·60·120 일 추세다. T/v1(롱숏)의 숏은 9 년 동안 가격 손익 −1,527 · funding +1,290 으로 **0 근처**였다(15 §7).
F1 은 **더 빠른 추세**(5·10·20 또는 10·20·40 일)로 롱과 숏을 모두 드는 선물 전략이다. 묻는 것은 두 가지다.

1. 빠른 추세라면 선물 숏이 돈을 버는가(2022 같은 긴 하락에서 T/v2 는 현금으로 쉬지만 F1 은 숏을 든다)?
2. 빠른 만큼 늘어나는 비용과 숏 스퀴즈 꼬리를 감당할 수 있는가?

크기 규칙은 T 와 같다: 방향(부호 평균) × min(15% / σ60, 0.5). 판정 d → 체결 d+1. 아래 회전율은 밴드 없이 센 **상한**이다.

**가장 큰 두 값은 무기한 최종 체결가 윅이다(자료 오류 아님, 현물과 비교):**

| 날 | 무기한 고가 | 현물 고가 | 전날 종가 대비 무기한 / 현물 |
|---|---:|---:|---|
| ETH 2020-03-13 | 323.00 | 139.68 | +203% / +30% |
| BTC 2021-07-26 | 48,168.6 | 40,550 | +36% / +9% |

거래소 청산·스톱은 **mark price** 기준이라 이런 순간 윅에는 대개 닿지 않는다. 그러나 최종 체결가 고가로 청산을 판정하면
1x 숏도 ETH 2020-03-13 에 청산된다. **청산 판정 기준(최종 체결가 / mark price)은 사전 등록 전에 정해야 한다**(§3).
F1a·F1b 는 이날 ETH 숏이었고 T 참고는 아니었다.

비용 부담(기준 연 3.8~5.4%)이 그 우위를 먼저 먹는다.

## 2. 해석과 권고

1. **사전 기대는 낮다 — 먼저 적는다.** 느린 추세의 숏이 0 이었고, 빠를수록 비용이 늘며(F1a 연 5.4%), 단기(2~24h) 방향 예측 계열은 모두 0 이었다.
   F1 은 그 사이 구간(수일~수주)이다. 기각될 가능성이 크고, 기각도 유효한 결과다.
2. **F1a 는 권하지 않는다.** 기준 비용으로 연 5.4% 를 먼저 이겨야 한다.
3. **F1b (10·20·40) 를 권한다.** 비용이 T 의 1.7 배이면서 T 와 다른 속도(정보)를 본다. 숏의 73% 가 T/v2 현금 구간 — 보완 성격이다.
4. 판정 방식 안 (사전 등록에서 고정):
   - **단독 판정:** F1b 롱숏 1x 의 일간 순수익(비용·funding 후) 평균 − 2SE > 0 (T/v1 과 같은 형식), 청산 0, 계좌 정지 0.
   - **기준 비용**으로 판정, 참고 비용은 참고 줄(42 §8).
   - 최악의 경우 기준: 숏 보유일 +20% 급등 날의 손실, 최악의 하루·30 일, MDD.
   - T/v2 와 섞은 포트폴리오는 보고만.
