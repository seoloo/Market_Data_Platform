# 56 — 데모 선물: Elliott + 피보나치 2·4파 되돌림 (BTC, 레버리지 5x) 등록

작성: 2026-09-25 (Opus) · 상태: **등록 · 상주 실행기 준비 완료** · 가짜 돈(Binance 선물 데모)만 쓴다.
사용자 요청 (2026-09-25): "선물 btc 같은 경우는 전에 엘리엇 파동 + 피보나치 되돌림을 사용한 연구를 btc 선물 데모로 진행하면 좋겠거든?
그래서 배율을 5배로 잡고 한번 진행해볼래?" · 설계 선택: **2·4파 되돌림 매수/매도 · 레버리지 설정 5x + 거래당 위험 1% · 상위 시나리오 다수 합의**.

## 0. 먼저 적는 것 — 이것은 검증이 아니다

- Elliott·피보나치 **단독 수익 우위는 확인되지 않았다**: Elliott 5 일 되돌림 판정 불가(34), 피보나치 구간 1 일 차이 −0.09%p p 0.79(37).
- 과거 셋업 빈도(아래 §3) 기준 **한 달 1~3 번**. 몇 달 데모로 수익을 통계적으로 말할 수 없다.
- 목적: ① 연구 판독기(EW-3d′ 시나리오 묶음)를 **실시간으로** 돌려 보고, ② 파동 규칙에서 나온 손절·목표로 **실제 주문 흐름**(예약·체결 즉시 보호·청산)을 확인하고,
  ③ 사용자가 텔레그램으로 **왜 들어갔는지**를 보며 판독을 관찰하는 것. 결과는 기록하고 보고하되 전략 판정에 쓰지 않는다.
- Elliott 코드는 여전히 **매매 경로(src 의 core·strategy·risk·execution 등)에서 import 하지 않는다** — 데모 스크립트(`scripts/demo_ew_btc.py`)만 쓰고, 주문은 데모 전용 어댑터만 낸다(import 규칙 유지).

## 1. 규칙 (고정)

| 항목 | 값 |
|---|---|
| 신호 자료 | 실거래소 공개 **BTCUSDT 무기한** 1m, 최근 90 일 → 1h·4h 집계 → EW-3d′ 인과 스캐너(연구와 같은 코드, 2% 4h 피벗·1h 하위파) |
| 발동 | 새 4h 가시 꼭짓점이 확정될 때(4h 마감 90 초 뒤 스캔) |
| 셋업 | 그 발동의 시나리오 묶음에서 **기준 순위 상위 10 개 중 6 개 이상이 같은 방향 "충격파 5파 종료"**(`demo_setup.setup_from_set`) |
| 해석 | 끝난 충격파를 더 큰 파동의 1파(또는 3파)로 보고, 이어질 **2파(4파) 되돌림**에서 추세 방향으로 진입 |
| A·B | 합의한 시나리오 중 순위 1 등의 시작점 A(0) · 끝점 B(5) |
| 진입 | **B − 0.5 × (B − A)** 에 post-only 지정가(GTX) 예약 |
| 손절 | **A** (되돌림이 충격파 시작을 넘으면 2파 규칙 위반 → 해석 무효) — STOP_MARKET closePosition, mark price 발동 |
| 목표 | **진입가 + 1.618 × \|B − A\|** — TAKE_PROFIT_MARKET closePosition |
| 크기 | 손절에 닿으면 USDC 잔고의 **1%** 손실(명목의 0.07% 비용 여유 포함). 레버리지 설정 **5x**, 교차 증거금 |
| 예약 취소 | 체결 전에 가격이 B 를 넘음(충격파 연장) · 10 일 미체결 · 새 셋업이 나오면 교체 |
| 건너뜀 | 셋업 확정 순간 이미 0.5 되돌림을 지났으면 들지 않는다 |
| 보유 | 한 번에 하나. 보유 중 새 셋업은 기록만. **최대 30 일** 뒤 시장가 청산 |
| 보호 | 데모 거래소는 포지션 없이 closePosition 스톱을 받지 않는다(−4509, 실측). → 실행기가 **2 초마다** 진입 주문을 확인하고 체결 즉시 손절·목표를 건다. 걸린 시간을 기록한다(TRADING_CORE 보호 공백 5 초) |
| 재시작 | 켜질 때 거래소와 기록을 맞춘다: 보호 없는 포지션 → 즉시 보호, 기록에 없는 포지션 → 시장가 정리 |

**종목 BTCUSDC:** 21:08 Phase 7 매일 훈련이 **같은 데모 계좌의 BTCUSDT** 를 쓰고 "시작 시 포지션 0, 모르는 포지션은 정리" 규칙이라 충돌한다.
그래서 데모 주문은 **BTCUSDC 무기한**(USDC 증거금, 데모 잔고 USDC 5,000 확인)에 낸다. 신호는 BTCUSDT 로 계산한다(연구와 같은 자료).
데모 BTCUSDC 호가는 얇다(실측 스프레드 23 USDC ≈ 2.7bp, 실거래소 0.1) — 스톱·목표 시장가 체결의 미끄러짐으로 기록한다.
