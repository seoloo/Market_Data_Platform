# 64 — O + 선물부터 줄이기 (세 추세 신호가 모두 상승일 때만 선물 추가분) — 사전 등록

작성: 2026-09-25 (Opus) · 상태: **사전 등록 · 수익·낙폭 미계산 · 판정은 사용자 승인 뒤 1 회.**
사용자 (2026-09-25): 수익 모델을 위해 연구한다 → O/v3 낙폭 문제와 "선물부터 줄이기" 후보 제안에 "그렇게 해줘".

## 1. 왜

- O/v3(2 배)의 과거 MDD 는 **29.9%**(42 §8) — 전향 중단선 25%·계좌 정지 30% 에 붙어 있다. 10/23 O/v3 보고에서 이것이 판단을 좌우한다.
- O/v2(1.5 배)의 MDD 23.2% 는 **2021-11 → 2022-11 의 1 년짜리 완만한 하락**이다(43 §7). 변동성 끄기(B′)는 이것을 전혀 줄이지 못했다(0%p).
- "선물부터 줄이기"(52 §1.1)는 추세가 약해지면 현물은 T/v2 대로 두고 **선물 추가분부터 0** 으로 만든다 — 완만한 하락에서 신호가 하나씩 꺾일 때 작동하는 규칙이다.
  사용자 원칙("변동성이 커도 방향이 맞으면 유지")과 맞다: 변동성이 아니라 **추세 신호**가 꺾일 때만 끈다.

## 2. 규칙 (고정, `OverlayConfig(futures_full_trend_only=True)`)

- 판정 d 의 종가까지로 T/v2 의 세 신호(현재 종가 > 20·60·120 일 전 종가)를 본다. **셋 다 상승이 아니면** d+1 체결에서 그 종목의 노출 배수를 **1.0** 으로
  (선물 추가분 0, 현물은 T/v2 목표 그대로). 셋 다 상승이면 O 그대로(1.5 배·2 배).
- 구현은 43 의 종목별 배수 장치를 그대로 쓴다(`weak_trends` ∪ `vol_spikes`). 비상 스톱 −20%·레버리지 상한 3 배·일 손실 2%·계좌 정지 30% 그대로.
- T/v2 는 바꾸지 않는다(현물 목표·밴드·비용 동일).

| 이름 | 설정 |

## 3. 구간·판정 — O 와 같은 구간, 한 번 (`python -m scripts.run_o_futfirst run`)

**2020-03-01 ~ 2026-08-31, 초기 10,000, 기준 비용.** 대조: A = T/v2 단독, B2 = O/v2, B3 = O/v3.

**F2 — O/v2 를 대체할 만한가 (43 과 같은 기준):**

| # | 기준 |
|---|---|
| W1 | O 기준(24 §3 O1~O5)을 F2 가 **모두** 통과: 정지 0 · 청산 0 · MDD ≤ 25% · CAGR > A · 두 절반 각각 > A |
| W2 | **위험 감소:** MDD(B2) − MDD(F2) ≥ **2%p** |
| W3 | **비용:** CAGR(B2) − CAGR(F2) ≤ **2%p** |

**F3 — 2 배를 한도 안으로 가져오나:**

| # | 기준 |
|---|---|
| X1 | O 기준(O1~O5)을 F3 가 **모두** 통과 — 특히 **MDD ≤ 25%** |
| X2 | CAGR(F3) > CAGR(B2) — 2 배를 쓰는 대가로 O/v2 보다 더 벌어야 의미가 있다 |

각각 전부 통과해야 PASS. **최악의 경우를 먼저 보고한다:** 봉 안 최악 낙폭·최악의 하루·최악의 30 일·MDD 구간. 그다음 샤프·연도별·선물 끈 (종목, 날)·비용·funding.
현실 비용 줄은 **참고로만**(판정은 기준 비용, 메모리 원칙).

**실패 시:** 같은 자료로 신호 수(2/3 등)·배수(1.25 등)를 바꿔 다시 판정하지 않는다.
