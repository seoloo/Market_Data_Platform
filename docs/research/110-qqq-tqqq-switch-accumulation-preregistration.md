## 0. 먼저 알려진 결과

- [87](87-rsi-dip-accumulation-preregistration.md) RD (RSI ≤ 35 일 때만 사기, 기다리는 동안 현금): **REJECT** — 10 년 창 99 개 중 기다린 쪽이 이긴 창 0 개. 기다리는 동안 놓친 상승이 컸다.

- **QS 가 다른 점**: 기다린 현금을 **추세 회복 때 3 배(TQQQ)로** 넣어 놓친 상승을 되찾고, 다음 하락 추세에서는 TQQQ 를 팔아 큰 하락을 피한다.

## 1. 질문

같은 돈을 매달 넣을 때, **QS 가 매달 QQQ 를 바로 사는 것(A)보다 더 많이 남는가** — 세금까지 넣고, 낙폭은 크게 늘리지 않고.

## 2. 규칙 (고정)

| 항목 | 값 |
|---|---|
| 입금 | 매달 첫 거래일에 1,000 USD 가 현금으로 들어온다 |
| 추세 신호 | QQQ 배당 조정 종가로 T 규칙: 20·60·120 거래일 수익 부호의 평균(`features.tsmom.trend_direction`). **> 0 이면 켜짐, ≤ 0 이면 꺼짐** |
| 시차 | t 일 종가로 계산한 신호를 **t+1 일 종가**에 실행한다 (미래를 보지 않음) |
| **A (지금 방식)** | 입금한 날 종가에 전액 QQQ. 팔지 않는다 |
| **QS** | 켜짐: 입금한 날 QQQ 를 산다. 꺼짐: 입금은 현금으로 쌓인다. **꺼짐 → 켜짐 날: 쌓인 현금 전액으로 TQQQ.** **켜짐 → 꺼짐 날: TQQQ 전부 판다(현금).** QQQ 는 팔지 않는다 |
| TQQQ | 2010-02 상장 전이 있으므로 전 구간 **가상 TQQQ**: 일간 수익 = 3 × QQQ 일간 수익 − (2 × 전날 DTB3 + 0.84%) / 252 |
| 비용 | 사고팔 때마다 **0.25%** (KIS 일반 해외주식 수수료, 87 과 같음) |
| **세금 (판정에 넣음)** | QS 의 TQQQ 매도 이익: **달력 연도마다 실현 손익 합이 양수면 22%** 를 그해 마지막 거래일에 현금에서 뺀다(공제 250 만 원·이월결손은 없다고 보수적으로). A 는 팔지 않으니 세금 없음. 끝날 때 남은 평가 이익에는 둘 다 세금을 매기지 않는다 |
| 현금 이자 | **0%** (판정). 참고 줄: DTB3 |
| 평가 | 마지막 날 평가액 = QQQ 수량 × 종가 + TQQQ 수량 × 가상 가격 + 현금 |
