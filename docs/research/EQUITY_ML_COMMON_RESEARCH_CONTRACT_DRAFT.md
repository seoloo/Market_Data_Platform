# 주식 ML 연구 공통 계약 — 초안

작성: Codex · 2026-10-07 · **Phase 0 / DRAFT / NOT_TESTED**

사용자가 요청한 논문 1번은 [IDEAS 20 비용 고려 배분](EQUITY_COST_AWARE_PREREGISTRATION_DRAFT.md), 2번은 [IDEAS 21 수익 예측](EQUITY_RETURN_PREDICTION_PREREGISTRATION_DRAFT.md)이다. 이 문서는 두 초안의 자료·실행·검증 경계다. 확정 사전등록, 학습·성과 계산, 운영 변경 승인이 아니다. 숫자는 제안값이며 Claude가 자료 감사 뒤 수익 열람 전에 이유를 남겨 보정·확정한다.

## 1. 범위와 순서

- **제안 순서: 공통 Phase 0 감사 → 21 예측 모델 → 20 비용 고려 배분.** 21은 정보를 조합하는 방법, 20은 같은 예측에서 교체 비용을 고려하는 방법을 묻는다. 두 결과 중 좋은 것만 선택하는 경연이 아니다.
- 사용자가 두 초안 작성을 요청한 것과 두 모델의 성과 실행을 승인한 것은 구분한다. 다음 단계는 자료·안전성·검정력 감사다. 구현·판정할 하나와 범위를 확인한 뒤 진행한다.
- 21이 자료/검정력 미달 또는 기각이면 20으로 자동 넘어가지 않는다. 기존 신호를 이용한 별도 비용 연구는 사용자 재선택과 새 초안이 필요하다.
- 기존 실적 개선형 연구 4·5, 기각한 가격 모멘텀, 버린 DMN 19, 운영 중 T/v2·O·QS와 그 일정은 변경하지 않는다. 같은 자료는 공유할 수 있지만 연구 원장·모델·판정은 분리한다.

## 2. 시장·자료 관문

**시장 미확정.** 무료 자료를 확보 중인 한국 유가증권시장 비금융 보통주 경로를 우선 제안한다. 미국 논문을 한국에서 응용하는 연구이지 미국 실증의 재현이 아니다. 미국을 택하면 당시 구성 종목·상장폐지·기업행동·공시 시점까지 무료로 확보 가능한지 먼저 감사한다. 현재 S&P 500 명부나 유료 CRSP/WRDS로 대체하지 않는다.

한국 경로는 [기존 재무 연구 관문](FUNDAMENTAL_KR_GATES.md)을 참고하되 통과를 승계하지 않는다. 예약 수집 완료·계정 존재만으로 PIT 자료나 전체 커버리지가 확보됐다고 쓰지 않는다.

| 관문 | 성과 전에 확인할 내용 |
|---|---|
| 당시 종목군 | 월말 당시 상장·폐지·티커 변경 이력. 현재 살아남은 종목만 사용 금지 |
| PIT 재무 | 접수일·원본 버전·연결/별도 우선순위·단위·정정 이력. 정정 값은 실제 공개 이후만 반영 |
| 관측 가능 시점 | 공시 접수 다음 거래일 마감 이후 사용을 제안. 가격·거래대금은 마감봉만. 원천별 `available_at_ms <= as_of_ms` |
| 재무 기간 | 누적 현금흐름을 분기로 변환, 12분기·TTM 분모 검증. 과거 분기의 값이 나중에 공개됐으면 소급 사용 금지 |
| 가격·권리 | 원시 OHLC·거래량과 분할/합병/배당/권리·폐지 회계. 미래를 포함한 조정 가격으로 거래 가격·당시 거래대금 계산 금지 |
| 시가총액·자본 | 당시 시가총액과 자본 계정. 현재 발행주식 수를 과거에 곱하지 않음. 자본/시총 특성의 확보 여부는 신규 관문 |
| 업종 | 비금융 분류는 당시 기록으로. 오늘 업종 또는 API 결측으로 금융사를 추정해 빼지 않음 |
| 자료 노출 | 이미 본 시장·기간·성과·연구 목록과 해시. 이전 연구에서 본 2015~2026 가격을 새로운 최종 OOS라고 부르지 않음 |

종목군 제안: 매월 과거 63거래일 거래대금 상위 200을 **먼저** 고정한다. 모델 입력에 필요한 과거 자료가 없으면 결측으로 기록하고 201위로 채우지 않는다. 입력 자격에는 과거 252거래일 가격과 필요한 재무 이력을 요구한다. 원래 200개 대비 유효 입력 90% 이상·최소 100개를 제안하되 실제 분포를 감사한 뒤 확정한다. 이 기준을 넘는 날짜만 사후 선택해 성과를 계산하지 않는다. 결측 때문에 전체 관문 미달이면 `DATA_NOT_READY`다.

## 3. 공통 실행·회계 — 주식 롱만

- 가상 시작 자본 1,000만 원, 추가 납입 없음, 차입·공매도·레버리지 없음을 제안한다. 기존 실계좌와 연결하지 않는다. 월말 평가 후 다음 정상 거래일부터 주문하며, 선정 유지 시 보유를 계속한다. 임의의 일 거래 수·연속 진입 제한·최대 보유시간을 추가하지 않는다.
- **모든 주문은 가격 한도 지정가.** T/v2 시장가 추격 예외를 주식에 가져오지 않는다. 같은 월말 종가 체결, 가격 한도 없는 청산, 마지막 자료 날의 강제 현금화는 금지다.
- 봉 자료용 초안: 매 거래일 주문 전 알려진 직전 원시 종가의 매수 1.005배/매도 0.995배를 당시 호가 단위에 각각 아래/위로 맞춘다. 매수는 당일 종가가 한도보다 엄격히 낮고, 매도는 엄격히 높을 때만 체결 후보다. 정상 거래·거래량 양수·가격 제한/정지 아님을 확인한다. 매수 가격 `min(한도, 당일 고가)`, 매도 `max(한도, 당일 저가)`를 보수적 대리값으로 제안한다. 고가/저가 닿음만으로는 체결 처리하지 않는다.
- 이 규칙도 호가 대기열·부분 체결의 실증이 아니다. 당일 거래량과 과거 63일 평균 거래량의 각각 0.1%로 체결 수량을 제한하고 정수 주식으로 내림한다. 결측 가격 제한/호가 단위는 신규 진입 거부. 주문 충돌·현금 부족·부분 체결·예약 잔고와 매수/매도 우선순위를 확정한다.
- 매수 미체결은 최대 5거래일 뒤 취소·다음 월까지 현금. 매도 잔량은 평가손익에 남기고 다음 정상 세션에 한도 지정가를 다시 평가한다. 위험 정지 중 위험 축소는 허용하며, 못 판 위험을 숨기지 않는다.
- 기간별 수수료·매도 세금·슬리피지·시장충격의 근거/버전/적용일을 고정한다. 실제 개인 계좌 비용을 모르면 가정으로 표시한다. 리베이트·VIP 등급·0 비용은 가정하지 않는다. 세법의 현재 수치를 과거 전 기간에 복사하지 않는다.
- 두 비교군에 같은 비용표·체결 규칙·결측·현금 결제 지연을 적용한다. 매도 대금은 사용 가능 시점 이후만 재투자. 배당은 권리·미수·지급을 분리하고 폐지는 종료 대가 또는 불명 손실을 보수적으로 기록한다.
- [TRADING_CORE](../current/TRADING_CORE.md)의 포지션 위험·일 손실·누적 DD·연패·보호 규칙과 주식 경로의 충돌을 먼저 표로 만든다. **주식 손절/보호 가능 여부 및 사이징 계약은 미확정 관문**이다. 종목 5% 상한은 손절 계약을 대신하지 않는다. 기존 현물 무손절 예외를 자동 승계하거나 한도를 완화하지 않는다. 위험 통제 포함 계좌 재생을 판정 경로로 하며, 통제 없는 연구 수익은 보조 진단으로만 구분한다.

## 4. 학습·시간 분할

1. 시장·자료·개발/계획/역사 확인/최종 미열람 구간을 날짜로 적고 해시를 남긴다. 날짜는 커버리지와 열람 이력으로 정하며 좋은 성과 때문에 바꾸지 않는다.
2. 프로젝트 기본 TRAIN 12개월 / 다음 3개월을 제안한다. 월 단위 모델은 종목 행이 많아도 시간 표본은 12개월뿐임을 따로 보고한다. 장기 학습 창 변경이 필요하면 수익 전에 이유와 승인을 확보한다.
3. 다음 달 수익을 label로 쓸 때 학습 마감 전 그 수익과 권리/종료 처리가 실제로 확정된 행만 학습한다. 경계 중첩을 purge하고 embargo 기간을 고정한다. 랜덤 행 분할 금지.
4. 입력 정규화는 당시 월말 종목군의 횡단면 순위. 전체 기간 평균/분산·미래 업종·전체 표본 이상치 경계 금지. 같은 달 횡단면 사용은 허용되지만 당시 관측 자료만 쓴다.
5. 모델 구조·고정 시드·특성·학습 주기·선정/동점 규칙·라이브러리 버전을 확정한다. 내부 후보/시드 탐색·early stopping 성과 선택·OOS 재학습 튜닝은 하지 않는다.
6. 모델 산출은 별도 학습 계층, Pure Core에는 해시가 있는 고정 산출/모델만 넣는다. 미래 행 추가 시 과거 예측 불변, label cutoff, 종목 폐지·정정 공시·기업행동·부분 체결을 시험한다. 외부 백테스트 엔진으로 별도 경로를 만들지 않는다.

walk-forward 구간을 이어 붙일 때 계좌·보유 잔량·미체결 주문·위험 누적을 유지한다. 모델 교체 시 포지션을 무료 청산하거나 계좌 정지를 초기화하지 않는다. 무제한 보유를 임의의 최대 보유기간으로 바꿔 purge를 계산하지 않으며, 경계 포지션/label 중첩 계약은 확정 전 관문이다.

## 5. 검정력과 판정 계약

**21과 20 각각의 주 판정은 동일 달 두 계좌의 비용 후 수익 차이 `d_t`다. 종목×월·체결 수를 독립 시장 기간으로 세지 않는다.** 월 수익 장기 분산과 시계열 의존성을 반영한다. HAC lag 3을 주 추정, lag 6을 보조 점검으로 제안하며 결과가 유리한 쪽을 선택하지 않는다.

- 검출할 최소 연간 추가 효과 `delta_user`는 **미확정**이다. Claude는 가능한 효과별 필요 월수와 현재 표본의 최소 검출 효과를 표로 제시하고 사용자에게 경제적 가치가 있는 문턱을 확인한다. 검정력을 맞추려고 큰 효과를 꾸며 넣지 않는다.
- 평균 월 차이로 환산할 때 단순 연간 평균 추가 효과는 `/12`; CAGR 차이를 `/12`한 것과 같다고 쓰지 않는다. `n >= ((2 + 0.8416) * sigma_LR / delta_month)^2`는 80% 검정력의 근사 계획식이다. 유효 월수·분산 불확실성과 겹친 walk-forward 기간을 감사한다.
- **기준선 단독 SD는 모델 간 차이 SD가 아니다.** 기존 DMN 19 감사의 SD/필요 기간을 주식 ML의 검정력으로 복사하지 않는다. 아직 학습하지 않은 모델의 `sigma_LR`를 실측이라고 쓰지 않는다.
- 실제 차이 분산을 얻으려면 학습 파일럿이 필요할 수 있다. 이는 별도 승인된 고정 계획 구간에서만 수행하고 최종 확인 표본에서 제외한다. 파일럿 수익을 보고 구조를 바꾸면 변경·열람을 기록하고 새 확인 자료가 필요하다. 현재 초안은 파일럿 실행 승인도 아니다.
- 독립 월수·최소 효과·단일 후보의 80% 관문이 미달이면 `DATA_INSUFFICIENT`로 멈춘다. 두 연구의 개별 80%가 전체 연구 사슬 80%를 보장하지 않는다. 두 효과를 함께 입증하는 주장에는 공동 오류/검정력 계획을 별도로 확정한다.
- 주 기준 초안: 비용 후 차이 평균의 **2SE 하한 > 0**, 양의 절대 순수익, 대응 시장 총수익 기준선 대비 CAGR·Sharpe 열위 없음, 계좌 위험 계약 준수. 계산 정의·연율화·현금 금리·시장 기준선의 실제 투자 가능성과 비용을 모두 성과 전에 확정한다. 여러 기준의 공동 검정력도 따로 보고한다.
- IC·예측 R²·적중률·거래 횟수·회전율은 보조 설명이지 주 기준을 대체하지 않는다. 업종/크기/시기 집중과 앞뒤 기간은 사전 지정 진단이며 사후 합격 조건을 만들지 않는다.
- 이 월별 추가 효과 검정은 [BACKTEST_AND_TESTING](../current/BACKTEST_AND_TESTING.md)의 기존 Phase 게이트를 대체하지 않는다. TRAIN·확인 구간 각각의 필요 표본 중 큰 쪽을 계획하고, Phase 4 실제 체결 n≥100 및 거래당 손익 검정력·다른 필수 요건은 별도로 감사한다. 거래 수가 많아도 독립 월수 부족을 구제하지 못한다. 주식 월별 비교와 현행 거래당 기준의 적용 충돌은 확정 전 사용자 결정 사항이다.
- 노출된 역사 자료에서 유의해도 `HISTORICAL_SUPPORT`까지만. 충분한 검정력의 미열람 확인 없이 `VALIDATED`·실거래 가능이라고 쓰지 않는다. 확정 뒤 미달은 기각/한계로 기록하고 모델 깊이·상위 종목 수만 바꿔 재시도하지 않는다.

## 6. Opus 다음 작업과 산출물

**지금 할 일은 Phase 0 감사만**이다: 시장 선택 질문 → 무료 자료 명세·결측/노출 지도 → 주식 지정가/보호·위험 계약 충돌 → 고정 모델 용량과 월 단위 표본 → 최소 효과·80% 계획 → 확정 가능한지 보고. 자료 파일럿 이상의 학습/성과가 필요하면 목적·구간·노출·권한을 먼저 확인한다.

감사 후 미확정 관문이 없고 사용자 선택 범위가 명확할 때만 Claude가 사전등록을 확정 커밋한다. 이후 승인된 코드·시험·1회 판정과 기록을 담당한다. Codex 초안 커밋을 확정 커밋으로 세지 않는다.
