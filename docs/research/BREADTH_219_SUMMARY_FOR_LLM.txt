[연구 219 — 코인 상승 참여 급확대(4시간봉 오른 종목 비율 ≤30% → ≥80%) → BTCUSDT 선물 롱 24시간 / 결론: 불리 종료 (후향 파일럿, 판정 아님)]
원문: docs/research/219-breadth-expansion-btc-pilot.md (사전 계약 dcba23d → 1회 실행)

가설
- BTC·코인 평균 상승률이 비슷해도, 오르는 코인이 소수 → 다수로 급히 넓어지면 공통 매수 압력이 이어져 BTC 24시간 롱이 비용을 넘는다
- 참여자 정체·주문 계획을 확인했다고 주장하지 않음. '넓은 참여 → 지속' 관계 자체를 시험

중복 대조 (실제 규칙)
- R1(강한 코인 롱·약한 코인 숏) · H3(OI·funding 포지셔닝 롱숏) · 215(시가총액 도미넌스) · TA(코인별 추세) · 212/217(같은 종목군, 개별 코인 롱)와 다름
- QS-WARN BREADTH(166): 업종 ETF 9개 중 200일선 위 ≤4 → QS 3배를 1배로(장기 하락 경고, 수준). 219는 4시간 만에 폭이 넓어지는 '변화' → BTC 진입(24시간). 방향·시계·행동 반대 → 같은 가설 아님

자료
- 종목군: 212의 월별 USD-M 거래대금 상위 20 (BTC 제외·ETH 포함·폐지 포함·180일 이상 상장·스테이블/자산연동/비코인 제외), 그달 고정
- 공개 아카이브 4시간봉 1,938개(sha256), 실행은 BTCUSDT 1분봉·funding·mark(210 캐시), 2020-07 ~ 2026-08 (신호는 2020-09부터: 2020-07~08 종목 2·11개)
- B_(t−1)과 B_t를 같은 유효 종목(봉 t−2·t−1·t 모두 있는 그달 종목)으로 셈 → 구성 변경·결측의 가짜 전환 방지. 유효 <15면 신호 없음

규칙 A (결과 전 고정)
- 신호: B_(t−1) ≤ 30% · B_t ≥ 80% · BTC 4h 수익 > 0 (B = 4h 수익 > 0 종목 비율, 동일가중, 0은 상승 아님)
- 다음 1분봉부터 20분 지정가, 상한 = 신호 종가 × 1.003, 시가가 상한 이하일 때만 체결, 미체결이면 폐기
- 보호 = 신호 봉 BTC 저가 (STOP_MARKET 예외, 비상 +1%), 진입 전 보호가 이하면 진입 안 함, 첫 체결 + 24시간 지정가 청산
- 위험 0.25%, 명목 ≤ 25%, 1배 격리, 일 손실 2%·누적 30% 정지, 편도 0.095% + 실제 funding
- 비교 B: BTC 4h > 0 만 (같은 실행). 비교 C: BTC 4h 수익·종목군 평균 4h 수익·BTC 7일 변동성이 가까운 비-A 시점 5개 (A 신호 ±12시간 제외, 균형 SMD < 0.1 통과)

감사 (손익 없음)
- 참여율이 양 끝에 몰림 (≤30% 39%, ≥80% 31% 봉) → A 신호 1,749 (24시간 묶음 독립 876, 주 311), B 6,930
- 참여율 vs 종목군 평균 수익 상관 0.80, 같은 시장 상승 범위의 87%가 B ≥ 80% → 참여율은 시장 평균 수익을 대부분 다시 표현. 남는 정보는 '직전 ≤30%에서 급전환'
