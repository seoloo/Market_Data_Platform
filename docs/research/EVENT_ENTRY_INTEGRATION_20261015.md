# 개별주 발표 일정과 신규 매수 보류 규칙

2026-10-15 사용자 승인 범위는 공통 일정, 추천과 알림, 결측과 휴장일 검증,
신규 매수 보류 및 복귀 규칙의 구현이다. 기존 Deneb·Vega·Altair·Paper·자동 적립에는 적용하지 않는다.
수익을 최적화하는 연구가 아니라 개별주 도구의 안전 입력 일치 작업이며 새 성과를 계산하지 않는다.

## 적용 규칙

- 미국 개별주 신규 매수: 예정 정규장 미국 날짜의 CPI·PCE·NFP·FOMC가 있으면 그 세션 전체 보류.
  장중 발표가 끝나도 같은 세션에는 재개하지 않는다. 다음 정규장에 일정·추세·잔고를 다시 확인한다.
- PPI·GDP는 주의만 표시한다. 추가 비중 배수나 자동 매도 규칙을 만들지 않는다.
- 해당 종목 실적: 진입 예정 세션부터 실제 개장하는 세션 세 번 안의 발표 및 같은 날 발표를 보류.
  발표 시각 미정·장 마감 뒤 발표도 해당 미국 날짜 전체를 보류한다. 발표 다음 정규장부터 재평가한다.
- 보류된 기존 예약은 취소 종결하며 자동으로 다음 날 매수하지 않는다. 복귀는 새 추천·새 예약이다.
- 예약 시점과 각 추가 매수 주문 직전에 같은 자료를 다시 확인한다. 변경·결측이면 남은 신규 주문을
  멈추고 기존 주문 취소 확인 및 체결 대조를 먼저 한다. 일부 산 수량의 손절 경로는 유지한다.
- 일정 차단·수집 장애가 손절·매도·위험 축소를 막아서는 안 된다. 일정 코드에는 주문 API가 없다.

## 자료와 유효성

미국 거시는 기존 config/event_calendar.yaml을 단일 원천으로 사용한다. 시작·끝 커버리지와 검증일을
명시하고 범위 밖·손상·검증일 미래·유효기간 경과는 신규 진입을 거부한다. 일정 변경을 자동 추측하지 않는다.
실적은 Nasdaq 날짜별 응답을 data/event_calendar/ 아래 두 소비자가 공유한다. 출처·시장 날짜·수집 UTC ms·
내용 digest·정상/확인 실패를 구분한다. 오래된 캐시나 누락/오류 응답을 빈 정상 명단으로 바꾸지 않는다.
Nasdaq 명단은 예정 일정이지 회사의 확정 공시나 전체 회사의 완전성 보증이 아니다.
미국/한국 거래일 수는 기존 증권사 정규장 달력 응답으로 세며 주말·공휴일·조기폐장을 반영한다.
국내 종목의 실적 원천은 미확보이므로 확인 불가로 신규 진입을 막고, 기존 보유 손절은 유지한다.

## 추천과 알림

기본 비중 계산과 실제 진입 허용을 구분한다. 25% 상한·지수 아래 절반·추세·현금 제한은 그대로 두고,
추세/지수/실적/거시 확인 실패는 명시적으로 차단한다. 손절가와 위험금액은 보장치가 아닌 계획치다.
아침/장전 알림은 같은 일정 원천과 저장된 예약·보유 장부를 읽으며, 종목·상태·발표 위험을 덧붙인다.
알림 설정 off나 전송 실패가 주문 안전 판정 off로 바뀌지 않는다. 별도 봇 메뉴·tick 등록은 타 세션 파일을
점유 중이므로 건드리지 않고 기존 호출 경로 안에서 통합한다. 실계좌·메시지 시험발송·예약 활성화는 하지 않는다.

## 검증

정상/빈 정상/결측/오류/오래된 캐시/미래 캐시, ET/KST·DST, 주말·휴장·조기폐장,
FOMC 장중·자정 넘어선 KST, 겹친 일정, 재개 첫 세션·추가 발표, 예약 후 변경,
미체결 취소 확인·부분 체결·조회 불명·보호 매도 지속을 가짜 자료로 확인한다.
전체 pytest·leakage·mypy·ruff·lint-imports와 문서 링크·자기 파일 커밋 범위 검사를 수행한다.

## 구현 범위와 운영 경계

`event_store.py`는 날짜별 실적 자료를 두 소비자가 공유하게 한다. 정상 캐시는 5분, 실패 기록은
1분이며 주문 직전에는 정상 캐시도 다시 요청한다. 원천 오류·누락·오래됨·미래 수집 시각·저장 실패를
정상 빈 명단으로 대체하지 않는다. 일정 판정은 `data/event_calendar/checks/`에 규칙 버전·코드 digest·
당시 시각·입력 digest·거래일·차단 사유와 함께 보관한다. 자료 확인은 일정 안전성을 높이기 위한 것이며,
Nasdaq에 없는 회사나 미정·추후 변경된 실적의 부재를 확정하는 인증은 아니다.

거시 달력의 검증일 유효기간은 30일이다. 자동 갱신은 구현하지 않으므로 만료 전 공식 일정과 대조하고
검증일을 갱신해야 신규 매수가 계속 가능하다. 이 만료는 기존 자동매매 장부에는 전파하지 않는다.
실제 정규장 달력에는 토스 API의 휴장·정규장 시각을 사용하며, null 휴장과 손상 응답을 구분한다.
장 시작 기준은 최초 관측 호가가 아니라 정규장 시작 시각과 일치하는 첫 1분봉 시가다.
그 봉이 없거나 거래량 0이면 새 주문을 내지 않는다. 일봉은 현재 미완성 세션을 제외한다.
관련 공식 계약은 [토스 OpenAPI 명세](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json)에서 확인했다.

이번 변경은 기존 개별주 실행기의 사전 점검·알림에만 연결했다. 실제 계좌·주문·발송 시험과 봇 메뉴·
2분 tick 등록은 하지 않는다. `telegram_bot.py`·`user_settings.py`는 다른 세션 점유 중이다.
따라서 기능 구현·가짜 자료 검증과 실제 상시 가동을 구분한다. 로컬 2분 감시·지정가 미체결·PC 꺼짐의
손절 한계는 그대로이며 거래소 측 독립 보호가 인증된 실행기로 설명하지 않는다.

## 세이브티커 활용 검토

사용자 추가 요청으로 [뉴스](https://www.saveticker.com/news)와
[캘린더](https://www.saveticker.com/calendar)의 비로그인 공개 화면을 확인했다.
뉴스에는 출처·시각·관련 티커, 속보·SAVE PICK·SAVE 리포트·로이터 등의 구분이 있고,
PPI에서 PCE에 들어가는 항목 해설, CPI 기관별 예상치, 기업 실적 요약 제목이 보인다.
캘린더에는 물가·고용·경기·연준 발언·국채 입찰이 있으며 시간 기준은 사용자 현지 시간이라고 표시한다.
확인한 상세 해설과 캘린더 상세는 로그인을 요구했으며 회원가입·인증·유료 결제는 하지 않았다.

활용 우선순위는 공식 일정의 누락·변경 대조, 발표 전 예상치 출처 후보, 발표 후 맥락 해설,
보유 종목 관련 뉴스 링크다. 헤드라인을 인과 확정이나 수익 신호로 바꾸지 않고, 기업 보도자료·
독립 보도·소문·AI 요약을 구분한다. 같은 원문을 재전송한 속보는 독립 근거 여러 개로 세지 않는다.
공식 실제 발표값과 세이브티커의 보조 해설을 분리하고 서로 충돌하면 판단을 보류한다.

공개 API·RSS·자동 수집 및 재사용 허가는 미확인이다. 확인한 일부 기사에는 AI 번역·요약의 한계와
무단 전재·재배포 금지 안내가 있다([예시 기사](https://www.saveticker.com/news/158744)).
이번에는 크롤러·계정 연동·기사 본문 저장·텔레그램 재배포를 구현하지 않았다.
현재 승인된 결정론적 매수 차단에 뉴스·AI 점수를 넣지 않으며 기존 Shadow 경계를 유지한다.
