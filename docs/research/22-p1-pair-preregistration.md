## 1. 가설

ETH/BTC 상대 가격에도 수 주~수 개월 추세가 있다. 비율의 20·60·120일 추세 방향으로 ETH 롱/BTC 숏(또는 반대)을
같은 명목으로 들면 시장 방향과 거의 무관한(BTC와 상관 0.04, 21 §1) 순수익이 난다. 선물 숏 다리가 구조적으로 필요하다.
[R1](../archive/research/26-r1-preregistration.md)(다종목 횡단면 상대 추세 21일 롱3·숏3, 기각)과 달리 **한 쌍의 비율 절대 추세**다.

## 2. 규칙 (고정, `backtest/pair_trend.py` 기본값)

| 항목 | 값 |
|---|---|
| 비율 | R = ETHUSDT 일봉 종가 / BTCUSDT 일봉 종가 (Binance 현물을 가격 대리로 사용 — 2019 이전 선물 없음) |
| 방향 | `(sign(R/R₋₂₀−1) + sign(R/R₋₆₀−1) + sign(R/R₋₁₂₀−1)) / 3` |
| 크기 | ETH 다리 비중 = 방향 × min(**15%** / R의 60일 연변동성, **0.5**). BTC 다리 = 같은 명목의 반대 방향 |
| 체결 | 종가 d 목표 → 종가 d+1 두 다리 체결(1일 지연). ETH 다리 |목표 − 현재| < **5%p** 이고 방향 같으면 거래 안 함, 체결 시 두 다리 같은 명목으로 재설정 |
| 비용 | 다리별 편도 **0.095%** (선물 taker 0.045% + 슬리피지 0.05%) |
| funding | 보유 중 정산마다 롱 지급·숏 수취(실측: BTC 2020-01~, ETH 2020-03~). 그 이전은 0 |
| 청산 | 교차 증거금, 두 다리가 동시에 최악 가격(롱 저가·숏 고가)이면 자본 ≤ 명목 × 1% → 전부 청산 |
| 현금 | 이자 0 |

## 4. 노출

- ETH/BTC 비율의 큰 흐름(2017 급등, 2018 급락, 2021 강세, 2022 이후 약세)은 공지의 사실이다 — 규칙은 T 표준형 그대로.
- BTC·ETH 가격은 T/v1·T/v2에서 추세 규칙으로 이미 봤다. 비율 추세의 수익은 계산하지 않았다.
