## 1. 가설

> **BTC 변동성이 수축한 뒤에는 확장이 따르고, 확장의 방향은 상위 시간대 추세를 따른다.
> 이때의 총우위는 왕복 비용을 넘는다.**

경제적 수익원은 **변동성 클러스터링**이다. 방향을 예측해서 버는 것이 아니라,
**큰 움직임이 시작되는 시점**에 들어가 고정비용(19.05bps)을 회수한다.
저변동 구간에는 호가가 얇게 쌓이고, 확장이 시작되면 그 얇은 구간을 가격이 빠르게
통과한다 — 그 통과를 먼저 타는 대가다.

방향 자체는 **예측하지 않는다.** 상위 시간대 추세에 위임한다.

## 2. H1 과 무엇이 다른가 (필수 논증)

[01 §2](01-candidate-comparison.md) 에서 A 의 최대 위험을 **H1 과의 중복**으로 기록했다.
둘 다 BTC 가격 파생, 다중 시간대, 상위 추세 필터를 쓴다. 차이를 논증하지 못하면
A1 은 H1 의 재시도이고 사전등록할 자격이 없다.

| | H1 (기각) | **A1** |
|---|---|---|
| 진입 조건의 종류 | **시퀀스** — 되돌림 후 모멘텀 재개 | **상태** — 변동성이 수축 분위에 있음 |
| 예측 대상 | 가격의 **방향** | 움직임의 **크기와 시점** |
| 방향 결정 | 점수 합산 (70점 이상) | 상위 추세에 위임, 점수 없음 |
| 실패한 지점 | 신호 6,650개가 **전부 비용 게이트에서 차단** — 기대 edge 가 비용 미만 | 필요 edge 40.9bps 를 **사전에 고정**하고 TRAIN 에서 직접 측정 |

H1 의 사인은 "짧은 horizon 점수의 정보력 부족" 이었다. A1 은 그 점수 체계를
쓰지 않는다. 진입 여부는 **변동성 분위 + 레인지 돌파**라는 두 개의 이진 조건으로
결정되고, 연속 점수도 임계값 70 도 없다.

**그래도 논증만으로는 부족하다.** §4 의 대조군이 이것을 실증으로 판정한다.

## 3. 규칙 (전부 수치 고정)

### 3.1 진입

모든 판정은 **마감된 5분봉**으로 한다. 판단 시각은 `snapshot.as_of_ms`.

| 조건 | 정의 |
|---|---|
| 1. 변동성 수축 | 직전 24시간 실현변동성(5분 수익률 SD)이 **직전 30일 분포의 하위 30%** |
| 2. 상위 추세 | **돌파 직전 봉** 종가가 200시간 전 종가보다 높으면 LONG, 낮으면 SHORT |
| 3. 구조 돌파 | 현재 종가가 **직전 6시간** 고가(LONG) / 저가(SHORT)를 넘음 |
| 4. 중복 차단 | 트리거 후 6시간 동안 새 트리거를 만들지 않음 |

조건 2가 **돌파 봉 자신을 제외**하는 이유: 돌파 봉을 넣으면 역방향 급변이 추세
판정까지 뒤집어 "추세 방향 돌파" 가 아니라 "아무 급변" 을 잡는다
(2026-09-23 테스트로 발견·수정).

### 3.2 청산·손절

| 항목 | 값 |
|---|---|
| 보유 | **2시간** 고정 (24봉). `min_hold_minutes=120` 과 일치 |
| 목표가 | **없음.** 손절 또는 2시간 경과로만 청산 |
| 손절 거리 | `max(2.0 × σ5m × √24, min_stop_distance)` |
| 봉 내 선후 | 알 수 없으므로 **손절 우선** |

손절 배수 2.0 의 근거: 하한이 지배하는 2h 구간에서 배수는 SD 를 거의 바꾸지 않는다
(0.5σ 69.9 vs 2.0σ 72.5). 통계적으로 미세하게 유리한 쪽 대신 **고변동 국면에서
봉 잡음에 기계적으로 걸리지 않는** 쪽을 택했다.

### 3.3 자유도 — 8개, 전부 여기서 고정

| # | 파라미터 | 값 |
|---|---|---|
| 1 | 변동성 창 | 24시간 |
| 2 | 분위 창 | 30일 |
| 3 | 수축 분위 | 0.30 |
| 4 | 추세 창 | 200시간 |
| 5 | 레인지 창 | 6시간 |
| 6 | 보유 horizon | 2시간 |
| 7 | 손절 배수 | 2.0σ |
| 8 | 중복 차단 | 6시간 |

**탐색하지 않는다.** 결과를 본 뒤 이 값들을 움직이면 A1 은 기각이고 A2 도 만들지 않는다.

## 4. 대조군 — 수축 조건이 제 값을 하는지 실증한다 (필수)

같은 규칙에서 **조건 1(변동성 수축)만 제거**한 판본을 같은 실행에서 함께 측정한다.

| | 주 arm | 대조군 |
|---|---:|---:|
| 원 트리거 | 1,874 | 5,061 |
| 거래 가능 (한도 적용 후) | **615** | **1,111** |
| 거래당 손익 SD | 76.9bps | 100.5bps |
| TRAIN (2020~2022) 표본 | 278 | 513 |

**판정**: TRAIN 에서 `주 arm 순기댓값 − 대조군 순기댓값` 의 2SE 하한 > 0.
TRAIN 표본(278 / 513) 기준 차이의 2SE 는 **12.8bps** 이므로, 주 arm 이 대조군을
**12.8bps 이상 앞서야** 한다.

> **대조군을 유의하게 앞서지 못하면 A1 을 기각한다.** 수축 조건이 기여하지 않는다는
> 뜻이고, 그러면 남는 것은 "상위 추세 방향 레인지 돌파" 이며 이는 H1 의 변형이다.
> 주 arm 이 단독으로 기준을 넘더라도 이 검사를 통과하지 못하면 진행하지 않는다.

## 5. 검정력 — OOS 가 구속조건이다

| 입력 | 값 | 출처 |
|---|---|---|
| 거래당 손익 SD | **76.9bps** | 트리거 시점 실측, 손절·한도 적용 |
| 왕복 비용 | **19.05bps** | 수수료 13 + 슬리피지 5 × 1.21 (트리거 시점 실측 배율) |
| 검정력 | 80% | 게이트 기본값 |
| OOS 최소 거래 | 100 | Phase 4 |

**필요 효과 = 40.9bps** — OOS 100거래로 확인 가능한 최소 총우위.

C8 선택지 1 에 따라 이 값을 사전등록 기준으로 쓴다. TRAIN 은 101표본이면 충분하고
278개가 있으므로 여유가 있다. **구속하는 것은 OOS 다.**

40.9bps 는 왕복 비용의 **2.14배**다. 2시간 보유로 이만큼 벌어야 한다.
이것이 이 전략에 요구되는 실제 문턱이며, 낮추지 않는다.

## 7. 통과 기준 (미리 고정 — 낮추지 않는다)

순기댓값은 `가격손익 − 19.05bps − 보유 중 funding` 이다.

### TRAIN

| # | 기준 |
|---|---|
| T1 | 순기댓값의 **평균 − 2SE > 0** |
| T2 | 순기댓값 **평균 ≥ 40.9bps** — 이보다 작으면 OOS 에서 확인할 수 없으므로 통과시키지 않는다 |
| T3 | **대조군 대비 우위의 2SE 하한 > 0** (§4) |
| T4 | 2020·2021·2022 **각 연도 부호 동일** |
| T5 | LONG·SHORT **각각 부호 동일** — 한쪽 방향에만 있으면 시장 국면 효과다 |

T2 는 점검이지 가설검정이 아니다. TRAIN 표본 278개에서 SE 는 약 4.6bps 이므로
참효과가 정확히 40.9 일 때 통과 확률은 약 절반이다. **그 보수성을 의도한다** —
경계선 효과는 OOS 에서 확인되지 않기 때문이다.

### VALIDATION (TRAIN 통과 시 1회)

정의를 **한 글자도 바꾸지 않고** 재현한다. 기준은 T1 · T2 · T4(2023·2024) · T5.

### TEST (VALIDATION 통과 시 1회)

기준은 T1 · T2. 노출 이력 때문에 최종 승인 근거로 쓰지 않는다.

### 강건성 (C2 해소 — 아래 §8)

| # | 기준 |
|---|---|
| R1 | **지연 강건성**: 진입을 1봉(5분) 늦춰도 순기댓값 부호 유지 + 하락폭 50% 이내 |
| R2 | **셔플 null**: 진입 방향을 무작위로 섞으면 순기댓값의 2SE 하한 ≤ 0 |
| R3 | **비용 2배**: 비용 38.1bps 에서도 순기댓값 > 0 |
| R4 | **파라미터 ±20%**: §3.3 의 1~5, 8 을 각각 ±20% 흔들어 부호 유지 |
| R5 | **시작일 ±30일**: 결론 동일 |

R4 는 **민감도 확인이지 탐색이 아니다.** 가장 좋은 값을 고르지 않는다.

## 8. 미해결 항목 처리

### C2 — 지연 검사 정의 확정

기존 문서의 "1일/1봉" 과 "부호 유지/성과 소멸" 충돌을 **두 개의 다른 검사**로 분리한다.

- **지연 강건성(R1)** 은 **1봉(5분)** 이다. 보유가 2시간인 전략에 1일 지연은 의미가 없다.
  기대 결과는 **부호 유지**다 — 진짜 우위라면 5분 늦어도 남아야 한다.
- **셔플 null(R2)** 은 **성과 소멸**이 기대 결과다. 방향을 섞었는데도 우위가 남으면
  그것은 신호가 아니라 구간 편향이다.

### C4 — purge / embargo

A1 은 보유가 **2시간 고정**이므로 D12 의 무제한 보유가 적용되지 않는다.
따라서 이 전략에 한해 C4 는 다음으로 확정된다.

- embargo = **2시간** (보유 horizon과 동일)
- 한 거래가 점유하는 구간은 보유 2시간 + 재진입 대기 60분 = **3시간**
- 분할 경계를 걸치는 포지션은 **양쪽 구간 모두에서 제외**한다

### C1 — 손절 하한이 100% 발동한다 (기록, 변경 없음)

2h 손절의 중앙값은 23.8bps(0.5σ)~95.4bps(2.0σ) 인데 `min_stop_distance = 1%` 이므로
**2h 0.5σ 기준 100%, 2.0σ 기준 53%** 가 WIDEN 된다.

A1 은 **현재 설정 그대로** 사전등록한다. 위 SD 76.9bps 와 필요 효과 40.9bps 는
하한이 적용된 값이다. 하한을 낮추면 SD 가 줄어 문턱도 낮아지지만
(하한 없는 0.5σ 기준 35.1bps), 그것은 C1 의 별도 승인·코드 변경·경계 테스트가
필요한 사안이므로 여기서 건드리지 않는다.

### C8 — OOS 기준 상향 (사용자 결정: 선택지 1)

`n ≥ 100` 게이트는 그대로 두고 필요 효과를 **40.9bps** 로 올렸다. §5 참조.

### 빈도 한도 — H1 을 막았던 것과 같은 한도

`same_direction_limit = 2` 가 원 트리거의 **65%** 를 막는다 (방향 런 최장 50회).
연 279회가 연 92회로 준다. **한도를 완화하지 않는다** — 위 표본·검정력은 전부
한도 적용 후의 값이다.

## 9. 중단 기준

- **TRAIN 에서 T1~T5 중 하나라도 실패** → A1 기각. 파라미터를 바꾸지 않는다.
- **특히 T3(대조군) 실패** → 수축 조건이 무의미하다는 뜻이므로 A1 기각.
  "조건을 빼고 다시" 로 넘어가지 않는다. 그건 H1 이다.
- **VALIDATION 실패** → A1 기각. 재현은 1회뿐이다.
- **A1 이 기각되면 A2 를 만들지 않는다.** 후보 B 로 가려면 [01 §7](01-candidate-comparison.md) 의
  비용 문제(3.06배)를 먼저 해결하는 별도 설계가 있어야 한다.
