## 1. 무엇이 달라졌나

이전 Yahoo/Stooq/KIS 요청에서 TWTR 가격을 얻지 못했다는 사실은 그대로다.
이번에는 공개 화면의 종료 가격과 공급자 종목 메타데이터를 찾았고,
무료 구성 변경 CSV의 실제 범위와 공식 공고 일치 여부를 확인했다.
**가격의 존재는 확인했지만, 사용 허용된 전체 일별 가격 파일은 아직 확보하지 못했다.**
새로운 수익 모델·성과 판정이 아니라 자료 경로의 타당성 조사다. 접근 실패와 전략 기각은 다르다.

## 2. 종료 가격: 표에 행이 있어도 그날 거래했다는 뜻은 아니다

[Stock Analysis TWTR 공개 이력](https://stockanalysis.com/stocks/twtr/history/)은
Tiingo를 원천으로 표시하며, 첫 화면에 50행과 1/3 페이지·6M 선택을 표시했다.
전체 2013~2022 일별 자료나 모든 종료 종목 coverage로 해석하지 않는다.

| 공개 화면에서 확인한 항목 | 관측 | 연구에서의 사용 경계 |
|---|---|---|
| 마지막 거래 표시 | 2022-10-27 | 공급자 표시이며 실제 실행/체결 원장 인증 아님 |
| 10/27 행 | O/H/L/C 53.91/54.00/53.70/53.70, 거래량 140,831,508 | 제한 참고 사례. raw/수정 방식·전체 기간·호가/일중 지정가 체결은 미검증 |
| 10/28 행 | O/H/L/C 모두 53.70, 거래량 `-` | 정상 거래 봉으로 채택 금지. 0 거래량으로도 임의 변환하지 않음 |

[SEC 실제 합병 8-K](https://www.sec.gov/Archives/edgar/data/1418091/000119312522272772/d411753d8k.htm) Item 3.01은
10/28 장 시작 전 NYSE 거래 정지를 설명한다. 따라서 표의 10/28 행은 이날 매매 가능성 증거가 아니다.
마지막 종가 53.70과 일반 적격 주식의 합병 현금 권리 54.20은 서로 다른 입력이다.
권리를 마지막 종가로 바꾸거나 즉시 현금 재투자를 가정하지 않는다.

[이용 조건](https://stockanalysis.com/terms-of-use/)은 일반 자동/프로그램 수집을 제한하며,
robots.txt를 준수하는 검색 엔진·AI 에이전트 등의 예외도 별도로 둔다.
[robots.txt](https://stockanalysis.com/robots.txt)를 확인하고 공개 페이지의 제한 조사만 했다.
AI 열람 예외를 전체 가격 ETL·계정/유료 제한 우회·DB 구축/학습 허가로 확대하지 않았다.
로그인·사이트 내부 API 탐색·일별 자료 스크래퍼·대량 수집·전체 표 복제는 하지 않았다.
페이지/약관 관측은 manifest의 요약 기록이며 응답 전문/가격 원본 파일이 아니다.

## 3. Tiingo: 공개 메타데이터가 있고, 가격 API는 별도 인증이 필요하다

[공식 EOD 문서](https://www.tiingo.com/documentation/end-of-day)가 연결하는
공개 `supported_tickers.zip`을 인증 없이 한 번 내려받아 보존했다(797,329 bytes).
압축 크기 3MiB·CSV 비압축 크기 40MiB 이내 조건을 확인하고 메모리에서 읽었다.
**108,936행은 종목 메타데이터이지 가격 봉·독립 표본·당시 유니버스가 아니다.**

| 조사 대상 | 공개 목록의 startDate / endDate | 해석 |
|---|---|---|
| TWTR | 2013-11-07 / 2022-10-28 | 마지막 거래 표시 10/27보다 늦음. endDate를 매매 가능일로 쓰지 않음 |
| CTXS | 1995-12-08 / 2022-11-02 | 기존 Nasdaq 근거의 마지막 거래 9/29보다 늦음. 공급자 종료일≠거래 종료일 |
| NLSN | 2011-01-27 / 2022-10-11 | 가격/실제 거래/정산 원문 대조는 아직 안 함 |

문서는 목록에 현재 지원 대상 외 예약 심볼도 포함될 수 있으며,
실제 API 제공 여부는 인증된 metadata endpoint로 확인하라고 명시한다.
따라서 이 세 행만으로 현재 계정에서 가격을 받을 수 있다고 보장하지 않는다.
CIK·영구 증권 ID·재사용 티커·주식 종류를 인증한 목록도 아니다.

[일반 문서](https://www.tiingo.com/documentation/general)는 계정·토큰이 필요하다고 설명한다.
[가격/한도 페이지](https://www.tiingo.com/pricing)의 개인 Starter는 $0/month,
월 고유 심볼 500·시간당 요청 50·하루 1,000·월 1GB를 표시했다(10/05 확인, 변경 가능).
**무료 계정도 가격 확보를 보장하지 않으며 유료 업그레이드 승인이 아니다.**
사용자는 유료 데이터 구매를 금지했다. 가입·로그인·키 확인·인증 가격 API 호출·유료 결제는 하지 않았다.
다음 실제 API 소표본 확인에는 사용자 제공 무료 계정/토큰과 사용 범위 확인이 필요하다.
키를 채팅/보고서/Git에 넣지 않는다. 제한된 개인 내부 사용이며 원본 재배포는 허용된 것으로 가정하지 않는다.
가격은 raw/조정 OHLCV·배당/분할 필드가 별도여서 현재 KIS 수정주가와 자동 혼합하지 않는다.
Tiingo 유료 재무 add-on은 사용하지 않고 기존 무료 SEC 공시 연구 경계를 유지한다.

## 4. 과거 구성 후보: 무료 변경 목록은 확보, 전체 공식 명부는 미확보

[fja05680/sp500](https://github.com/fja05680/sp500)의 제작자 README·MIT 라이선스·변경 CSV를
`a2430f2af0c79ddf0748e91de11bdeb1616ab5a7`에 고정해 보존했다.
저장소 커밋 일시는 2026-09-07 14:56:49 UTC이나 개별 사건의 최초 공고 시각이 아니다.
CSV 125행·2019-01-18~2026-08-18·빈 추가/삭제 동시 행 0·중복 날짜 0을 확인했다.
행수는 독립 변경 사건/매매 표본 수가 아니다. 하나의 행에 여러 종목 변경이 있다.

제작자는 1996~2019 원본을 책의 부속 자료에서 얻고 이후 Wikipedia와 수동 검색으로 갱신했다고 설명한다.
초기 약 5년의 누락 가능성도 밝힌다. 이 설명/라이선스는 거래소나 S&P의 완전성 인증이 아니며,
기반 자료의 권리와 날짜 정의까지 일괄 보증하지 않는다. 출처/라이선스를 보존하고 원본을 Git에 재배포하지 않는다.
외부 notebook을 실행하지 않았다. ticker 변경을 매도/신규 매수로 처리하라는 제작자의 운영 가정도 채택하지 않는다.

## 5. 실질적 결론과 유한한 다음 단계

이번 경로의 상태는 **PUBLIC_PRICE_TABLE_OBSERVED / METADATA_ONLY_ACQUIRED / MEMBERSHIP_CANDIDATE_PARTIALLY_CROSSCHECKED**다.
전체 가격 원본·공식 구성 체인·현금 정산은 여전히 미확보다. 무료 복원이 불가능하다는 결론도 아니다.

다음은 검사 도구를 더 늘리는 대신 다음 확보 게이트를 확인한다.

1. 사용자 제공 무료 Tiingo 계정 사용이 가능할 때만 **TWTR·CTXS·NLSN 최대 3종목**의 metadata/종료 부근 가격 요청부터 검토한다. 미제공 상태에서는 인증 호출을 하지 않는다. 가격 제공 여부·권리·raw/수정·정지 이후 행을 확인하고 실패하면 기록 후 중단한다.
2. 구성 CSV는 공식 자료 검색의 후보 목록으로만 쓴다. **2022-09-30~11-01 제한 구간**의 공식 시작/끝 명부와 중간 사건 누락을 검증할 수 있는지 먼저 판단한다. 기간은 자료 감사 범위이지 성과 시험 분할/새 전략 기간이 아니다.
3. 가격과 명부가 모두 확보될 때만 분기 공시/증권 ID/달력/정산과 연결한다. 현재 500+400 전체 기업 대량 수집·무료 한도 회피·생존 종목 대체는 하지 않는다.
4. 이후 가용 기간·기업/시장 군집·실제 독립 관측으로 80% 검정력을 설계한다. 50 가격 행·125 변경 행·108,936 metadata 행을 n으로 넣지 않는다. 현재 SD/효과/필요 n은 미측정이다.

실제 지급 시각 없이 재투자 현금 흐름을 만들지 않으며, 미확인 상태를 0으로 대체하지 않는다.
미해결 조건이 남으면 DATA_NOT_READY를 유지한다. 전향 관찰로의 변경·사전등록·랭킹·수익 계산·실거래는 별도 단계다.

## 6. 보존·검증

새 원자료 **5개, 861,766 bytes(약 0.82MiB)**, 누적 **34개**를 Git 제외 보관했다.
기존 29개 SHA256/bytes 불변, 새 파일 덮어쓰기/삭제 없음. zip을 디스크에 풀지 않았으며 외부 코드를 실행하지 않았다.
공개 페이지 관측은 응답 전문이 아니고 원본 파일 수량에 포함하지 않는다.
코드/config/운영 DB/예약/골든/계좌/API 키는 이번에 변경하거나 조회하지 않았다.

문서 전용 변경이나 커밋 규약에 따라 로컬 검사도 실행했다:
전체 pytest **2,668건**(180.65초), leakage **90건**(18.80초), strict mypy **421파일**,
ruff check/format **586파일**, import 계약 **5/5** 통과.
최초 import 검사 호출의 모듈 진입 오류는 기존 `lint-imports.exe`로 재호출해 확인했다. 코드 오류가 아니며 코드 수정 없음.
원본 해시·CSV 구조/세 사건·JSON·문서 링크 209개·연락처/비밀값 비보관·변경 범위 검사를 별도로 수행했다. 수익성 검증/골든 변경은 없다.
