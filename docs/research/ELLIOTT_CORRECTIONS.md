## 0. 핵심: 같은 이름도 출처마다 정의가 다르다

| 항목 | EWI (Frost·Prechter) | NEoWave (Neely) | "11 가지 패턴" 규칙집 (Scott Levin, 소프트웨어식) | 이 프로젝트 판독기 |
|---|---|---|---|---|
| 플랫 B ÷ A | **90% 이상** 되돌림 | 61.8% 이상(약함 61.8~80, 보통 80~100, 강함 100~123.6+) | **50% 이상 · 200% 미만** | 0.618 ~ 1.618 |
| 지그재그 B | A 시작을 넘지 않음 | B ≤ 61.8% of A (보통 지그재그) | — | B 는 A 시작을 넘지 않음 |
| 2 파 자리 삼각형 | 없음 | 일부 해설: 제한 삼각형 가능 | **2 파는 삼각형 불가** | 없음 |
| 5 파 최소 길이 | — | — | **5 파 ≥ 4 파의 70%** | 없음 |

→ "엘리엇 파동이 맞다/틀리다"를 말하려면 **어느 규칙집인지**부터 정해야 한다. 학계 비판(규칙이 느슨해 어떤 과거도 맞춘다, Aronson)이 나오는 이유다. 이 프로젝트가 판독기를 고정하고 사전 등록하는 이유이기도 하다.

## 1. "불규칙(irregular)" — 용어의 역사

- **Elliott(1938·1946)** 은 조정을 지그재그·플랫·**불규칙(irregular)**·삼각형으로 나눴다. 불규칙 조정 = **B 파가 앞 추세의 고점을 넘어 새 고점**을 만들고, C 파가 A 시작 근처나 그 아래까지 내려가는 모양. 🟢 (Wikipedia·여러 해설)
- **Frost·Prechter** 는 이것을 **확장 플랫(expanded flat)** 으로 불렀다 — "불규칙이라는 말은 맞지 않다, 오히려 정규 플랫보다 **훨씬 흔하다**". 🟢 EWI
- 그래서 **불규칙 파동 = 확장 플랫**(현대 용어). NEoWave 는 "불규칙 플랫(irregular flat)"·"불규칙 실패(irregular failure)"라는 세부 이름을 따로 쓴다(§2).

## 2. 플랫 (3-3-5)

**정통 3 가지 (EWI 🟢):**

| | B | C | 특징 |
|---|---|---|---|
| 정규 | A 시작 근처 | A 끝을 약간 넘음 | |
| **확장(=불규칙)** | **A 시작을 넘음** | **A 끝을 한참 넘음** | **가장 흔함**, 앞 충격파를 넘는 극값. B ≈ A 의 123.6~138.2% 라는 해설 🟡 |
| 러닝 | A 시작을 한참 넘음 | A 끝에 못 미침 | **강하고 빠른 시장에서만**, "거의 예가 없다", 성급히 붙이지 말 것 |

- 플랫은 큰 추세가 강할 때 나오고, 지그재그보다 덜 되돌린다. **4 파에 흔하고 2 파에는 드물다.** 연장 바로 앞이나 뒤에 거의 늘 나온다. 🟢 EWI

**NEoWave 세분류 (B 파 세기 × C 파 길이) 🟡 (TradingPedia 해설):**

| B 세기 (B ÷ A) | C 길이 | 이름 |
|---|---|---|
| **약함** 61.8~80% | C < 100% of B | 이중 실패(double failure) |
| | C 100~138.2% of B | B 실패(B-failure) |
| | C > 138.2% of B | 늘어난 플랫(elongated) |
| **보통** 80~100% | C ≈ 100~123.6% of B | **보통 플랫(common, 가장 흔함)** |
| | C 짧음 | C 실패(C-failure) |
| | C 김 | 늘어난 플랫 |
| **강함** 100~123.6%+ | C 가 A 끝에 못 미침 | 불규칙 실패(irregular failure) |
| | C 가 A 끝을 넘음 | 불규칙 플랫(irregular) |
| | C 매우 김 | 늘어난 플랫 |

## 3. 지그재그 (5-3-5)

| 종류 | C ÷ A | 뒤에 일어나는 일 | 신뢰 |
|---|---|---|---|
| **보통** | 61.8~161.8% (B ≤ 61.8% of A) | | 🟡 |
| **잘린(truncated)** | 38.2~61.8% | 뒤따르는 움직임이 **지그재그 전체를 최소 80%, 흔히 100% 되돌림** | 🟡 NEoWave 해설 |
| **늘어난(elongated)** | > 161.8% | **충격파를 가장 잘 흉내 낸다** — 오판 위험 | 🟡 |

- 규칙: A 는 충격파·선행 대각선, B 는 조정, C 는 충격파·종결 대각선. 🟢 EWI
- **이중·삼중 지그재그(W-X-Y, W-X-Y-X-Z)**: 첫 지그재그가 정상 목표에 못 미칠 때 이어 붙는다. 각 W·Y·Z 는 지그재그, X 는 조정(규칙집: X 는 W 보다 짧고, Y 는 X 이상). 날카롭게 **가격을 더 늘린다**. 🟢 EWI · 🟢 규칙집

## 4. 복합 조정 (combination, "옆걸음")

- **이중 3(W-X-Y)·삼중 3(W-X-Y-X-Z)**: 지그재그·플랫·삼각형을 X 로 이어 붙여 **옆으로 시간을 끈다**(이중·삼중 지그재그는 가격을, 복합 조정은 시간을 늘림). 4 파·B 파에 흔하다. 🟢 EWI
- 흔한 조합: **플랫 + 삼각형**(가장 전형), 플랫 + 지그재그, 지그재그 + 삼각형. 삼각형은 **마지막 조각으로만**. 확장 삼각형은 복합 조정 조각으로 관찰된 적 없음. **삼중 3 은 "이론상에만 있을 수도"**. 🟢 EWI
- 비율(해설): X 는 W 의 50·61.8·76.4·85.4% 되돌림, Y 는 W 의 161.8% 를 넘지 않음(넘으면 충격파 3 파일 수 있음), Z 목표 W 의 61.8·100·123.6%. 🟡
- 규칙집: W·X 는 삼각형·복합 불가, X 는 W 를 50% 이상 되돌림, W 가 지그재그면 Y 는 지그재그 불가, Y < W 의 200%. 🟢 규칙집
- 파동 수: 추진은 5·9·13, 조정은 3·7·11. 🟢 EWI

## 5. NEoWave 의 큰 조정

- **다이아메트릭(diametric, 7 다리 a~g)**: X 없이 이어지는 7 다리, **각 다리의 시간이 비슷**. 커졌다 작아지면 다이아몬드, 작아졌다 커지면 나비넥타이 모양. 🟡
- **대칭(symmetrical, 9 다리)**: 거의 모든 다리의 시간이 비슷. 🟡
- 정통 엘리엇에는 없다 — Neely 가 "정통 패턴으로 정직하게 설명할 수 없는 움직임"을 위해 추가.

## 6. 강세장(강한 추세)에서 나오는 패턴 — "강세 패턴"

강한 추세에서는 조정이 **얕고 짧고 추세 쪽으로 기운다**:

| 패턴 | 모양 | 뜻 |
|---|---|---|
| **러닝 플랫** | B 가 A 시작을 넘고 C 가 A 끝에 못 미침 | 추세 쪽 힘이 커서 조정이 기울어짐 — 드묾 |
| **러닝 삼각형** | B 가 A 시작을 넘음 | 큰 추세 쪽으로 기운 삼각형 |
| **확장 플랫** | B·C 모두 넘음 | 연장 앞뒤에 흔함 |
| **1-2-1-2 겹침** | 여러 단계 1·2 파가 겹침 | 곧 **3 파의 3 파 가속** |
| **돌파 없는 4 파 삼각형** | 강한 시장에서는 짧은 돌파 대신 **길게 늘어난 5 파** | EWI |
| **연장된 3 파 / (코인·원자재) 연장된 5 파** | 한 추진파가 길게 펼쳐짐 | 코인은 5 파 연장이 흔하다는 관찰 🟡 |

## 7. "11 가지 패턴" 규칙집 (Scott Levin, 소프트웨어식) 🟢

충격파(IM) · 선행 대각선(LD) · 종결 대각선(ED) · 지그재그(ZZ) · 이중 지그재그(DZ) · 삼중 지그재그(TZ) · 플랫(FL) · 이중 3 · 삼중 3 · 수렴 삼각형(CT) · 확장 삼각형(ET).
각 패턴에 "하위 파동은 어떤 패턴이어야 하나 + 길이 조건"이 번호로 붙어 있다(예: 충격파 2 파는 삼각형 불가, 5 파 ≥ 4 파의 70%; 대각선 2·4 파 겹침 필수, 5 파 ≥ 4 파의 50%; 수렴 삼각형 E 는 A 영역 안에서 끝남, 한쪽 선만 수평 가능).
"종결 대각선이 선행 대각선보다 훨씬 흔하다", "확장 삼각형은 드물다", "삼중 지그재그는 드물다".
**판독기에 옮기기 좋은 형식** — 판독기 확장(대각선·복합 조정) 때 기준 후보.

## 8. 판독기와의 대조

| 패턴 | 판독기 | 비고 |
|---|---|---|
| 확장(불규칙)·정규 플랫 | ✅ (B/A 0.618~1.618) | 세부 이름은 보고용 |
| 러닝 플랫 | △ (B/A 범위 안이면 플랫으로) | 따로 구분 안 함 |
| 보통 지그재그 | ✅ | 잘린·늘어난 지그재그 구분 없음 |
| 이중·삼중 지그재그 · 이중·삼중 3 | ❌ | 다른 모양으로 오판 가능 |
| 수렴 삼각형 | ✅ | 확장·러닝 삼각형 미지원 |
| 다이아메트릭·대칭 | ❌ | 정통 밖 |

**시험 후보로 이어질 것(사전 등록 전):** ① 잘린 지그재그 뒤 "최소 80% 되돌림" (NEoWave 패턴 뒤 논리 — 기계적으로 잴 수 있음) ② 판독기에 이중 지그재그·복합 조정 추가 뒤 97 의 "충격파 끝을 조정으로 오판" 이 줄어드는지.
