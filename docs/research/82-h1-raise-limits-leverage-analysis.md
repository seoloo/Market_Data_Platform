## 1. 최악의 경우 먼저 — 하루 급락 스트레스 (산술)

과거 **가장 많이 들었던 날**의 구성(T/v2 합계 비중 0.86)에서 하루에 가격이 크게 빠지면 계좌가 잃는 비율이다.
O 구성 식(현물 k·w, 선물 (배수 − k)·w, 선물 레버리지 ≤ 3 × 선물 지갑)으로 계산했다.

| 배율 | 하루 −20% | −30% (스톱 작동 / 실패) | −40% (스톱 작동 / 실패) | −50% (스톱 작동 / 실패) |
|---|---:|---:|---:|---:|
| 1.5배 (O/v2) | −26% | −35% / −39% | −43% / **−49% 청산** | −52% / −57% 청산 |
| **2.0배** | **−34%** | **−42% / −52%** | −48% / **−62% 청산** | −55% / −68% 청산 |
| 2.5배 | −43% | −49% / −65% | −53% / **−75% 청산** | −58% / −79% 청산 |
| 3.0배 | −52% | −56% / −77% | −58% / **−87% 청산** | −60% / −90% 청산 |

- "스톱 작동"은 선물 추가분의 비상 스톱이 −20% 에서 1% 불리하게 체결된 경우다. "실패"는 거래소 장애·갭으로 저가까지 빠진 경우다.
- 선물 레버리지가 3배 상한에 걸리는 날은 청산 거리가 약 **−33%** 다. 스톱이 실패하면 −40% 부터 선물 지갑이 청산된다.
- **보유 비중이 보통인 날**(중앙값 0.29)은 훨씬 작다. 2배 기준으로 −30% 에 −15%/−17%, −50% 에 −21%/−29% 다.
- **과거에는 이런 날이 없었다.** 2020-03-12(BTC 장중 약 −39%) 때 T/v2 는 추세가 꺾여 현금이었다. 과거 최악의 하루는 1.5배 −10.3%, 2배 −13.9% 다.
  **추세 필터가 그때 우리를 밖에 두었던 것은 운의 몫도 있다.** 추세가 살아 있을 때 폭락이 오면 위 표가 된다.

## 2. 과거 경로 — 계좌 정지를 끄고 (2020-03 ~ 2026-08, 판정 아님)

O/v2 규칙(비상 스톱 −20% · 선물 레버리지 ≤ 3 × 선물 지갑 · 일 손실 2%)은 그대로 두고 배수만 바꿨다.

**읽는 법:**
1. **배율 0.5배당 필요한 정지선이 약 7~8%p 씩 는다.** 30 의 산술 추정(2배 29~32%, 2.5배 35~40%, 3배 40~48%)과 맞다.
2. **청산은 한 번도 없었다.** 비상 스톱과 선물 레버리지 상한(3배)이 막았다. 대신 배율이 높을수록 상한에 걸려 선물을 줄인 날이 는다(1 → 11 → 28 → 51일).
3. **샤프는 배율을 올릴수록 떨어진다(1.17 → 0.99).** funding 이 배율보다 빠르게 는다(1.5배 −4,169 → 3배 −32,172). 강세장일수록 funding 이 비싸서 가장 벌어야 할 때 비용이 가장 크다. **더 버는 만큼 위험은 더 빨리 는다.**
4. **약한 해는 배율로 좋아지지 않는다.** 2025년은 1.5배 2.3% · 3배 −1.2%. 수익은 강세장(2020·2023·2024)에서 나온다.
5. **물속 기간은 배율과 거의 무관하게 약 2년이다**(2021-11-08 → 2023-12). 배율이 높으면 같은 2년을 더 깊게 견뎌야 한다.
6. 이전에 적힌 "O/v3 CAGR 30.1%" 는 **정지가 난 경로**의 숫자다(64). 정지를 끄면 37.0% 였고, 대신 봉 안 −31.1% 를 겪었다.

| | 한도 (계좌 정지 / 중단선) | 무엇을 받아들이나 | 과거 경로와의 여유 |

| C. 2.5배 이상 | 45% 이상 / 40% 이상 | 봉 안 −40% 이상, 하루 −30% 급락 때 최악 −49~65% | 2.5배는 45% 로도 5%p 뿐 |

**권고:**
- H1 로 간다면 **B (2배, 계좌 정지 40% · 중단선 35%)** 까지가 과거 경로에 비해 여유가 있다.
- C 는 과거 경로에서 이미 정지선에 붙는다. 그리고 앞으로 추세가 살아 있을 때 폭락이 오면(§1) 계좌의 절반 이상을 잃는 구조다.
- B 를 고르면 **이미 돌고 있는 O/v3 Paper(2배)의 한도를 바꿔 계속 관찰**한다. 65 D3 는 한도를 바꾸지 않으면 10/23 에 끝내자고 권했다.
  과거 자료로 새로 판정하지 않는다. 확인은 앞으로 12개월 관찰로만 한다.
- 가장 유력한 보완은 **H2(낙폭 연동 배율)** 다. 한도를 올린 2배 위에 얹을지는 H2 를 따로 사전 등록·판정한 뒤에 정한다.
- 실거래는 Phase 8 1단계(T/v2 현물)가 먼저다. 선물(2단계)은 O/v2 가 첫 후보다(65 D2). 한도 상향은 **2단계 후보를 바꾸는 결정**이 아니라 **관찰할 대상을 넓히는 결정**이다.
