## 1. 사용자 요청과 범위

사용자는 버핏 지수·한미 빚투·고용·PPI·PCE·금리 등으로 시장을 이해하고,
지표의 뜻과 호재/중립/악재 해석 및 "오늘 밤 발표" 알림을 요청했다.
이번 범위는 지표 사전·출처·해석·출력·검산 명세 작성과 기존 일정 누락 보완이다.
자동매매 수익 연구·전략 채택·주문·veto·사이징·실거래 승인이 아니다.
Deneb/Vega/Altair, 기존 Paper·연구 판정·주문·예약·설정값·연구 208은 변경하지 않는다.
새 Codex 자동화·Windows 예약·새 API 가입·유료 구매·LLM 호출은 만들거나 실행하지 않는다.

기존 [IDEAS 29](IDEAS.md#29번-정보-도구-초안--하락-브리핑vix미국-대형주-뉴스-2026-10-08-codex)를

## 2. 지표 사전 — 미국 핵심

각 행은 서로 다른 발표표·주기·단위를 가진다. 전체·근원은 별도 series_id로 저장한다.

| ID | 지표·우선 출처 | 의미 | 비교·주의사항 |
|---|---|---|---|
| US_CPI | CPI/근원 CPI, BLS | 소비자가 구입하는 상품·서비스 물가 | MoM/YoY·계절조정 구분. 주거비/서비스/에너지 기여. PCE와 중복 호재표 금지 |
| US_PPI | 최종수요 PPI 및 식품·에너지·무역서비스 제외 항목, BLS | 국내 생산자가 받는 상품·서비스 판매가격 | 원자재 가격만이 아님. 제외 항목 정의 고정. 전 항목이 CPI/PCE에 기계적으로 전가된다고 가정하지 않음 |
| US_PCE_PRICE | 전체/식품·에너지 제외 PCE 물가지수, BEA | 소비지출을 폭넓게 반영한 물가 | 소비지출 금액과 다른 시계열. 연준 장기 2% 목표는 전체 PCE 연간 상승률, 근원은 기조 참고 |
| US_PAYROLL | 비농업 고용 증감, BLS | 사업체의 일자리 변화 | 월간 증감 인원·이전 두 달 수정치·업종·근로시간. 실업률 조사와 구분 |
| US_LABOR | 실업률/참가율/고용률, BLS | 가계조사 기준 고용·구직 상태 | 실업률 하락을 무조건 고용 개선으로 보지 않음. 노동시장 이탈/유입 대조 |
| US_WAGES | 시간당 임금, BLS | 임금의 변화 | MoM/YoY·구성 효과. 구매력 긍정과 비용/물가 압력을 분리 |
| US_CLAIMS | 신규/계속 실업수당 청구, 미국 노동부 | 실직·재취업 상황의 주간 관찰 | 서로 기준 주가 다를 수 있음. 4주 평균·수정치·계절 요인, 한 주로 침체 확정 금지 |
| US_POLICY | 목표금리 범위/FOMC 성명·전망, 연준 | 정책 수준·변화·조건 | 동결/인하 자체와 예상 대비 차이 분리. 점도표는 약속 아님. 결정·회견·의사록은 다른 이벤트 |
| US_YIELDS | 국채 2년/10년·실질금리, 미국 재무부/FRED 원출처 | 시장금리·할인율의 변화 | 정책 기대·기대물가·기간 프리미엄의 원인 후보. 명목금리 하락을 자동 호재로 보지 않음 |
| US_ACTIVITY | 실질 소비/소매판매/생산/GDP, BEA·Census·연준 | 수요·생산의 흐름 | 명목/실질·월/분기·연율 단위 구분. GDP 속보/잠정/확정의 판본 유지 |

첫 구현은 핵심 발표의 사실 표부터 시작한다. 모든 자료의 자동 확보를 이미 인증한 목록은 아니다.
예상치는 발표기관의 실제값과 별도 자료이며 무료 접근·재사용 조건을 먼저 확인한다.

## 3. 한국 및 시장 배경

| 영역 | 한국 우선 후보 | 미국·공통 배경 | 해석 경계 |
|---|---|---|---|
| 물가 | 소비자/근원물가, 생산자/수입물가 | US_CPI/US_PPI/US_PCE_PRICE | 한국 지표에 미국 core 정의·계절조정을 그대로 적용하지 않음 |
| 고용·경기 | 취업자 증감·실업/고용/참가율, 수출·생산·소매판매 | US_PAYROLL/US_LABOR/US_ACTIVITY | 연령·계절·영업일·수출 가격/물량 효과를 확인 |
| 금리·환율 | 한국은행 기준금리, 국고채, 원/달러 | US_POLICY/US_YIELDS | 원화 약세는 수출 기업·수입 비용·달러자산 평가에 다른 영향 |
| 레버리지 | KOFIA 신용융자/예탁금, 시장별 잔고 | FINRA 마진계좌 차입잔고 | 증권사 신용 범위일 뿐 모든 빚투 아님. 국가·기준일·분모가 다른 비율 직접 비교 금지 |
| 신용·금융여건 | 회사채-국채 금리 차이 | NFCI 등 | 신용 경색·완화 설명. NFCI의 수정값·원천 중복·공개 지연 확인 |
| 가격 부담·시장 내부 | 시총/GDP, 시장 폭·집중도 | 버핏 지수, VIX | 장기 배경과 단기 충격 분리. VIX는 방향 예측치 아님 |

한국은 ECOS·KOSIS·관세청 등 작성기관 원문과 KOFIA/KRX를 우선 감사한다.
시총/GDP는 주식 범위와 연간 명목 GDP 정의를 먼저 고정한다. 미국의 단기 판정 문턱을 한국에 복제하지 않는다.
FINRA 월말 잔고는 발표 후에만 이용한다. 신용잔고 감소만으로 반대매매/강제청산을 확정하지 않는다.

## 4. 자료·시각 계약 — 구현 전 확정할 필드

다음은 제안 스키마이며 현재 DB 마이그레이션·자동 수집은 없다.

- 식별: indicator_id, series_id, country, category, source_url, source_document_id,
  source_sha256, source_terms, observation_period, release_version.
- 실제값: actual, prior_original, prior_revised, unit, change_basis(MoM/YoY/level),
  seasonal_adjustment, core_definition. 숫자 파싱/차이는 Decimal, 저장은 문자열.
- 시각: reference_end_ms, scheduled_at_ms, released_at_ms, fetched_at_ms, as_of_ms.
  확정 시각은 UTC epoch milliseconds; 표시는 Asia/Seoul, 원 일정은 원 시간대 유지.
- 예상치: consensus_value, consensus_source_url, consensus_captured_at_ms,
  consensus_statistic(중앙/평균), consensus_dispersion(가용할 때).
  발표 전에 확보한 동일 항목/기간/단위의 예상치만 surprise 계산에 사용한다.
- 품질: VERIFIED/PARTIAL/MISSING/STALE/CONFLICT, 누락·접근·수정 사유.
  공식 숫자 인증과 해석의 확실성을 동일시하지 않는다.

불명·결측은 0/중립으로 바꾸지 않는다. 처음 발표값을 수정값으로 덮어쓰지 않는다.
전체/근원·전월/전년·%/%p/bps·인원/천 명·계절조정 여부를 혼합 비교하면 판단 보류다.
예상치를 확보하지 못하면 이전 값·추세 비교만 제공하고 "예상보다"라는 문장을 생성하지 않는다.
분석시각 뒤에 공개된 값과 나중에 본 수정본을 과거 설명에 역으로 넣지 않는다.
추세는 같은 판본의 최소 3개/6개 완전 관측으로 비교한다. 부족하면 해당 추세만 미확보다.
3개월 연율은 계절조정된 가격지수로 계산 가능할 때만 사용하고 연율과 YoY를 구분한다.
고정된 숫자 차이를 경제적 유의성으로 단정하지 않으며, 반올림·예상 분산·변동성을 확인한다.

## 5. 조건부 해석 규칙

분석 순서는 발표 사실 → 이전·수정·예상 차이 → 추세 → 전달 경로 → 상충 근거 → 대상별 결론이다.
아래는 설명 원칙이지 검증된 주가 예측식·성과 기반 문턱·매매 신호가 아니다.

| 관측 | 긍정 경로 | 부정/상충 경로 | 허용 결론 예 |
|---|---|---|---|
| 물가 상승률 둔화 | 물가·긴축 부담 완화 | 수요/고용까지 급락하면 경기 위험 | 고용·소비 유지 확인 시 주식에 호재 쪽, 불명 시 혼재 |
| PPI 상승 | 특정 품목의 일시 요인일 수 있음 | 가격 상승이 광범위·지속되면 비용/물가 압력 | 구성 확인 전 주식 악재로 고정하지 않음 |
| 고용 예상 상회 | 소득·수요·이익 지지 | 물가 과열 중이면 금리 부담 | 경기 긍정/정책 부담을 함께 제시 |
| 실업률 상승 | 참가율 상승·완만한 수급 정상화 | 취업 감소·청구 증가면 고용 악화 | 참가율/고용과 대조 전 혼재 또는 보류 |
| 임금 상승 둔화 | 비용/물가 압력 완화 | 실질소득·소비 약화 가능 | 물가 대비 실질 변화와 고용 동반 확인 |
| 정책금리 인하 | 물가 안정 속 완화 | 침체/금융불안 대응이면 이익 위험 | 인하를 무조건 주식 호재로 표시하지 않음 |
| 국채금리 하락 | 할인율 부담 완화 | 침체 우려·위험 회피 | 다른 근거 없이 하락 원인 확정 금지 |
| 신용잔고 급증/축소 | 위험 선호 확대/레버리지 정리 가능 | 취약성 축적/자금 압박 가능 | 가격·신용·거래 조건과 함께 설명, 강제 매도 단정 금지 |

정책 환경 자체가 불명확하면 물가우세/성장우세 중 하나를 임의 선택하지 않는다.
금리와 기업이익이라는 상반된 경로를 제시한다. 물가 상승률 둔화와 가격 하락을 구분한다.
개별 지표의 결론은 호재/중립/악재/혼재/판단보류 5개로 한다.
중립은 확인된 근거가 대체로 균형인 경우, 보류는 필요한 근거가 없거나 충돌하는 경우다.

- 대상: 미국 주식/한국 주식/국채/달러·원화/코인, 근거가 있는 대상만 제공.
- 기간: 발표 직후 해석과 수주~수개월 배경을 분리. 다음 봉 상승 확률로 표현하지 않음.
- 사실 품질: 공식 원문 확인/일부 확인/근거 부족. LLM 자기 확신을 정확도 확률로 표시하지 않음.
- CPI/PPI/PCE는 물가 영역, 고용/실업/임금은 고용 영역으로 묶는다.
  같은 정보를 중복 투표해 "호재 6개" 같은 합계·무근거 위험점수를 만들지 않는다.
- 실제 가격 반응은 별도 관측이다. 가격이 올랐다는 이유로 발표를 사후 호재로 바꾸지 않는다.

## 6. 출력과 LLM 경계

개별 카드: 쉬운 뜻 / 실제·이전·수정·예상 / 기준월·발표 KST / 최근 흐름 /
경기 영향 / 물가·정책 영향 / 자산별 조건부 결론 / 반대 근거 / 추가 확인 / 원문·품질.
상단: 물가·고용·경기·금리/신용·가격부담/레버리지별 요약, 새 발표와 오래된 배경 구분.
가상 예시는 반드시 가상 표시한다. 현재 관측이 없으면 그럴듯한 최신 값으로 채우지 않는다.

수집기=허용 공식 원문, 계산기=수치/단위/차이/시각, LLM=근거 범위 안의 쉬운 설명,
검증기=숫자·URL·시각·근거 ID·논리·금지 문구 대조로 역할을 나눈다.
공급자 비종속 입력/출력과 모델·프롬프트·입력 해시·저장 응답 재생을 요구한다.
외부 문서의 명령은 실행하지 않고 .env/키/계좌·개인 잔고를 LLM에 보내지 않는다.
무료 호출 예산·캐시·실패 처리는 구현 전에 확정한다. 유료 자동 전환은 금지한다.

## 7. 발표 전 알림 — 기존 경로와 새 초안 구분

### 7.1 이미 있는 기능의 코드 감사

- [일정표](../../config/event_calendar.yaml) →
  [순수 문구/시간 변환](../../src/auto_trading/ops/event_calendar.py) →
  [기존 텔레그램 실행](../../scripts/event_alert.py).
- `scripts/telegram_bot.py`가 기존 반복 실행 때 `maybe_send`를 호출한다.
  이 파일은 다른 에이전트 작업 범위이므로 변경하지 않았다.
- `alerts.events`의 기본값은 true. 이번에 본 사용자 설정에는 별도 override가 없었다.
  설정값은 수정하지 않았다. 자격증명 값·계좌 API는 열거나 호출하지 않았다.
- 기존 시간대: 07:35~16:30 아침 묶음, 16:30~23:30 당일 묶음, 슬롯별 하루 한 번.
  아침에는 오늘 일정과 내일의 고중요도 일정, 오후에는 오늘 일정이 포함된다.
  따라서 내일 PPI는 기존 고중요도 분류가 아니어서 전날 아침 묶음에 보장되지 않는다.
- PC와 기존 봇이 실행 중이고 설정/텔레그램 연결이 준비돼야 도착한다.
  이번 작업은 새 예약 등록·프로세스 재시작·시험 알림 전송을 하지 않는다.
- `data/event_alert/state.json`의 본 날짜 슬롯 표시는 무자료/자격증명 없음에도 기록될 수 있다.
  슬롯 존재는 실제 텔레그램 수신 증명이 아니다. 상태를 지워 재전송하지 않는다.
- 공식 BLS 10월 표와 대조해 빠진 10/02 고용, 10/14 CPI, 10/15 PPI를 보완했다.
  10/15 PPI 예정은 08:30 EDT = 21:30 KST, 조사 시 이미 지났다. 사전 전송 성공을 주장하지 않는다.
  과거 누락을 고친 것으로 당시 알림이 전송됐다는 의미가 아니다.

### 7.2 공식 대조한 예정 시각 예시

| 미국 기준 일정 | KST | 원천 |
|---|---|---|
| 2026-10-15 08:30 PPI | 10/15 21:30, 조사 시 지난 예정 | BLS 10월 표 |
| 2026-10-29 08:30 PCE·소득·소비 / GDP | 10/29 21:30 | BEA 일정 |
| 2026-11-13 08:30 PPI | 11/13 22:30 | BLS PPI 표 |

ET를 UTC-5로 고정하지 않고 America/New_York에서 Asia/Seoul로 변환한다.
다음 날 새벽 이벤트는 정확한 KST 날짜를 함께 쓴다. 일정 변경 시 재확인이 필요하다.
기존 FOMC 행의 14:00은 결정 발표 시각이며, 이벤트명에 회견이 있어도 회견 동시 시작으로 읽지 않는다.
회견·의사록은 건강검진 새 이벤트 모델에서 별도 ID와 공식 시각을 확보해야 한다.

### 7.3 건강검진 확장 알림의 제안 계약 — 미구현

기본 채널 후보는 기존 텔레그램이다. Codex 자동화/다른 채널을 중복 등록하지 않는다.
다음은 설계이며 지금 켜진 기능으로 보고하지 않는다.

1. 당일 요약: 기존 07:35/16:30 경로 재사용, 중요한 일정·KST·기준월·쉬운 의미를 함께 표시.
2. 발표 30분 전: 사용자 적용 선택과 기존 봇 파일의 작업 종료 후 구현. 아직 전송 없음.
3. 발표 후: 공식 실제값을 확인한 뒤 별도 요약. 예상치 없으면 예상 대비 판정 제외.
   예정 시각이 지났다고 발표 완료/숫자 확보로 간주하지 않음. 현재 자동 분석 없음.

새 모델의 중복키는 event_id + stage + schedule_revision, 전송 응답/불명/재시도 기록을 분리한다.
일정 수정·취소는 정정 알림, 휴면 PC 복귀는 지난 이벤트를 예정이라고 보내지 않고 놓친 상태로 구분한다.
공식 일정의 범위·확인일·해시·출처·변경을 저장하고 만료/확보 실패를 "일정 없음"으로 대체하지 않는다.
현재 YAML의 covered_until=2026-12-31은 모든 이벤트의 완전성 인증이 아니다.
일부 2027 BLS/FOMC가 있어도 BEA 2027 전체 확보로 읽지 않는다. 자동 갱신도 현재 없다.
기존 코드의 빈 날 만료 경고 누락/자격증명 부재의 슬롯 처리/발표 후 늦은 경고는 후속 검증 항목이다.
현재 매수 보류/크기 주의 문구는 사용자 직접매매용 기존 경고이며 자동 주문·비중에는 영향 없다.
새 건강검진의 호재/악재는 매수·매도·차단 명령으로 변환하지 않는다.

## 8. 검산·완료 기준

기능 검산용 30개 사례를 제안한다. 수익성·통계적 정확도 인증 표본 수가 아니다.
범주별로 물가 6/고용 6/금리 4/상충·예상부재 6/일정·시각·장애 8개를 결과 전에 정한다.

- 원문 숫자/단위/기준월/출처 일치, 전체·근원/계절조정 혼입 0.
- 발표 후 예상치 역유입/수정값 소급/미래 자료 입력 0.
- 근거 없는 최신 숫자·상승 확률·정확도 확률·원인 단정 0.
- 예상 부재·원천 장애·휴면 PC·중복·취소/연기·ET 서머타임/자정 넘김의 명시 처리.
- PPI와 PCE 각각 사전 문구 출력, 발표 전 숫자 미기입, 일정 만료와 빈 일정 구분.
- 정보 도구에서 주문·veto·사이징·거래 설정 변경 경로 0.

중대 오류가 있으면 정보 공개/새 알림 활성화 전에 수정·재검산한다.
현재 수행한 시험과 위 미구현 시험 계획을 혼합하지 않는다.
순서: 명세 초안 → 출처/예상치·일정 커버리지 감사 → 사용자 구현 범위 확인 →
분리 수집/계산/설명·알림 구현과 합성 검산 → 읽기 전용 관찰. 수익 연구는 별도다.
