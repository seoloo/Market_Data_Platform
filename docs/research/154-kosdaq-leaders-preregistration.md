## 0. 왜 · 무엇을 묻나

- 142 의 수급 주도주는 유가증권시장에서 통과했지만 **2025~26 을 빼면 문턱 미달**이었다. 같은 규칙이 **한 번도 보지 않은 시장(코스닥)** 에서도 EW 를 이기면 '규칙에 무언가 있다' 는 증거가 되고, 지면 유가증권시장 통과는 그 시기 대형주 장세 덕일 가능성이 커진다. **이번 묶음의 주 시험은 FLOW-KQ.**
- 141(가격 주도주)은 유가증권시장에서 EW 와 같았다 — 코스닥에서도 같이 본다(같은 틀의 대조).
- IDEAS 1 의 보완(작은 섹터 제외)은 141·142 에서 **결과를 본 뒤** 나온 생각이라 유가증권시장으로는 시험할 수 없다. 코스닥은 안 본 자료라 결과 전에 고정해 볼 수 있다 — 단 보조 시험.

## 1. 자료

- **그날 코스닥 소속:** KRX Open API 코스닥 일별매매정보(`data/research/krx/ksq/`) — 그날 상장된 모든 종목(뒤에 폐지·유가증권시장으로 옮긴 종목 포함). KRX 는 **2010-01 부터** 준다(2008 은 0 행). 한국투자증권 종목정보는 지금 시장만 알려 줘서(셀트리온·카카오는 코스닥 날짜가 지워짐) 소속 판단에 쓰지 않는다.
- **종목군 후보:** 월말마다 그날 코스닥 종목 중 63 거래일 평균 거래대금 상위 **300** 의 합집합(`fetch_kq_stocks universe`) — 실제 종목군(141 정의 상위 200)은 판에서 다시 고른다.
- **가격:** 한국투자증권 수정주가 일봉(141 과 같은 경로), 그 종목의 코스닥 첫날 300 일 앞부터. 판에는 **그날 코스닥 소속이고 거래한 날만** 넣는다.
- **수급:** 한국투자증권 종목별 투자자 매매(142 와 같은 경로), 코스닥 첫날 120 일 앞부터.
- **업종:** 한국투자증권 KSIC → 141 의 11 개 묶음(같은 표). **코스닥 지수:** 한국투자증권 업종 지수 1001(2009-01 ~).
- 자료 해시·표본 수: (audit 뒤 이 자리에 적는다).

## 2. 규칙 (141 · 142 코드 그대로)

- 종목군: 월말에 141 `members` (그날 거래 · 1·3·6 달 수익을 낼 수 있음 — 즉 코스닥에 6 달 이상 · 63 일 평균 거래대금 상위 200). 보통주만(141 과 같음), **스팩 제외**(이름에 '스팩' — 유가증권시장엔 종목군에 없던 종류라 141 에 규칙이 없었다).
- **LT-KQ:** 141 `simulate_kr` 기본(가격 주도 점수 → 섹터 중앙값 상위 3 → 상위 10, T 추세 + 50 일선, 매달 진입·추매, 추세 꺾임/−35% 매도, 0.25%).
- **FLOW-KQ (주 시험):** 142 `flow_picker`(외국인 + 기관 순매수 ÷ 거래대금, 20·60 일 백분위 평균), 나머지 141 그대로.
- **보조 둘 (IDEAS 1):** 위 둘에 '그 시점 종목군에서 종목 **5 개 미만**인 섹터의 종목(과 섹터 모름)은 주도주 후보에서 뺀다'.
- 시장 여지: **코스닥 지수 > 200 일선**(141 의 KOSPI 자리). 코스닥에서 빠지는 날(폐지·유가증권시장 이전) = 141 의 상장폐지처럼 마지막 코스닥 거래일 종가에 판다.
- 비교: 같은 종목군 EW(141 `equal_weight_pit`) · 코스닥 지수(참고).
- 기간 **2011-01-01 ~ 2026-08-31**, 반쪽 경계 2017-01-01.

## 3. 판정 기준 (141 · 142 와 같음, 시험마다)

| | 기준 |
|---|---|
| L1 | 전 기간 샤프 ≥ EW + 0.20 |
| L2 | 두 반쪽 모두 연 수익 > EW |
| L3 | 최대 낙폭 ≤ max(EW 낙폭, 40%) |

셋 다 → `PASS`. **주 시험은 FLOW-KQ 하나** — 보조 셋(LT-KQ · 두 MIN5)은 통과해도 그것만으로 새 전략을 세우지 않는다(넷 중 하나는 운으로 통과할 수 있다).

- **FLOW-KQ 가 통과하면:** 142 의 수급 주도주가 두 시장에서 통과 → 143 그림자 기록에 코스닥 수급 목록을 더하는 사전 등록을 따로 한다(바로 매매 안 함).
- **FLOW-KQ 가 실패하면:** 142 통과는 유가증권시장 2025~26 대형주 장세에 기댄 것으로 본다(143 기록은 예정대로 2027-10 판단).
