## 0. 왜

- 사용자 (2026-10-18): Altair 수익을 늘릴 방법 → Claude 제안 ①(실거래 30% 정지가 수익에 주는 영향) → **"일단 altair 1번 진행해."**
- 실거래 `scripts/altair_live.py`: 단위 가치가 고점에서 **30%** 빠지면 **새 노출(롱 늘리기 · 새 숏) 금지**, 줄이기 · 정리 · 스톱은 그대로, `unhalt` 로만 푼다(풀 때 고점을 지금으로).

- **설명용 참고 계산. 판정 없음.** 어떤 풀기 규칙을 쓸지(또는 정지를 둘지)는 사용자가 정한다. 실거래 코드는 사용자 결정 뒤에만 바꾼다.

## 2. 정지 · 풀기 규칙 (숫자는 여기서 처음 정함)

- **정지**: 4 시간봉 마감 체크포인트마다 평가액 ÷ 정지용 고점 ≤ **0.70** 이면 정지. 정지용 고점은 처음 10,000, 이후 체크포인트 평가액의 최고(정지 중에도 갱신). 입금 · 출금이 없어 평가액 = 단위 가치.
- **정지 중**: 엔진의 새 위험 관문(`_new_allowed`)이 막힌다 → 롱 늘리기 · 새 현물 매수 · 새 숏 안 함. **줄이기 · 정리 · 손절 · 숏 청산은 그대로**(실거래와 같음).

| 규칙 | 풀기 |
|---|---|
| **NONE** | 정지 없음 — 지금 백테스트(235 와 같아야 함, 대조) |
| **NEVER** | 안 풂 |
| **D30** | 정지 30 일 뒤 첫 체크포인트에 풂 |
| **TREND** | 정지 중 BTC 롱 목표(Altair 자기 T/v2 목표)가 **한 번 0 이 된 뒤 다시 0 보다 커지는** 첫 체크포인트에 풂 — 추세 꺼짐 → 다시 켜짐 |

- 풀 때 정지용 고점 = 그때 평가액(실거래 `unhalt` 와 같음). 다시 30% 빠지면 다시 정지.
- 엔진에 원래 있는 규칙(평가액 ≤ 처음 30% 면 전부 정리 · 하루 −2% 새 위험 막음 · 숏 연패 쉼)은 그대로 둔다.
