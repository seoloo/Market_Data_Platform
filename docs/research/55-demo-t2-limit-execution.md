# 55 — 데모 T/v2 현물: 지정가 L240 체결 비용 실측 (2026-09-25 등록)

작성: 2026-09-25 (Opus) · 상태: **등록 · 첫 실행 2026-09-25** · 가짜 돈(Binance 현물 데모 모드)만 쓴다.
사용자 요청 (2026-09-25): "데모 T/v2 체결 시험 진행해줘 … 데모 하는 것도 텔레그램에 알림이 갔으면 좋겠어.
어떠한 연구를 테스트 하기 위해 해당 포지션을 지정해서 예약 및 진입을 했고 왜 그렇게 들어갔는지를 … 짧게만."

## 1. 무엇을 묻나

[42](42-execution-cost-limit-orders.md)는 1분봉 모형으로 "지정가 L240(post-only, 최대 4 시간, 남은 수량 시장가)이 시장가보다 싸다"고 판정했다.
모형이 못 본 것 — 대기 순서·부분 체결·post-only 거절·실제 호가 — 을 **실제와 비슷한 호가**에서 잰다. 동시에 **T/v2 현물 주문 경로를
처음으로 거래소 API 에 실어** 본다(지금까지는 가짜 거래소·읽기 전용 그림자 운영뿐, [51](51-phase8-shadow-t2-registration.md)).

## 2. 설정

| 항목 | 값 |
|---|---|
| 거래소 | Binance **현물 데모 모드** `https://demo-api.binance.com` — 가격·호가가 실거래소와 비슷, 필터·한도는 같다(공식 문서). 어댑터는 이 주소에만 묶인다(`exchange/binance_spot_demo.py`) |
| 키 | 선물 데모와 같은 데모 키(`BINANCE_TESTNET_API_*`). 2026-09-25 잔고 조회로 확인: USDT 5,000, 수수료 maker = taker = 0.10% |
| 전략 | T/v2 그대로(16): 20·60·120 일 추세, 크기 min(15%/σ60, 0.5), 밴드 5%p, **종가 d 결정 → 다음 실행 체결**. 신호는 실거래소 공개 일봉(키 불필요) |
| 자본 | 데모 계좌 잔고(시작 USDT 5,000). Paper(10,000)와 비율로 같다 |
| 주문 | 매수 = 매수 1호가, 매도 = 매도 1호가 **LIMIT_MAKER**. 거절되면 호가 다시 읽어 최대 3 번. 4 시간 안 미체결 수량은 취소 뒤 시장가. 30 초마다 조회 |
| 실행 | `python scripts/demo_t2_spot.py` 매일 **21:12 KST**(사용자 스케줄 등록). 첫 실행은 d−1 목표를 공개 일봉으로 다시 계산해 체결(과거 종가만 사용) |
| 알림 | 텔레그램 + `reports/demo_t2/outbox.log`: 예약(무슨 연구·주문·이유) · 체결(대기·비용) · 추격 |
| 기록 | `reports/demo_t2/days.jsonl` — 주문마다 P0(주문 순간 중간가)·지정가·maker/taker 수량·평균가·수수료(USDT 환산)·IS(bp)·대기·거절·추격 |

42 모형과 다른 점(의도): 모형은 **최종 체결가 P0 에 걸고 뚫고 지나가야 체결**, 여기서는 **1호가에 걸고 중간가 대비**로 잰다.
모형은 00:00 UTC 체결, 여기서는 21:12 KST(12:12 UTC) 실행 — 42 §7.5 가 지적한 실행 시각 차이를 그대로 안고 간다.

## 3. 보고 (2026-10-23, Paper 검토와 함께) — 판정 아님, 측정

| # | 항목 | 비교 기준 |
|---|---|---|
| K1 | 주문 경로 안전: 중복 주문 0, 해소 안 된 주문 0, 추격 뒤 남은 수량 0 | 필수 — 하나라도 어기면 원인과 수정을 먼저 적는다 |
| K2 | maker 체결 비율(명목), 평균 대기 | 42 모형 현물 L240: 99.2%, 1~2 분 |
| K3 | 평균 IS = 가격 부분(중간가 대비) + 수수료 | 42 모형 10.23bp · 현재 백테스트 가정 15bp · 참고 줄 11bp |
| K4 | post-only 거절 횟수, 추격 건과 그 비용 | 모형에 없던 것 |

**한계:** T/v2 는 며칠에 한 번 거래한다 → 4 주 동안 **주문 5~15 건** 정도. 비용 **추정이 아니라 확인**(모형과 크게 어긋나는지)이다.
데모 호가는 "비슷한" 것이지 실제가 아니다(공식 문서의 경고). 실거래 비용은 Phase 8 에서 다시 잰다.
