## 1. 계산 경로 (코드: `research/fundamental_kr.py` · `scripts/fundamental_kr.py`)

- **보고서 버전마다 값**을 둔다: (가용 거래일, 값). 월말 t 에는 그때 보이던 버전만 쓴다. 가용 = 그 버전 접수일 **다음 거래일 종가 뒤**(초안 §3-1).
- 재무 API 가 준 버전 = JSON. **그 앞 버전 = XBRL 원본**(표준 태그 `ifrs(-full):Revenue` · `dart:OperatingIncomeLoss` · `ifrs(-full):CashFlowsFromUsedInOperatingActivities`, 차원이 연결/별도 하나뿐인 값, 기간 끝 = 보고서 기간 끝, 3 개월 = 80~100 일 · 누적 = 가장 긴 기간). XBRL 이 없으면 그 버전 값은 **모름** → 그 분기를 쓰는 월은 결측.
- 시험: XBRL 원본 3 개(SK하이닉스·현대차 2017 사업보고서, 동화약품 2026 반기)에서 세 측정치가 재무 API 값과 원 단위까지 같았다(이 셋은 숫자 안 바뀐 정정).
- 4분기 = 1 년 − 3분기 누적, 현금흐름 = 누적 − 앞 보고서 누적 — 두 보고서의 **그때 버전**을 함께 쓴다. 연결·별도가 섞이면 결측.

### 새로 알게 된 사실 (결과 전)

| 사실 | 영향 · 처리 |
|---|---|
| **재무 API 에 2015 년 1~3분기가 없다**(SK하이닉스 등 '013 자료 없음', 2015 사업보고서부터) | 그대로면 12 분기가 2016 년부터 차서 첫 신호가 2019-04. **처리:** DART 에 없는 해는 **다음 해 같은 보고서의 '전년 같은 기간' 칸**(`frmtrm_q_amount` · `frmtrm_add_amount` · 현금흐름 `frmtrm_amount`/`frmtrm_q_amount`)으로 채우고, 그 값은 **다음 해 보고서 가용일부터만** 쓴다(그때 공개된 값이라 미래 정보 아님). 초안의 '2018 년부터' 계획을 지키기 위한 자료 처리이며 결과를 보고 고른 것이 아니다 |

| 보험·증권·은행은 재무 API 가 CFS·OFS 모두 '013' | §3 금융 서식 |

## 3. 당시 비금융 여부 — '금융 서식' 으로

- 지금 KSIC '기타 금융업(6409)' 에 **일반 지주회사(SK·LG·GS·HD현대·LS 등)와 금융지주(KB·신한 등)가 섞여** 있다 → 지금 KSIC 로 거르면 일반 지주회사를 잘못 뺀다(종목군 200 중 30~40 개가 '금융').
- DART 재무 API 는 **은행·보험·증권 서식 회사에 '013 자료 없음'** 을 준다(삼성화재·현대해상·DB손보·NH투자증권·대신증권 확인), LG 등 일반 지주회사는 정상 재무제표.
- **처리(제안):** 재무 API 정상 응답이 하나도 없는 회사 = 금융 서식 → 비금융 분모에서 빼고 수를 따로 보고. 공시 서식 자체가 그 시점 기준이라 '지금 업종 소급' 문제가 없다. 한계: 회사 단위 판정(중간에 서식이 바뀐 회사는 정상 응답 기간만 쓰임). 금융지주(KB 등)가 정상 응답이면 비금융으로 들어온다 — 전체 수집 뒤 확인.

## 4. 기간별 비용표 (유가증권시장)

매수·매도 각각 `max(0.25%, 실제)`(초안 §5). 실제 = 수수료 0.015%(온라인, 가정) + 매도 때 세금.

| 매매일 | 매도 세금 (증권거래세 + 농어촌특별세) | 매도 비용 | 매수 비용 |
|---|---|---|---|
| ~ 2019-05-29 | 0.15% + 0.15% = **0.30%** | 0.315% | 0.25% |
| 2019-05-30 ~ 2020-12-31 | 0.10% + 0.15% = 0.25% | 0.265% | 0.25% |
| 2021 ~ 2022 | 0.08% + 0.15% = 0.23% | 0.25% | 0.25% |
| 2023 | 0.05% + 0.15% = 0.20% | 0.25% | 0.25% |
| 2024 | 0.03% + 0.15% = 0.18% | 0.25% | 0.25% |
| 2025 | 0.00% + 0.15% = 0.15% | 0.25% | 0.25% |
| 2026 ~ | 0.05% + 0.15% = **0.20%** | 0.25% | 0.25% |

근거: [서울신문 2019-05-22](https://www.seoul.co.kr/news/economy/securities/2019/05/22/20190522024015)(2019-05-30 체결분부터 0.05%p 인하) · [한국세정신문](https://www.taxtimes.co.kr/news/article.html?no=257823)(0.23 → 0.20 → 0.18 → 0.15%) · [KNN](https://news.knn.co.kr/news/article_sns/282)(2026 코스피 0.05%, 농특세 0.15% 유지). 지정가 한도에서의 불리한 체결은 초안 §5 의 한도 가격 모형이 따로 반영한다(이중 차감 확인용으로 따로 보고). 스트레스 = 2 배.

## 5. 배당 · 총수익

- **한국투자증권 '예탁원 배당일정'(HHKDB669102C0)** 이 종목·기간별 **기준일 · 주당 배당금(당시 원래 가격 기준) · 지급일 · 결산/분기/중간 구분**을 준다 — 2015 ~ 2026 확인(삼성전자 분기 배당·50:1 분할 전후, SK하이닉스 2025 뒤 기준일 2 월 말로 바뀜까지).
- **처리(제안):** 기준일 R 의 권리 = R 까지의 **마지막 거래일 바로 전 거래일 종가**에 들고 있으면(T+2 결제) 받는다. 현금은 **지급일**에 들어와 그 뒤 매수에 쓴다(초안 §5 결제 가용). 배당률 = 주당 배당금 ÷ 원래(비수정) 종가. 배당 0 줄은 무시.
- 받기 완료(2026-10-06 저녁, `python -m scripts.fetch_kr_stocks dividends`): 880 종목 실패 0, 현금 배당 있는 종목 710, 줄 1 만여 개(결산 8,819 · 분기 973 · 반기 208). 기준일 달: 12 월 5,073 · 3 월 512 · 6 월 470 · 2 월 148(개편 뒤 이동) 등. 한 구간 최대 51 줄(월배당 종목 155900) — 응답 잘림 없음.
