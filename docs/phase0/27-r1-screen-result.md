## 4. 해석 범위

이번 결과는 **21일 상대 추세 롱3/숏3**가 현재 Binance USD-M 데이터에서 비용 후
수익원이라는 주장을 지지하지 않는다. 모든 중기 추세나 모든 자동매매가 불가능하다는
뜻은 아니다. 다만 같은 데이터에서 lookback만 바꿔 성공값을 찾는 것은 과최적화이므로
R1 내부 탐색은 여기서 끝낸다.

다음 연구를 한다면 R1 파라미터 변형이 아니라, 경제적 수익원이 다른 별도 프로그램을
먼저 사전등록해야 한다.
