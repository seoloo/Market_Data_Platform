## 2. 무엇이 일어났는지 정확히

"효과가 사라졌다" 와 "효과를 못 봤다" 는 다르다. 숫자가 말하는 것은 후자에 가깝다.

| | TRAIN (2021+2023) | VALIDATION (2024) |
|---|---:|---:|
| 6h 하위 decile | +34.57 ± 9.96 | +15.08 ± 8.93 |
| 표본 | 421 | **189** |
| 방향 | 양수 | 양수 (동일) |
| horizon 증가 패턴 | 11.6 → 22.7 → 34.6 | 4.9 → 9.8 → 15.1 (동일 모양) |

두 추정치의 차이는 **+19.49 ± 13.38 (t = 1.46)** 로 **서로 구별되지 않는다.**
즉 2024 결과는 "TRAIN 값이 맞다" 와 "효과가 0 이다" 를 **모두** 허용한다.
구분할 힘이 없는 검정이었다.

### 검정 설계가 부족했다

내가 1년짜리 재현 검정을 사전 등록한 것이 잘못이었다. 6h decile 조건부 표본은
연간 약 190개뿐이라, 필요한 표본에 못 미친다.

하위 decile 6h 수익률 SD ≈ **123bps**, 두 구간 풀링 추정 **+23.77 ± 6.65** 기준:

| 확인하려는 것 | 필요 표본 | 필요 연수 |
|---|---:|---:|
| 0 보다 크다 | 107 | 0.6년 |
| **maker 비용 12.5bps 돌파** | **476** | **2.5년** |
| **taker 비용 18bps 돌파** | **1,814** | **9.5년** |

**taker 비용 기준으로는 9.5년이 필요하다.** metrics 아카이브는 2021 부터이고
2022 는 비어 있으므로 쓸 수 있는 것은 약 4.5년이다 — 물리적으로 판정할 수 없다.

## 3. 접근 재검토 (16 §4.4 가 지시한 단계)

두 가설을 기각하면서 쌓인 것은 실패 목록이 아니라 **문제의 구조**다.

### 3.1 지금까지 측정한 것

| 정보원 | 결과 |
|---|---|
| 가격 파생 (EMA·RSI·ATR·모멘텀·거래량) | edge 없음. 2h 에서 ±1.5bps 정밀도로 확인 — 표본 부족이 아니라 **효과 없음** |
| 포지셔닝 (funding·OI·테이커) | 4개 무효. funding 은 연도 일관성조차 없었다 |
| 포지셔닝 (군중 vs 상위 트레이더 괴리) | 방향은 두 구간에서 일치, 크기 +15~35bps. **판정 불가** |

### 3.2 진짜 제약은 가설이 아니라 산수다

```
잡을 수 있는 효과 크기   ~20bps (F5, 6시간 보유, 추정)
왕복 비용 (taker)        13bps + 안전마진 5 = 18bps
6시간 수익률 SD          ~123bps (decile 조건부)
연간 독립 표본           ~190개
```

효과가 비용과 같은 자릿수인데 잡음은 그 6배다. **이 조합에서는 어떤 가설을 세워도
taker 비용 기준으로는 데이터가 모자란다.** H1·H2 가 실패한 것이 아니라, 이 설정에서
성공을 *증명할* 방법이 없다.

### 3.3 그래서 선택지는 세 개뿐이다

| | 내용 | 전제 |
|---|---|---|
| **A. 종료** | 두 가설이 기각됐고 세 번째를 만들지 않기로 미리 정했다. 정상적인 결과다 (07 §8) | — |
| **B. 비용을 먼저 줄인다** | post-only 진입으로 기준을 18 → **12.5bps** 로 내린다. 그러면 F5 판정에 **2.5년**이면 되고 데이터가 있다 | 지정가 미체결률을 보수적으로 모델링해야 함 |
| **C. 목표를 바꾼다** | 방향성 예측을 포기하고 funding 수취·베이시스 같은 **구조적 수익**을 노린다 | 사실상 다른 프로젝트 |

**B 만이 지금 구조를 유지한 채 판정 가능한 문제로 바꾼다.** 기준을 완화하는 것이
아니라 비용을 실제로 줄이는 것이며, 그 결과 필요 표본이 1,814 → 476 으로 준다.

> 다만 B 를 택하더라도 **먼저 해야 할 일은 체결 모델링이지 F5 재검정이 아니다.**
> 미체결률을 모른 채 12.5bps 를 가정하면 그건 비용 절감이 아니라 희망이다.

## 4. 남긴 것

기각된 것은 가설이지 인프라가 아니다. 다음에 무엇을 하든 그대로 쓴다.

- 데이터: 캔들 414만봉 · funding 7,305건 · **포지셔닝 지표 327,958건** (2021·2023~2024)
- 인과성 관문, 백테스트 엔진·체결·회계, 리스크·사이징
- **사전 등록 선별 도구** — 가설 하나를 몇 시간 만에 기각할 수 있게 해준 것
- 검정력 계산 — "이 질문에 답할 데이터가 있는가" 를 **먼저** 묻는 습관

H1 은 기각까지 수 주가 걸렸고, H2 는 **하루** 걸렸다. 그 차이가 이 프로젝트에서
실제로 만들어진 자산이다.
