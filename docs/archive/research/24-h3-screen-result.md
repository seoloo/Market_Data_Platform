## 3. 이번 실패는 이전 두 번과 성격이 다르다

H1·H2 는 **판정 불가**였다. 표본이 모자라 "엣지가 없다" 와 "엣지가 있는데 못 본다" 를
구분할 수 없었다 ([15](15-h1-postmortem.md), [18](18-h2-validation-result.md)).

이번에는 **판정했다.** SE 가 0.52~2.49bps 라 5bps 짜리 효과도 0 과 구별된다.
실제로 X4 는 0 과 구별된다 — **다만 22bps 에 4배 못 미친다.**

[22](22-multi-symbol-pivot.md) 의 검정력 계산이 맞았다는 뜻이기도 하다.
측정은 제대로 됐고, 잴 수 있게 된 다음에 **잴 것이 작다는 사실**이 드러났다.

## 4. X4_rel_crowd_gap 에 대해 — 기각하되 기록은 남긴다

군중·상위 트레이더 롱숏비 괴리는 **세 번째로** 구조를 보였다.

1. H2 단일 심볼 선별에서 5개 중 유일하게 구조 (F5)
2. H2 VALIDATION 재현 — 판정 불가 (검정력 부족)
3. H3 횡단면 — 2023·2024 부호 일치, 4h·6h 5분위 **단조**, horizon 에 따라 단조 증가

효과 크기가 horizon 에 거의 비례한다: `2h −2.14 · 4h −3.88 · 6h −5.27`.

방향은 **군중 쏠림이 큰 쪽을 숏**하는 것이다 (부호가 음수이므로).
경제적으로 말이 되고, 통계적으로도 0 이 아니다.

**그래도 기각한다.** 6시간 보유로 5.3bps 를 벌자고 22bps 를 내는 것은 거래가 아니다.
23 §5 의 기준은 이 상황을 위해 미리 고정해 둔 것이다.

## 5. 이제 병목은 신호가 아니라 비용이다

세 가설을 거치며 병목이 옮겨 갔다.

| | 병목 | 해소됐나 |
|---|---|---|
| H1 | 표본 부족 (연 190개) | 다중 심볼로 해소 (연 4,400개) |
| H2 | 표본 부족 + 시장 방향 잡음 | 횡단면으로 해소 (SD 4배 축소) |
| **H3** | **효과 5bps vs 비용 22bps** | **미해소** |

비용 인하는 이미 시도했고 실패했다 — post-only 진입은 신호 시점에서 역선택이
27배로 뛰어 taker 보다 나빴다 ([20](20-signal-time-fills.md)).

## 7. 인계 후 재판정 감사 (2026-09-22)

원자료의 저장된 digest를 내용으로 재계산해 대조하고, 사전등록한 5개 신호와
각각의 2h·4h·6h 결과가 모두 있는지 확인한 뒤
`reports/phase4/h3_screen_audited.json`으로 재판정했다. **5개 신호 모두 비용·표본
수치 조건을 통과하지 못하며 H3 기각 결론은 유지된다.** 원자료와 기존 결과는 보존했다.

이전 종합 결과는 수치 통과 horizon이 없을 때 `MONOTONICITY`, `YEAR_SIGN`도
실패 이유로 붙였다. 이는 빈 후보 목록에 대한 검사 때문이었으며, X4의 실제 단조성과
연도 일관성 측정값을 부정하는 근거가 아니다. 감사 결과는 이때 `EDGE_OR_SAMPLE`만
기록한다. 판정 기준·측정 수치·통과 여부는 바뀌지 않았다.

재판정기는 원자료 해시 불일치, 비용·표본 기준 불일치, 신호/horizon 누락·중복,
원자료와 출력 경로가 같은 경우에 출력을 만들지 않는다. 파생 필드(하한·단조성·연도
일관성·수치 통과)는 저장된 플래그 대신 수치로 다시 계산한다.

이 감사는 저장된 집계 결과의 무결성과 판정 경로를 검사한다. 원천 시장 데이터에서
선별 전체를 재실행하거나, 표본 독립성·데이터의 시점별 완전성까지 입증한 것은 아니다.
기존 100% 적재율은 **심볼별 데이터 존재 비율**이며 모든 시점의 결측률 0%를 뜻하지 않는다.
